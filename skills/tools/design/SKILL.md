# Design

Use this with the overall Lolly skill. Read [the Design workflow](skill/workflow.md)
for composition and review. Read [the actual input definitions](reference/inputs.json)
for this installed tool version; `boxes` contains the layers.

Read the effective design system before choosing type, colours or catalog assets.
Preserve stable layer IDs and existing content. Use the document's actual size,
selection and revision, rather than a terminal's unrelated system or a screenshot's
display dimensions.

For a live connection, verify `tool: design`, document ID and the adapter's
capabilities. Layer editing belongs to a layer adapter. Read access permits
inspection only. Use the revision returned by the editor and a unique transaction
ID for a requested change. Inspect the result before handing over the editable
source. A tool skill grants no connection or editing rights.
