# Lolly 1.2.3

Not released yet. These notes collect what has merged to `main` after [v1.2.2](https://github.com/lolly-tools/lolly/releases/tag/v1.2.2) and will be finished when the release is prepared.

## Security

- **Older Node releases are no longer accepted.** Node's own Brotli decoder, which `fetch` uses on every compressed response, had an out-of-bounds write (CVE-2026-111497). It is fixed in Node 22.23.4, 24.22.1 and 26.12.1. The CLI, the TUI and the MCP server now refuse to start on an older release of any of those lines, and on Node 23 or 25, which never got the fix; `pnpm install` refuses them too. The `engines` field reads `^22.23.4 || ^24.22.1 || >=26.12.1`. 1.2.2 printed a warning on those releases and carried on.

## Fixes

- **Uploaded fonts outline in every design system.** A font you upload now belongs to the design system you are using. Before, every upload went to the device's first design system, so on a new device, or in a design system you made, the font did not show in the Fonts list or on the page, and an SVG or PDF export kept its words as text in another face. Uploading a font while the design system that came with Lolly is active makes your own copy of it first, as any other edit there does.
- **A still shows the timed lines the timeline shows at that moment.** A Design page with timed lines, exported as a picture without the browser, drew every line at once. It now draws only those on screen at the still's moment (the start, unless the export names another), as the browser does.
