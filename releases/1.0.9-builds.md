## Reproduce

Install the root workspace and the selected Tauri shell's separate dependencies with `pnpm install --frozen-lockfile`. Set `LOLLY_PROFILE=lolly-start` and `LOLLY_EMBED_CATALOG=profile`. Supply `LOLLY_CATALOG_SIGNING_KEY` and `VITE_CATALOG_PUBLIC_KEY_JWK` from private credential storage.

Run `pnpm run build:desktop` on macOS, or `pnpm -C shells/tauri-mobile run tauri android build --target aarch64` for Android. Android signing uses the four `ANDROID_KEY_*` variables documented in [Build mobile](../docs/build-mobile.md). The desktop build includes the CLI and Quick Look extensions. Native runtime dependencies must match the target architecture.

Dispatch the named workflows from a fixed source ref. Download their artifacts only after successful completion, record the source commit and SHA-256 hashes, and test the packaged application. Store submission, npm publication and changes to the stable `lolly-latest.*` aliases are separate release actions.

Intel macOS distribution signing uses `macos/IntelEntitlements.plist` for the bundled Node runtime. Preserve its JIT and executable-memory entitlements when re-signing the collected app; the Apple silicon entitlement file is insufficient for Intel V8. The release's Intel app was re-signed with this correction and passed CLI catalog loading plus native SVG, PNG, PDF and publishing-page PNG exports under Rosetta.

## Verification record

- The Apple silicon app and DMG are signed, notarised and stapled. Gatekeeper accepts the app. Its packaged CLI lists the catalog, and native WebKit exports produce valid SVG, PNG and PDF files. A full publishing page retains its headline and both columns in PNG.
- [Installed Linux DEBs](https://github.com/lolly-tools/lolly/actions/runs/35535665064) pass CLI catalog loading and native WebKit SVG/PNG exports on x86_64 and ARM64. The AppImage entry point passes catalog loading. The [installed Flatpak](https://github.com/lolly-tools/lolly/actions/runs/35536077248) passes CLI and native SVG export checks.
- The Arch executable is byte-identical to the verified x86_64 DEB executable. Both RPMs pass their distribution build checks, contain the native CLI and SVG addon, declare the WebKit and Ayatana dependencies, and link ONNX Runtime statically.
- The installed Windows MSI and NSIS packages pass CLI catalog loading, SVG, PNG, PDF, a repeated PNG launch and a full publishing-page PNG check. Native bundles skip PWA service-worker registration, preventing the previous worker from intercepting a later WebView2 launch.
- Android APK signature verification, AAB signature verification, bundletool validation, ZIP integrity and 16 KB alignment checks pass. The packages contain ARM64 native libraries; version code is `1000009`, minimum SDK is 24 and target SDK is 36.
- The iOS IPA's ARM64 executable, 1.0.9 version, Apple Distribution signature and App Store provisioning profile are verified. It was built with the non-beta iPhoneOS 26.2 SDK. Its store-upload step was skipped.
- Documentation navigation, wording and size checks pass: 111 registered pages, no orphan pages, and 178.0 MB gzip against the 178 MB budget.

No physical Android or iOS device acceptance was performed. No npm package, store submission, GitHub release or stable download alias was published by this build task. Final package digests are recorded in the artifact directory after all packages pass their required checks.
