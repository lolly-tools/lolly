# Lolly 1.0.9: the DTP one

**Released 22 September 2026.**

Lolly gets a new set of publishing tools: text that flows through columns and linked frames, typography that follows a path, and controls that make detailed page work easier. Agenda grows into a complete programme editor, while Design brings sharing, vector editing and export closer to the way you work.

## Highlights this release

- **Edit text on the canvas.** Select a word, format a passage, paste an article or insert an emoji where the caret is. Paragraph breaks, soft breaks and source text survive editing, saving and reopening.
- **Build a proper publication.** Flow one story through linked frames and across artboards. Use columns, paragraph and character styles, spacing, indents, tabs, drop capitals and baseline grids. Keep rules help control awkward breaks; an overflow indicator tells you when the final frame needs more room.
- **Choose how paragraphs compose.** Standard, Balanced and Best paragraph modes give you different ways to distribute lines. Avoid short last lines, use supported hyphenation and wrap text around other objects.
- **Take type around a bend.** Put a heading on a circle or a drawn path. Edit the words and guide, adjust the offset and baseline, reverse direction or move the text to the other side. Detach it when you want an ordinary frame again.
- **Start with Publishing.** Three editable examples in the template picker's Publishing filter demonstrate balanced columns, linked editorial pages and text on curved paths: Field notes, The long read and Type in orbit.

Read [Text in Design](https://lolly.tools/info/create/text-composition.html) for the new publishing workflow.

## More room to work

- **A tidier inspector.** Common controls come first. Advanced character, paragraph and frame settings open when needed, with consistent components and brand tokens. Numeric fields support dragging, arithmetic, modifier keys and a single Undo step for an adjustment.
- **Share gets its own tab.** Links and editable `.lolly` downloads live beside Inspector and Export. The link follows the current design, and Share opens as a dialog on compact screens.
- **Reach every canvas edge.** Zoomed artwork remains accessible with wheel, middle-button and Space-drag panning. Fit accounts for the tool panels and rulers, including right-to-left layouts.
- **Turn text and emoji into editable vectors.** Convert a whole object or a selected range, with an optional editable source copy. Ungroup converted objects, edit their individual paths and group them again. Paint and credits travel with the result; shared effects that cannot be separated faithfully stay together.

## One programme, several ways to show it

Agenda now includes the programme editor, import-column mapping, multi-day scheduling and event export bundles. Build a foyer screen, a room display, an interactive attendee page or a printable programme from the same sessions. Motion supports long titles, reading holds and reduced-motion output. PowerPoint offers supported editable objects or rendered animation, depending on the output you choose.

The new Agenda and publishing controls and help have been completed across 26 interface languages using an offline translation workflow.

## Motion, colour and output

- **More expressive 3D scenes.** Motion presets, editable camera moves and Burst join reusable studios and coordinated collections. Place a 3D scene inside Design, retain its source in an editable file and drive it from Sequence.
- **Lottie clips in Design.** Choose an animation from a dotLottie package and edit supported internal layers, timing, transforms and paint for each instance. Structural dotLottie export preserves its supported animation content.
- **Consistent emoji artwork.** Chosen emoji sets render through the shared preview and export path, with source credits preserved. The picker keeps its position and insertion range while panels move.
- **HDR and JPEG XL.** The release includes the current wide-gamut/HDR editing and export work, plus lossy and lossless JPEG XL output. Display and format support still determine how those files appear elsewhere.
- **Export corrections.** Composed text uses settled glyph placement in still, document and Sequence exports, and full publishing pages rasterise in WebKit without oversized intermediate files. EMF and WMF retain the complete canvas bounds. PowerPoint keeps notes, dwell and supported click-build metadata. SCORM keeps saved Design dimensions and visible text. GIF transparency and requested TIFF/BMP export sizing are also corrected.
- **More reliable vector operations.** Bounded curve searches and stable root solving improve geometry operations on difficult paths.
- **Native package fixes.** Windows command-line exports load reliably across repeated launches. Desktop packages include their matching native CLI resources, and the macOS minimum is 13.5 to match the bundled runtime.
- **A quicker first visit.** The welcome screen opens without waiting for the full tool catalog, and cold brand discovery shares its catalog work.

## Compatibility and support limits

Older documents keep their existing input and URL meanings. New authored text and 3D content need a reader that supports those features; use a supported rendered export for recipients with older clients.

Faithful text exports may contain outlines rather than editable text. dotLottie supports a defined structural subset and refuses text, audio and converted vectors with independent paint; MP4 or WebM can render those compositions. Text on a path currently supports one paragraph on one continuous guide.

Collaboration synchronises complete text documents rather than merging simultaneous character edits. Conflicting drafts have recovery controls. Portable files carry the resources needed by their authored text.

Automated checks cover the implemented publishing workflows and export routes. Physical-device IME, touch, screen-reader and native Office acceptance are still unverified. The proposed 50 ms native-edit feedback target is not met; measured performance and the detailed limits are recorded in the [text-composition implementation guide](https://lolly.tools/info/build/text-composition-engine.html).

## Downloads

Verified packages are attached to [Lolly 1.0.9 on GitHub](https://github.com/lolly-tools/lolly/releases/tag/v1.0.9), alongside SHA-256 checksums and a manifest recording each package's source commit.

- **macOS 13.5 or later:** Apple silicon and Intel DMGs, signed and notarised.
- **Windows x64:** MSI and EXE installers, unsigned.
- **Linux:** x86_64 and ARM64 DEBs, x86_64 AppImage and Flatpak, openSUSE Tumbleweed and Leap 16 RPMs, and an Arch package.
- **Android ARM64:** release-signed APK and AAB.
- **iOS:** an Apple Distribution-signed IPA prepared for App Store submission; it is not a general sideloading package.
- **Self-hosted web app:** [signed web archive](https://lolli.li/lolly-web-1.0.9.tar.gz) and [YunoHost 1.0.9~ynh2](https://github.com/lolly-tools/lolly_ynh/releases/tag/v1.0.9-ynh2). YunoHost administrators can add storage origins to `connect-src` through the configuration panel; the setting survives upgrades.
- **Terminal:** the independently versioned CLI/TUI package remains 0.1.0.

See the [build and verification record](https://github.com/lolly-tools/lolly/blob/main/releases/1.0.9-builds.md) for platform evidence and the source commits used for the native packages. Store availability follows the platform review process.
