Lolly makes on-brand creative assets - images, PDFs, video, audio, slides and documents - from simple inputs, entirely in the browser. Nothing you make leaves the device: files, brand and history live in the browser's own storage, so the server only hands out the app.

- **Your brand, once.** Import design tokens (DTCG, Tokens Studio, Penpot) or build the brand in the app; every tool then renders inside those constraints.
- **Tools, not templates.** QR codes, charts, social cards, print sheets, gradients, photo clean-up, speech to text and text to speech, redaction and more - each one a URL you can share, embed or script.
- **Works offline.** It is a progressive web app: install it from the browser, keep working without the network, and pick which on-device models to keep.
- **Provenance built in.** Exports can carry Content Credentials (C2PA) signed on the device.

This package serves the prebuilt web app on a domain of your own. It runs no server-side code and stores nothing on the server, which also means it has no accounts: whoever you allow to reach the domain works on their own device.
