# Plans from the 2026-09-06 iOS feedback

Six plans, each its own body of work with its own PR set. Every item was traced to code before a fix was proposed; file references are pinned in each document.

| Plan | What | Size | Repos |
|---|---|---|---|
| [Revision history](plan-2026-09-06-revision-history.md) | Every save kept, a thumbnail strip, restore, pin; local on the standalone app, per user and per project on lolly-work, one UI over a source seam | L (three phases) | `lolly-web`, `lolly-mobile`, `lolly-work` |
| [Mobile shell](plan-2026-09-06-mobile-shell.md) | Downloads that never appear, uploads that vanish, Sign in portrait, Clean's refusal, the picker's default tab and "+" menu, the design toolbar over the timeline, the design mobile review, the eyedropper | nine items, S to M | `lolly-web`, `lolly-tools`, `lolly-mobile` |
| [Trim and sequence](plan-2026-09-06-trim-and-sequence.md) | A shared clip-range control with filmstrip and waveform for the Trim utility; Alt for ripple and slip in the timeline; the non-destructive model made visible | M | `lolly-web`, `lolly-tools`, umbrella schema |
| [Profile and dashboard](plan-2026-09-06-profile-dashboard.md) | One `#/profile` with the dashboard's tabs; the brand hero's ink chosen by APCA | M | `lolly-web`, `lolly-docs` |
| [Brand colour](plan-2026-09-06-brand-colour.md) | A "+" on blend and ramp swatches that adds the colour to the brand | S | `lolly-web` |
| [Agent skill](plan-2026-09-06-agent-skill.md) | A generated skill over URL mode, the render route, MCP, the CLI and lolly-work's API, with chart, design and deck worked in full | M | umbrella, `lolly-docs` |

Suggested order: the mobile shell's day-one items (downloads, picker, loose ends), then brand colour and the hero ink, then the rest of the mobile shell, then trim, then the profile merge, with revision history and the agent skill as independent tracks that can start any time.

Two constraints hold across all six: the web boot path is at 135.8 of a 136.0 KB budget, so every new surface loads lazily; and the maintainability budget must go down on `profile.ts` and `free-canvas.ts`, not up.
