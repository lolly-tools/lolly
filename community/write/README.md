# Write

Write is a plain text and Markdown editor using the shared Text workspace and code editor. The utility opens directly in writing mode, with a filename, format choice, word count, undo, find and replace, and Markdown preview. Save to Projects keeps an editable document using the normal saved-session storage, history and folder rules. Save to Assets and Download make text files. Assets opened through Open in Write keep their source identity and conflict checks.

Markdown preview opens alongside the editor and updates as you type, including Markdown written in a .txt file. Use Markdown preview or Writing check to switch the companion pane, and Hide to return to the full-width editor. Drag the divider to resize the panes; arrow keys resize and Enter or a double-click restores equal widths. On narrow screens the pane sits below the editor.

Line length offers the full editor width, preset or custom character measures, and No wrap for horizontal scrolling. Line focus highlights the row at the cursor and dims other rows. Fullscreen hides the application controls and companion pane; Escape or Exit fullscreen restores the workspace. Ctrl/Cmd+Shift+Enter toggles fullscreen writing. These controls change the view and preserve the document's text and undo history.

Writing check offers local English readability estimates, reading time, long-sentence highlights, adverb checks, possible passive voice and simpler wording suggestions. Find in text selects the original passage. Use a wording suggestion to replace that passage; Undo restores the original. Checks ignore Markdown code and link destinations, scan up to 50,000 characters and show up to 100 suggestions. These are style hints, not a full grammar checker. The complete document remains editable and is saved normally.

Projects offers New file in its toolbar, empty state and background menu. Choose Text file or Markdown file and a filename. The empty Write document is saved before opening, including at Projects root; shared projects create a shared session under their existing permissions. Nothing is uploaded merely by opening Write. The shared Text limits apply: UTF-8 files up to 4 MiB.
