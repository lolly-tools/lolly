# Unicode names

`names.json` contains names and named ranges from Unicode 17.0.0 `UnicodeData.txt`, retrieved from https://www.unicode.org/Public/17.0.0/ucd/UnicodeData.txt on 11 September 2026. `LICENSE.txt` is the Unicode data license. Decimal object keys are code points. Range entries are `[first, last, name]` for paired First/Last records; their labels also show the code point.

The character browser intersects this data with the selected brand font's cmap. It does not claim that system fallback glyphs are present in that font. Emoji data and rendering continue to use the shared emoji picker.
