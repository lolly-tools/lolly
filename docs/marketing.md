# Lolly for marketing teams

You need a social card, a certificate and a profile badge today, not next sprint. Lolly hands them back finished and on-brand, even if you have never opened a design tool.

- **Fill in a few fields, get the finished file.** No fonts to pick, no colours to second-guess, no "is this the right logo?" The tool already knows. Start with [Make your first file](/info/make-something.html).
- **Endless variations, one source of truth.** Localise a link card into a dozen languages, make a certificate for every name on a roster or make every size variant for every placement, without touching the design. Drive it all from a spreadsheet in the batch grid: paste or import a CSV and get one finished file per row - see [Using Lolly](/info/using.html).
- **Optional organisation services.** Optional **lolly.work** adds organisation sign-in, shared projects and assets, live work collabs, approvals and governed delivery. See [Use Lolly at your organisation](/info/organisation.html); these services sit alongside the app's local creation tools.
- **Routine files, self-serve.** Link cards, event countdowns, certificates and QR codes - everything the team needs on a Tuesday at 4pm.
- **Nothing to buy for one picture.** Lolly needs no subscription and no per-seat licence for the person who needs one tile.

The rules themselves are set once in the [Brand Studio](/info/brand-studio.html) by whoever owns the design system, and every file above follows them.
