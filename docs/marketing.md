# Lolly for marketing teams

You need a social card, a certificate and a profile badge today. Lolly makes them finished and on-brand, even if you have never opened a design tool.

- **Fill in a few fields, get the finished file.** The tool already sets the fonts, the colours and the logo. Start with [Make your first file](/info/make-something.html).
- **Endless versions, one source.** Localise a link card into a dozen languages, make a certificate for every name on a roster or make every size for every placement, without touching the design.
- **Routine files, self-serve.** Link cards, countdowns, certificates, work avatars, QR codes and [quote cards](/t/quote-card) with a speaker's picture, name and role.
- **Nothing to buy for one picture.** Lolly needs no subscription and no per-seat licence for the person who needs one tile.

## One file per row

Paste or import a spreadsheet in [Lolly Batch](/info/batch.html#make-many-versions-of-one-design) and get one finished file per row, in the formats and sizes you set.

![Lolly Batch export settings: file name, default format, units, DPI and the number of rows to render](/info/shots/use-batch-toolbar.svg)

Whoever owns the design system sets the rules once in [Lolly Design System Setup](/info/brand-studio.html). Every file above follows them. If your organisation runs Lolly Work, Lolly Work adds sign-in, shared projects and assets, live work collabs and approvals. See [Use Lolly at your organisation](/info/organisation.html).
