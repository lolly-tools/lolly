From a token to a file

  1. 1Get a tokenlw tokens create

    An owner mints it once. Send it as Bearer lwt_…

  2. 2Ask what it may doGET /api/v1/discovery/me

    Formats this server renders, and whether the token may render

  3. 3Read the inputsGET /api/v1/schema/:toolId

    Hidden, locked and choice inputs already applied

  4. 4RenderPOST /api/v1/render

    { toolId, format, inputs }

Step 4 answers in one of two ways

The file, straight away

200 with the bytes, their media type and an x-lolly-brand-check header

A job, with ?async=1
  • 202 { jobId, statusUrl }
  • read the result with the x-lw-job-token header
  • or take a signed callback at notify.webhook.url
  • or deliver it to a destination by reference
