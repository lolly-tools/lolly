HTTPS proxy or ingressNeeded for a team

Caddy, nginx or your cluster ingress ends TLS and forwards to the server.

Lolly Work server, one processRequired

  • The console at /admin
  • The API, share and embed links
  • Live collaboration, owned by this one process
  • SVG and PNG renders, in process
  • The Lolly web app at /, when you mount it
  • A design-system pack, mounted read-only

PostgreSQLRequired

Accounts, projects, approvals, jobs and the audit log; asset bytes too with the default pg driver.

Chromium render workerOptional

Adds JPG and PDF and tools with scripts. Without it, the server refuses those requests and tells apps up front.

S3-compatible storageOptional

Holds asset bytes with the s3 driver; back it up separately from the database.

Identity providerOptional

OIDC single sign-on and SCIM. Built-in email and password sign-in works without one.
