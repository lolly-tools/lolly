A link

lolly.tools1/t/qr-code2?url=example.com&color=%230336333&format=png&export4

  1. 1Where Lolly runs

    lolly.tools, your organisation's own site, or lolly:// for the installed app.

  2. 2The tool

    /t/ and the tool's id. A tool id is permanent, so the link keeps working.

  3. 3Its inputs

    One parameter for each input you set, called by the input's id. Inputs you leave out keep their defaults.

  4. 4Reserved words

    The format, the size and what happens on open. No tool may use these names for an input.

The same request on the command line

lolly qr-code--url=example.com --color=#033633--export=png

The command line has no host part: the tool runs on your machine, and writing the file is the export.
