One event, at the door

  1. Arrives

    POST /api/v1/telemetry, for example render.export

    telemetry off: nothing is stored

  2. Known event?

    Only ids on a fixed list are kept

    an unknown id is dropped

  3. Its labels only

    Each event keeps its own short list, such as toolId and format

    other labels, and any over 200 characters, are dropped

  4. Named or not

    A user id is kept only at standard, and with opt-in only after that person agrees

    otherwise the user id is stripped

  5. Stored

    Counted on the Overview; the Activity feed shows only events with a user id

No event has a field for what anyone typed or made, and a profile update keeps only the names of eight contact fields.
