# Make your first file

By the end of this page you will have downloaded a QR code for a web address and saved a copy you can open and change later. You need no account and nothing set up first.

::: note Before you start
Have the web address the code should open, starting with `https://`.
:::

## Make the code

1. Open [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). The controls sit beside the preview, or above it on a phone; what the preview shows is what the file will be.
2. In **URL**, replace the example address with yours, in full. The preview changes as you type.
3. To match your own colours, set **Module colour** and **Background**. Keep a strong contrast between them, or phones struggle to read the code.
4. **Quiet zone**, under **Modules**, starts at 4. Keep it at 4 or more: that plain margin is what a phone camera looks for.

## Download the file

1. Press **Export** on the **Export | Save as** pill, at the foot of the controls on a computer or floating at the bottom of the screen on a phone.
2. Open the format menu beside the file name (it starts on **SVG**) and choose **PNG** for a screen or a message. For print, see the note below.
3. Press **Download**. The file goes to your browser's downloads; if it is not there, see [Find a file you downloaded](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scan the code before you share the file
Open the downloaded file on a screen and scan the code with a phone camera. If you made it on your phone, scan it from a second phone or a computer screen. The phone should offer your web address.
:::

::: details If the code will be printed or handled
Choose **SVG** or **PDF** so the code stays sharp at any size, and test a print at the size it will be used. If the code might get scuffed or rained on, set **Error correction**, under **Modules**, to **High (30%)**: a damaged code still reads.
:::

## Keep an editable copy

The file you downloaded is finished. To change the code later, save your work as well:

1. Press **Save as**, then **Save**. With the Export panel open, **Save as** is in the panel; with it closed, it is the tick beside **Export**. The code goes to **My library**, and a **Saved** message offers **Open Projects**.
2. Next time, press **Home** and open **Projects** (the folder icon on a phone). Your code is there, named **QR Code**. Open it, change anything and export again.

Saved work stays on this device, in the browser or app you used, unless you turn on [Sync](/info/sync.html). [Find and recover your work](/info/find-your-work.html) covers folders, earlier versions and moving your work to another device.

## Other first projects

- [Audiogram](/#/tool/audiogram) turns a voice note into a video: a moving waveform, your words on the cover, your colours. Drop the recording into **Audio**, add a **Title**, then export **MP4**.
- [Filter](/#/tool/filter) treats a photo for a poster: printed halftone dots, two flat colours or a few blocks of tone. Choose the photo under **Image**, pick an **Effect**, then export **PNG**, or **SVG** on an effect badged *vector*.
