# Lolly and online file converters

_Last checked: 28 September 2026._

If you usually search for "HEIC to JPG" or "compress PDF" and upload the file to whichever site comes up, Lolly does the same conversion in your browser, on your own device.

## What a converter site can do better

Some converter sites handle formats Lolly does not, and need nothing set up first. Choose a converter by the formats and fidelity you need as well as by where it processes the file: some conversions keep editable structure and others flatten the result.

## Where the conversion happens

A browser-based converter may upload a file for processing or convert locally. Lolly's conversion utilities process the file locally, with no account, ads or trackers, and add no Lolly watermark or Content Credentials. Once the assets a conversion needs are saved, they work offline. File size is bounded by the device's memory and the particular format reader.

## When a team needs more

An organisation's members keep using the on-device utilities for local conversions even when the organisation runs Lolly Work. A shared upload, server render or delivery is the point where data goes to its server; [What runs where](/info/compare.html#what-runs-where) explains the separation.
