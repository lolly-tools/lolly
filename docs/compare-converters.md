# Lolly and online file converters

_Last checked: 28 September 2026._

If you usually search for "HEIC to JPG" or "compress PDF" and upload the file to whichever site comes up, Lolly does the same conversion in your browser, on your own device.

<!--i:eti-award-->
## What a converter site can do better

Some converter sites handle formats Lolly does not and need no setup. Choose a converter by the formats and fidelity you need, and by where it processes the file. Some conversions keep editable structure and others flatten the result.

<!--i:eti-map-pin-->
## Where the conversion happens

A browser-based converter may upload a file for processing or convert locally. Lolly's conversion utilities process the file locally, with no account, ads or trackers. They add no Lolly watermark or Content Credentials. The utilities work offline once the assets a conversion needs are saved. File size is limited by the device's memory and the format reader.

## When a team needs more

Members of an organisation that runs Lolly Work still use the on-device utilities for local conversions. Data goes to the organisation's server only for a shared upload, server render or delivery. [What runs where](/info/compare.html#what-runs-where) explains the separation.
