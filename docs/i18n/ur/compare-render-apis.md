# Lolly اور رینڈرنگ APIs

_آخری جانچ: 5 نومبر 2026۔_

اگر آپ API کے ذریعے ٹیمپلیٹس سے تصاویر بناتے ہیں تو یہ صفحہ بتاتا ہے کہ وہ پروڈکشن اپنی ڈیوائس، CI یا اپنے کنٹرول والے سرور پر چلانے سے کیا بدلتا ہے۔ [ہوسٹڈ رینڈر API سے منتقل ہوں](/info/work-move-from-render-api.html) مراحل بتاتا ہے۔

<!--i:eti-award-->
## ہوسٹڈ رینڈرنگ APIs کیا بہتر کرتی ہیں

[Bannerbear](https://www.bannerbear.com/) اور [Placid](https://placid.app/) منظم سروسز ہیں: آپ درخواست بھیجتے ہیں اور سرورز کوئی اور چلاتا ہے۔

- **چلانے کے لیے کچھ نہیں۔** نہ سرور، نہ ڈیٹابیس، نہ اسٹوریج، نہ اپ ڈیٹس اور نہ گنجائش کی منصوبہ بندی۔
- **ہوسٹڈ ٹیمپلیٹ ایڈیٹر**، ایسے ٹیمپلیٹس کے ساتھ جو ڈھالنے کے لیے تیار ہیں۔
- **ایک API سے آؤٹ پٹ کی زیادہ اقسام۔** دونوں ویڈیو اور PDF اینڈ پوائنٹس شائع کرتی ہیں، اور Bannerbear اینیمیٹڈ آؤٹ پٹ، WebP اور AVIF، اسکرین شاٹس اور AI سے پس منظر ہٹانے کی دستاویزات بھی دیتا ہے۔
- **ان کے اپنے انضمام اور سپورٹ۔**

اگر آپ یہی انتظام چاہتے ہیں تو یہ سروسز مناسب انتخاب ہیں۔

<!--i:eti-home-->
## خود ہوسٹ کرنے سے کیا ملتا ہے

- **آپ کا مواد آپ کے سسٹمز پر رہتا ہے۔** ان پٹس، ایسیٹس اور آؤٹ پٹس آپ کے چنے ہوئے انفراسٹرکچر پر رہتے ہیں۔ ڈیوائس یا CI میں رینڈرنگ کے لیے کسی سروس کی ضرورت نہیں۔
- **قواعد ٹول میں رہتے ہیں۔** رنگ، ٹائپ، لوگوز اور مقفل ان پٹس آپ کے [ڈیزائن سسٹم](/info/brand-studio.html) سے آتے ہیں، اس لیے کال کرنے والا صرف وہی بدل سکتا ہے جس کی آپ اجازت دیں۔ [Lolly Work](/info/compare.html#what-runs-where) ہر درخواست پر ٹول کے نظر آنے اور ان پٹس کی پالیسیاں لاگو کرتا ہے۔
- **ہر جگہ وہی ٹول۔** ٹول لیپ ٹاپ، CI جاب یا سرور پر یکساں ان پٹس سے رینڈر کرتا ہے۔ لوگ ایپ میں اسی ٹول کو ایڈٹ کر سکتے ہیں۔
- **ریکارڈز آپ کے پاس۔** [رینڈر رسیدیں](/info/work-renders.html#evidence-and-identity)، آڈٹ ٹریل اور جہاں آپ دستخط کی شناخت ترتیب دیں وہاں Content Credentials۔
- **اوپن سورس، استعمال کے حساب سے کوئی بل نہیں۔** آپ کوڈ چلاتے ہیں اور صرف اپنے انفراسٹرکچر کی ادائیگی کرتے ہیں۔

وہ کام آپ سنبھالتے ہیں جو یہ سروسز آپ کے لیے کرتی ہیں۔ پائیدار سرور کو مستقل ڈیٹابیس اور آؤٹ پٹ اسٹوریج چاہیے۔ جن ٹولز کو براؤزر چاہیے انہیں Chromium ورکر درکار ہے۔ [Lolly Work انسٹال کریں](/info/work-install.html) دونوں کی وضاحت کرتا ہے۔

## کاموں کا موازنہ

| کام | ہوسٹڈ رینڈرنگ API | Lolly |
|---|---|---|
| ڈیٹا سے ٹیمپلیٹ بھرنا | ٹیمپلیٹ اور اس کی لیئرز کے نام والی API درخواست | ٹول اور اس کے ان پٹس کے نام والا [URL](/info/url-mode.html)، [CLI](/info/cli.html) یا [سرور API](/info/work-automation-api.html) |
| جدول سے بہت سی فائلیں | بیچز اور کلیکشنز | آپ کی ڈیوائس پر [Batch](/info/batch.html)، یا سرور پر [رینڈر بیچز](/info/work-renders.html#batches-with-durable-rows) |
| نتیجے کا انتظار یا بار بار پوچھنا | پولنگ، یا ہم وقت آپشن | پائیدار رینڈرز جن کے لیے آپ پول کرتے ہیں، یا فوری رینڈر |
| مکمل ہونے پر ویب ہک کال کرنا | ہاں | آپ کے اجازت دیے ہوئے اوریجنز پر [دستخط شدہ کال بیکس](/info/work-renders.html) |
| متحرک تصویر URL | ہاں | [شیئر لنکس اور `/render` URLs](/info/url-mode.html) |
| ٹیمپلیٹ ایڈٹ کرنا | ہوسٹڈ ایڈیٹر | آپ کی ڈیوائس پر [Design](/info/using.html) |
| ایجنٹس | دونوں MCP سرور شائع کرتی ہیں | [MCP](/info/mcp.html)، Lolly Work پر ٹوکن کی پالیسی کے تحت تنظیمی اینڈ پوائنٹ کے ساتھ |

Lolly کی اپنی آؤٹ پٹ اقسام [ایکسپورٹ کرنا](/info/exporting.html) میں درج ہیں۔ فی الحال Work سرور پر پائیدار رینڈرز SVG، PNG، JPG اور PDF بناتے ہیں، اور [ویڈیو ڈیوائس، CLI اور MCP پر رہتی ہے](/info/work-renders.html#production-still-checks-and-permitted-repairs)۔

## کیا منتقل ہوتا ہے، اور کیا نہیں

| | Bannerbear V5 | Bannerbear V2 | Placid |
|---|---|---|---|
| آپ کی درخواستیں | Work کی منتقلی API وہی ساخت قبول کرتی ہے | یکساں | یکساں |
| آپ کے ٹیمپلیٹس | قابل ترمیم دستاویزات کے طور پر **Import**، سوائے ان لیئر اقسام کے جن کا مصدقہ اسکیما نہیں | صرف فیلڈ کے نام اور پری ویو۔ ہر ایک دوبارہ بنائیں | صرف فیلڈ کے نام اور پری ویو۔ ہر ایک دوبارہ بنائیں |
| موجودہ متحرک URLs | سپورٹ نہیں | سپورٹ نہیں | ہوسٹ بدلنے کے بعد دستخط شدہ URLs آپ کے پرانے نجی ٹوکن کے ساتھ کام کرتے رہتے ہیں |
| ویب ہکس | رجسٹرڈ ویب ہکس کی سپورٹ نہیں | `webhook_url` کام کرتا ہے | `webhook_success` کام کرتا ہے |
| WebP اور AVIF آؤٹ پٹ | نام کی بنیاد پر مسترد | پیش نہیں کیا جاتا | WebP نام کی بنیاد پر مسترد |
| اینیمیشنز، ویڈیوز، کلیکشنز، اسکرین شاٹس | منتقلی API پر نہیں | منتقلی API پر نہیں | منتقلی API پر نہیں |

::: note عوامی دستاویزات سے بنایا گیا
یہ ہر فراہم کنندہ کی عوامی دستاویزات سے بنایا گیا اور اسے لائیو اکاؤنٹ پر نہیں چلایا گیا۔ اگر آپ کے پاس اکاؤنٹ ہے تو [منتقلی کی گائیڈ](/info/work-move-from-render-api.html#check-it-on-your-own-account) میں مختصر چیک لسٹ ہے۔
:::

آپ ایک ٹیمپلیٹ منتقل کر کے باقی وہیں رکھ سکتے ہیں جہاں وہ ہیں۔ [Lolly چھوڑنا](/info/work-move-from-render-api.html#leave-lolly-too) بھی اتنا ہی کھلا ہے: ٹولز سادہ فائلیں ہیں اور CLI انہیں بغیر سرور رینڈر کرتا ہے۔

## سروس کون چلاتا ہے

Lolly کے ساتھ کوئی فرد مقامی طور پر رینڈر کرتا ہے، یا ٹیم اپنے انفراسٹرکچر پر Lolly Work چلاتی ہے۔ سرور جاب اپنے ان پٹس اور درکار ایسیٹس اس انسٹینس کو بھیجتی ہے۔ ڈیوائس والا راستہ ایسا نہیں کرتا۔

Bannerbear اور Placid اپنے مالکان کے ٹریڈ مارکس ہیں۔ یہ صفحہ ان کی عوامی دستاویزات کی بنیاد پر بتاتا ہے کہ پروڈکٹس میں کیا مشترک ہے، اور اس کا کسی سے بھی تعلق نہیں۔
