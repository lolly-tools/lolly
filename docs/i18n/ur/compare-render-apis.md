# Lolly اور رینڈرنگ APIs

_آخری جانچ: 28 ستمبر 2026۔_

اگر آپ آج API کے ذریعے ٹیمپلیٹس سے تصاویر بناتے ہیں تو یہ صفحہ بتاتا ہے کہ Lolly وہی کام آپ کی اپنی ڈیوائس پر، CI میں یا آپ کے اپنے سرور پر کیسے کرتا ہے۔

## ہوسٹڈ رینڈرنگ APIs کیا بہتر کرتی ہیں

[Bannerbear](https://www.bannerbear.com/) اور [Placid](https://placid.app/) رینڈرنگ کو منظم سروسز کے طور پر پیک کرتے ہیں، اپنے انفراسٹرکچر، انضمام اور سپورٹ کے ساتھ۔ آپ درخواست بھیجتے ہیں اور سرورز کوئی اور چلاتا ہے۔

## جہاں یہ ایک دوسرے سے ملتے ہیں

دونوں ٹیمپلیٹ اور ان پٹس کو میڈیا میں بدلتے ہیں۔ Lolly ان پٹس [لنک](/info/url-mode.html)، [CLI](/info/cli.html)، batch گرڈ یا سرور اینڈ پوائنٹ سے لیتا ہے۔

## Lolly مشترک کام کیسے کرتا ہے

وہی ٹول لیپ ٹاپ پر، CI جاب میں یا سرور پر، انہی ان پٹس سے رینڈر ہوتا ہے۔ مقامی اور CI رینڈرنگ کو کسی سروس کی ضرورت نہیں۔

![Batch ایکسپورٹ سیٹنگز: فائل کا نام، ڈیفالٹ فارمیٹ، یونٹس، DPI اور رینڈر کرنے کی قطاروں کی تعداد](/info/shots/use-batch-toolbar.svg)

سرور پر [Lolly Work](/info/compare.html#what-runs-where) API کے پیچھے Lolly انجن چلاتا ہے اور ٹول کی نمائش اور ان پٹ پالیسیاں لاگو کرتا ہے۔ اس کی [قابل بحالی رینڈر سروس](/info/work-renders.html) واحد جابز اور batches، idempotent جمع آوری، اسٹیٹس، محدود دوبارہ کوششیں، منسوخی اور برقرار رکھے آؤٹ پٹس سپورٹ کرتی ہے، اور رکا ہوا کام ری اسٹارٹ کے بعد دوبارہ شروع ہوتا ہے جب مستقل اسٹوریج ترتیب دیا گیا ہو۔

سرور کے پاس تیز SVG اور PNG راستہ ہے اور اختیاری Chromium worker ان ٹولز کے لیے جنہیں براؤزر چاہیے۔ آٹومیشن service ٹوکنز سے سائن اِن کرتی ہے، مکمل آؤٹ پٹ [منظور شدہ ڈیلیوری](/info/work-delivery.html) کے ذریعے تنظیمی منزلوں تک جا سکتی ہے، اور ترتیب دی گئی دستخطی شناخت معاون آؤٹ پٹ میں Content Credentials شامل کرتی ہے۔

## سروس کون چلاتا ہے

Lolly کے ساتھ فرد مقامی طور پر رینڈر کرتا ہے، یا ٹیم اپنے انفراسٹرکچر پر Lolly Work چلاتی ہے۔ سرور جاب جمع کرانا اس کے ان پٹس اور ضروری ایسیٹس اس انسٹینس کو بھیجتا ہے، جو آن ڈیوائس راستے سے مختلف ہے۔ پائیدار سروس کو مستقل ڈیٹا بیس اور آؤٹ پٹ اسٹوریج چاہیے، اور براؤزر پر منحصر ٹولز کو Chromium worker؛ [Install Lolly Work](/info/work-install.html) دونوں بیان کرتا ہے۔

Bannerbear اور Placid اپنے مالکان کے ٹریڈ مارکس ہیں۔ یہ صفحہ بیان کرتا ہے کہ پروڈکٹس کہاں ملتی ہیں اور کسی سے وابستہ نہیں ہے۔
