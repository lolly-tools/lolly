## اپنا برانڈ شامل کریں

lolly.tools، Lolly کے اپنے نمونہ ڈیزائن سسٹم **Lolly Demo** میں کھلتا ہے ([Lolly Demo سے ملیں](/info/lolly-demo.html))۔ آپ کا ڈیزائن سسٹم Lolly Demo کی جگہ لیتا ہے۔ یہ ڈیزائن ٹوکنز کا چھوٹا مجموعہ ہے (رنگ، فونٹس اور چند اصول) جس سے ہر ٹول ڈرا کرتا ہے۔ اسے ایک بار مقرر کریں، اور آپ کی ہر تخلیق شروع ہی سے برانڈ کے مطابق ہوگی۔

اپنی موجودہ چیزوں کے مطابق راستہ چنیں:

- <!--i:palette--> **ایک رنگ۔** **Design System Setup** منظر (`#/start`) کھولیں، اپنے ڈیزائن سسٹم کو نام دیں اور بنیادی رنگ چنیں۔ Lolly اس رنگ سے رسائی کے لحاظ سے موزوں پیلیٹ بناتا ہے، روشن اور تاریک سطحوں، متن اور نمایاں رنگوں کے ساتھ۔ فونٹ چنیں اور آپ کا قابل استعمال برانڈ تیار ہے۔
- <!--i:upload--> **ٹوکنز کی فائل۔** Lolly Design System Setup کے اوپر **Add from…**، DTCG، Tokens Studio یا Penpot ٹوکنز فائل، SVG یا `LollyBrand` پیک لیتا ہے۔ پیلیٹ فائل سے بھر جاتا ہے۔ ڈیزائن سسٹم خالی ہو تو Board پر **Start from a reference** یہی پکر کھولتا ہے۔
- <!--i:pentool--> **مکمل ڈیزائن۔** Lolly Design میں **Import a design** چنیں اور Figma، Penpot، Illustrator، InDesign، Affinity، Photoshop، PowerPoint یا SVG فائل ڈالیں ([ہر فارمیٹ](/info/design-import.html#what-comes-in-from-each-app))۔ نیچے [اپنے پاس موجود کام لائیں](#bring-in-what-you-already-have) دیکھیں۔

جب آپ پہلی بار گیلری کھولتے ہیں تو اوپر خیر مقدمی پیغام ایک اگلا قدم پیش کرتا ہے۔ lolly.tools پر **Start making**، Lolly Design میں Launch پوسٹر کھولتا ہے۔ نئی تنصیب پر **Make it yours**، Lolly Design System Setup کھولتا ہے۔ اس بٹن کے نیچے **Bring a file** ڈیزائن کے لیے فائل پکر کھولتا ہے، اور ان دو انتخابوں میں سے دوسرا لنک کے طور پر دکھتا ہے۔ ان میں سے کوئی بھی، یا بند کرنے کا بٹن، خیر مقدمی پیغام مستقل ہٹا دیتا ہے۔

![نئے ڈیزائن سسٹم پر Lolly Design System Setup کا Colours کمرہ: ایک لائیو چپ، ایک فیلڈ اور پورا پہلا فیصلہ](/t/url-shot?url=%2F%23%2Fstart%3Farea%3Dcolor&system=new-design-system&width=1440&height=740&dpi=192&waitMs=1800&format=svg&walker=1&dark=1&filename=bs-colours-new-system)

آٹھ کمرے، کسی بھی ترتیب میں استعمال کیے جا سکتے ہیں، ڈیزائن سسٹم کو آگے بڑھاتے ہیں: **Board**، **Colours**، **Type**، **Logos**، **Tokens**، **Files**، **Rules** اور **Skills**۔ ایپ کا ہر پری ویو آپ کے ٹائپ کرتے ہی اپ ڈیٹ ہوتا ہے۔ [Lolly Design System Setup](/info/brand-studio.html) ہر کمرے کی تفصیل دیتا ہے۔

فونٹس آپ کی ڈیوائس پر رکھے جاتے ہیں۔ آپ کا منتخب Google Font برانڈ ایسیٹ کے طور پر محفوظ ہوتا ہے، اس لیے آپ کی ٹائپ آف لائن کام کرتی ہے اور ٹول کے ڈرا کرتے وقت کچھ حاصل نہیں کیا جاتا۔

### ڈیزائن سسٹم دیکھیں، بدلیں اور شیئر کریں

- **فعال سسٹم دیکھیں۔** **Settings → Design system** فعال ڈیزائن سسٹم کو سرورق اور صفحات کے طور پر دکھاتا ہے، صرف پڑھنے کے لیے۔
- **ان کے درمیان بدلیں۔** **Settings → Preferences → Design systems** اس ڈیوائس کے ہر ڈیزائن سسٹم کو درج کرتا ہے۔ ایک تنظیم کئی ڈیزائن سسٹمز چلا سکتی ہے، یا کئی کلر ویز والا ایک سسٹم۔ [برانڈ کی ساختیں](/info/brand-architectures.html) ان انتظامات کا نقشہ دکھاتا ہے۔
- **ایک شیئر کریں۔** ڈیزائن سسٹم کو `LollyBrand` پیک کے طور پر ایکسپورٹ کریں: ایک فائل جسے ساتھی امپورٹ کر کے وہی پیلیٹ، فونٹس اور اصول حاصل کرتا ہے۔

آپ کی بلڈ یا تنظیم کا فراہم کردہ ڈیزائن سسٹم **زیر انتظام** ہوتا ہے: اس پر تالے کا نشان ہوتا ہے اور اسے صرف پڑھا جا سکتا ہے۔ اسے بدلنے کے لیے **Settings → Preferences → Design systems** سے قابل ترمیم کاپی بنائیں۔

![Settings میں Design system ٹیب: فعال ڈیزائن سسٹم ایک سرورق اور صفحات کی صورت میں](/t/url-shot?url=%2F%23%2Fd%3Ftab%3Dbrand&width=1440&height=900&dpi=192&waitMs=1800&format=svg&walker=1&localize=1&dark=1&filename=dashboard-brand&waitSelector=%5Bdata-issue-ready%5D)

آپ کا ڈیزائن سسٹم DTCG ٹوکنز پر مشتمل ہے، وہی فارمیٹ جسے Penpot پڑھتا اور لکھتا ہے اور Tokens Studio، Figma میں لاتا ہے۔ جس پیلیٹ سے آپ ڈیزائن کرتے ہیں اور جسے Lolly لاگو کرتا ہے وہ ایک ہی دستاویز ہیں۔ تفصیل [ڈیزائن ٹوکنز](/info/design-tokens.html) میں ہے۔

::: details ڈویلپرز کے لیے: کمانڈ لائن سے برانڈ پیک بنائیں
`ingest:brand` چیک آؤٹ میں دوبارہ استعمال ہونے والا برانڈ پیک بناتا ہے۔ یہ Penpot اور Tokens Studio کے ایکسپورٹ کردہ تین کنٹینرز قبول کرتا ہے: ایک `tokens.json`، ہر سیٹ کی الگ فائلوں اور `$metadata.json` والی ڈائریکٹری یا `project.penpot` آرکائیو۔

```bash
pnpm run ingest:brand ./my-tokens.json --name acme --label "Acme" --activate
```

`--activate` برانڈ کو پروفائل کے طور پر رجسٹر کرتا ہے اور اس کا کیٹلاگ بناتا اور اس کی توثیق کرتا ہے۔ یہ ڈیفالٹ پروفائل کبھی نہیں بدلتا: نیا پیک استعمال کرنے کے لیے `LOLLY_PROFILE=acme` کے ساتھ چلائیں۔ [ترتیب](/info/configuration.html) بتاتی ہے کہ برانڈ پیکس اور پروفائلز ایک ساتھ کیسے کام کرتے ہیں۔
:::

## اپنا موجودہ کام لائیں

**Lolly Design فائلیں۔** Figma، Penpot، Illustrator، InDesign یا کسی بھی SVG ایپ میں مکمل کیا گیا کام Lolly Design میں قابل ترمیم لے آؤٹ کے طور پر کھلتا ہے۔ متن دوبارہ ٹائپ کیا جا سکتا ہے، شکلیں شکلیں رہتی ہیں اور تصاویر آپ کی لائبریری میں آ جاتی ہیں۔ فائل آپ کے براؤزر میں پڑھی جاتی ہے اور کچھ اپ لوڈ نہیں ہوتا۔ [ڈیزائن امپورٹ کریں](/info/design-import.html) ہر فارمیٹ اور اس میں برقرار رہنے والی چیزیں درج کرتا ہے۔

**ڈیکس۔** PowerPoint کی `.pptx` فائل Lolly پر ڈالیں تاکہ اس کی سلائیڈز ایسیٹس کے طور پر محفوظ ہوں۔ **Lolly Markdown Slides** میں Markdown سے نیا ڈیک لکھیں۔ [ڈیک کو نیا برانڈ دیں](/info/rebrand.html) ڈیک کو آپ کے ڈیزائن سسٹم پر منتقل کرتا ہے۔

**ڈیٹا۔** ٹول کے دہرائے جانے والے فیلڈز بھرنے کے لیے CSV یا JSON جدول پیسٹ کریں یا ڈالیں۔ [Lolly Batch](/info/batch.html#make-many-versions-of-one-design) ہر قطار کے لیے ایک مکمل فائل بناتا ہے۔

### ایک بار کے کام سے ٹیمپلیٹ تک

امپورٹ کیا گیا لے آؤٹ ایک عام Lolly Design سیشن ہے۔ **Share with rules** سیشن کو ٹول بنا دیتا ہے۔ آپ چنتے ہیں کہ دوسرے لوگ کون سے حصے بدل سکتے ہیں، اور وہ صرف انہی کو بھرتے ہیں۔

![Lolly Design کی ماسٹر کاپی رکھیں، تدوین کے لیے بنائی گئی کاپی میں ان پٹس اور حدیں چنیں، پھر دوبارہ استعمال ہونے والا .lolly ٹول شیئر کریں جسے وصول کرنے والے بھرتے ہیں](/info/diagrams/concepts/share-with-rules.svg)

[قواعد کے ساتھ ڈیزائن شیئر کریں](/info/create-a-tool.html) ہر قدم کی رہنمائی کرتا ہے۔

## کئی فائلیں بنائیں، شیئر کریں اور خودکار بنائیں

- <!--i:download--> **ایکسپورٹ کریں۔** ٹولز SVG، PDF، PNG، JPG، WebP، ویڈیو اور مزید فارمیٹس بناتے ہیں، ضرورت ہو تو اصل پرنٹ سائز پر۔ ہر ٹول اپنے فارمیٹس پیش کرتا ہے۔ [فائل ایکسپورٹ کریں](/info/exporting.html) دیکھیں۔
- <!--i:link--> **لنک شیئر کریں۔** ٹول کی سیٹنگز اس کے لنک میں شامل ہوتی ہیں، اس لیے لنک کہیں بھی وہی فائل دوبارہ کھولتا ہے۔
- <!--i:layers--> **ہر قطار کے لیے ایک بنائیں۔** [Lolly Batch](/info/batch.html#make-many-versions-of-one-design) میں اسپریڈشیٹ سے ٹول چلائیں۔
- <!--i:cpu--> **خودکار بنائیں۔** وہی رینڈر [CLI](/info/cli.html) اور [AI ایجنٹ](/info/ai-agents.html) سے چلتا ہے۔

لنک ایک مکمل درخواست ہے۔ نیچے دیے گئے چارٹ کی ٹائپ، سرخی اور ڈیٹا جدول ایڈریس بار میں ٹائپ کیے گئے تھے۔
