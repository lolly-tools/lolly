# آغاز

اس صفحے کے اختتام تک آپ کے ٹولز آپ کے اپنے رنگوں اور فونٹس میں ہوں گے، اور آپ کا موجودہ کام دوبارہ استعمال کے لیے تیار ہوگا۔ آپ کو اکاؤنٹ کی ضرورت نہیں، اور بنانا اور ایکسپورٹ کرنا آپ کی ڈیوائس پر چلتا ہے۔

::: timeline
- <!--i:sparkle--> **ایک فائل بنائیں۔** [اپنی پہلی فائل بنائیں](/info/make-something.html) چند منٹ میں آپ کو QR کوڈ بنانا سکھاتا ہے۔
- <!--i:palette--> **اپنا برانڈ شامل کریں۔** ایک رنگ، ٹوکنز فائل یا مکمل ڈیزائن سے شروع کریں۔
- <!--i:layers--> **اسی طرح مزید بنائیں۔** لنک شیئر کریں، اسپریڈ شیٹ بھریں یا اسکرپٹ سے ٹول چلائیں۔
:::

خود اس خیال سے نئے ہیں؟ [Lolly کیا ہے؟](/info/what-is-lolly.html) پانچ منٹ کا تعارف ہے، اور [Lolly کیسے کام کرتا ہے](/info/how-lolly-works.html) دکھاتا ہے کہ کون کیا کرتا ہے۔

## اپنا برانڈ شامل کریں

lolly.tools **Lolly Demo** میں کھلتا ہے، جو Lolly کا اپنا نمونہ ڈیزائن سسٹم ہے؛ [Lolly Demo سے ملیں](/info/lolly-demo.html) دکھاتا ہے کہ آپ کیا دیکھ رہے ہیں۔ آپ کا ڈیزائن سسٹم اس کی جگہ لیتا ہے: ڈیزائن ٹوکنز کا ایک چھوٹا سیٹ، یعنی رنگ، فونٹس اور چند اصول، جن سے ہر ٹول ڈرا کرتا ہے۔ اسے ایک بار سیٹ کریں، اور آپ جو کچھ بھی بنائیں گے وہ آن برانڈ شروع ہوگا۔

اپنے پاس موجود چیز کے مطابق راستہ چنیں:

- <!--i:palette--> **ایک رنگ۔** **Design System Setup** (`#/start`) کھولیں، اپنے ڈیزائن سسٹم کو نام دیں اور بنیادی رنگ چنیں۔ Lolly اس سے مکمل، قابل رسائی پیلیٹ بناتا ہے، روشن اور تاریک سطحوں، متن اور ایکسنٹس کے ساتھ۔ فونٹ چنیں اور آپ کے پاس کام کرنے والا برانڈ ہے۔
- <!--i:upload--> **ٹوکنز فائل۔** Design System Setup میں روم ریل کے آخر میں **Add from…** DTCG، Tokens Studio یا Penpot ٹوکنز فائل، SVG یا `LollyBrand` پیک لیتا ہے۔ اسے ڈالیں اور پیلیٹ بھر جاتا ہے۔ جب تک ڈیزائن سسٹم خالی ہو، Overview روم میں **Start from a reference** وہی پکر کھولتا ہے۔
- <!--i:pentool--> **مکمل ڈیزائن۔** Design میں **Import a design** چنیں اور `.fig`، `.penpot`، `.ai`، `.idml` یا SVG فائل ڈالیں۔ نیچے [جو آپ کے پاس پہلے سے ہے اسے لائیں](#bring-in-what-you-already-have) دیکھیں۔

جب آپ پہلی بار گیلری کھولتے ہیں تو ایک مختصر خیر مقدم وہی انتخاب پیش کرتا ہے: **Make it yours** Design System Setup کھولتا ہے، **Bring your design** ڈیزائن کے لیے فائل پکر کھولتا ہے اور **Explore the community tools** خیر مقدم بند کرتا ہے۔

![نئی انسٹالیشن پر Design System Setup کا Colours روم: ایک لائیو چپ، ایک فیلڈ اور پہلے فیصلے کا پورا حصہ](/t/url-shot?url=%2F%23%2Fstart%3Farea%3Dcolor&width=1440&height=740&dpi=192&waitMs=1800&format=svg&walker=1&localize=1&dark=1&filename=brand-colours)

وہاں سے سات روم اسے جتنا آپ چاہیں آگے لے جاتے ہیں، کسی بھی ترتیب میں: **Overview**، **Colours**، **Type**، **Logos**، **Tokens**، **Files** اور **Usage & rules**۔ ایپ میں ہر پری ویو آپ کے ٹائپ کرتے ہی اپ ڈیٹ ہوتا ہے۔ [Design System Setup](/info/brand-studio.html) ہر روم کا احاطہ کرتا ہے۔

فونٹس آپ کی ڈیوائس پر رکھے جاتے ہیں۔ Google Font چنیں اور Lolly فائل کو برانڈ ایسیٹ کے طور پر محفوظ کرتا ہے، اس لیے آپ کی ٹائپ آف لائن ساتھ چلتی ہے اور ٹول کے ڈرا کرتے وقت کچھ حاصل نہیں ہوتا۔

### ڈیزائن سسٹم دیکھیں، بدلیں اور شیئر کریں

- **فعال والا دیکھیں۔** **Settings → Design system** فعال ڈیزائن سسٹم کو کور اور صفحات کے طور پر دکھاتا ہے، صرف پڑھنے کے لیے۔
- **ان کے درمیان بدلیں۔** **Settings → Preferences → Design systems** اس ڈیوائس پر ہر ڈیزائن سسٹم درج کرتا ہے۔ ایک تنظیم کئی ڈیزائن سسٹم، یا کئی کلر ویز والا ایک چلا سکتی ہے؛ [Brand architectures](/info/brand-architectures.html) ترتیبوں کا نقشہ دیتا ہے۔
- **ایک شیئر کریں۔** ڈیزائن سسٹم کو `LollyBrand` پیک کے طور پر ایکسپورٹ کریں: ایک فائل جسے ساتھی امپورٹ کر کے وہی پیلیٹ، فونٹس اور اصول حاصل کرتا ہے۔

جو ڈیزائن سسٹم آپ کا بلڈ یا تنظیم فراہم کرے وہ **منظم** ہے: وہ لاک دکھاتا ہے اور صرف پڑھنے کے لیے رہتا ہے۔ اسے بدلنے کے لیے **Settings → Preferences → Design systems** سے قابل ترمیم کاپی بنائیں۔

![Settings میں Design system ٹیب: فعال ڈیزائن سسٹم کور اور صفحات کے طور پر](/t/url-shot?url=%2F%23%2Fd%3Ftab%3Dbrand&width=1440&height=900&dpi=192&waitMs=1800&format=svg&walker=1&localize=1&dark=1&filename=dashboard-brand&waitSelector=%5Bdata-issue-ready%5D)

آپ کا ڈیزائن سسٹم DTCG ٹوکنز ہے، وہ فارمیٹ جو Penpot پڑھتا اور لکھتا ہے اور Tokens Studio Figma میں لاتا ہے، اس لیے جس پیلیٹ سے آپ ڈیزائن کرتے ہیں اور جو Lolly لاگو کرتا ہے وہ ایک ہی دستاویز ہیں۔ [Design Tokens](/info/design-tokens.html) میں تفصیلات ہیں۔

::: details ڈیولپرز کے لیے: کمانڈ لائن سے برانڈ پیک بنائیں
چیک آؤٹ میں دوبارہ قابل استعمال برانڈ پیک کھڑا کرنے کے لیے، `ingest:brand` وہ تین کنٹینرز قبول کرتا ہے جو Penpot اور Tokens Studio ایکسپورٹ کرتے ہیں: ایک `tokens.json`، `$metadata.json` کے ساتھ فی سیٹ فائلوں کی ڈائریکٹری، یا `project.penpot` آرکائیو۔

```bash
pnpm run ingest:brand ./my-tokens.json --name acme --label "Acme" --activate
```

`--activate` برانڈ کو پروفائل کے طور پر رجسٹر کرتا ہے اور اس کا کیٹلاگ بناتا اور جانچتا ہے۔ یہ ڈیفالٹ پروفائل کبھی نہیں بدلتا: نیا پیک استعمال کرنے کے لیے `LOLLY_PROFILE=acme` کے ساتھ چلائیں۔ [Configuration](/info/configuration.html) بتاتا ہے کہ برانڈ پیکس اور پروفائلز کیسے جڑتے ہیں۔
:::

## جو آپ کے پاس پہلے سے ہے اسے لائیں

آپ کو خالی صفحے سے شروع نہیں کرنا پڑتا۔

**ڈیزائن فائلیں۔** Figma، Penpot، Illustrator، InDesign یا کسی بھی SVG ایپ کا مکمل کام Design میں زندہ لے آؤٹ کے طور پر کھلتا ہے: متن دوبارہ ٹائپ کیا جا سکتا ہے، شکلیں شکلیں رہتی ہیں اور تصاویر آپ کی لائبریری میں آتی ہیں۔ فائل آپ کے براؤزر میں پڑھی جاتی ہے اور کچھ اپ لوڈ نہیں ہوتا۔ [Import a design](/info/design-import.html) ہر فارمیٹ اور جو کچھ ساتھ آتا ہے اسے درج کرتا ہے۔

**ڈیکس۔** PowerPoint کی `.pptx` کو Lolly پر ڈالیں تاکہ اس کی سلائیڈز ایسیٹس کے طور پر فائل ہوں، **Markdown Slides** میں Markdown سے نیا ڈیک لکھیں، یا پورے ڈیک کو اپنے ڈیزائن سسٹم پر لانے کے لیے [Rebrand a deck](/info/rebrand.html) استعمال کریں۔

**ڈیٹا۔** CSV یا JSON جدول پیسٹ کریں یا ڈالیں اور ٹول کے دہرائے جانے والے فیلڈز اس سے بھر جاتے ہیں، یا [Batch](/info/batch.html#make-many-versions-of-one-design) ہر قطار کے لیے ایک مکمل فائل بناتا ہے۔

### ایک بار کے ڈیزائن سے ٹیمپلیٹ تک

امپورٹ کیا ہوا لے آؤٹ عام Design سیشن ہے۔ **Share with rules** اسے ٹول میں بدل دیتا ہے: آپ چنتے ہیں کہ دوسرے لوگ کون سے حصے بدل سکتے ہیں، اور وہ صرف وہی بھرتے ہیں۔

![Design ماسٹر رکھیں، تصنیفی کاپی میں ان پٹس اور حدود چنیں، پھر دوبارہ قابل استعمال .lolly ٹول شیئر کریں جسے وصول کنندگان بھرتے ہیں](/info/diagrams/concepts/share-with-rules.svg)

[اصولوں کے ساتھ ڈیزائن شیئر کریں](/info/create-a-tool.html) ہر قدم سے گزارتا ہے۔

## بہت سے بنائیں، شیئر کریں اور خودکار بنائیں

- <!--i:download--> **ایکسپورٹ۔** ٹولز SVG، PDF، PNG، JPG، WebP، ویڈیو اور مزید بناتے ہیں، ان فارمیٹس میں جو ہر ٹول پیش کرے، ضرورت ہو تو حقیقی پرنٹ سائزوں پر۔ دیکھیں [فائل ایکسپورٹ کریں](/info/exporting.html)۔
- <!--i:link--> **لنک شیئر کریں۔** ٹول کی سیٹنگز اس کے لنک میں سفر کرتی ہیں، اس لیے لنک کہیں بھی وہی فائل دوبارہ کھولتا ہے۔
- <!--i:layers--> **ہر قطار کے لیے ایک بنائیں۔** [Batch](/info/batch.html#make-many-versions-of-one-design) میں اسپریڈ شیٹ سے ٹول چلائیں۔
- <!--i:cpu--> **خودکار بنائیں۔** یہی رینڈر [CLI](/info/cli.html) اور [AI ایجنٹ](/info/ai-agents.html) سے چلتا ہے۔

لنک مکمل درخواست ہے۔ نیچے کا چارٹ کسی نے نہیں بنایا: اس کی قسم، عنوان اور پورا ڈیٹا جدول ایڈریس بار میں ٹائپ کیا گیا تھا، اور وہی لنک کسی بھی ڈیوائس پر وہی چارٹ بناتا ہے۔
