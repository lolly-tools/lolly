# براؤزر ایکسٹینشن

ویب صفحہ دوسری ویب سائٹ کے پکسلز نہیں پڑھ سکتا، اس لیے Lolly ویب ایپ کو صفحے کا اسکرین شاٹ لینے کے لیے مدد چاہیے۔ Chromium پر مبنی براؤزر میں (Chrome، Edge، Brave، Arc یا Opera، Chrome 111 سے)، مفت **Lolly URL Screenshot** ایکسٹینشن یہ مدد دیتی ہے، وہی کیپچر استعمال کرتے ہوئے جو ڈیسک ٹاپ ایپ استعمال کرتی ہے۔ اس کے انسٹال ہونے پر:

- **[Lolly URL Screenshot](/t/url-shot)** آپ کا بنایا صفحہ فائل کے طور پر محفوظ کرتا ہے؛
- تصویر کے سلاٹ میں پیسٹ کیا ہوا ویب ایڈریس **Screenshot this page** کے ساتھ اس صفحے کا اسکرین شاٹ بن سکتا ہے؛
- [Lolly Design System Setup](/info/brand-studio.html) میں **Website** ماخذ ڈیزائن سسٹم شروع کرنے کے لیے ایک صفحہ پڑھ سکتا ہے۔

آپ ہر درخواست کی منظوری دیتے ہیں، اور ڈیسک ٹاپ ایپ یہی کام ایکسٹینشن کے بغیر کرتی ہے۔

## انسٹال کریں

**Chrome Web Store سے:** جلد آ رہا ہے۔ ایکسٹینشن شائع ہونے پر آپ اسے ایک کلک میں انسٹال کریں گے۔

**خود لوڈ کریں (ڈیولپرز)۔** ایکسٹینشن کا سورس ریپوزٹری میں `shells/chrome-extension/` پر ہے۔ پیکیجنگ مرحلہ اس فولڈر سے پروڈکشن پیکیج بناتا ہے، جو صرف `https://lolly.tools` پر Lolly کے ساتھ کام کرتا ہے۔

1. `pnpm run pack:chrome-extension` چلائیں۔ یہ پیکیج `dist/chrome-extension/` میں بناتا ہے۔
2. `chrome://extensions` کھولیں۔
3. **Developer mode** آن کریں (اوپر دائیں)۔
4. **Load unpacked** پر کلک کریں اور `dist/chrome-extension/` فولڈر چنیں۔
5. Lolly ٹیب ری لوڈ کریں۔ شناخت صفحہ لوڈ ہونے پر ہوتی ہے، اس لیے "Get the extension" پرامپٹ غائب ہو جاتا ہے۔ **Lolly URL Screenshot** (Utilities کے تحت) پھر کیپچرز فائل میں محفوظ کر سکتا ہے اور Lolly Batch موڈ میں دستیاب ہو جاتا ہے۔

مقامی development server کے لیے `pnpm run pack:chrome-extension:dev` چلائیں اور اس کے بجائے `dist/chrome-extension-dev` لوڈ کریں۔ وہ پیکیج `http://localhost:5173` کو بھی قبول کرتا ہے اور اس کے نام میں **Development** ہوتا ہے۔

`shells/chrome-extension/` فولڈر کو خود لوڈ کرنا بھی PNG اسکرین شاٹس کے لیے کام کرتا ہے۔ اس فولڈر میں page walk نہیں (پیکیجنگ مرحلہ ایک شامل کرتا ہے)، اس لیے اس سے SVG شکلوں کے بجائے اسکرین شاٹ رکھتی ہے۔

## جب Lolly مانگتا ہے تو کیا ہوتا ہے

![Lolly ٹیب ایک صفحہ مانگتا ہے اور آپ ایکسٹینشن کی منظوری ونڈو میں Approve once دباتے ہیں۔ پس منظر ٹیب کھلتا ہے، صفحہ پڑھتا ہے اور بند ہو جاتا ہے۔ پھر Lolly ٹیب کو نتیجہ ملتا ہے۔](/info/diagrams/concepts/extension-request.svg)

1. **Lolly مانگتا ہے۔** ایک چھوٹا اسکرپٹ Lolly کو بتاتا ہے کہ ایکسٹینشن موجود ہے، اس لیے کیپچر یا صفحہ پڑھنا بغیر مزید سیٹ اپ کے شروع ہو سکتا ہے۔
2. **آپ منظور کرتے ہیں۔** ایکسٹینشن اپنی **Approve page request** ونڈو کھولتی ہے۔ یہ درخواست کرنے والی سائٹ، اسکرین شاٹ چاہیے یا صفحے کا مواد، اور صفحے کا ایڈریس دکھاتی ہے۔ **Approve once** دبانے تک کچھ نہیں پڑھا جاتا۔ **Cancel**، یا ونڈو بند کرنا، درخواست ختم کرتا ہے۔
3. **Chrome فی سائٹ ایک بار پوچھتا ہے۔** جب آپ پہلی بار سائٹ کی درخواست منظور کرتے ہیں تو Chrome یہ بھی پوچھتا ہے کہ ایکسٹینشن اس سائٹ تک رسائی لے سکتی ہے یا نہیں۔ آپ کے اجازت دینے پر Chrome وہ رسائی رکھتا ہے، لیکن بعد کی ہر درخواست کو اپنا **Approve once** چاہیے۔
4. **صفحہ پس منظر ٹیب میں پڑھا جاتا ہے۔** ایکسٹینشن ہدف صفحہ پس منظر ٹیب میں کھولتی ہے، اسے DevTools Protocol کے ذریعے کیپچر کرتی ہے (وہی `Page.captureScreenshot` جو ڈیسک ٹاپ ایپ استعمال کرتی ہے)، ٹیب بند کرتی ہے اور نتیجہ اس Lolly ٹیب کو دیتی ہے جس نے مانگا۔

**SVG** کے لیے ایکسٹینشن اسکرین کی تصویر لینے کے بجائے صفحے کو walk کرتی ہے۔ ایکسٹینشن کے ساتھ پیک کیا گیا اسکرپٹ اس پس منظر ٹیب میں صفحے کا لے آؤٹ پڑھتا ہے اور صفحے کو شکلوں اور آؤٹ لائن متن میں بدل دیتا ہے، اس لیے فائل ہر سائز پر تیز رہتی ہے اور ہر حصہ قابل ترمیم رہتا ہے۔ صفحے کی تصاویر ویسی ہی تصاویر کے طور پر آتی ہیں جیسی وہ ہیں، اور جو صفحہ canvas، ویڈیو یا ایسے اثر سے بناتا ہے جس کی SVG میں کوئی شکل نہیں وہ اسی لمحے کے اسکرین شاٹ سے نقل ہوتا ہے۔ Lolly نتیجے کو اس اسکرین شاٹ سے جانچتا ہے، اور جب دونوں میں فرق بہت زیادہ ہو تو SVG اسکرین شاٹ رکھتی ہے۔

صفحے کے اپنے ٹائپ فیس میں متن کی آؤٹ لائن بنانے کے لیے ایکسٹینشن Lolly کو وہ فونٹ فائلیں دیتی ہے جو صفحے نے لوڈ کیں۔ Chrome فونٹ کے بائٹس وہاں نہیں رکھتا جہاں ایکسٹینشن انہیں پڑھ سکے، اس لیے ایکسٹینشن صفحے سے ہر فونٹ دوبارہ مانگتی ہے۔ آپ کا براؤزر عموماً اپنی cache سے جواب دیتا ہے، اور صفحے کی اپنی سیکیورٹی پالیسی اس درخواست پر پھر بھی لاگو ہوتی ہے۔

منظوری ایک درخواست کو ڈھانپتی ہے اور 30 سیکنڈ میں ختم ہو جاتی ہے۔ ایک وقت میں صرف ایک درخواست انتظار یا چل سکتی ہے، اور منظور شدہ درخواست 55 سیکنڈ بعد رک جاتی ہے۔ اگر Lolly صفحہ بند یا تبدیل ہو، یا ہدف صفحہ دوسری سائٹ پر چلا جائے، تو درخواست منسوخ ہو جاتی ہے۔

کیپچر آپ کے براؤزر میں، آپ کے نیٹ ورک پر چلتا ہے، اس لیے `localhost` اور اندرونی سائٹس کام کرتی ہیں۔ صفحہ آپ کے براؤزر سیشن کے ساتھ لوڈ ہوتا ہے، اس لیے جس صفحے پر آپ سائن اِن ہیں وہ نتیجے میں نجی معلومات دکھا سکتا ہے۔ کیپچر اپ لوڈ نہیں ہوتا: واحد نیٹ ورک ٹریفک آپ کا اپنا براؤزر ہے جو آپ کا مانگا صفحہ لوڈ کرتا ہے، اور SVG کے لیے اس صفحے کی فونٹ فائلیں دوسری بار۔

کیپچر چلتے وقت آپ عارضی ٹیب پر مختصراً *"…started debugging this browser"* بینر دیکھ سکتے ہیں۔ یہ DevTools Protocol کا کام ہے، اور شاٹ مکمل ہونے پر بینر صاف ہو جاتا ہے۔

## Lolly Design System Setup کے لیے سائٹ پڑھنا

Lolly Design System Setup میں **Website** ماخذ آپ کی پہلے سے موجود سائٹ سے ڈیزائن سسٹم شروع کرتا ہے۔ Chromium براؤزر میں ایکسٹینشن صفحہ پڑھتی ہے۔ ڈیسک ٹاپ ایپ میں ایپ خود صفحہ حاصل کرتی ہے۔ ایکسٹینشن کے بغیر براؤزر میں Website ٹائل پیش نہیں ہوتی۔

- **ایک ایڈریس، ایک صفحہ۔** آپ کی منظوری کے بعد ایکسٹینشن صفحہ اسی قسم کے پس منظر ٹیب میں کھولتی ہے، رینڈر شدہ markup، اسٹائل شیٹ کا متن اور مٹھی بھر آئیکن اور لوگو تصاویر پڑھتی ہے، پھر ٹیب بند کرتی ہے۔ یہ لنکس کی پیروی یا crawl نہیں کرتی۔
- **کہیں اور ہوسٹ اسٹائل شیٹس** (CDN یا فونٹ سروس) بھی حاصل کی جاتی ہیں، کیونکہ صفحے کے رنگ اور ٹائپ ان میں ہیں۔ cross-origin درخواستیں آپ کی کوکیز کے بغیر جاتی ہیں؛ same-origin درخواستیں انہیں استعمال کرتی ہیں، جیسے صفحہ خود کرتا۔
- **ہر چیز محدود ہے**، اسٹائل شیٹس اور تصاویر کی تعداد اور بائٹس کی حد کے ساتھ، اس لیے مخالف یا آدھا ٹوٹا صفحہ لٹکنے کے بجائے جزوی مواد لوٹاتا ہے۔
- **پارسنگ آپ کی ڈیوائس پر ہوتی ہے۔** بائٹس سیدھے اس Lolly ٹیب کو واپس جاتے ہیں جس نے مانگا، جو انہیں رنگوں، ٹائپ اور لوگوز میں بدلتا ہے۔

ایڈریس پیسٹ کرنا صرف فیلڈ بھرتا ہے۔ جب تک آپ پڑھت شروع نہ کریں اور **Approve once** نہ دبائیں کچھ نہیں پڑھا جاتا۔

## اجازتیں

ایکسٹینشن کا `manifest.json` چار اجازتیں اعلان کرتا ہے، ساتھ سائٹ رسائی جو یہ ایک وقت میں ایک سائٹ کے لیے مانگتی ہے۔ یہ `minimum_chrome_version: 111` سیٹ کرتا ہے، اور موجودہ ورژن 0.5.0 ہے۔

| اجازت | یہ کس لیے ہے | کب دی جاتی ہے |
|---|---|---|
| `debugger` | پس منظر ٹیب کو DevTools Protocol سے چلاتی ہے، جو اسکرین شاٹ لیتی ہے اور SVG کے لیے page walk چلاتی ہے۔ | انسٹال پر |
| `tabs` | عارضی پس منظر ٹیب کھولتی ہے اور بعد میں بند کرتی ہے، اور جانچتی ہے کہ آپ کی منظوری کے بعد نہ Lolly صفحہ ہلا نہ ہدف صفحہ۔ | انسٹال پر |
| `scripting` | Website ماخذ کے لیے آپ کی نامزد سائٹ کے اندر ایک صفحہ ریڈر چلاتی ہے۔ | انسٹال پر |
| `storage` | اپنے کھولے ٹیب کی آئی ڈی نوٹ کرتی ہے، صرف سیشن اسٹوریج میں، تاکہ براؤزر پڑھنے کے دوران ایکسٹینشن معطل کرے تب بھی ٹیب بند ہو۔ اگلے آغاز پر صاف ہو جاتی ہے؛ آپ کے بارے میں کچھ محفوظ نہیں ہوتا۔ | انسٹال پر |
| `optional_host_permissions: ["http://*/*", "https://*/*"]` | سائٹ رسائی، انسٹال پر نہیں دی جاتی۔ جب آپ **Approve once** دباتے ہیں تو ایکسٹینشن Chrome سے اس درخواست کی ایک سائٹ کی رسائی مانگتی ہے۔ | جب آپ پہلی بار اس سائٹ کی درخواست منظور کرتے ہیں، Chrome کے آپ سے پوچھنے کے بعد |

ایکسٹینشن صرف وہ ایک صفحہ پڑھتی ہے جو آپ منظور کرتے ہیں۔ یہ آپ کا براؤزنگ ڈیٹا نہ پڑھتی ہے نہ بھیجتی ہے، اور کچھ اپ لوڈ نہیں ہوتا۔

## مسئلہ حل

- **اب بھی "Get the extension" نظر آ رہا ہے؟** Lolly ٹیب ری لوڈ کریں۔
- **اس سائٹ پر کچھ نہیں ہوتا؟** ایکسٹینشن صرف `https://lolly.tools` پر کام کرتی ہے، اور ڈیولپمنٹ پیکج میں `http://localhost:5173`۔ کوئی دوسرا ماخذ، مثلاً Lolly کی خود میزبانی والی کاپی، کو ایکسٹینشن کا اپنا بلڈ چاہیے جو اس ماخذ کو `manifest.json` اور `policy.js` دونوں میں درج کرے۔ صرف مینی فیسٹ ایڈٹ کرنا کام نہیں کرتا۔
- **کیپچر ناکام ہوتا ہے؟** جانچیں کہ URL تک رسائی ہو اور `http://` یا `https://` سے شروع ہو۔ کچھ صفحات خودکار کیپچر روکتے ہیں۔ اگر آپ نے **Cancel** دبایا، منظوری کی ونڈو بند کی یا 30 سیکنڈ سے زیادہ انتظار کیا تو کیپچر دوبارہ شروع کریں۔
