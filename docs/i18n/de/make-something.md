# Ihre erste Datei erstellen

Laden Sie einen QR-Code für eine Webadresse herunter und speichern Sie eine Kopie, die Sie später öffnen und ändern können. Sie brauchen kein Konto und müssen vorher nichts einrichten. Sie brauchen kein Konto und keine Einrichtung.

::: note Bevor Sie beginnen
Halten Sie die Webadresse bereit, die der Code öffnen soll. Sie muss mit `https://` beginnen.
:::

::: steps
- <!--i:eti-pen--> **[Den Code erstellen](#make-the-code)** Geben Sie Ihre Adresse in Lolly QR Code ein und legen Sie seine Farben fest.
- <!--i:eti-download--> **[Die Datei herunterladen](#download-the-file)** Exportieren Sie eine PNG-Datei für einen Bildschirm oder eine SVG- oder PDF-Datei für den Druck.
- <!--i:eti-folder-plus--> **[Eine bearbeitbare Kopie behalten](#keep-an-editable-copy)** Speichern Sie Ihre Arbeit, damit Sie den Code später ändern können.
:::

<!--i:eti-pen-->
## Den Code erstellen

1. Öffnen Sie [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Die Steuerelemente stehen neben der Vorschau, auf einem Smartphone darüber. Die Vorschau zeigt, wie die Datei aussehen wird.
2. Ersetzen Sie unter **URL** die gesamte Beispieladresse durch Ihre eigene. Die Vorschau ändert sich während der Eingabe.
3. Stellen Sie **Module colour** und **Background** auf Ihre eigenen Farben ein. Achten Sie auf einen starken Kontrast zwischen beiden, sonst können Smartphones den Code nur schwer lesen.
4. **Quiet zone** unter **Modules** steht anfangs auf 4. Lassen Sie den Wert bei 4 oder höher. Eine Smartphone-Kamera sucht nach diesem freien Rand.

<!--i:eti-download-->
## Die Datei herunterladen

1. Drücken Sie **Export** auf der Pille **Export | Save as**, die auf einem Computer unter den Steuerelementen und auf einem Smartphone schwebend am unteren Bildschirmrand liegt.
2. Öffnen Sie das Formatmenü neben dem Dateinamen (es steht anfangs auf **SVG**) und wählen Sie **PNG** für einen Bildschirm oder eine Nachricht. Für den Druck beachten Sie den Hinweis unten.
3. Drücken Sie **Download**. Die Datei landet in den Downloads Ihres Browsers. Falls sie dort nicht liegt, siehe [Eine heruntergeladene Datei finden](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scannen Sie den Code, bevor Sie die Datei teilen
Öffnen Sie die heruntergeladene Datei auf einem Bildschirm und scannen Sie den Code mit einer Smartphone-Kamera. Falls Sie ihn auf Ihrem Smartphone erstellt haben, scannen Sie ihn von einem zweiten Smartphone oder einem Computerbildschirm. Das Smartphone sollte Ihre Webadresse anbieten.
:::

::: note Wenn der Code gedruckt oder angefasst wird
Wählen Sie **SVG** oder **PDF**, damit der Code in jeder Größe scharf bleibt. Testen Sie einen Ausdruck in der Größe, in der er verwendet wird. Falls der Code abgenutzt oder nass werden könnte, stellen Sie **Error correction** unter **Modules** auf **High (30%)**, damit auch ein beschädigter Code noch lesbar ist.
:::

<!--i:eti-folder-plus-->
## Eine bearbeitbare Kopie behalten

Speichern Sie auch Ihre Arbeit, um den Code später ändern zu können:

1. Drücken Sie **Save as**, dann **Save**. Wenn das Export-Panel geöffnet ist, finden Sie **Save as** im Panel. Ist es geschlossen, verwenden Sie das Häkchen neben **Export**. Der Code landet in **My library**, und eine Meldung **Saved** bietet **Open Projects** an.
2. Drücken Sie beim nächsten Mal **Home** und öffnen Sie die Ansicht **Projects** (das Ordnersymbol auf einem Smartphone). Ihr Code liegt dort unter dem Namen **QR Code**. Öffnen Sie ihn, ändern Sie etwas und exportieren Sie ihn erneut.

Gespeicherte Arbeit bleibt auf diesem Gerät in dem Browser oder der App, die Sie verwendet haben, sofern Sie [Sync](/info/sync.html) nicht einschalten. [Ihre Arbeit finden und wiederherstellen](/info/find-your-work.html) behandelt Ordner, frühere Versionen und das Übertragen Ihrer Arbeit auf ein anderes Gerät.

## Weitere erste Projekte

- [Lolly Audiogram](/#/tool/audiogram) macht aus einer Sprachnotiz ein Video mit bewegter Wellenform, Ihren Worten auf dem Titelbild und Ihren Farben. Ziehen Sie die Aufnahme in **Audio**, fügen Sie einen **Title** hinzu und exportieren Sie dann **MP4**.
- [Lolly Filter](/#/tool/filter) bearbeitet ein Foto für ein Poster: gedruckte Rasterpunkte, zwei flächige Farben oder wenige Tonwertblöcke. Wählen Sie das Foto unter **Image**, wählen Sie einen **Effect** und exportieren Sie dann **PNG** oder **SVG** bei einem mit *vector* gekennzeichneten Effekt.
- Der [Musikgenerator](/#/music) komponiert einen Track aus einem Genre und einem Startwert. Drücken Sie die runde Zufallsschaltfläche, bis Ihnen gefällt, was Sie hören. Öffnen Sie dann **Render** und laden Sie eine M4A- oder WAV-Datei herunter. Die Musik, die Sie erstellen, können Sie mit dem Hinweis **Musik erstellt mit Lolly (https://lolly.tools), CC BY 4.0** kostenlos nutzen, auch kommerziell. Die [Anleitung zum Musikgenerator](/info/music-generator.html) zeigt jedes Steuerelement, und [Kostenlose Hintergrundmusik](/info/background-music.html) enthält ein Beispiel für jedes Genre.

## Weiter

- **Einen Link statt einer Datei senden.** Jedes Steuerelement, das Sie geändert haben, ist in der Seitenadresse enthalten. **Share** im Export-Panel liefert einen Link, der dasselbe Design auf dem Bildschirm einer anderen Person öffnet. Ein Foto, das Sie von Ihrem eigenen Gerät hochgeladen haben, reist nicht im Link mit. Siehe [Ihre Arbeit teilen](/info/using.html#sharing-your-work).
- **Ihre Farben und Schriften einmal hinzufügen**, damit jedes Tool damit startet: der [Schnellstart](/info/quickstart.html).
- [Lolly verwenden](/info/using.html) ist die vollständige Anleitung zur App. [Lolly für Kreative](/info/creators.html) zeigt, was Sie sonst noch mit Lolly erstellen können.
