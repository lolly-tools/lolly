# Ihre erste Datei erstellen

Am Ende dieser Seite haben Sie einen QR-Code für eine Webadresse heruntergeladen und eine Kopie gespeichert, die Sie später öffnen und ändern können. Sie brauchen kein Konto und müssen vorher nichts einrichten.

::: note Bevor Sie beginnen
Halten Sie die Webadresse bereit, die der Code öffnen soll, beginnend mit `https://`.
:::

## Den Code erstellen

1. Öffnen Sie [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Die Steuerelemente sitzen neben der Vorschau, auf dem Smartphone darüber; was die Vorschau zeigt, ist das, was die Datei sein wird.
2. Ersetzen Sie unter **URL** die Beispieladresse vollständig durch Ihre eigene. Die Vorschau ändert sich, während Sie tippen.
3. Um Ihre eigenen Farben zu verwenden, stellen Sie **Module colour** und **Background** ein. Halten Sie zwischen beiden einen starken Kontrast, sonst haben Smartphones Mühe, den Code zu lesen.
4. **Quiet zone**, unter **Modules**, beginnt bei 4. Belassen Sie es bei 4 oder mehr: Dieser schlichte Rand ist es, wonach eine Handykamera sucht.

## Die Datei herunterladen

1. Drücken Sie **Export** auf der **Export | Save as**-Pille, am Fuß der Steuerelemente auf dem Computer oder schwebend am unteren Bildschirmrand auf dem Smartphone.
2. Öffnen Sie das Formatmenü neben dem Dateinamen (es beginnt bei **SVG**) und wählen Sie **PNG** für einen Bildschirm oder eine Nachricht. Für den Druck siehe den Hinweis unten.
3. Drücken Sie **Herunterladen**. Die Datei geht an die Downloads Ihres Browsers; wenn sie dort nicht ist, siehe [Eine heruntergeladene Datei finden](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scannen Sie den Code, bevor Sie die Datei teilen
Öffnen Sie die heruntergeladene Datei auf einem Bildschirm und scannen Sie den Code mit einer Handykamera. Wenn Sie ihn auf Ihrem Smartphone erstellt haben, scannen Sie ihn von einem zweiten Smartphone oder einem Computerbildschirm aus. Das Smartphone sollte Ihnen Ihre Webadresse anbieten.
:::

::: details Wenn der Code gedruckt oder angefasst wird
Wählen Sie **SVG** oder **PDF**, damit der Code in jeder Größe scharf bleibt, und testen Sie einen Druck in der tatsächlich verwendeten Größe. Wenn der Code verschmutzt werden oder nass werden könnte, stellen Sie **Error correction**, unter **Modules**, auf **High (30%)**: Ein beschädigter Code lässt sich dann noch lesen.
:::

## Eine bearbeitbare Kopie behalten

Die heruntergeladene Datei ist fertig. Um den Code später zu ändern, speichern Sie zusätzlich Ihre Arbeit:

1. Drücken Sie **Speichern unter**, dann **Speichern**. Bei geöffnetem Exportbereich befindet sich **Speichern unter** im Bereich; ist er geschlossen, ist es der Haken neben **Export**. Der Code geht in **Meine Bibliothek**, und eine **Gespeichert**-Meldung bietet **Projekte öffnen** an.
2. Drücken Sie beim nächsten Mal auf **Start** und öffnen Sie **Projekte** (das Ordnersymbol auf dem Smartphone). Ihr Code liegt dort, benannt **QR Code**. Öffnen Sie ihn, ändern Sie etwas und exportieren Sie erneut.

Gespeicherte Arbeit bleibt auf diesem Gerät, in dem Browser oder der App, die Sie verwendet haben, sofern Sie nicht die [Synchronisierung](/info/sync.html) aktivieren. [Ihre Arbeit finden und wiederherstellen](/info/find-your-work.html) behandelt Ordner, frühere Versionen und den Umzug Ihrer Arbeit auf ein anderes Gerät.

## Weitere erste Projekte

- [Audiogram](/#/tool/audiogram) verwandelt eine Sprachnotiz in ein Video: eine bewegte Wellenform, Ihre Worte auf dem Cover, Ihre Farben. Legen Sie die Aufnahme in **Audio** ab, fügen Sie einen **Titel** hinzu und exportieren Sie dann **MP4**.
- [Filter](/#/tool/filter) bereitet ein Foto für ein Poster auf: gedruckte Rasterpunkte, zwei Volltonfarben oder ein paar Tonblöcke. Wählen Sie das Foto unter **Bild**, wählen Sie einen **Effekt** und exportieren Sie dann **PNG** oder, bei einem mit *vector* gekennzeichneten Effekt, **SVG**.

## Wie es weitergeht

- **Einen Link statt einer Datei senden.** Jedes Steuerelement, das Sie berührt haben, wird in die Seitenadresse geschrieben, sodass **Teilen** im Exportbereich einen Link liefert, der dasselbe Design auf dem Bildschirm einer anderen Person wieder öffnet. Ein Foto, das Sie von Ihrem eigenen Gerät hochgeladen haben, reist nicht mit dem Link. Siehe [Ihre Arbeit teilen](/info/using.html#sharing-your-work).
- **Fügen Sie Ihre Farben und Schriften einmal hinzu**, damit jedes Tool damit beginnt: der [Schnellstart](/info/quickstart.html).
- [Lolly nutzen](/info/using.html) ist die vollständige Anleitung zur App, und [Lolly für Kreative](/info/creators.html) zeigt, was sie sonst noch erstellt.
