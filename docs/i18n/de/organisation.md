# Lolly in Ihrer Organisation nutzen

Ihre Organisation kann ihr eigenes Lolly betreiben: dieselbe App, mit den Tools und dem Design-System, die sie gewählt hat, und manchmal einer Anmeldung. Diese Seite zeigt, wie Sie dorthin gelangen und was sich dann ändert.

::: note Was Sie von Ihrer Organisation brauchen
Die Webadresse ihres Lolly, oder eine `.lolly`-Setup-Datei, die Ihre Organisation erstellt hat. lolly.tools allein verbindet sich mit keiner Organisation.
:::

## Im Browser

Öffnen Sie die Adresse, die Ihre Organisation Ihnen gegeben hat. Wenn die Seite Sie zur Anmeldung auffordert, drücken Sie **Anmelden** und folgen Sie der sich öffnenden Anmeldeseite. Danach funktioniert es wie jedes Lolly, mit den Tools und dem Design-System Ihrer Organisation.

Ein Browser hat keine Einstellung, um zu einem anderen Lolly zu wechseln. Öffnen Sie daher die eigene Adresse Ihrer Organisation statt lolly.tools.

## In der Desktop- oder Mobile-App

Beim ersten Start der App fragt sie: **Woher soll Lolly seine Tools beziehen?**

1. Wählen Sie **Mit einer Lolly-Instanz verbinden**.
2. Geben Sie die Webadresse Ihrer Organisation ein und drücken Sie **Prüfen und verbinden**.
3. Drücken Sie **Diese Instanz verwenden**. Der nächste Bildschirm, **Ihre Daten importieren (optional)**, überträgt gespeicherte Arbeit aus einem Lolly-Backup; drücken Sie **Überspringen**, wenn Sie keines haben.
4. Melden Sie sich an, falls die App danach fragt.

Tools einer verbundenen Instanz laufen mit demselben Vertrauen wie die eigenen der App, verbinden Sie sich daher nur mit einer, der Sie vertrauen. Ihre Organisation kann Ihnen stattdessen eine `.lolly`-Setup-Datei schicken, die die App für Sie verbindet.

Um später zu wechseln, öffnen Sie **Einstellungen**: Die Karte **Lolly-Instanz** hat **Ändern** und **Verlassen**.

## Mit einem Code anmelden

Wenn die Anmeldung auf diesem Gerät umständlich ist und das Lolly Ihrer Organisation es anbietet, drücken Sie **Mit einem Code auf einem anderen Gerät anmelden**. Lolly zeigt einen kurzen Code und eine Adresse: Öffnen Sie die Adresse auf einem Smartphone oder Computer, auf dem Sie bereits angemeldet sind, und geben Sie dort den Code ein. Der Code gilt etwa zehn Minuten.

## Was dort anders ist

- **Manche Steuerelemente sind für Sie festgelegt.** Ein Steuerelement, das Ihre Organisation verwaltet, zeigt **Managed by** und den Namen der Organisation, oder **Von Ihrer Organisation verwaltet**. Ein fest eingestelltes Steuerelement lässt sich nicht ändern, ein Menü bietet möglicherweise nur einen Teil seiner Auswahl, und eine Zeile, die mit **Set by** beginnt, kann sagen, welche Regel gilt und warum. Manche Steuerelemente werden gar nicht angezeigt.
- **Nur ihre eigenen Tools sind aufgeführt.** Ein Tool, das Ihre Organisation nicht anbietet, wird gar nicht angezeigt.
- **Gemeinsame Projekte.** Wenn Ihre Organisation Projekte mit Ihnen teilt, zeigt **Projekte** eine Kachel **Teamprojekte**.
- **Manche Exporte benötigen möglicherweise eine Freigabe.** Wo Ihre Organisation eine Freigabe verlangt, tritt **Freigabe anfordern** an die Stelle von **Herunterladen**, und ein Tool bietet möglicherweise weniger Formate an.
- **Ihre eigenen Speicherungen** bleiben auf diesem Gerät, sofern Sie nicht die [Synchronisierung](/info/sync.html) aktivieren, wie überall in Lolly.

## Verlassen

**Verlassen** auf der Karte **Lolly-Instanz** in **Einstellungen** entfernt das Design-System, die Tools und den Katalog Ihrer Organisation. Ihre eigene Arbeit bleibt erhalten. Alles, was Sie mit ihren Tools erstellt haben, öffnet sich erst wieder, wenn Sie sich erneut verbinden, und alles, was Sie bei der Organisation gespeichert haben, bleibt bei der Organisation. In einem Browser unter der eigenen Adresse Ihrer Organisation gibt es nichts zu verlassen: Öffnen Sie stattdessen eine andere Adresse.

## An wen Sie sich wenden

Was den Server Ihrer Organisation erreicht, wer ihre gemeinsamen Projekte sehen kann und welche Einstellungen fest sind, sind Entscheidungen Ihrer Organisation. Fragen Sie, wer das Lolly Ihrer Organisation betreibt. [Datenschutzerklärung](/info/privacy.html) behandelt, was Lolly selbst mit Ihren Daten macht.
