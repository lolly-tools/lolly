# Lolly und Online-Dateikonverter

_Zuletzt geprüft: 28. September 2026._

Wenn Sie gewöhnlich nach „HEIC zu JPG“ oder „PDF komprimieren“ suchen und die Datei auf irgendeine gefundene Website hochladen, erledigt Lolly dieselbe Umwandlung in Ihrem Browser auf Ihrem eigenen Gerät.

<!--i:eti-award-->
## Was eine Konverter-Website besser kann

Einige Konverter-Websites verarbeiten Formate, die Lolly nicht unterstützt, und brauchen keine Einrichtung. Wählen Sie einen Konverter nach den benötigten Formaten und der Wiedergabetreue sowie danach, wo er die Datei verarbeitet. Manche Umwandlungen erhalten die bearbeitbare Struktur, andere reduzieren das Ergebnis auf eine Ebene.

<!--i:eti-map-pin-->
## Wo die Umwandlung stattfindet

Ein browserbasierter Konverter kann eine Datei zur Verarbeitung hochladen oder sie lokal umwandeln. Die Umwandlungs-Utilities von Lolly verarbeiten die Datei lokal, ohne Konto, Werbung oder Tracker. Sie fügen weder ein Lolly-Wasserzeichen noch Content Credentials hinzu. Die Utilities funktionieren offline, sobald die für eine Umwandlung benötigten Assets gespeichert sind. Die Dateigröße ist durch den Arbeitsspeicher des Geräts und das Leseprogramm für das Format begrenzt.

## Wenn ein Team mehr braucht

Mitglieder einer Organisation, die Lolly Work betreibt, nutzen für lokale Umwandlungen weiterhin die Utilities auf dem Gerät. Daten gehen nur bei einem gemeinsamen Upload, einem Server-Rendering oder einer Lieferung an den Server der Organisation. [Was wo läuft](/info/compare.html#what-runs-where) erklärt die Trennung.
