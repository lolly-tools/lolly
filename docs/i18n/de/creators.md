# Erstellen

Füllen Sie ein paar Felder aus und erhalten Sie eine fertige Datei auf Ihrem eigenen Gerät. Schriften, Farben und Layout sind bereits festgelegt. Die Markenregeln stecken im Tool, sodass Ihr Name nie auf einer Datei steht, die von der Marke abweicht.

Wenn Sie neu dabei sind, beginnen Sie mit **[Ihre erste Datei erstellen](/info/make-something.html)**. [So funktioniert Lolly](/info/how-lolly-works.html) zeigt, wie ein Tool auch über ein Skript oder das Smartphone einer Kollegin laufen kann. [Fragen & Antworten](/info/faq.html) behandelt die Fragen, die Menschen stellen, bevor sie einem kostenlosen Tool vertrauen.

## Gestalten

Wählen Sie ein Tool und füllen Sie es aus oder gestalten Sie eine Seite frei auf der Arbeitsfläche von Lolly Design.

- **[Ihre erste Datei erstellen](/info/make-something.html)** - eine kurze Lektion ohne Einrichtung: ein QR-Code, heruntergeladen und als bearbeitbare Kopie gespeichert.
- **[Lolly verwenden](/info/using.html)** - die Arbeitsfläche, die Steuerelemente, Speichern, Projects und die Nutzung auf dem Smartphone.
- **[Lolly Design](/info/design.html)** - die freie Arbeitsfläche für Layouts, die keine Vorlage abdeckt: ein Poster, ein Deck, ein Bewegungsstück.
- **[Vorlagen](/info/templates.html)** - mit einem gespeicherten Layout statt einem leeren Tool beginnen.
- **[Text in Lolly Design](/info/text-composition.html)** - Überschriften, Fließtext und Schrift, die in ihre Box passt.
- **[Lolly Chart](/info/chart.html)** - eine eingefügte Tabelle als Vektordiagramm, statistischer Plot, 3-D-Szene oder filmischer Kameraflug.
- **[Lolly 3D Studio](/info/3d-studio.html)** - SVG-Grafiken und 3D-Modelle, als eine Szene angeordnet, beleuchtet und gerendert.
- **[Lolly Darkroom](/info/darkroom.html)** - die Farben von Fotos und Videos bearbeiten und einen Look als LUT behalten.
- **[Lolly Utilities](/info/utilities.html)** - eine Datei auf Ihrem Gerät bearbeiten: sicher teilen, zwei Versionen vergleichen, das Format ändern, den Text extrahieren oder eine Farbe prüfen.
- **[Browsererweiterung](/info/extension.html)** - aus der Web-App einen Screenshot einer aktuellen Webseite aufnehmen oder eine Website auslesen, um ein Designsystem zu beginnen.

- **[Ein Design importieren](/info/design-import.html)** - eine Datei aus Figma, Penpot, Illustrator, InDesign, Affinity, Photoshop, PowerPoint oder eine SVG-Datei als bearbeitbares Layout statt als flaches Bild öffnen ([alle Formate](/info/design-import.html#what-comes-in-from-each-app)).

- **[Ein Design mit Regeln teilen](/info/create-a-tool.html)** - ein Layout in ein Tool verwandeln, das andere ausfüllen.

## Animieren

Bewegter Text, Szenen auf einer Zeitleiste und Animationen im Stil Ihrer Marke. Ein Bewegungsexport wird Bild für Bild nach einer gesteuerten Uhr gezeichnet, nicht vom Bildschirm aufgenommen. Deshalb erzeugt derselbe Link denselben Clip.

- **[Animieren](/info/animating.html)** - Keyframes, Tiefe und eine Szenenkamera.
- **[Der Sequenzeditor](/info/sequence-editor.html)** - Clips, Overlay-Spuren, Kürzen und Teilen, Übergänge und die Audiomischung.
- **[Erweiterter Farbraum und HDR](/info/hdr-editing.html)** - Farben jenseits des üblichen Bereichs, auf Bildschirmen und in Formaten, die diesen zusätzlichen Bereich darstellen können.

## Aufnehmen und präsentieren

Machen Sie eine saubere Aufnahme mit Einzähler und Pegelanzeige oder stellen Sie sich selbst vor Ihre Folien.

- **[Die Zeitleiste von Lolly Design](/info/design.html#timeline-sequence)** - einen Sprechertext auf die Zeitleiste aufnehmen.
- **[Ihre erste Datei erstellen](/info/make-something.html#other-first-projects)** - das Audiogramm, um gehört zu werden, ohne vor der Kamera zu erscheinen.
- **[Musikgenerator](/info/music-generator.html)** - einen eigenen Track in jedem Genre erstellen, mit Quellenangabe kostenlos nutzbar. [Kostenlose Hintergrundmusik](/info/background-music.html) enthält ein Beispiel für jedes Genre. [Generierte Musik](/info/generated-music.html) erklärt, wie die Musik entsteht.
- **[Mit Kamera präsentieren](/info/presenting.html)** - Ihre Kamera, Ihr Logo und Ihr Name über einem Deck oder Countdown, mit privaten Steuerelementen in einem separaten Fenster.
- **[Live-Seiten, die sich mit dem Presenter steuern lassen](/info/interactive-pages.html)** und **[Agenda-Bildschirme](/info/agenda.html)** - Seiten und Programme für den Raum.

## Zusammenarbeiten

Zwei Personen bearbeiten auf zwei Geräten ein Design live, ohne Konto und ohne Server dazwischen.

- **[Zusammenarbeiten](/info/collaborate.html)** - private Collabs zwischen Geräten und Work-Collabs über das Lolly Work Ihrer Organisation.
- **[Lolly verwenden](/info/using.html#sharing-your-work)** - ein Link zum Teilen, der den gesamten Zustand enthält, oder eine einzelne `.lolly`-Datei.
- **[Lolly in Ihrer Organisation verwenden](/info/organisation.html)** - Anmeldung, Teamprojekte und verwaltete Einstellungen, wenn Ihre Organisation Lolly Work betreibt.
