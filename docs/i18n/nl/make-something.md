# Je eerste bestand maken

Download een QR-code voor een webadres en sla een kopie op die je later kunt openen en wijzigen. Je hebt geen account nodig en hoeft vooraf niets in te stellen. Je hebt geen account nodig en hoeft niets in te stellen.

::: note Voordat je begint
Houd het webadres bij de hand dat de code moet openen, beginnend met `https://`.
:::

## De code maken

1. Open [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). De bediening staat naast het voorbeeld, of erboven op een telefoon. Het voorbeeld laat zien hoe het bestand eruit zal zien.
2. Vervang in **URL** het volledige voorbeeldadres door je eigen adres. Het voorbeeld verandert terwijl je typt.
3. Stel **Module colour** en **Background** in om je eigen kleuren te gebruiken. Zorg voor een sterk contrast, anders kunnen telefoons de code moeilijk lezen.
4. **Quiet zone**, onder **Modules**, staat standaard op 4. Houd deze waarde op 4 of hoger. Een telefooncamera zoekt naar die onbedrukte marge.

<!--i:eti-download-->
## Het bestand downloaden

1. Druk op **Export** op de pil **Export | Save as**, op een computer onder de bediening of op een telefoon zwevend onderaan het scherm.
2. Open het formaatmenu naast de bestandsnaam (het staat standaard op **SVG**) en kies **PNG** voor een scherm of een bericht. Zie de opmerking hieronder voor drukwerk.
3. Druk op **Download**. Het bestand komt bij de downloads van je browser. Staat het daar niet, zie dan [Een gedownload bestand vinden](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scan de code voordat je het bestand deelt
Open het gedownloade bestand op een scherm en scan de code met een telefooncamera. Heb je het op je telefoon gemaakt, scan het dan vanaf een tweede telefoon of een computerscherm. De telefoon moet je webadres aanbieden.
:::

::: note Als de code wordt afgedrukt of vastgepakt
Kies **SVG** of **PDF** zodat de code op elk formaat scherp blijft. Test een afdruk op het formaat waarin de code gebruikt wordt. Kan de code beschadigd of nat worden, stel dan **Error correction**, onder **Modules**, in op **High (30%)** zodat ook een beschadigde code leesbaar blijft.
:::

## Een bewerkbare kopie bewaren

Sla ook je werk op om de code later te kunnen wijzigen:

1. Druk op **Save as** en daarna op **Save**. Als het exportpaneel openstaat, vind je **Save as** in dat paneel. Als het paneel gesloten is, gebruik je het vinkje naast **Export**. De code komt in **My library** en een melding **Saved** biedt **Open Projects** aan.
2. Druk de volgende keer op **Home** en open de weergave **Projects** (het mappictogram op een telefoon). Daar staat je code, met de naam **QR Code**. Open hem, wijzig wat je wilt en exporteer opnieuw.

Opgeslagen werk blijft op dit apparaat, in de browser of app die je gebruikte, tenzij je [Sync](/info/sync.html) inschakelt. [Je werk vinden en herstellen](/info/find-your-work.html) behandelt mappen, eerdere versies en het verplaatsen van je werk naar een ander apparaat.

## Andere eerste projecten

- [Lolly Audiogram](/#/tool/audiogram) maakt van een spraakmemo een video met een bewegende golfvorm, je woorden op de omslag en je kleuren. Sleep de opname naar **Audio**, voeg een **Title** toe en exporteer als **MP4**.
- [Lolly Filter](/#/tool/filter) bewerkt een foto voor een poster: gedrukte rasterpunten, twee egale kleuren of een paar toonvlakken. Kies de foto onder **Image**, kies een **Effect** en exporteer als **PNG**, of als **SVG** bij een effect met het label *vector*.
- De [muziekgenerator](/#/music) componeert een track op basis van een genre en een seed. Druk op de ronde shuffleknop tot je tevreden bent met wat je hoort, open dan **Render** en download een M4A- of WAV-bestand. Je mag de muziek die je maakt vrij gebruiken, ook commercieel, met de vermelding **Muziek gemaakt met Lolly (https://lolly.tools), CC BY 4.0**. De [gids voor de muziekgenerator](/info/music-generator.html) toont alle bediening en [Gratis achtergrondmuziek](/info/background-music.html) bevat een voorbeeld van elk genre.

## Verder

- **Stuur een link in plaats van een bestand.** Elke instelling die je hebt aangepast, staat in het pagina-adres. **Share** in het exportpaneel geeft een link die hetzelfde ontwerp op het scherm van iemand anders opent. Een foto die je vanaf je eigen apparaat hebt geüpload, gaat niet mee in de link. Zie [Je werk delen](/info/using.html#sharing-your-work).
- **Voeg je kleuren en lettertypen één keer toe**, zodat elke tool ermee begint: de [Snelstart](/info/quickstart.html).
- [Lolly gebruiken](/info/using.html) is de volledige gids voor de app. [Lolly for Creators](/info/creators.html) laat zien wat je nog meer met Lolly kunt maken.
