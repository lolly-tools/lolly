# Je eerste bestand maken

Aan het einde van deze pagina heb je een QR-code voor een webadres gedownload en een kopie opgeslagen die je later kunt openen en wijzigen. Je hebt geen account nodig en niets vooraf in te stellen.

::: note Voordat je begint
Zorg dat je het webadres bij de hand hebt dat de code moet openen, beginnend met `https://`.
:::

## De code maken

1. Open [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). De bedieningselementen staan naast de voorvertoning, of erboven op een telefoon; wat de voorvertoning toont, is wat het bestand zal zijn.
2. Vervang bij **URL** het hele voorbeeldadres door het jouwe. De voorvertoning verandert terwijl je typt.
3. Om bij je eigen kleuren aan te sluiten, stel je **Module colour** en **Background** in. Houd een sterk contrast tussen beide aan, anders hebben telefoons moeite om de code te lezen.
4. **Quiet zone**, onder **Modules**, begint op 4. Houd het op 4 of hoger: die vlakke marge is waar een telefooncamera naar zoekt.

## Het bestand downloaden

1. Druk op **Exporteren** op de pil **Exporteren | Opslaan als**, onder aan de bedieningselementen op een computer of zwevend onder aan het scherm op een telefoon.
2. Open het formaatmenu naast de bestandsnaam (het begint op **SVG**) en kies **PNG** voor een scherm of een bericht. Voor drukwerk, zie de notitie hieronder.
3. Druk op **Downloaden**. Het bestand gaat naar de downloads van je browser; staat het daar niet, zie [Een gedownload bestand vinden](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scan de code voordat je het bestand deelt
Open het gedownloade bestand op een scherm en scan de code met een telefooncamera. Als je hem op je telefoon hebt gemaakt, scan hem dan vanaf een tweede telefoon of een computerscherm. De telefoon zou je webadres moeten aanbieden.
:::

::: details Als de code afgedrukt of gehanteerd wordt
Kies **SVG** of **PDF** zodat de code op elke grootte scherp blijft, en test een afdruk op het formaat waarin hij gebruikt wordt. Als de code bekrast kan raken of nat kan worden, zet **Error correction**, onder **Modules**, op **High (30%)**: een beschadigde code is dan nog steeds leesbaar.
:::

## Een bewerkbare kopie bewaren

Het bestand dat je hebt gedownload, is af. Om de code later te wijzigen, sla je je werk ook op:

1. Druk op **Opslaan als**, dan op **Opslaan**. Met het exportpaneel open staat **Opslaan als** in het paneel; is het gesloten, dan is het het vinkje naast **Exporteren**. De code gaat naar **Mijn bibliotheek**, en een melding **Saved** biedt **Open Projects** aan.
2. Druk de volgende keer op **Home** en open **Projecten** (het mapicoon op een telefoon). Je code staat daar, genoemd **QR Code**. Open hem, wijzig iets en exporteer opnieuw.

Opgeslagen werk blijft op dit apparaat, in de browser of app die je gebruikte, tenzij je [Synchronisatie](/info/sync.html) aanzet. [Vind en herstel je werk](/info/find-your-work.html) behandelt mappen, eerdere versies en het verplaatsen van je werk naar een ander apparaat.

## Andere eerste projecten

- [Audiogram](/#/tool/audiogram) verandert een spraakmemo in een video: een bewegende waveform, je woorden op de cover, je kleuren. Zet de opname in **Audio**, voeg een **Titel** toe en exporteer dan **MP4**.
- [Filter](/#/tool/filter) bewerkt een foto voor een poster: gedrukte halftoonpunten, twee vlakke kleuren of een paar tinten. Kies de foto onder **Afbeelding**, kies een **Effect**, en exporteer dan **PNG**, of **SVG** bij een effect met het label *vector*.

## Hierna

- **Stuur een link in plaats van een bestand.** Elk bedieningselement dat je hebt aangeraakt, wordt in het pagina-adres geschreven, dus **Delen** in het exportpaneel geeft een link die hetzelfde ontwerp op het scherm van iemand anders heropent. Een foto die je vanaf je eigen apparaat hebt geüpload, reist niet mee met de link. Zie [Je werk delen](/info/using.html#sharing-your-work).
- **Voeg je kleuren en lettertypen eenmalig toe**, zodat elke tool ermee begint: de [Snelstart](/info/quickstart.html).
- [Lolly gebruiken](/info/using.html) is de volledige handleiding voor de app, en [Lolly voor makers](/info/creators.html) toont een rondleiding langs wat hij verder nog maakt.
