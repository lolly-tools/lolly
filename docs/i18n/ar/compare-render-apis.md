# Lolly وواجهات API للعرض

_آخر تحقق: 5 نوفمبر 2026._

إذا كنت تولد صورا من قوالب عبر API، فهذه الصفحة توضح ما يتغير حين تشغل هذا الإنتاج على جهازك أو في CI أو على خادم تتحكم فيه. وتقدم صفحة [الانتقال من API مستضاف للعرض](/info/work-move-from-render-api.html) الخطوات.

<!--i:eti-award-->
## ما تتفوق فيه واجهات API المستضافة للعرض

[Bannerbear](https://www.bannerbear.com/) و[Placid](https://placid.app/) خدمتان مدارتان: ترسل طلبا ويتولى غيرك تشغيل الخوادم.

- **لا شيء تشغله.** لا خادم ولا قاعدة بيانات ولا تخزين ولا تحديثات ولا تخطيط للسعة.
- **محرر قوالب مستضاف** مع قوالب جاهزة للتعديل.
- **أنواع مخرجات أكثر من API واحد.** تنشر كلتاهما نقاط نهاية للفيديو وPDF، وتوثق Bannerbear أيضا المخرجات المتحركة وWebP وAVIF ولقطات الشاشة وإزالة الخلفية بالذكاء الاصطناعي.
- **تكاملاتهما ودعمهما الخاصان.**

إذا كان هذا هو الترتيب الذي تريده، فهاتان الخدمتان خيار مناسب.

<!--i:eti-home-->
## ما تمنحك إياه الاستضافة الذاتية

- **يبقى محتواك على أنظمتك.** توجد المدخلات والأصول والمخرجات على بنية تحتية اخترتها. ولا يحتاج العرض على جهاز أو في CI إلى خدمة.
- **القواعد في الأداة.** تأتي الألوان والخطوط والشعارات والمدخلات المقفلة من [نظام تصميمك](/info/brand-studio.html)، فلا يستطيع المستدعي تغيير إلا ما تسمح به. يطبق [Lolly Work](/info/compare.html#what-runs-where) إتاحة الأدوات وسياسات المدخلات على كل طلب.
- **الأداة نفسها في كل مكان.** تعرض الأداة من المدخلات نفسها على حاسوب محمول أو في مهمة CI أو على خادم. ويمكن للأشخاص تحرير الأداة نفسها في التطبيق.
- **سجلات تحتفظ بها.** [إيصالات العرض](/info/work-renders.html#evidence-and-identity) وسجل تدقيق وContent Credentials حيث تضبط هوية توقيع.
- **مفتوح المصدر وبلا رسوم حسب الاستخدام.** تشغل الشفرة وتدفع فقط تكلفة بنيتك التحتية.

تتولى العمل الذي تنجزه تلك الخدمات من أجلك. يحتاج الخادم الدائم إلى قاعدة بيانات دائمة وتخزين للمخرجات. وتحتاج الأدوات التي تتطلب متصفحا إلى عامل Chromium. ويصف [تثبيت Lolly Work](/info/work-install.html) الأمرين.

## كيف تتقابل المهام

| المهمة | API مستضاف للعرض | Lolly |
|---|---|---|
| ملء قالب من البيانات | طلب API يسمي قالبا وطبقاته | [URL](/info/url-mode.html) أو [CLI](/info/cli.html) أو [API للخادم](/info/work-automation-api.html) يسمي أداة ومدخلاتها |
| ملفات كثيرة من جدول | دفعات ومجموعات | [دفعة](/info/batch.html) على جهازك، أو [دفعات عرض](/info/work-renders.html#batches-with-durable-rows) على خادم |
| الانتظار أو الاستعلام المتكرر عن نتيجة | استعلام متكرر، أو خيار متزامن | عمليات عرض دائمة تستعلم عنها، أو عرض فوري |
| استدعاء webhook عند الانتهاء | نعم | [استدعاءات راجعة موقعة](/info/work-renders.html) إلى الأصول التي تسمح بها |
| URL ديناميكي للصورة | نعم | [روابط مشاركة وعناوين URL من نوع `/render`](/info/url-mode.html) |
| تحرير قالب | محرر مستضاف | [Design](/info/using.html)، على جهازك |
| الوكلاء | تنشر كلتاهما خادم MCP | [MCP](/info/mcp.html)، مع نقطة نهاية للمؤسسة تخضع لسياسة رمز وصول في Lolly Work |

تسرد صفحة [التصدير](/info/exporting.html) أنواع مخرجات Lolly نفسه. على خادم Work اليوم، تنتج عمليات العرض الدائمة SVG وPNG وJPG وPDF، و[يبقى الفيديو على الجهاز وCLI وMCP](/info/work-renders.html#production-still-checks-and-permitted-repairs).

## ما ينتقل وما لا ينتقل

| | Bannerbear V5 | Bannerbear V2 | Placid |
|---|---|---|---|
| طلباتك | يقبل API الترحيل في Work البنية نفسها | كذلك | كذلك |
| قوالبك | **Import** كمستندات قابلة للتحرير، باستثناء أنواع الطبقات التي ليس لها مخطط مؤكد | أسماء الحقول ومعاينة فقط. أعد بناء كل قالب | أسماء الحقول ومعاينة فقط. أعد بناء كل قالب |
| عناوين URL الديناميكية الحالية | غير مدعومة | غير مدعومة | تظل عناوين URL الموقعة تعمل بعد تغيير المضيف، باستخدام رمزك الخاص القديم |
| Webhooks | Webhooks المسجلة غير مدعومة | يعمل `webhook_url` | يعمل `webhook_success` |
| مخرجات WebP وAVIF | ترفض بالاسم | غير متاحة | يرفض WebP بالاسم |
| الرسوم المتحركة والفيديو والمجموعات ولقطات الشاشة | ليست ضمن API الترحيل | ليست ضمن API الترحيل | ليست ضمن API الترحيل |

::: note بني اعتمادا على الوثائق العامة
بني هذا اعتمادا على الوثائق العامة لكل مزود، ولم يشغل على حساب فعلي. إذا كان لديك حساب، ففي [دليل الانتقال](/info/work-move-from-render-api.html#check-it-on-your-own-account) قائمة تحقق قصيرة.
:::

يمكنك نقل قالب واحد وإبقاء البقية حيث هي. و[مغادرة Lolly](/info/work-move-from-render-api.html#leave-lolly-too) متاحة بالقدر نفسه: الأدوات ملفات عادية ويعرضها CLI دون خادم.

## من يشغل الخدمة

مع Lolly، يعرض الفرد محليا، أو يشغل فريق Lolly Work على بنيته التحتية. ترسل مهمة الخادم مدخلاتها والأصول المطلوبة إلى تلك النسخة. أما المسار على الجهاز فلا يفعل ذلك.

Bannerbear وPlacid علامتان تجاريتان لمالكيهما. تصف هذه الصفحة مواضع التداخل بين المنتجات، استنادا إلى وثائقها العامة، ولا تتبع أيا منهما.
