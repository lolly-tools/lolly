# Lolly وبوابات العلامة التجارية

_آخر تحقق: 28 سبتمبر 2026._

إذا كانت مؤسستك تحتفظ بأصولها المعتمدة في Bynder أو Frontify أو Marq أو Brandfolder، فتقارن هذه الصفحة ذلك بـ Lolly مع Lolly Work: كيف يجد الناس أصول العلامة، وكيف يصنعون منها ملفات جديدة.

## ما تفعله البوابة الراسخة أفضل

تقدم البوابات الراسخة استضافة مُدارة ودعماً وسير عمل واسعاً لإدارة الأصول. فمثلاً يجمع [DAM المؤسسي من Frontify](https://www.frontify.com/en/solution/enterprise-digital-asset-management) اكتشاف الأصول وضوابط الوصول وسير عمل الموافقة والتوزيع. حزمة Lolly أحدث وسلاسل موافقتها تسلسلية لا سير عمل متفرع عشوائي. ويسجّل [حالة Work وخارطة الطريق](/info/work-status.html) حدود نشرها.

## أين يتقاطعان

كلاهما يغطي الأصول المعتمدة والقوالب المقفلة وضبط الوصول والمراجعة والتوزيع. يصنع Lolly الملفات: تحدد القوالب ورموز التصميم والمدخلات المسموحة ما يستطيع أحد تغييره، ويمكن للعرض أن يبقى على جهازه. ويضيف Lolly Work الهوية والتخزين المشترك والسياسة والموافقات والتقارير على بنية تحتية تتحكم فيها المؤسسة.

## ما يوفره Lolly وLolly Work

| الحاجة | Lolly + Lolly Work |
|---|---|
| تسجيل الدخول والتزويد | تسجيل دخول موحد بـ OIDC، ومزوّدو هوية متعددون، وتزويد مستخدمين وعضوية مجموعات بـ SCIM 2.0، وتعطيل حسابات يلغي الجلسات القائمة. ويمكن لمزوّد هوية بـ SAML فقط الاتصال عبر جسر OIDC مثل Keycloak. |
| القوالب المعتمدة | يحدد Lolly المدخلات القابلة للتحرير في القالب؛ ويطبق Lolly Work رؤية المجموعات وسياسات المدخلات التي تقفل القيم أو تقيّد الخيارات أو تخفي عناصر التحكم. |
| مكتبة أصول مشتركة | ملفات مرفوعة تملكها النسخة ومجموعات وبيانات وصفية مخصصة وفهارس بضبط وصول، إضافة إلى موصّلات تقرأ مكتبات DAM والتخزين القائمة. |
| المراجعة | خطوات موافقة مرتبة ومجموعات موافقين مؤهلين وقواعد نصاب وفصل مهام؛ ويمكن للمراجعة أن تحكم تقديمات الفهرس والتسليم إلى أهداف المؤسسة. |
| تاريخ الأصول وتوافرها | إصدارات وتراجع للأصول التي تملكها النسخة، واحتفاظ وتجميد، وتوافر مجدول وانتهاء صلاحية وإلغاء. تحتفظ المزوّدات المتصلة بتاريخ مصدرها الخاص. |
| التراخيص والنسب | يسجّل Lolly ترخيص كل مصدر يستخدمه ملف ويعدّ النسب الذي يدين به؛ ويشرح [حقوق الإبداع والنسب](/info/creative-rights.html) ما يسجله وأين يُكتب النسب. هو لا يخلّص الحقوق. |
| التقارير | أعداد استخدام الأصول وتنزيلها ونشاط الأدوات والتصدير ولوحات المعلومات وسجل تدقيق. ويتبع نسب الاستخدام سياسة القياس عن بعد للنشر؛ ويتطلب إعداد النسب الافتراضي موافقة. |
| التوزيع | روابط تنتهي وتُلغى ومجموعات مشتركة ووصول ضيوف وتسليم إلى وجهات المؤسسة المضبوطة. |

يصف [الفهرس والمحتوى](/info/work-catalog.html) و[الموافقات](/info/work-approvals.html) و[السياسة والحوكمة](/info/work-governance.html) هذه الميزات وإعدادها.

## الإبقاء على بوابتك الحالية

يمكن لـ DAM قائم أن يبقى مصدر الحقيقة. تتيح موصّلات فهرس Lolly Work أصوله المعتمدة في Lolly، حيث يصنع الناس ملفات جديدة تحت قواعد المؤسسة. هذا خيار تكامل؛ ومكتبة Lolly وموافقاته موجودة عندما تريد المؤسسة تشغيلها بنفسها. ويسرد [ما يعمل أين](/info/compare.html#what-runs-where) الحدود التي تتشاركها كل مقارنة.

راجع [كيف يقارن Lolly](/info/positioning.html) لمقارنة القدرات. أسماء الموردين تحدد المنتجات المقارَنة؛ و Lolly غير تابع لها.
