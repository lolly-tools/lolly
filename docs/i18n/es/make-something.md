# Crea tu primer archivo

Descarga un código QR para una dirección web y guarda una copia que puedas abrir y cambiar más adelante. No necesitas una cuenta ni configurar nada antes. No necesitas una cuenta ni configuración.

::: note Antes de empezar
Ten a mano la dirección web que debe abrir el código, empezando por `https://`.
:::

::: steps
- <!--i:eti-pen--> **[Crea el código](#make-the-code)** Pon tu dirección en Lolly QR Code y ajusta sus colores.
- <!--i:eti-download--> **[Descarga el archivo](#download-the-file)** Exporta un PNG para una pantalla o un SVG o PDF para impresión.
- <!--i:eti-folder-plus--> **[Conserva una copia editable](#keep-an-editable-copy)** Guarda tu trabajo para poder cambiar el código más adelante.
:::

<!--i:eti-pen-->
## Crea el código

1. Abre [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Los controles están junto a la vista previa, o encima en un teléfono. La vista previa muestra cómo será el archivo.
2. En **URL**, sustituye toda la dirección de ejemplo por la tuya. La vista previa cambia mientras escribes.
3. Para usar tus propios colores, ajusta **Module colour** y **Background**. Mantén un contraste alto entre ellos o a los teléfonos les costará leer el código.
4. **Quiet zone**, en **Modules**, empieza en 4. Déjalo en 4 o más. La cámara de un teléfono busca ese margen sin contenido.

<!--i:eti-download-->
## Descarga el archivo

1. Pulsa **Export** en la píldora **Export | Save as**, al pie de los controles en un ordenador o flotando en la parte inferior de la pantalla en un teléfono.
2. Abre el menú de formato junto al nombre del archivo (empieza en **SVG**) y elige **PNG** para una pantalla o un mensaje. Para impresión, consulta la nota de abajo.
3. Pulsa **Download**. El archivo va a las descargas de tu navegador. Si el archivo no está ahí, consulta [Encontrar un archivo que descargaste](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Escanea el código antes de compartir el archivo
Abre el archivo descargado en una pantalla y escanea el código con la cámara de un teléfono. Si lo creaste en tu teléfono, escanéalo desde un segundo teléfono o una pantalla de ordenador. El teléfono debería ofrecerte tu dirección web.
:::

::: note Si el código se va a imprimir o manipular
Elige **SVG** o **PDF** para que el código se mantenga nítido a cualquier tamaño. Prueba una impresión al tamaño en que se usará. Si el código puede rozarse o mojarse, pon **Error correction**, en **Modules**, en **High (30%)** para que siga siendo legible aunque esté dañado.
:::

<!--i:eti-folder-plus-->
## Conserva una copia editable

Para cambiar el código más adelante, guarda también tu trabajo:

1. Pulsa **Save as** y después **Save**. Con el panel Export abierto, **Save as** está en el panel. Con el panel cerrado, usa la marca de verificación junto a **Export**. El código va a **My library** y un mensaje **Saved** ofrece **Open Projects**.
2. La próxima vez, pulsa **Home** y abre la vista **Projects** (el icono de carpeta en un teléfono). Tu código está ahí, con el nombre **QR Code**. Ábrelo, cambia lo que quieras y vuelve a exportarlo.

El trabajo guardado se queda en este dispositivo, en el navegador o la aplicación que usaste, salvo que actives [Sync](/info/sync.html). [Encontrar y recuperar tu trabajo](/info/find-your-work.html) explica las carpetas, las versiones anteriores y cómo trasladar tu trabajo a otro dispositivo.

## Otros primeros proyectos

- [Lolly Audiogram](/#/tool/audiogram) convierte una nota de voz en un vídeo con una forma de onda en movimiento, tus palabras en la portada y tus colores. Suelta la grabación en **Audio**, añade un **Title** y exporta **MP4**.
- [Lolly Filter](/#/tool/filter) trata una foto para un póster: puntos de semitono impresos, dos colores planos o unos pocos bloques de tono. Elige la foto en **Image**, selecciona un **Effect** y exporta **PNG**, o **SVG** si el efecto lleva la etiqueta *vector*.
- El [generador de música](/#/music) compone una pista a partir de un género y una semilla. Pulsa el botón redondo de mezcla aleatoria hasta que te guste lo que suena, luego abre **Render** y descarga un archivo M4A o WAV. Puedes usar gratis la música que creas, incluso con fines comerciales, con el crédito **Música creada con Lolly (https://lolly.tools), CC BY 4.0**. La [guía del generador de música](/info/music-generator.html) muestra cada control y [Música de fondo gratis](/info/background-music.html) incluye una muestra de cada género.

## A continuación

- **Envía un enlace en lugar de un archivo.** Cada control que tocaste está en la dirección de la página. **Share** en el panel de exportación te da un enlace que vuelve a abrir el mismo diseño en la pantalla de otra persona. Una foto que subiste desde tu propio dispositivo no viaja con el enlace. Consulta [Compartir tu trabajo](/info/using.html#sharing-your-work).
- **Añade tus colores y fuentes una vez**, para que cada herramienta empiece con ellos: la [Guía de inicio rápido](/info/quickstart.html).
- [Usar Lolly](/info/using.html) es la guía completa de la aplicación. [Lolly para creadores](/info/creators.html) muestra qué más puedes crear con Lolly.
