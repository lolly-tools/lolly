# Lolly Batch 與 Lolly Multi-edit

<a id="batch-and-multi-edit"></a>

**Lolly Batch** 為同一份設計製作多個版本，例如十幾種語言的卡片，或橫幅的各種尺寸。**Lolly Multi-edit** 則對數份不同的已儲存設計套用同一項變更，例如新的日期或標題。

兩者都在你的裝置上執行，並經由與工具相同的渲染路徑匯出。

::: cols
## Batch

- 一個範本，多列資料。每列是一組輸入，產生一個檔案。
- 以輸入、從試算表貼上或匯入 CSV 的方式填入資料列。
- 列數不限；每頁顯示 50 列。
- 從 Projects 標頭中的 **Lolly Batch** 開啟（`#/batch`）。

<a id="multi-edit"></a>
## Lolly Multi-edit

- 兩到八份不同的已儲存設計，以即時卡片並排顯示。
- 在同一個側邊欄編輯共用輸入，再編輯各張卡片自己的輸入。
- 每份設計儲存回原本的位置。
- 從 Projects 選取列中的 **Edit together** 開啟。
:::

## 為同一份設計製作多個版本

開啟 **Projects** 檢視，按下標頭中的 **Batch**。格線一開始只有一列。在該列選擇範本，再複製該列或從試算表貼上資料。從資料夾內開啟時，Batch 會讓你回到該資料夾。

![Batch 的新格線：頂端列出檔名與資料列工具，第一列的範本清單已開啟，顯示可選擇的工具](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**填入資料列。** 在儲存格中輸入，或從 Excel、Google Sheets 或其他試算表貼上區塊。**Import CSV** 可新增資料列或取代整個批次。貼入含有匯出設定的儲存格時，Lolly 會詢問貼上的各欄要填入哪個輸入。**Export CSV** 會將格線寫出。開啟格線下方的 **Columns** 可顯示更多輸入，或各列的寬度、高度、單位與 DPI。數字、文字或選項欄的 **Fill** 彈出視窗也有 **Design token** 區段，可將同一個 token 連結至該欄各列（[一次連結多份文件](/info/token-workflows.html#link-many-documents-at-once)）。

**設定輸出。** 工具列可為所有資料列設定 zip 檔名、**Default format**、單位與 DPI。格式選單採用匯出面板的分組清單，列出目錄提供且瀏覽器支援的格式。已自行設定格式、尺寸或檔名的列會保留自己的設定。

**渲染。** **Render all** 會將所有資料列匯出為一個 `.zip`。選取資料列後，**Render selected**、**Export selected CSV** 與 **Print selected rows** 只會處理那些列。清除選取範圍即可再次處理整個批次。**Print sheet** 會將資料列排列在可列印的版面上。**Batch activity** 會回報每次匯入與渲染，並可收合。

**保存批次。** 無論選取哪些內容，**Sessions** 都會將格線中的所有資料列儲存為具名的批次工作階段。工作階段可從 Projects 重新開啟。同一選單中的 **Folders…** 會將 Projects 資料夾開啟為資料列，每個已儲存的工作階段一列；每個檔名都包含其資料夾路徑。

::: details 選取資料列與儲存格
使用核取方塊選取資料列，或按住 Shift 並點擊核取方塊以選取一段範圍。標頭的核取方塊會選取目前頁面，而 **Select all *N* rows** 也會選取其他頁面的資料列。切換頁面時會保留選取範圍。**Edit input**、**Duplicate** 與 **Remove** 作用於選取的資料列，**Undo remove** 則還原上次移除的列。儲存格取得焦點時，Shift+Space 會選取該列，Escape 則清除選取範圍。

拖曳跨過儲存格、按住 Shift 並點擊儲存格，或使用 Shift+方向鍵可選取矩形範圍。**Copy cells** 或 Ctrl+C / Command+C 會複製供試算表使用的值。儲存格取得焦點時，Ctrl+A / Command+A 會選取所有頁面的所有可見欄；列核取方塊取得焦點時，相同快捷鍵則會選取所有列。選取儲存格不會取消已勾選的資料列。按兩下儲存格或按 Enter 可編輯其文字。從剪貼簿貼上矩形範圍，或貼上一個值以填滿所有選取的儲存格；空白儲存格與多行文字會保留其位置。
:::

### 各列的配色方案與主題

每列都保留自己的主題選擇：淺色或深色，以及設計系統提供的配色方案。從 Projects、資料夾或已儲存批次開啟的資料列，會依其工作階段儲存時的選擇渲染與預覽。列印版面、複製的列與填入的列都會保留這些選擇。

CSV 會在尺寸欄之後的 `_themes` 欄攜帶這些選擇。該欄使用與 `_themes` 連結參數相同的 JSON，例如 `{"":"dark","colourway":"beach"}`。空白儲存格或 `{}` 代表設計系統的預設值。只有某列含有選擇時，才會寫出該欄。匯入時，主題選擇無效的儲存格會列為問題，該列則以預設值渲染。

::: note 在 CSV 中設定資料列的選擇
格線尚未提供變更資料列選擇的控制項，因此請在 CSV 或已儲存的工作階段中設定。
:::

### 為各列指定語言

會印出內建文字的工具（例如 Certificate）可接受 `language` 欄，填入 `de`、`ja` 或 `ar` 等簡短語言代碼。之後每列會以該語言印出文字與日期。阿拉伯文與烏爾都文的列會由右至左排版。空白儲存格會遵循應用程式的語言。Lolly 尚未提供翻譯的語言會以英文印出，日期也一樣，因此證書絕不會只翻譯一半。

### Batch 或 Render folder

若要重新渲染已儲存的工作階段，請在 Projects 中選取它們並使用 **Render selection**，或使用 **Render folder** 處理整個資料夾。[尋找並復原你的作品](/info/find-your-work.html#find-something-you-saved)涵蓋兩者。

## 一起編輯數份已儲存的設計

在 **Projects** 中勾選兩到八個已儲存的工作階段，並從選取列選擇 **Edit together**。它們會在 `#/multi?s=<slot>,<slot>…` 以即時卡片並排開啟。每張卡片都是其工作階段的實際渲染，顯示將匯出的內容。

同一個側邊欄控制所有卡片：

- <!--i:sliders--> **Shared** 排在最前面：包含兩個或更多工作階段以相同方式宣告的每個輸入（相同的 id、類型與限制，與批次格線各欄使用的規則一致）。變更共用控制項會套用到每個宣告該輸入的工作階段，在每張卡片即時顯示。同一工具的兩個工作階段共用所有輸入；不同工具的兩個工作階段只共用相同的輸入。Shared 卡片的 **Input actions** 選單可在每個宣告該輸入的工作階段中連結設計 token。
- <!--i:document--> Shared 卡片下方，**每個工作階段各有一張收合卡片**，包含該工作階段自己的所有輸入，與工具本身的側邊欄相同，並附有精簡的匯出區塊：**Format**、**W** / **H**、**Unit**、**DPI** 與 **Download**。這裡的 Download 會先儲存工作階段，再以與工具匯出相同的檔名、格式與 Content Credentials 渲染檔案。
- <!--i:search--> 頂端的 **Filter inputs…** 會同時篩選所有卡片的控制項。

點擊任一卡片（或在卡片上按 Enter）即可開啟該工作階段的側邊欄卡片。**Save all** 會將每個工作階段寫回各自的儲存位置。**Download all** 會先儲存，再將整組渲染為一個 zip，與 Projects 中的 **Render selection** 相同，並提供選用的密碼鎖。

每張卡片會依其工作階段的主題選擇繪製，包含放在設計內的工具。卡片周圍的應用程式保留自己的色彩。**Save all**、下載、**Batch grid** 與 **Send to Print Sheet** 都會保留各工作階段的選擇。

### 限制

- **最多八個。** 每張卡片都會載入自己的即時執行環境，八張卡片仍能保持流暢回應。連結要求超過此數量，或要求已不存在的工作階段時，會說明情況，不會只載入一部分。
- **連結僅限本機。** 它指定你自己的儲存位置，並在這部裝置上重新開啟該組工作階段。它不是分享連結。
- **數量更多時，** 請在同一個選取列中選擇 **Edit as sheet**。它會將選取項目開啟為批次格線中的資料列（`#/batch?s=…`），沒有數量限制，也不要求使用同一個工具。兩者都不包含資料夾：可透過 **Sessions → Folders…** 在格線中開啟資料夾，或在 Projects 中使用 **Render folder** 渲染資料夾。
- **搜尋不涵蓋 Lolly Multi-edit。** 這是搜尋欄唯一未涵蓋的檢視。
