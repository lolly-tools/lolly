# Batch 與 Multi-edit

一旦你經常製作同一類檔案，就會遇到兩種工作。有時你需要同一份設計的許多版本：十幾種語言的卡片，或橫幅的每一種尺寸。有時你有數份不同的已儲存設計，希望一次更動就能影響全部，例如新的日期或新的標題。

**Batch** 負責第一種工作，**Multi-edit** 負責第二種。兩者都在你的裝置上執行，並經由與工具本身相同的渲染路徑匯出。

::: cols
## Batch

- 一個範本，許多列。每一列是一組輸入，並產生一個檔案。
- 以輸入、從試算表貼上或匯入 CSV 來填入各列。
- 列數沒有上限；每頁顯示 50 列。
- 從 Projects 標頭中的 **Batch** 開啟（`#/batch`）。

## Multi-edit

- 兩到八份不同的已儲存設計，並排顯示為即時卡片。
- 一個側邊欄編輯它們共有的輸入，然後是每張卡片自己的輸入。
- 每份設計會存回它原本的位置。
- 從 Projects 選取列中的 **Edit together** 開啟。
:::

## 製作同一份設計的許多版本

開啟 **Projects** 並按下其標頭中的 **Batch**。格線一開始有一列：在其中選擇範本，然後複製該列，或從試算表貼上資料。從資料夾內開啟時，Batch 會讓你回到該資料夾。

![新格線上的 Batch：頂端是檔名與列工具，第一列的範本清單已展開，列出你可以選擇的工具](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**填入各列。** 在儲存格中輸入，或直接從 Excel、Google Sheets 或其他試算表貼上一個區塊。**Import CSV** 會新增列或取代批次。當你貼到包含匯出設定的儲存格時，Lolly 會詢問每個貼上的欄位填入哪個輸入。**Export CSV** 會把格線寫回檔案。開啟格線下方的 **Columns**，可顯示更多輸入，或每列的寬度、高度、單位與 DPI。

**設定輸出。** 工具列為每一列設定 zip 的檔名、**Default format**、單位與 DPI。格式選單是匯出面板的分組清單，顯示目錄提供且你的瀏覽器支援的格式。擁有自己格式、大小或檔名的列會保留自己的設定。

**渲染。** **Render all** 會將每一列匯出到同一個 `.zip`。先選取列，則 **Render selected**、**Export selected CSV** 與 **Print selected rows** 只對那些列動作；清除選取即可再次處理整個批次。**Print sheet** 會把各列排在可列印的頁面上。**Batch activity** 回報每一次匯入與渲染，並可摺疊起來，給表格更多空間。

**保留批次。** **Sessions** 會把整個格線儲存為具名的批次工作階段，之後可從 Projects 重新開啟。無論選取了什麼，Sessions 一律儲存每一列。同一選單中的 **Folders…** 會把整個 Projects 資料夾開啟為列，每個已儲存的工作階段一列，每個檔名都帶有其資料夾路徑。

::: details 選取列與儲存格
用核取方塊選取列，或按住 Shift 點擊核取方塊選取範圍。標頭核取方塊選取目前這一頁，**Select all *N* rows** 則連其他頁面的列也一併選取。在頁面之間移動時，選取會維持。**Edit input**、**Duplicate** 與 **Remove** 對選取的列動作，**Undo remove** 會還原最後移除的列。在取得焦點的儲存格中，Shift+Space 選取該列，Escape 清除選取。

拖曳跨過儲存格、按住 Shift 點擊儲存格，或使用 Shift+方向鍵來選取一個矩形。**Copy cells** 或 Ctrl+C / Command+C 會複製供試算表使用的值。在取得焦點的儲存格中按 Ctrl+A / Command+A 會選取每一頁上的每個可見欄；在列核取方塊上，相同的快捷鍵會選取每一列。選取儲存格不會取消已勾選的列。按兩下儲存格或按 Enter 即可編輯其文字。從剪貼簿貼上一個矩形，或貼上單一值以填滿每個選取的儲存格；空白儲存格與多行文字會保留其位置。
:::

### 每一列的配色方案與主題

每一列各自保留其主題選擇：淺色或深色，以及在設計系統有配色方案時的配色方案。從 Projects、資料夾或儲存的批次開啟的列，會以其工作階段儲存時的選擇渲染，其預覽也以此開啟。列印頁面、複製的列與填入的列都會保留它們。

CSV 會在尺寸欄之後的 `_themes` 欄中帶著這些選擇，內容與 `_themes` 連結參數的 JSON 相同，例如 `{"":"dark","colourway":"beach"}`。空白儲存格或 `{}` 表示設計系統的預設值。只有在某一列有選擇時才會寫出該欄，所以沒有任何選擇的批次匯出的 CSV 與以前相同。匯入時，不是有效主題選擇的儲存格會被列為問題，其列則以預設值渲染。格線目前還沒有可更改某一列選擇的控制項，所以請在 CSV 或儲存的工作階段中設定。

### Batch，或 Render folder

Batch 產生同一個範本的許多變體。若要重新渲染你已儲存的工作階段，請在 Projects 中選取它們並使用 **Render selection**，或對整個資料夾使用 **Render folder**；[尋找並復原你的作品](/info/find-your-work.html#find-something-you-saved)涵蓋這兩者。

## 一起編輯數份已儲存的設計

在 **Projects** 中勾選兩到八個已儲存的工作階段，並從選取列選擇 **Edit together**。它們會在 `#/multi?s=<slot>,<slot>…` 以即時卡片並排開啟。每張卡片都是其工作階段的真實渲染，所以你看到的就是將匯出的內容。

一個側邊欄驅動所有卡片：

- <!--i:sliders--> **Shared** 排在最前面：兩個或更多工作階段以相同方式宣告的每個輸入（相同的 id、相同的類型、相同的限制，與批次格線用於其欄位的規則相同）。編輯一次共用控制項，值就會到達每個宣告該輸入的工作階段，並即時反映在每張卡片上。同一個工具的兩個工作階段共用一切；兩個不同的工具只共用它們共有的輸入。
- <!--i:document--> 其下，**每個工作階段一張摺疊的卡片**，包含該工作階段自己的所有輸入，與工具自己的側邊欄一樣完整，並附有精簡的匯出區塊：**Format**、**W** / **H**、**Unit**、**DPI** 與 **Download**。該 Download 會先儲存工作階段，然後以與從工具匯出時相同的檔名、格式與 Content Credentials 渲染檔案。
- <!--i:search--> 頂端的 **Filter inputs…** 會同時縮小每張卡片上的控制項，讓你不必捲動，就能在八個工作階段中找到「標題」。

點擊任一張卡片（或在其上按 Enter）即可開啟該工作階段的側邊欄卡片。**Save all** 會把每個工作階段寫回它自己的位置。**Download all** 會先儲存，然後把整組渲染成一個 zip，與 Projects 中的 **Render selection** 相同，並在過程中提供選用的密碼鎖。

每張卡片都以其自身工作階段的主題選擇繪製，包括放在設計內的工具。不同外觀的卡片並排顯示，而周圍的應用程式維持自己的色彩，**Save all**、下載、**Batch grid** 與 **Send to Print Sheet** 則會保留每個工作階段的選擇。

### 限制

- **最多八個。** 每張卡片都會掛載自己的即時執行階段，而八個是能維持回應速度的數量。要求更多，或要求已不存在的工作階段的連結，會直說，而不是只載入一半。
- **連結是本機的。** 它指向你自己儲存的位置，所以會在這部裝置上重新開啟那一組。它不是分享連結。
- **更大的規模時，**請在同一個選取列中選擇 **Edit as sheet**。它會把整個選取範圍以列的形式在批次格線中開啟（`#/batch?s=…`），沒有大小限制，也沒有相同工具的規則。資料夾不在這兩者之內：請用 **Sessions → Folders…** 在格線中開啟資料夾，或在 Projects 中用 **Render folder** 渲染。
- **搜尋不涵蓋 Multi-edit。** 它是搜尋列唯一不認識的檢視。
