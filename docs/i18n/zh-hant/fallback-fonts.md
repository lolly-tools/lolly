# 備用字型

設計系統的字型往往只涵蓋世界上部分的文字系統。Lolly Demo 的標題用 Outfit、內文用 SUSE，這兩套字型都沒有西里爾、希臘、阿拉伯、希伯來、天城文、孟加拉、泰、中文、日文或韓文的字母。當文件含有設計系統字型畫不出來的字母時，Lolly 會改用開放的 Noto 字型來畫這些字母，所以匯出時它們會保留為向量外框，而不是把文字變成一張圖片。

設計系統的字型永遠優先，順序依設計系統列出的先後。Outfit 沒有越南文字母，所以越南文標題會從 SUSE 取得，也就是 Lolly Demo 清單中的下一套字型。備用字型只畫上述字型都畫不出來的字元，所以品牌字型保有它擁有的每個字母、數字與符號，即使它們位於另一種文字的詞語之中。品牌字型若有某個中文字，也一樣保留該字。

## 內建了什麼

共十五套字型，全部取自 Google Fonts 的固定提交版本，並全部採用 SIL Open Font License 1.1。每個檔案旁都標示下載大小。

| 文字系統 | 字型 | 版本 | 下載大小 |
|---|---|---|---|
| 阿拉伯文，包括烏爾都文與波斯文字母 | Noto Sans Arabic | 2.012 | 206 KB |
| 希伯來文 | Noto Sans Hebrew | 3.001 | 37 KB |
| 天城文（印地語、馬拉地語、尼泊爾語） | Noto Sans Devanagari | 2.007 | 147 KB |
| 孟加拉文 | Noto Sans Bengali | 3.011 | 136 KB |
| 泰文 | Noto Sans Thai | 2.002 | 61 KB |
| 西里爾文 | Noto Sans，西里爾字母 | 2.015 | 112 KB，斜體 129 KB |
| 希臘文 | Noto Sans，希臘字母 | 2.015 | 75 KB，斜體 81 KB |
| 拉丁文，包括越南文與其他帶重音符號的字母 | Noto Sans，拉丁字母 | 2.015 | 309 KB，斜體 342 KB |
| 簡體中文，GB 2312 字元 | Noto Sans SC | 2.004 | 1.9 MB |
| 繁體中文，Big5 字元 | Noto Sans TC | 2.004 | 3.6 MB |
| 日文，Shift_JIS 字元 | Noto Sans JP | 2.004 | 2.1 MB |
| 韓文，所有韓文音節與 KS X 1001 字元 | Noto Sans KR | 2.004 | 2.4 MB |

每套字型的字重軸都完整保留，所以設計要求的每一種字重仍然能畫出來，粗體的中文、日文或韓文標題也確實是粗體。Noto Sans 系列字型的字寬軸固定為標準，這讓每個檔案縮小一半；中文、日文與韓文字型沒有字寬軸。Noto Sans 依文字系統拆分，所以一個西里爾文詞語只會下載西里爾字母。字形外框就是上游的外框，沒有更動。

這些字型放在一個共用資料夾 `community/fallback-fonts`，由 `/catalog/packs/fallback-fonts/` 提供給每個設計系統，做法與共用表情符號組相同。`scripts/import-fallback-fonts.ts` 依 `scripts/data/fallback-fonts.json` 中固定的上游字型建出這些檔案，對照記錄的 SHA-256 檢查每個上游檔案，並把授權文字寫在字型旁邊。

## 中文、日文與韓文

一整套中文、日文或韓文字型有 9.6 MB 到 17.8 MB，所以這幾套字型都裁切成其讀者日常使用的國家字元集，再加上連續文字中的標點、假名、全形字元與符號：

- 簡體中文：GB 2312，6,763 個常用漢字及其符號，共 7,522 個字元。
- 繁體中文：Big5，13,053 個漢字及其符號，共 13,629 個字元。不含香港增補字符集。
- 日文：Windows 與網頁所讀取的 Shift_JIS，也就是 JIS X 0208 加上「髙」與「﨑」這類人名所需的 NEC 與 IBM 增補字元、所有假名與半形片假名，共 7,432 個字元。
- 韓文：全部 11,172 個韓文音節與 KS X 1001（含其 4,888 個漢字），共 17,082 個字元。

這四套字型不含拉丁、希臘與西里爾字母，因為設計系統的字型與上述字型已經能畫出它們。字元集讀自 Encoding Standard 在固定提交版本中的索引檔，所以重新建置會得到相同的檔案。

中文、日文與韓文共用大部分字元，但各自畫出許多字的方式不同。同一個字「直」，中文與日文的寫法就不一樣。所以一段文字會把它所有的共用字元取自其中一套字型，絕不會取自兩套，而 Lolly 依下列順序挑選該字型：

1. 該段文字的語言，取自它的元素或文件中最近的上層元素的 `lang`。工具的語言設定（例如證書的 Language）會設定這個值。Lolly 自己介面的語言與設計系統的語言不算在內，所以同一份文件對每個人匯出的結果都相同。
2. 該段文字的文字系統：有假名代表日文，有韓文字母代表韓文。當該段文字本身兩者皆無時，會讀取整份文件，所以日文文件中一個只有漢字的標題會以日文畫出。同時含有假名與韓文字母的文件在這裡無法決定結果。
3. 該段文字中，或是文件中，有只有繁體中文使用的字元（例如「體」或「說」），代表繁體中文；除非同一段文字也含有只有簡體中文使用的字元。
4. 否則，使用簡體中文。

所選字型沒有的字元，絕不會從其他三套字型取得。它會維持為圖片，如下所述。所選字型缺少的假名或韓文字母（例如標為日文的一行中的韓文詞語），仍可取自日文或韓文字型，但僅限該字型不會畫出該行任何共用字元時。

在頁面上，含有其中兩種語言的畫布會列出兩套字型，瀏覽器以第一套畫出共用字元。匯出則是每段文字各用它自己的字型畫出。

## 字型何時下載

在文件含有設計系統任何字型都畫不出來的字元之前，什麼都不會下載。英文文件，或設計系統所涵蓋的任何語言的文件，絕不會下載備用字型。英文行中的符號（例如 ★ 或 ※）也絕不會下載中文、日文或韓文字型。

文件第一次需要時，Lolly 會下載那一套字型，只針對那一種文字系統，並保存在你的裝置上。日文文件只下載日文字型，2.1 MB；繁體中文文件則下載 3.6 MB 的繁體字型。從此之後，該文字系統就能離線繪製，而且整理目錄時字型也會保留。字型與目錄自己的檔案放在一起，絕不會出現在你上傳的字型之中，所以不會顯示在你品牌的字型清單裡。

命令列、終端機應用程式與 MCP 伺服器會從磁碟讀取相同的檔案，所以不需要下載。

## 在頁面上與在匯出中

頁面使用與匯出相同的備用字型。沒有這一點，瀏覽器會用系統字型畫這些字母，而匯出用的是 Noto，含有這些字母的一行在兩者之間寬度就會改變。Lolly 只在該畫布上，把備用字型加到設計系統字型清單的最後，位於設計系統自己的字型之後、任何系統字型之前。設計系統所涵蓋的畫布，字型清單與先前完全相同。

在 PDF 中，無論你選擇哪一種文字設定，這些文字都會變成以備用字型畫出的外框，因為即時的 PDF 文字無法承載內嵌字型所缺少的文字系統。在 SVG、EMF、EPS、DXF 與 WMF 中，只要文字轉為外框，它們就會變成外框；文字保持即時時，則與先前一樣，由讀者自己的字型來畫。當備用字型畫了匯出內容的一部分時，匯出面板會顯示類似這樣的備註：

> 日文文字以 Noto Sans JP 繪製，因為此設計系統的字型沒有這些字母。

命令列會把相同的句子印成備註。

## 什麼會維持為圖片

四種國家字元集之外的字元沒有備用字型。罕見字元（例如 𠮷）、香港增補字符集為香港加入的字元，以及沒有備用字型的文字系統（例如坦米爾文、衣索比亞文或敘利亞文），處理方式全都相同。在 PDF 中，含有這類字元的那一行會以 300 dpi 的圖片放入，匯出面板會列出這些文字系統。在 SVG 中，該段文字維持為即時文字，由讀者自己的字型來畫。

## 授權與署名

每套備用字型都採用 SIL Open Font License 1.1，且每個目錄項目都記錄該授權及授權文字的雜湊值，所以[創作權利與署名](/info/creative-rights.html)中的權利規則會像讀其他字型的授權一樣讀取它。授權文字與字型放在一起。Noto Sans 檔案沒有宣告保留字型名稱。中文、日文與韓文字型是 Adobe 的，並保留名稱 Source；裁切後的檔案保留它們的 Noto 名稱，並未使用該名稱。

授權指出其條款不適用於以這些字型製作的文件。匯出只含有它所用字母的繪製外框，與設計系統自己的字型相同，而 Lolly 不會為備用字型加入字型程式、署名行或新的內容憑證項目。
