# 管理

Lolly 在每個人的裝置上執行。當團隊需要登入、共用專案、受管轄的素材、審閱與伺服器工作時，組織會加入 **Lolly Work**，也就是同一個專案的開源組織伺服器。這些頁面寫給負責設定與維護該伺服器的人。

先從[在你的組織使用 Lolly](/info/organisation.html)看成員能得到什麼，或從 [Lolly Work 架構](/info/work-overview.html)看伺服器負責什麼。

## 設定存取與政策

- [採用與治理](/info/adoption-governance.html)涵蓋推行，以及品牌規則的角色。
- [身分與工作階段](/info/work-identity.html)涵蓋登入與群組對應。[角色與授權](/info/work-permissions.html)說明角色、授權與擁有者防護。
- [政策與治理](/info/work-governance.html)涵蓋工具覆疊、鎖定的輸入與政策。[管理組織 AI 政策](/info/work-ai-policy.html)涵蓋核准與執行限制。
- [帳號資料控制](/info/work-account-lifecycle.html)與 [Work 儲存與資料生命週期](/info/work-data-lifecycle.html)涵蓋匯出、離職處理、保留及其限制。
- [設定檔、品牌與工具設定](/info/configuration.html)涵蓋 Lolly 的建置版本帶有哪些工具與設計系統。

## 連接素材並審閱工作

- [設計系統管理](/info/work-design-system-administration.html)涵蓋來源清冊、審閱過的變更與回復。
- [目錄與內容](/info/work-catalog.html)涵蓋共用素材與公開規則。[提供者指南](/info/work-provider-guides.html)提供各來源平台的設定與驗證要求。
- [核准](/info/work-approvals.html)涵蓋審閱鏈與職責分離。[渲染與分享](/info/work-sharing.html)涵蓋連結與伺服器輸出。
- [邀請代理加入文件](/info/work-document-agents.html)涵蓋有範圍的文件存取、到期與撤銷。邀請不會授予部署或基礎架構的存取權。
