# 製作你的第一個檔案

讀完這個頁面，你就會為一個網址下載好一個 QR code，並儲存一份以後可以開啟和修改的副本。你不需要帳號，事先也不用做任何設定。

::: note 開始之前
準備好 QR code 應該開啟的網址，以 `https://` 開頭。
:::

## 製作 QR code

1. 開啟 [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)。控制項位在預覽旁邊，在手機上則在預覽上方；預覽顯示的就是檔案最終的樣子。
2. 在**URL**中，把範例地址完整換成你自己的。預覽會隨輸入即時變化。
3. 要搭配你自己的顏色，請設定 **Module colour** 與**背景**。兩者之間要保持強烈對比，否則手機會難以辨識這個 QR code。
4. **Modules** 底下的 **Quiet zone** 預設從 4 開始。請保持在 4 以上：手機相機正是靠這圈素淨的邊距來辨識 QR code 的。

## 下載檔案

1. 在**匯出 | 另存為**膠囊按鈕上按**匯出**，它在電腦上位於控制項區底部，在手機上則浮在螢幕底部。
2. 開啟檔案名稱旁邊的格式選單（預設是 **SVG**），如果要用於螢幕或訊息，選擇 **PNG**。如果要用於印刷，請看下面的說明。
3. 按**下載**。檔案會進入你瀏覽器的下載記錄；如果找不到，請見[找到你下載的檔案](/info/find-your-work.html#find-a-file-you-downloaded)。

::: check 分享檔案之前先掃一下 QR code
在螢幕上開啟下載好的檔案，用手機相機掃描這個 QR code。如果你是在手機上製作的，就用另一支手機或電腦螢幕來掃描。手機應該會顯示你的網址。
:::

::: details 如果這個 QR code 要印刷或經手傳遞
選擇 **SVG** 或 **PDF**，讓 QR code 在任何尺寸下都保持清晰，並按實際使用的尺寸試印一次。如果 QR code 可能被磨損或淋雨，把 **Modules** 底下的**Error correction** 設為 **High (30%)**：即使 QR code 有損壞，也依然能被辨識。
:::

## 保留一份可編輯的副本

你下載的檔案已經是成品。如果以後還想修改這個 QR code，也要儲存你的作品：

1. 按**另存為**，然後按**儲存**。匯出面板開啟時，**另存為**在面板裡；面板關閉時，它是**匯出**旁邊的那個勾號。這個 QR code 會進入**我的資料庫**，並彈出一則**已儲存**的訊息，提供**開啟專案**。
2. 下次回來時，按**首頁**並開啟**專案**（在手機上是資料夾圖示）。你的 QR code 就在那裡，名稱是**QR Code**。開啟它，做任何修改，再次匯出。

已儲存的作品會留在這台裝置上，留在你使用的瀏覽器或應用程式裡，除非你開啟[同步](/info/sync.html)。[找回你的成果](/info/find-your-work.html)介紹了資料夾、較早版本，以及把作品移到另一台裝置的方法。

## 其他入門專案

- [Audiogram](/#/tool/audiogram) 把一段語音備忘變成一段影片：一條跳動的波形、封面上的文字、你的配色。把錄音拖進**音訊**，加一個**標題**，然後匯出 **MP4**。
- [Filter](/#/tool/filter) 為海報處理一張照片：印刷網點、兩種純色或幾階色調色塊。在**圖片**底下選好照片，挑一個**效果**，然後匯出 **PNG**；如果效果標著*向量*，就匯出 **SVG**。

## 接下來

- **傳送連結，而不是檔案。** 你動過的每一項設定都會寫進頁面地址，所以匯出面板裡的**分享**會給出一個連結，能在別人的螢幕上重新開啟同一個設計。你從自己裝置上傳的照片不會隨連結一起傳遞。見[分享你的作品](/info/using.html#sharing-your-work)。
- **一次把你的顏色與字型設定好**，讓每個工具都以它們為起點：見[快速上手](/info/quickstart.html)。
- [使用 Lolly](/info/using.html) 是這個應用程式的完整指南，[給創作者的 Lolly](/info/creators.html) 則介紹了它還能做的其他事情。
