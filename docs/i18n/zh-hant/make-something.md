# 製作你的第一個檔案

下載一個指向網址的 QR code，並儲存一份之後能開啟與更改的副本。不需要帳號，也不必先設定任何東西。不需要帳號或設定。

::: note 開始之前
準備好 QR code 應開啟的網址，以 `https://` 開頭。
:::

::: steps
- <!--i:eti-pen--> **[製作 QR code](#make-the-code)** 在 Lolly QR Code 中輸入網址，並設定色彩。
- <!--i:eti-download--> **[下載檔案](#download-the-file)** 匯出供螢幕使用的 PNG，或供印刷使用的 SVG 或 PDF。
- <!--i:eti-folder-plus--> **[保留可編輯的副本](#keep-an-editable-copy)** 儲存作品，以便之後更改 QR code。
:::

<!--i:eti-pen-->
## 製作 QR code

1. 開啟 [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)。控制項位於預覽旁，在手機上則位於預覽上方。預覽顯示檔案將會呈現的樣子。
2. 在 **URL** 中，將整個範例網址換成你的網址。預覽會隨著輸入而變化。
3. 若要使用自己的色彩，請設定 **Module colour** 與 **Background**。兩者要有強烈對比，否則手機會難以辨識 QR code。
4. **Modules** 下的 **Quiet zone** 初始值為 4。請保持在 4 或以上。手機攝影機會尋找這圈空白邊界。

<!--i:eti-download-->
## 下載檔案

1. 按下 **Export | Save as** 膠囊上的 **Export**。在電腦上，它位於控制項底部；在手機上，則浮在螢幕底部。
2. 開啟檔名旁的格式選單（初始為 **SVG**），選擇 **PNG** 供螢幕或訊息使用。若要印刷，請見下方說明。
3. 按下 **Download**。檔案會存到瀏覽器的下載位置。若檔案不在那裡，請見[尋找你下載的檔案](/info/find-your-work.html#find-a-file-you-downloaded)。

::: check 分享檔案之前先掃描 QR code
在螢幕上開啟下載的檔案，並用手機攝影機掃描 QR code。若是在手機上製作，請從另一支手機或電腦螢幕掃描。手機應會顯示你的網址。
:::

::: note 如果 QR code 會用於印刷或經常被觸碰
選擇 **SVG** 或 **PDF**，讓 QR code 在任何尺寸下都保持清晰。以實際使用的尺寸試印。若 QR code 可能磨損或弄濕，請將 **Modules** 下的 **Error correction** 設為 **High (30%)**，讓受損的 QR code 仍可辨識。
:::

<!--i:eti-folder-plus-->
## 保留可編輯的副本

若要之後更改 QR code，也請儲存你的作品：

1. 按下 **Save as**，再按 **Save**。匯出面板開啟時，**Save as** 就在面板中。面板關閉時，使用 **Export** 旁的勾號。QR code 會存入 **My library**，**Saved** 訊息中會提供 **Open Projects**。
2. 下次按下 **Home**，再開啟 **Projects** 檢視（手機上是資料夾圖示）。你的 QR code 就在那裡，名稱為 **QR Code**。開啟後，可更改任何內容並再次匯出。

除非你開啟[同步](/info/sync.html)，否則儲存的作品會留在這部裝置上，保存在你使用的瀏覽器或應用程式中。[尋找並復原你的作品](/info/find-your-work.html)涵蓋資料夾、較早的版本，以及將作品移到另一部裝置的方法。

## 其他入門專案

- [Lolly Audiogram](/#/tool/audiogram) 將語音記事轉成影片，帶有動態波形、封面上的文字，以及你的色彩。將錄音拖放到 **Audio**，加入 **Title**，再匯出 **MP4**。
- [Lolly Filter](/#/tool/filter) 將照片處理成適合海報的效果：印刷半色調網點、兩種平塗色彩，或幾塊色調。在 **Image** 下選擇照片，挑選 **Effect**，再匯出 **PNG**；標有 *vector* 的效果也可匯出 **SVG**。
- [音樂產生器](/#/music) 依曲風與種子值譜曲。按下圓形隨機按鈕，直到你喜歡播放的音樂，再開啟 **Render** 並下載 M4A 或 WAV 檔案。你製作的音樂可免費使用，包括商業用途，只需署名 **Music made with Lolly (https://lolly.tools), CC BY 4.0**。[音樂產生器指南](/info/music-generator.html)介紹每個控制項，[免費背景音樂](/info/background-music.html)則提供每種曲風的範例。

## 下一步

- **傳送連結來代替檔案。** 你調整過的每個控制項都包含在頁面網址中。匯出面板中的 **Share** 會提供連結，讓別人在自己的螢幕上重新開啟相同的設計。你從裝置上傳的照片不會隨連結傳遞。請見[分享你的作品](/info/using.html#sharing-your-work)。
- **加入一次色彩與字型**，讓每個工具一開始就使用它們：請見[快速入門](/info/quickstart.html)。
- [使用 Lolly](/info/using.html)是應用程式的完整指南。[Lolly 創作者指南](/info/creators.html)介紹 Lolly 還能製作哪些內容。
