# Lolly 與 Figma

_最後核查：2026 年 9 月 28 日。_

如果你的設計師使用 Figma，本頁說明 Lolly 如何與它並存：Figma 做了 Lolly 沒做的什麼，以及 Lolly 在哪裡接手重複性的工作。

## Figma 做得更好的地方

[Figma Design](https://www.figma.com/design/) 結合了介面設計、元件、互動原型與開發者交接。當團隊需要設計並規格化整個應用程式時，它成熟的產品設計實務與生態系就很重要，而它的即時編輯也在 Lolly 的工作協作尚未達到的規模上運作。

## 重疊之處

兩者都讓你在畫布上排列字型、圖形與圖片，並與其他人合作。Figma 也涵蓋以範本為基礎的品牌製作：[Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz) 從範本製作素材並由 CSV 或 XLSX 檔案填入。Lolly 的[匯入設計](/info/design-import.html)會將 Figma 檔案開啟為可編輯的版面，所以兩者可以共用作品。

## Lolly 如何完成重疊的工作

Lolly 把設計變成[附規則的可重複使用工具](/info/create-a-tool.html)。工具在瀏覽器或 CLI 中執行，並從連結、指令碼或批次格線取得輸入，所以一個範本既服務編輯一個檔案的人，也服務製作許多檔案的團隊。

![Design 的自由畫布，工具列的 Lolly 選單中有 Import a design](/info/shots/design.svg)

[私人協作](/info/collaborate.html)直接配對兩部裝置，不需要帳號，在共用網路上也不需要網際網路。單機版 Lolly 離線渲染。支援的匯出預設開啟 Content Credentials，你可以關閉它。

## 搭配組織

Lolly Work 加入經過驗證的工作協作，具有共用編輯、即時游標與已儲存的團隊工作階段，加上單一登入、共用目錄、專案權限、核准與伺服器渲染。[什麼在哪裡執行](/info/compare.html#what-runs-where)把這兩部分並排比較。

Figma 是其擁有者的商標。本頁描述這兩項產品重疊之處，與 Figma 無關聯。
