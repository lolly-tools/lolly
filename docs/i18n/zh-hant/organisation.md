# 在你的組織中使用 Lolly

你的組織可以執行自己的 Lolly：同一個應用程式，配上它選定的工具與設計系統，有時還需要登入。本頁說明如何進入它，以及進入之後會有什麼不同。

::: note 你需要向組織取得的東西
它的 Lolly 網址，或是你的組織製作的 `.lolly` 設定檔。lolly.tools 本身不會連線到任何組織。
:::

## 在瀏覽器中

開啟你的組織給你的地址。如果頁面要求你登入，按**登入**並依照隨後開啟的登入頁面操作。之後，它的運作方式就和任何 Lolly 一樣，只是換成你的組織的工具與設計系統。

瀏覽器沒有可以切換到另一個 Lolly 的設定，因此請開啟你組織自己的地址，而不是 lolly.tools。

## 在桌面版或行動版應用程式中

應用程式首次啟動時，會詢問**Lolly 應該從哪裡取得工具？**

1. 選擇**連線至 Lolly 執行個體**。
2. 輸入你的組織的網址，然後按**檢查並連線**。
3. 按**使用此執行個體**。接下來的畫面**匯入你的資料（選填）**會把已儲存的作品從 Lolly 備份中帶過來；如果沒有，按**略過**。
4. 如果應用程式要求，請登入。

來自已連線執行個體的工具，執行時享有和應用程式自帶工具相同的信任層級，因此只連線到你信任的執行個體。你的組織也可能改為傳給你一個 `.lolly` 設定檔，替你完成應用程式的連線。

之後要切換，開啟**設定**：**Lolly 執行個體**卡片上有**變更**和**離開**。

## 用代碼登入

如果在這台裝置上登入不方便，而你組織的 Lolly 又提供這個選項，按**在其他裝置上用代碼登入**。Lolly 會顯示一個簡短的代碼和一個地址：在你已經登入的手機或電腦上開啟這個地址，並在那裡輸入代碼。代碼大約十分鐘內有效。

## 那裡有什麼不同

- **有些控制項已經替你設好。** 由你的組織管理的控制項會顯示 **Managed by** 和組織名稱，或顯示**由你的組織管理**。固定的控制項無法變更，選單可能只提供其中部分選項，以 **Set by** 開頭的一行則會說明適用哪條規則以及原因。有些控制項則完全不會顯示。
- **只列出它的工具。** 你的組織未提供的工具完全不會顯示。
- **共享專案。** 如果你的組織與你共享專案，**專案**中會出現一個**團隊專案**方塊。
- **部分匯出可能需要核准。** 在你的組織要求核准的地方，**要求核准**會取代**下載**，工具能提供的格式也可能更少。
- **你自己儲存的內容**會留在這台裝置上，除非你開啟[同步](/info/sync.html)，這一點在 Lolly 中處處皆然。

## 離開

**離開**，在**設定**中**Lolly 執行個體**卡片上，會移除你組織的設計系統、工具與目錄。你自己的作品會保留。用它的工具做出的任何東西，在你重新連線之前都無法再開啟；你儲存到組織那邊的任何東西，也仍然留在組織那邊。在瀏覽器中造訪組織自己的地址時，沒有什麼可以離開的：請改為開啟另一個地址。

## 該問誰

什麼內容會送到你組織的伺服器、誰能看到其共享專案、哪些設定是固定的，這些都由你的組織決定。請詢問負責執行你組織的 Lolly 的人。[隱私](/info/privacy.html)說明了 Lolly 本身如何處理你的資料。
