# Ask Lolly

Ask Lolly 會逐字引用這些指南中相符的章節來回答問題，註明來源頁面，並附上通往該章節的 **Open in docs** 連結。不會生成任何內容：答案是在你的裝置上找到並引用的。

引用章節下方會列出應用程式中與問題相符的位置：工具、Utility、已儲存的專案、目錄素材、設定或應用程式頁面。每列只會導覽到對應位置。答案中的任何內容都不會變更設定、開啟檔案或替你執行動作，與 [Lolly Search](/info/search.html) 的規則相同。

## 提出問題

在檢視底部的問題欄位中輸入，然後按 Enter。少於兩個字元的內容會被忽略。答案堆疊在欄位上方，最新的排在最後。

![Ask Lolly 已開啟且尚無內容：問題欄位位於檢視底部，並註明答案來自文件](/t/url-shot?url=%2F%23%2Fask&width=1200&height=820&waitMs=2200&format=svg&walker=1&filename=ask-view)

::: note 每個問題都是獨立的
先前的問題不會傳遞上下文，因此在詢問匯出之後接著問「那 PDF 呢？」，只會被視為關於 PDF 的問題。每次都要問完整的問題。
:::

問題的第一個詞決定答案先顯示什麼：

| 開頭用詞 | 最先顯示 |
|---|---|
| *where*、*find*、*open*、*show*、*go to*、*goto*、*take*、*jump*、*navigate*、*switch* | 應用程式中相符的位置 |
| *make*、*create*、*generate*、*build*、*design*、*convert*、*resize*、*compress*、*remove*、*strip*、*export*、*render*、*add* | 相符的工具 |
| 其他任何用詞，包括 *how do I* 與 *what is* | 文件章節，這是預設值 |

兩部分都一定會取得，因此即使誤解問題，也只會改變答案的順序。

比對會略過常見的提問用詞（*how*、*do*、*I*、*the*、*my*）。章節先依涵蓋多少其他用詞排序，再依相符的位置排序：標題的權重高於內文。比對採用子字串，忽略大小寫與重音符號，因此不會修正錯字。沒有相符內容時，Ask 會說明並指向文件索引。

**Better matching** 是選用功能。取得第一個答案後，Ask 可提供小型比對模型，並顯示下載大小。模型能將問題與用不同詞語描述同一件事的指南配對。只有在你同意時才會下載，在這部裝置上執行，只改變哪些章節排在最前面。答案仍是文件原文。你也可以在 **Settings → Preferences → Available offline** 下下載 **Ask matching model**（[離線可用](/info/dashboard.html#available-offline)）。

## 回傳的內容

答案卡片有固定的順序：

1. **章節本身**，從文件原始內容渲染：段落、清單、表格、程式碼與引文，其中的應用程式內連結與 `/info` 連結都可使用。較長的章節會以 **Show more** 結尾，可就地展開其餘內容。圖片會略過，而通往其他網站的連結會顯示為純文字。
2. **出處** - *頁面 › 標題* - 以及直接通往該章節的 **Open in docs** 連結。
3. **More in the docs** - 最多四個其他相符章節，以連結顯示。
4. **應用程式內的項目列**，放在與 Search 相同的群組標題下。

全文來自每個文件頁面在 `/info/<slug>.md` 發布的 Markdown 對應版本。這些版本只有英文。在其他語言中，以及少數不是由 Markdown 建立的頁面，答案會改為顯示搜尋索引中的簡短摘要。出處與 **Open in docs** 連結仍會指向你所用語言的頁面。

## 在哪裡開啟

路由是 `#/ask`。它沒有分頁，在 Utilities 格線中也沒有圖塊。你可從搜尋欄或透過位址進入這個檢視。

- <!--i:search--> **從搜尋開啟。** 每個結果面板都以 **Ask Lolly: *你的查詢*** 列結尾，位於其他群組的結果下方。該列會開啟 `#/ask?q=…`，檢視載入時會提問一次。帶入的文字為小寫且沒有標點，需要時可在問題欄位中調整。
- <!--i:link--> **從連結開啟。** `#/ask?q=how%20do%20I%20export%20a%20transparent%20png` 會開啟檢視並已提出該問題。雜湊片段只用於帶入第一個問題。之後輸入的問題會在原處回答，絕不改變位址。

這個檢視會隱藏搜尋欄，因為 Enter 鍵由問題欄位使用。返回膠囊按鈕會帶你回到原本的位置。

答案會保留在本次工作階段中：離開再回來仍然存在，重新載入則會清除。不會將任何內容寫入儲存空間，因此沒有需要管理的歷史記錄。

## 離線

答案來自文件網站發布的兩種靜態檔案：各語言的搜尋索引，以及頁面的 Markdown 對應版本。兩者都依名稱取得，因此快取後，Ask 就能在沒有連線時運作。在應用程式中閱讀指南會將它們快取。[離線可用](/info/dashboard.html#available-offline)下的 **Guides & docs** 可一次下載整個網站，包含螢幕截圖。

沒有這些檔案時，答案的文件部分不會出現，也不會顯示錯誤。應用程式內的項目列仍會出現，因為它們比對的是裝置上已有的資料。

<!--i:eti-lock-->
## 隱私

你的問題絕不會離開裝置。比對在本機執行，使用依名稱取得的檔案，因此你輸入的內容不會出現在任何請求中。沒有伺服器會看到你的問題，沒有帳號會保存它，重新載入後也不會留下記錄。[隱私權政策](/info/privacy.html)列出應用程式取得或傳送的所有內容。
