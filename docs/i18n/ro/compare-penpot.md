# Lolly și Penpot

_Ultima verificare: 28 septembrie 2026._

Dacă echipa ta face design în Penpot, Lolly funcționează alături de Penpot. Ambele sunt open-source și citesc aceleași tokenuri de design. Această pagină spune cărei sarcini îi este destinat fiecare.

<!--i:eti-award-->
## Ce face Penpot mai bine

[Penpot](https://penpot.app/) oferă design de interfețe, componente, layouturi flexibile, prototipuri interactive și inspecție pentru dezvoltatori, cu editare în timp real și cursoare live. Oferă implementări găzduite și pe infrastructura proprie, cu [opțiuni de instalare Docker și Kubernetes](https://help.penpot.app/technical-guide/getting-started/). Pentru proiectarea unei aplicații, Penpot este instrumentul potrivit.

<!--i:eti-blend-->
## Unde se suprapun

[Tokenurile de design Penpot](https://help.penpot.app/user-guide/design-systems/design-tokens/) folosesc formatul DTCG, pe care Lolly îl citește și el, astfel încât culorile, tipografia și alte valori ale tokenurilor se transferă între cele două. Funcția Lolly [Importă un design](/info/design-import.html) deschide un export `.penpot` ca layout editabil, iar **Send to Penpot** din Lolly trimite un design înapoi ca arhivă `.penpot`. Lolly întreține și [pluginul Lolly Export pentru Penpot](https://github.com/lolly-tools/lolly-plugins-penpot-export), care folosește motorul Lolly pentru a adăuga opțional Content Credentials pe dispozitiv.

<!--i:eti-lolly-->
## Cum face Lolly munca pe care o au în comun

Canvasul Lolly Design creează resurse editabile și poate transforma un layout într-un [instrument cu reguli](/info/create-a-tool.html). Același instrument randează în browser, în aplicația desktop sau în CLI și creează variante din date. Lolly folosit independent randează și semnează pe dispozitiv, fără cont sau server. O [colaborare privată](/info/collaborate.html) conectează direct două dispozitive.

<!--i:eti-building-->
## Într-o organizație

Lolly Work adaugă autentificare unică, provizionare SCIM, cataloage și proiecte partajate, roluri, aprobări, înregistrări de audit, colaborări de lucru și randare pe server. Ambele depozite sunt MPL-2.0 și o organizație le poate rula pe ambele. [Ce rulează unde](/info/compare.html#what-runs-where) pune cele două părți una lângă alta.

Le poți folosi pe ambele: Penpot pentru design de interfețe și prototipare, Lolly pentru fișiere repetabile.

Penpot este o marcă comercială a deținătorului său. Această pagină descrie unde se suprapun cele două produse și nu este afiliată cu Penpot.
