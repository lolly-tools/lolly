# Lolly comparat, instrument cu instrument

Lolly acoperă munca creativă, de la o singură conversie pe dispozitiv până la producția de active a unei organizații cu guvernanță. Aceste pagini compară fluxurile de lucru pe care le susține fiecare produs, modul de implementare și limitele care contează la alegerea unei soluții.

_Ultima verificare: 28 septembrie 2026._

## Un singur proiect, două părți implementate separat

**Lolly** este motorul, aplicațiile și instrumentele pentru a crea, edita, converti și exporta. Rulează pe dispozitivul tău, funcționează offline după ce activele necesare sunt disponibile și nu cere cont pentru utilizarea de sine stătătoare.

**[lolly.work](https://lolly.work)** este serviciul de organizație al proiectului, întreținut în [depozitul lolly-work](https://github.com/lolly-tools/lolly-work). Oferă SSO, provizionare SCIM, roluri și politici, cataloage și proiecte partajate, aprobări, colaborare de lucru, rapoarte de utilizare, jurnale de audit și randare pe server. Ambele părți sunt open source sub MPL-2.0. O organizație găzduiește lolly.work alături de Lolly și decide ce servicii activează.

Comparațiile acoperă **Lolly + lolly.work**. Funcțiile care necesită serviciul de organizație sunt identificate explicit. Utilizarea de sine stătătoare păstrează fișierele pe dispozitiv; dacă alegi proiecte partajate, colaborare de lucru, randare pe server sau livrare, datele relevante sunt trimise către serviciile configurate. Site-ul public lolly.work este un sandbox; consultă [ghidul de implementare](https://github.com/lolly-tools/lolly-work/blob/main/docs/install.md) și [starea curentă](https://github.com/lolly-tools/lolly-work/blob/main/docs/status.md) pentru o implementare în organizație.
