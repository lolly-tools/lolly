# 備用字型

當設計系統的字型無法繪製某個字元時，Lolly 會用開放的 Noto 字型繪製，讓匯出中的字元保留為向量外框，而非圖片。Lolly Demo 的字型，標題用的 Outfit 與內文用的 SUSE，都沒有西里爾、希臘、阿拉伯、希伯來、天城、孟加拉、泰文、中文、日文或韓文字元。

設計系統的字型一律優先使用，依其列出的順序。Outfit 沒有越南文字母，因此越南文標題會從 Lolly Demo 清單中的下一個字型 SUSE 取得字母。備用字型只繪製那些字型都無法繪製的字元。品牌字型會保留使用它所擁有的每個字母、數字與符號，包括中文字，即使它位於其他文字系統的字詞中也是如此。

十五個字型，全都來自 Google Fonts 的固定提交版本。每個檔案都會顯示下載大小。

每個字型都保留字重軸上的所有字重，因此中文、日文或韓文的粗體標題會以粗體呈現。Noto Sans 字型的寬度軸固定為標準，讓每個檔案縮小一半。中文、日文與韓文字型沒有寬度軸。Noto Sans 依文字系統分割，因此西里爾文字詞只會下載西里爾字母。外框與上游版本相同，沒有更改。

::: details 字型存放位置與建置方式
字型存放在共用資料夾 `community/fallback-fonts` 中，與表情符號集一樣，從 `/catalog/packs/fallback-fonts/` 提供給每個設計系統。`scripts/import-fallback-fonts.ts` 會根據 `scripts/data/fallback-fonts.json` 中固定版本的上游字型建置檔案，以記錄的 SHA-256 檢查每個上游檔案，並將授權文字寫在字型旁。
:::

## 中文、日文與韓文

未裁減的中文、日文或韓文字型大小為 9.6 MB 至 17.8 MB。每個字型都裁減為其國家字元集，再加上正文使用的標點、假名、全形字元與符號：

- 簡體中文：GB 2312，包含 6,763 個常用漢字及其符號，共 7,522 個字元。
- 繁體中文：Big5，包含 13,053 個漢字及其符號，共 13,629 個字元。不含香港增補字符集。
- 日文：Windows 與網頁所讀取的 Shift_JIS，也就是 JIS X 0208 加上姓名中髙與﨑等字所需的 NEC 與 IBM 擴充字元、所有假名與半形片假名，共 7,432 個字元。
- 韓文：全部 11,172 個韓文音節與 KS X 1001，其中包含 4,888 個韓文漢字，共 17,082 個字元。

這四個字型不包含拉丁、希臘與西里爾字母，這些由設計系統的字型與上述字型繪製。字元集來自 Encoding Standard 在固定提交版本中的索引檔案，因此重新建置會得到相同的檔案。

中文、日文與韓文共用大多數漢字，但許多字的寫法不同。例如「直」在中文與日文中就有不同寫法。同一段文字中的所有共用字元都會取自其中一個字型，絕不混用兩個。Lolly 依以下順序選擇字型：

1. 該段文字的語言，取自其元素或文件中最近的周邊元素的 `lang`。工具的語言設定，例如證書的 Language，會設定此值。Lolly 本身介面的語言與設計系統的語言不列入考量，因此文件對每個人都會匯出相同的結果。
2. 該段文字的文字系統：假名代表日文，韓文字母代表韓文。當該段文字兩者都沒有時，Lolly 會讀取整份文件，因此日文文件中只有漢字的標題會以日文字型繪製。同時包含假名與韓文字母的文件，在這一步無法判定。
3. 該段文字，或其次整份文件中，若有只有繁體中文使用的字，例如「體」或「說」，就代表繁體中文，除非同一份文字中也包含只有簡體中文使用的字。
4. 否則使用簡體中文。

所選字型缺少的字元，絕不會從其餘三個字型中取用。它會維持為圖片。所選字型缺少的假名或韓文字母，例如標記為日文的一行中的韓文字詞，仍可來自日文或韓文字型，但前提是該字型不會繪製該行中的任何共用字元。

在頁面上，包含這些語言中兩種語言的畫布會列出兩個字型，瀏覽器會用第一個字型繪製共用字元。匯出則會為每段文字使用各自的字型。

## 何時下載字型

只有當文件包含其設計系統的所有字型都無法繪製的字元時，才會下載。英文行中的符號，例如 ★ 或 ※，絕不會觸發下載中文、日文或韓文字型。

文件第一次需要備用字型時，Lolly 會下載那一個字型並保存在你的裝置上。日文文件只會下載 2.2 MB 的日文字型，繁體中文文件則下載 3.8 MB 的繁體中文字型。之後就能離線繪製該文字系統，整理目錄時字型也會保留。字型與目錄檔案存放在一起，絕不放在你上傳的字型中，也不會出現在品牌字型清單中。

命令列、終端機應用程式與 MCP 伺服器會從磁碟讀取相同的檔案，因此不需要下載。

## 在頁面與匯出中

頁面與匯出使用相同的備用字型，因此包含這類字元的文字行在兩者中的寬度相同。Lolly 只在該畫布中，將備用字型加在設計系統自己的字型之後、所有系統字型之前。在樣式或元素上自行設定字型清單的工具，也會在相同位置加入備用字型。設計系統能完整涵蓋的畫布，其字型清單維持不變。

如果字型清單以系統字型開頭，例如 `system-ui` 或 Helvetica，頁面會保持清單不變，因為匯出會以設計系統的字型繪製該文字，頁面則不會。

在 PDF 中，無論文字設定為何，這些字詞都會以備用字型轉為外框，因為即時 PDF 文字無法容納嵌入字型缺少的文字系統。在 SVG、EMF、EPS、DXF 與 WMF 中，只要將文字轉外框，這些字詞就會成為外框。保留即時文字時，則由閱讀器自己的字型繪製。當備用字型繪製了匯出的一部分時，匯出面板會顯示如下提示：

> 日文文字以 Noto Sans JP 繪製，因為此設計系統的字型沒有這些字元。

命令列會輸出相同的句子作為提示。

## 哪些內容仍是圖片

四個國家字元集以外的字元，例如𠮷或香港增補字元，沒有備用字型。𠮷等罕用字、香港增補字符集加入的字元，以及沒有備用字型的文字系統，例如泰米爾文、衣索比亞文或敘利亞文，都以相同方式處理。泰米爾文、衣索比亞文或敘利亞文等文字系統也沒有備用字型。在 PDF 中，包含這類文字的整行會以 300 dpi 圖片放入，匯出面板會列出這些文字系統。在 SVG 中，該段文字仍是即時文字，由閱讀器自己的字型繪製。

::: details 在 EPS、WMF 與 EMF 匯出中
開啟 **Outline fonts** 的 EPS、WMF 或 EMF 沒有即時文字可供備援，因此該段文字也會以 300 dpi 圖片放入。圖片只在字元所在位置繪上文字色彩，讓背景透出。匯出面板會列出這些文字系統。圖片只能正向繪製，因此旋轉或傾斜的文字段會使匯出停止，並以訊息引述該段文字。在 WMF 或 EMF 中，圖片由一對點陣圖操作組成：遮罩與上色。Microsoft Office 與 LibreOffice 會依預期繪製。忽略這些操作的應用程式，例如 Inkscape，會將文字顯示在白色方框上。

關閉 **Outline fonts** 的 EMF 會將這類文字段保留為即時文字，由閱讀器自己的字型繪製。例外是即時 EMF 文字無法容納的文字段，例如設定了字距的文字。Lolly 會將該段文字轉外框，因此沒有任何字型能繪製的文字段，在這裡也會以圖片放入。
:::

::: warning DXF 匯出遇到沒有字型能繪製的文字時會停止
DXF 交給切割機與 CAD 軟體使用，而這些需要外框，因此沒有字型能繪製的文字段會使 DXF 匯出停止。訊息會引述該段文字並指出其文字系統。請加入包含這些字元的字型，或匯出為 SVG 或 PDF。
:::

## 匯出前的檢查

Lolly Design 的 **Before you export** 卡片與 `lolly check` 的 `render` 檢查，會回報沒有任何字型能繪製的文字。它們與匯出一樣，依相同的各字型字元清單將備用字型納入考量，因此備用字型能繪製的文字不會被回報。沒有備用字型的文字系統，例如泰米爾文，以及國家字元集以外的中文、日文或韓文字元，仍會被回報，因為匯出會將它們繪製為圖片或即時文字，而 DXF 匯出遇到它們時會停止。檢查會從目錄讀取這些清單，不會下載字型。

## 授權與署名

每個備用字型都採用 SIL Open Font License 1.1。每個目錄項目都會記錄該授權與授權文字的雜湊值，因此[創作權利與署名](/info/creative-rights.html)中的權利規則會像讀取其他字型一樣讀取其授權。授權文字存放在字型旁。Noto Sans 檔案未宣告保留字型名稱。中文、日文與韓文字型屬於 Adobe，並保留 Source 這個名稱。裁減後的檔案保留 Noto 名稱，未使用該保留名稱。

授權規定，其條款不適用於使用這些字型製作的文件。與設計系統自己的字型一樣，匯出只包含所用字元的外框。Lolly 不會為備用字型加入字型程式、署名行或新的內容憑證項目。
