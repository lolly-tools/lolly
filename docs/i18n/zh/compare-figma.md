# Lolly 与 Figma

_最后核查：2026 年 9 月 28 日。_

如果你的设计师使用 Figma，本页会说明 Lolly 如何与之并存：Figma 做了而 Lolly 没有做的是什么，以及 Lolly 在哪里接手重复性工作。

## Figma 做得更好的地方

[Figma Design](https://www.figma.com/design/) 汇集了界面设计、组件、交互原型和开发者交付。当团队需要设计并规范整个应用时，它成熟的产品设计实践和生态系统很重要，它的实时编辑规模也是 Lolly 的工作协作尚未达到的。

## 重叠之处

两者都让你在画布上排布文字、形状和图片，并与他人协作。Figma 也涵盖基于模板的品牌制作：[Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz) 根据模板制作素材，并从 CSV 或 XLSX 文件填充。Lolly 的[导入设计](/info/design-import.html)把 Figma 文件作为可编辑的版面打开，所以两者可以共享工作。

## Lolly 如何完成重叠的工作

Lolly 把设计变成[带规则的可复用工具](/info/create-a-tool.html)。该工具在浏览器或 CLI 中运行，其输入项来自链接、脚本或批量网格，所以一个模板既服务于编辑一个文件的人，也服务于制作大量文件的团队。

![Design 的开放画布，工具栏的 Lolly 菜单中有 Import a design](/info/shots/design.svg)

[私密协作](/info/collaborate.html)把两台设备直接配对，在共享网络上无需账号，也无需互联网。独立使用的 Lolly 可离线渲染。Content Credentials 对受支持的导出默认开启，你可以关闭。

## 与组织一起

Lolly Work 增加带有共享编辑、实时光标和保存的团队会话的经过认证的工作协作，以及单点登录、共享目录、项目权限、审批和服务器渲染。[什么在哪里运行](/info/compare.html#what-runs-where)把这两部分并排对比。

Figma 是其所有者的商标。本页描述的是这两款产品重叠的地方，与 Figma 没有关联。
