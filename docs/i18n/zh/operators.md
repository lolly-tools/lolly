# 管理

Lolly 在每個人的裝置上執行。這些頁面寫給運行 **Lolly Work** 的人；它是此專案的開源組織伺服器，提供登入、共用專案、受管理素材、審閱與伺服器工作。

從[在你的組織使用 Lolly](/info/organisation.html)開始，了解成員可以使用什麼，或閱讀 [Lolly Work 架構](/info/work-overview.html)了解伺服器的功能。
