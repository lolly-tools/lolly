# 批量生成与多重编辑

当你经常制作同类文件时，会出现两种任务。有时你需要同一个设计的许多版本：十几种语言的卡片，或一张横幅的每种尺寸。有时你有几个不同的已保存设计，想让一处更改作用于所有设计，例如新的日期或新的标题。

**Batch** 负责第一种任务，**Multi-edit** 负责第二种。两者都在你的设备上运行，并通过与工具本身相同的渲染路径导出。

::: cols
## Batch

- 一个模板，多行数据。每一行是一组输入项，生成一个文件。
- 通过输入、从电子表格粘贴或导入 CSV 来填充各行。
- 行数没有上限；每页显示 50 行。
- 从 Projects 页头中的 **Batch** 打开（`#/batch`）。

## Multi-edit

- 两到八个不同的已保存设计，以实时卡片的形式并排显示。
- 一个侧栏先编辑它们共有的输入项，然后是每张卡片自己的输入项。
- 每个设计都保存回它的来源位置。
- 从 Projects 选择栏中的 **Edit together** 打开。
:::

## 制作同一设计的多个版本

打开 **Projects**，按其页头中的 **Batch**。网格从一行开始：在其中选择一个模板，然后复制该行，或从你的电子表格中粘贴数据。从文件夹内部打开时，Batch 会让你回到该文件夹。

![一个新建的 Batch 网格：顶部是文件名和行工具，第一行的模板列表展开，显示可选择的工具](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**填充各行。** 在单元格中输入，或直接从 Excel、Google Sheets 或其他电子表格粘贴一块内容。**Import CSV** 会添加行或替换整个批次。当你粘贴到包含导出设置的单元格时，Lolly 会询问每个粘贴的列填入哪个输入项。**Export CSV** 把网格写回文件。打开网格下方的 **Columns** 可以显示更多输入项，或每行的宽度、高度、单位和 DPI。

**设置输出。** 工具栏设置 zip 的文件名，以及每一行的 **Default format**、单位和 DPI。格式菜单是导出面板的分组列表，显示目录提供且你的浏览器支持的格式。有自己格式、尺寸或文件名的行会保留自己的设置。

**渲染。** **Render all** 会把每一行导出到一个 `.zip` 中。先选中若干行，**Render selected**、**Export selected CSV** 和 **Print selected rows** 就只作用于这些行；清除选择后又会对整个批次生效。**Print sheet** 把各行排版到可打印的页面上。**Batch activity** 报告每次导入和渲染，可以折叠起来，给表格留出更多空间。

**保留批次。** **Sessions** 会把整个网格保存为一个命名的批次会话，之后可从 Projects 重新打开。无论选中什么，Sessions 总是保存每一行。同一菜单中的 **Folders…** 会把整个 Projects 文件夹作为多行打开，每个已保存会话一行，每个文件名都带有它的文件夹路径。

::: details 选择行和单元格
用复选框选择行，或按住 Shift 点击复选框选择一个范围。表头复选框选择当前页，**Select all *N* rows** 也会包含其他页的行。在页面之间切换时，选择保持不变。**Edit input**、**Duplicate** 和 **Remove** 作用于选中的行，**Undo remove** 恢复最近一次移除的行。在获得焦点的单元格中，Shift+Space 选择该行，Escape 清除选择。

在单元格之间拖动、按住 Shift 点击单元格，或使用 Shift+方向键来选择一个矩形区域。**Copy cells** 或 Ctrl+C / Command+C 会复制可粘贴到电子表格的值。在获得焦点的单元格中按 Ctrl+A / Command+A 会选择每一页上所有可见的列；在行复选框上，同样的快捷键则选择所有行。选择单元格不会取消已勾选的行。双击单元格或按 Enter 可编辑其文字。可以从剪贴板粘贴一个矩形区域，也可以粘贴一个值来填充每个选中的单元格；空白单元格和多行文字会保持原位。
:::

### 每行的配色方案和主题

每一行都保留自己的主题选择：浅色或深色，以及设计系统提供时的配色方案。从 Projects、文件夹或已保存的批次打开的行，会以其会话保存时的选择渲染，其预览也以此打开。打印页、复制的行和已填充的行都会保留这些选择。

CSV 在尺寸列之后的 `_themes` 列中携带这些选择，其内容与 `_themes` 链接参数的 JSON 相同，例如 `{"":"dark","colourway":"beach"}`。空单元格或 `{}` 表示设计系统的默认值。只有在某一行有选择时才会写入该列，所以没有任何选择的批次导出的 CSV 与以前相同。导入时，不是有效主题选择的单元格会被列为问题，其所在行以默认值渲染。网格目前还没有用于更改某一行选择的控制项，所以请在 CSV 或已保存的会话中设置。

### Batch，或 Render folder

Batch 为一个模板生成多个变体。若要重新渲染你已保存的会话，请在 Projects 中选中它们并使用 **Render selection**，整个文件夹则用 **Render folder**；[查找和恢复你的作品](/info/find-your-work.html#find-something-you-saved)介绍了这两者。

## 同时编辑多个已保存的设计

在 **Projects** 中勾选两到八个已保存的会话，从选择栏中选择 **Edit together**。它们会作为实时卡片并排打开，地址为 `#/multi?s=<slot>,<slot>…`。每张卡片都是其会话的真实渲染，所以所见即所导出。

一个侧栏驱动它们所有：

- <!--i:sliders--> **Shared** 排在最前：两个或更多会话以相同方式声明的每个输入项（相同的 ID、相同的类型、相同的约束，即批量网格用于其列的规则）。共享控制项只需编辑一次，该值就会传到每个声明了该输入项的会话，每张卡片上实时可见。同一个工具的两个会话共享一切；两个不同工具只共享它们共有的输入项。
- <!--i:document--> 在其下方，**每个会话一张折叠的卡片**容纳该会话自己的所有输入项，与该工具自己的侧栏一样完整，并带有一个紧凑的导出区：**Format**、**W** / **H**、**Unit**、**DPI** 和 **Download**。该 Download 会先保存会话，然后用与从工具导出时相同的文件名、格式和 Content Credentials 渲染文件。
- <!--i:search--> 顶部的 **Filter inputs…** 一次性缩小每张卡片上的控制项范围，所以你无需滚动就能在八个会话中找到“标题”。

点击任意卡片（或在其上按 Enter）可打开该会话的侧栏卡片。**Save all** 把每个会话写回各自的位置。**Download all** 先保存，然后把整组渲染到一个 zip 中，与 Projects 中的 **Render selection** 方式相同，过程中可选择设置密码锁。

每张卡片都以其自身会话的主题选择绘制，包括放在设计内部的工具。不同外观的卡片并排放置，而它们周围的应用保持自己的颜色，**Save all**、下载、**Batch grid** 和 **Send to Print Sheet** 都会保留每个会话的选择。

### 限制

- **最多八个。** 每张卡片都挂载自己的实时运行时，八个是仍能保持响应的数量。要求更多，或要求一个已不存在的会话的链接，会明确告知，而不是只加载一半。
- **链接是本地的。** 它指向你自己保存的位置，所以会在这台设备上重新打开那一组。它不是分享链接。
- **对于更大的规模，**请在同一选择栏中选择 **Edit as sheet**。它会把整个选区作为多行在批量网格中打开（`#/batch?s=…`），没有大小限制，也没有同一工具的规则。文件夹两者都不适用：请用 **Sessions → Folders…** 在网格中打开文件夹，或用 Projects 中的 **Render folder** 渲染。
- **搜索不涵盖 Multi-edit。** 这是搜索栏唯一不识别的视图。
