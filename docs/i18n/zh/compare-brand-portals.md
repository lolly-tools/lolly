# Lolly 与品牌门户

_最后核查：2026 年 9 月 28 日。_

如果你所在组织把已批准的素材保存在 Bynder、Frontify、Marq 或 Brandfolder 中，本页会把它与 Lolly 加 Lolly Work 做比较：人们如何找到品牌素材，以及如何用它们制作新文件。

## 成熟的门户做得更好的地方

成熟的门户提供托管服务、支持和丰富的素材管理工作流。例如，[Frontify 的企业 DAM](https://www.frontify.com/en/solution/enterprise-digital-asset-management)结合了素材发现、访问控制、审批工作流和分发。Lolly 这套产品更年轻，它的审批链是顺序式的，而不是任意分支的工作流。[Work 状态与路线图](/info/work-status.html)记录了它的部署限制。

## 重叠之处

两者都涵盖已批准的素材、锁定的模板、访问控制、审阅和分发。Lolly 负责制作文件：模板、设计令牌和允许的输入项定义了人们可以更改什么，渲染可以留在他们的设备上。Lolly Work 在组织自己控制的基础设施上增加身份、共享存储、政策、审批和报告。

## Lolly 和 Lolly Work 提供什么

| 需求 | Lolly + Lolly Work |
|---|---|
| 登录与开通账号 | OIDC 单点登录、多个身份提供方、SCIM 2.0 用户开通和组成员关系，以及会撤销现有会话的账号停用。仅支持 SAML 的身份提供方可以通过 Keycloak 等 OIDC 桥接连接。 |
| 已批准的模板 | Lolly 定义模板的可编辑输入项；Lolly Work 应用组可见性和输入政策，锁定值、限制选项或隐藏控制项。 |
| 共享素材库 | 实例自有的上传、集合、自定义元数据和带访问控制的目录，以及读取现有 DAM 和存储库的连接器。 |
| 审阅 | 有序的审批步骤、符合条件的审批人组、法定人数规则和职责分离；审阅可以管控目录提交和交付到组织目标。 |
| 素材历史与可用性 | 实例自有素材的版本和回滚、保留和冻结、定时可用、过期和撤销。已连接的提供方保留自己的源历史。 |
| 许可协议与署名 | Lolly 记录文件所用每个来源的许可协议，并准备它应给出的署名；[创作版权与署名](/info/creative-rights.html)解释了它记录什么以及署名写在哪里。它不会为权利放行。 |
| 报告 | 素材使用和下载次数、工具和导出活动、仪表板和审计轨迹。使用归属遵循部署的遥测政策；默认的归属设置需要同意。 |
| 分发 | 会过期、可撤销的链接、共享集合、访客访问，以及交付到已配置的组织目的地。 |

[目录与内容](/info/work-catalog.html)、[审批](/info/work-approvals.html)和[政策与治理](/info/work-governance.html)介绍了这些功能及其配置。

## 保留你现有的门户

现有的 DAM 可以继续作为事实来源。Lolly Work 的目录连接器让它已批准的素材在 Lolly 中可用，人们在组织的规则下用它们制作新文件。这是一种集成选择；当组织想自己运行时，Lolly 自己的素材库和审批也在那里。[什么在哪里运行](/info/compare.html#what-runs-where)列出了每项对比共有的限制。

有关能力对比，请参见 [Lolly 如何对比](/info/positioning.html)。厂商名称用于标识被比较的产品；Lolly 与它们没有关联。
