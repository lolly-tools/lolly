# 在你的组织中使用 Lolly

你的组织可以运行自己的 Lolly：同一个应用，配上它选定的工具和设计系统，有时还需要登录。本页说明如何进入它，以及进入之后会有什么不同。

::: note 你需要从组织获取的信息
它的 Lolly 网址，或者你的组织制作的 `.lolly` 设置文件。lolly.tools 本身不会连接到某个组织。
:::

## 在浏览器中

打开你的组织给你的地址。如果页面要求你登录，按**登录**并按提示完成随后打开的登录页面。之后，它的运作方式就和任何 Lolly 一样，只是换成了你的组织的工具和设计系统。

浏览器没有可以切换到另一个 Lolly 的设置，因此请打开你组织自己的地址，而不是 lolly.tools。

## 在桌面版或移动版应用中

应用首次启动时，会询问**Lolly 应该从哪里获取工具？**

1. 选择**连接到 Lolly 实例**。
2. 输入你的组织的网址，然后按**检查并连接**。
3. 按**使用此实例**。接下来的界面**导入你的数据（可选）**会把已保存的作品从 Lolly 备份中带过来；如果没有，按**跳过**。
4. 如果应用要求，请登录。

来自已连接实例的工具，运行时享有和应用自带工具同样的信任级别，因此只连接你信任的实例。你的组织也可能改为向你发送一个 `.lolly` 设置文件，替你完成应用的连接。

以后要切换，打开**设置**：**Lolly 实例**卡片上有**更改**和**离开**。

## 用验证码登录

如果在这台设备上登录不方便，而你组织的 Lolly 又提供这个选项，按**在另一台设备上使用验证码登录**。Lolly 会显示一个简短的验证码和一个地址：在你已经登录的手机或电脑上打开这个地址，并在那里输入验证码。验证码大约十分钟内有效。

## 那里有什么不同

- **有些控件已经替你设好。** 由你的组织管理的控件会显示 **Managed by** 和组织名称，或者显示**由你的组织管理**。固定的控件无法更改，菜单可能只提供其中部分选项，以 **Set by** 开头的一行则会说明适用哪条规则以及原因。有些控件根本不会显示。
- **只列出它的工具。** 你的组织未提供的工具完全不会显示。
- **共享项目。** 如果你的组织与你共享项目，**项目**中会出现一个**团队项目**磁贴。
- **部分导出可能需要审批。** 在你的组织要求审批的地方，**请求审批**会取代**下载**，工具能提供的格式也可能更少。
- **你自己保存的内容**会留在本设备上，除非你开启[同步](/info/sync.html)，这一点在 Lolly 中处处如此。

## 离开

**离开**，在**设置**中**Lolly 实例**卡片上，会移除你组织的设计系统、工具和目录。你自己的作品会保留。用它的工具做出的任何东西，在你重新连接之前都无法再打开；你保存到组织那边的任何东西，也仍然留在组织那边。在浏览器里访问组织自己的地址时，没有什么可以离开的：请改为打开另一个地址。

## 该问谁

什么内容会到达你组织的服务器、谁能看到其共享项目、哪些设置是固定的，这些都由你的组织决定。请询问负责运行你组织的 Lolly 的人。[隐私](/info/privacy.html)说明了 Lolly 本身如何处理你的数据。
