# 创作

你填写几个字段，就能在自己的设备上得到成品文件，字体、颜色和版面都已确定。因为品牌规则在工具里，所以出现不符合品牌的文件时，上面绝不会是你的名字。选择与你今天所做之事相符的路线。

刚来？从 **[制作你的第一个文件](/info/make-something.html)** 开始。[Lolly 如何工作](/info/how-lolly-works.html)展示了你使用的工具也可以怎样通过脚本或同事的手机运行，[问答](/info/faq.html)则解答了人们在信任一个免费工具之前会问的问题。

## 制作

选一个工具并填写，或在 Design 画布上自由排版页面。

- **[制作你的第一个文件](/info/make-something.html)** - 一节无需任何准备的简短课程：一个二维码，下载并保存为可编辑的副本。
- **[使用 Lolly](/info/using.html)** - 画布、控制项、保存、Projects 和手机使用：应用本身的行为方式。
- **[模板](/info/templates.html)** - 从已保存的版面开始，而不是从空白工具开始。
- **[Design 中的文字](/info/text-composition.html)** - 标题、流动文字，以及适配其方框的字体。
- **[3D Studio](/info/3d-studio.html)** - 将 SVG 作品和 3D 模型排布、打光并渲染为同一个场景。
- **[实用工具](/info/utilities.html)** - 在你的设备上处理文件：安全地分享、比较两个版本、更改格式、提取文字或检查颜色。
- **[浏览器扩展](/info/extension.html)** - 从网页应用对实时网页截图，或读取网站以创建设计系统。

## 让它成为你的

你的设计系统决定每个工具的外观。

- **[Design System Setup](/info/brand-studio.html)** - 徽标、颜色、字体及其他一切，在 `#/start` 一次设定。
- **[实际使用 Lolly Demo](/info/lolly-demo-in-use.html)** - 在真实作品上使用配色方案，以及切换到你自己的设计系统。
- **[品牌架构](/info/brand-architectures.html)** - 一个组织使用多个设计系统，或一个带有多种配色方案的设计系统。
- **[导入设计](/info/design-import.html)** - 把 `.fig`、`.penpot`、`.ai`、`.idml` 或 SVG 文件作为可编辑的版面打开，而不是一张平面图片。
- **[重塑演示稿品牌](/info/rebrand.html)** - 把 PowerPoint 演示稿移到你的设计系统上，图表和动画保持完好。
- **[带规则分享设计](/info/create-a-tool.html)** - 把版面变成其他人填写的工具。

## 查找并保管你的作品

- **[查找和恢复你的作品](/info/find-your-work.html)** - 已保存、已下载或未保存的文件去了哪里。
- **[搜索](/info/search.html)**和 **[Ask Lolly](/info/ask.html)** - 用一个输入框查找你的工具、已保存的作品、素材和设置，并从这些指南中获得答案。
- **[设置](/info/dashboard.html)** - 这台设备能做什么、只读的设计系统，以及你的存储。
- **[你的收藏](/info/favourites.html)**和**[个人资料](/info/profile.html)** - 加星的工具、工具预填所用的详细信息，以及无障碍开关。
- **[同步你的设备](/info/sync.html)** - 通过你选择的存储，在电脑和手机上使用同样的作品。

## 动画

会动的文字、时间线上的场景，以及始终符合品牌的动态效果。动态导出是由受驱动的时钟逐帧绘制的，而不是从屏幕录制的，所以同一个链接会生成同样的片段。

- **[动画](/info/animating.html)** - 关键帧、真实的景深和场景摄像机。
- **[序列编辑器](/info/sequence-editor.html)** - 片段、叠加轨道、修剪与拆分、转场和音频混音。
- **[广色域与 HDR](/info/hdr-editing.html)** - 超出常规范围的色彩，用于能显示这一额外范围的屏幕和格式。

## 录制与演示

通过倒计时和电平表录出一段干净的录音，或者让自己出现在幻灯片前面。

- **[Design 时间线](/info/design.html#timeline-sequence)** - 直接在时间线上录制旁白。
- **[制作你的第一个文件](/info/make-something.html#other-first-projects)** - 音频图，适合你更想被听见而不是被看见的时候。
- **[带摄像头演示](/info/presenting.html)** - 你的摄像头、徽标和姓名叠加在演示稿或倒计时之上，私密控制项在单独的窗口中。
- **[响应翻页笔的实时页面](/info/interactive-pages.html)**和**[议程屏幕](/info/agenda.html)** - 为会场准备的页面和节目单。

## 协作

两个人，两台设备，一份设计，实时编辑，无需账号，中间也没有服务器。

- **[一起工作](/info/collaborate.html)** - 设备之间的私密协作，以及通过你所在组织的 Lolly Work 进行的工作协作。
- **[使用 Lolly](/info/using.html#sharing-your-work)** - 携带完整状态的分享链接，或一个 `.lolly` 文件。
- **[在你的组织中使用 Lolly](/info/organisation.html)** - 当你的组织运行 Lolly Work 时的登录、团队项目和受管理的设置。

## 发布

发送到需要它的地方：链接、与印刷一致的 PDF、视频、演示稿或一个变体文件夹，全都来自同一个源。

- **[导出文件](/info/exporting.html)** - 印刷单位、出血和裁切标记、视频、批量运行和导出面板。
- **[Lolly 可以打开和制作的所有格式](/info/formats.html)** - 完整的输入与输出列表。
- **[创作版权与署名](/info/creative-rights.html)** - 你所用内容的许可协议，以及随文件一起传递的署名。
