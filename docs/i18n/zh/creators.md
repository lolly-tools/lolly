# 面向创作者的 Lolly

您只需填写几个字段,一份成品文件便会生成,字体、颜色和版式都已在您自己的设备上决定完毕。几分钟内交付成果,效果却像是花了几个小时打磨,而且因为品牌规则已经内置在工具中,不合品牌规范的文件永远不会挂上您的名字。请从下方选择与您今天要做的事相符的路径。

您是这场接力中的一环:开发者可以把您使用的工具扩展成一条流水线,同事也可以自助运行它,[一次营销活动的生命周期](/info/overview.html#the-lifecycle-of-a-campaign)一文追踪的正是一份素材依次经过这三双手的全过程。

初次使用?先看 **[60 秒做出一件成品](/info/make-something.html)**,等您明确想深入了解哪一部分之后再回来。[常见问答](/info/faq.html) 收录了人们在信任一款免费工具之前会问的问题。[Lolly 与其他工具的比较](/info/positioning.html) 则如实说明了在什么情况下您应该改用别的工具。

## 制作

选择一个工具,填写几个字段,下载成品文件。或者打开 Design 画布,自由排版:无论哪种方式,颜色、字体和间距都取自您的品牌,而不是凭记忆拼凑,且全程无需账户。

- **[60 秒做出一件成品](/info/make-something.html)** - 如果您从未打开过 Lolly,这里有三段无需任何设置的简短演示。
- **[使用 Lolly](/info/using.html)** - 画布、控件、保存、Projects 与手机使用:应用本身的运作方式。
- **[品牌工作室](/info/brand-studio.html)** - 何时该用您自己的标志、颜色和字体,而不是默认值。
- **[导入设计](/info/design-import.html)** - 当作品已经存在于 `.fig`、`.penpot`、`.ai`、`.idml` 或 SVG 文件中,而您希望它可编辑而不是被拍平。
- **[实用视图](/info/utilities.html)** - 电子表格、转换器、Colour Lab、PDF 提取器和 Script audio,用于不属于工具渲染的那些工作。
- **[浏览器扩展](/info/extension.html)** - 捕获实时网页,并将其作为素材复用到您自己的设计中。
- **[搜索](/info/search.html)** - 一个字段即可触达您的工具、已保存的作品、目录和设置。
- **[问问 Lolly](/info/ask.html)** - 输入一个问题,即可获得这些指南中匹配的章节,并附上直达链接。
- **[仪表盘](/info/dashboard.html)** - 本设备能做什么、您的设计系统的只读视图,以及存储空间一览。
- **[您的收藏](/info/favourites.html)** - 为常用项加星标,它就会在网格上方拥有自己的图块。
- **[个人资料](/info/profile.html)** - 工具据以预填的详细信息,以及四个不改动导出内容任何一个像素、却能让应用更平静的无障碍开关。

## 动画

会动的文字、时间轴上的场景,以及始终符合品牌规范的动效。动态导出是按帧、依据一个受驱动的时钟合成而来,而不是从屏幕上录制,因此时间点绝不会漂移,同一个链接无论渲染多长都会得到同样的片段。

- **[制作动画](/info/animating.html)** - 关键帧、真实的景深,以及可以掠过成果飞行的场景摄像机。
- **[序列编辑器](/info/sequence-editor.html)** - 时间轴本身:片段、叠加轨道、剪切与分割、转场以及音频混音。
- **[导出与格式](/info/exporting.html)** - 动效确定之后,导出面板中视频、GIF 和动态 PNG 的部分。

## 录制

借助倒数提示、电平表和轻柔的引导,录制一段干净的素材,或者把一段语音备忘转变成随声音而动的成品视频。目前还没有独立的“录制”页面:相关内容收录在《使用 Lolly》的时间轴部分。

- **[使用 Lolly](/info/using.html#timeline-sequence-studio)** - 直接在时间轴上录制配音、素材保存在哪里,以及它如何进入混音。
- **[60 秒做出一件成品](/info/make-something.html#make)** - 音频图场景,适合您希望被听见而非被看见的时候。
- **[实用视图](/info/utilities.html)** - Script audio,适合先有文字、再生成声音的情形。

## 协作

两个人,两台设备,一个会话,实时共同编辑。隔着桌子扫一下码,两块屏幕上就会呈现同一份作品,中间既没有账户也没有服务器——如果两台设备处于同一网络,甚至完全不需要互联网。

- **[一起协作](/info/collaborate.html)** - 如何开始一个会话、设备之间会传递哪些内容,以及网络中断时会发生什么。
- **[使用 Lolly](/info/using.html#sharing-your-work)** - 更安静的交接方式:携带完整状态的分享链接,或是一个 `.lolly` 文件。

## 发布

把它送到需要的地方:一个携带设计的链接、一份所见即所印的 PDF、一段视频、一份幻灯片,或是一整个文件夹的变体。所有这些都出自同一个源文件,因此您只需构建一次。

- **[导出与格式](/info/exporting.html)** - 印刷单位、DPI、出血和裁切标记、视频、批量运行,以及导出面板本身。
- **[Lolly 能打开和生成的每一种格式](/info/formats.html)** - 完整的输入输出清单,每个标签背后都有一段通俗易懂的说明。
- **[数据迁移](/info/data-transfer.html)** - 备份包,用于将您制作的一切迁移到另一台设备。
