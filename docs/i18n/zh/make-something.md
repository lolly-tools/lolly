# 制作你的第一份文件

读完这个页面，你就会为一个网址下载好一个二维码，并保存一份以后可以打开和修改的副本。你不需要账号，事先也不用做任何设置。

::: note 开始之前
准备好二维码应该打开的网址，以 `https://` 开头。
:::

## 制作二维码

1. 打开 [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)。控件位于预览旁边，在手机上则在预览上方；预览显示的就是文件最终的样子。
2. 在**URL**中，把示例地址完整替换成你自己的。预览会随输入实时变化。
3. 要配合你自己的颜色，请设置 **Module colour** 和**背景**。两者之间要保持强烈对比，否则手机会难以识别这个码。
4. **Modules** 下的 **Quiet zone** 默认从 4 开始。请保持在 4 或以上：手机摄像头正是靠这圈素净的边距来识别码的。

## 下载文件

1. 在**导出 | 另存为**胶囊按钮上按**导出**，它在电脑上位于控件区底部，在手机上则悬浮在屏幕底部。
2. 打开文件名旁边的格式菜单（默认是 **SVG**），如果要用于屏幕或消息，选择 **PNG**。如果要用于印刷，请看下面的说明。
3. 按**下载**。文件会进入你浏览器的下载记录；如果找不到，请见[找到你下载的文件](/info/find-your-work.html#find-a-file-you-downloaded)。

::: check 分享文件之前先扫一下码
在屏幕上打开下载好的文件，用手机摄像头扫描这个码。如果你是在手机上制作的，就用另一部手机或电脑屏幕来扫描。手机应该会弹出你的网址。
:::

::: details 如果这个码要打印或经手传递
选择 **SVG** 或 **PDF**，让码在任何尺寸下都保持清晰，并按实际使用的尺寸试印一次。如果码可能被磨损或淋雨，把 **Modules** 下的**Error correction** 设为 **High (30%)**：即使码有损坏，也依然能被识别。
:::

## 保留一份可编辑的副本

你下载的文件已经是成品。如果以后还想修改这个码，也要保存你的作品：

1. 按**另存为**，然后按**保存**。导出面板打开时，**另存为**在面板里；面板关闭时，它是**导出**旁边的那个勾号。这个码会进入**我的素材库**，并弹出一条**已保存**的消息，提供**打开项目**。
2. 下次回来时，按**首页**并打开**项目**（在手机上是文件夹图标）。你的码就在那里，名称是**QR Code**。打开它，做任意修改，再次导出。

已保存的作品会留在这台设备上，留在你使用的浏览器或应用里，除非你开启[同步](/info/sync.html)。[找回你的作品](/info/find-your-work.html)介绍了文件夹、早期版本以及把作品移动到另一台设备的方法。

## 其他入门项目

- [Audiogram](/#/tool/audiogram) 把一段语音备忘变成一段视频：一条跳动的波形、封面上的文字、你的配色。把录音拖进**音频**，加一个**标题**，然后导出 **MP4**。
- [Filter](/#/tool/filter) 为海报处理一张照片：印刷网点、两种纯色或几档色调色块。在**图片**下选好照片，挑一个**效果**，然后导出 **PNG**；如果效果标着*矢量*，就导出 **SVG**。

## 接下来

- **发送链接，而不是文件。** 你动过的每一项设置都会写入页面地址，所以导出面板里的**分享**会给出一个链接，能在别人的屏幕上重新打开同一个设计。你从自己设备上传的照片不会随链接一起传递。参见[分享你的作品](/info/using.html#sharing-your-work)。
- **一次性添加你的颜色和字体**，让每个工具都以它们为起点：见[快速上手](/info/quickstart.html)。
- [使用 Lolly](/info/using.html) 是这个应用的完整指南，[面向创作者的 Lolly](/info/creators.html) 则介绍了它还能做的其他事情。
