# Lolly a confronto, strumento per strumento

Se usi già un altro prodotto, queste pagine dicono se Lolly lo sostituisce, lavora al suo fianco o non si adatta al tuo lavoro. Ognuna inizia con ciò che l'altro prodotto fa meglio.

_Ultima verifica: 28 settembre 2026._

Per la vista capacità per capacità, consulta [Come si confronta Lolly](/info/positioning.html). Ogni confronto è datato; un'affermazione che non corrisponde più a uno dei due prodotti va corretta.

## Cosa gira dove

Ogni confronto riguarda due parti di un unico progetto open source. **Lolly** è l'engine, le app e gli strumenti. **Lolly Work** è il server per organizzazioni, mantenuto nel [repository lolly-work](https://github.com/lolly-tools/lolly-work). Entrambi sono MPL-2.0, e un'organizzazione decide quali servizi di Lolly Work attivare.

::: cols
## Sul tuo dispositivo: Lolly

- Nessun account per l'uso standalone
- Creare, modificare, convertire ed esportare
- Funziona offline una volta salvati gli strumenti e le risorse che servono
- Content Credentials firmate sul dispositivo
- Collab private tra due dispositivi, senza server

## Sul server della tua organizzazione: Lolly Work

- Single sign-on, provisioning SCIM, ruoli e policy
- Cataloghi condivisi, progetti di team e collab di lavoro
- Approvazioni, report d'uso e record di audit
- Rendering sul server, lavori recuperabili e consegna approvata
- Firma sul server con l'identità dell'organizzazione
:::

L'uso standalone mantiene i file sul dispositivo. Scegliere progetti condivisi, una collab di lavoro, un rendering sul server o una consegna invia al server della tua organizzazione i dati che quella funzione richiede.

## Cosa assume ogni confronto

Questi limiti valgono per ogni pagina di questa serie, quindi sono dichiarati una volta qui:

- **Le collab di lavoro oggi girano su un solo nodo server.** La loro scala e la loro storia operativa differiscono da quelle dei prodotti ospitati consolidati da tempo. [Work status and roadmap](/info/work-status.html) registra i limiti attuali.
- **Il sito [lolly.work](https://lolly.work) è una sandbox dimostrativa.** Un'installazione durevole per un'organizzazione richiede archiviazione persistente e un operatore; [Install Lolly Work](/info/work-install.html) tratta entrambi.
- **Non c'è alcun costo di licenza software per utente** per Lolly o per un Lolly Work self-hosted. Hosting, archiviazione e gestione costano comunque denaro.
- **Una firma non è un firmatario attendibile.** Un verificatore deve fidarsi del certificato che ha firmato un file prima di mostrare il firmatario come attendibile; [Content Credentials Identity](/info/content-credentials-identity.html) spiega come.
