# Lolly a confronto, strumento per strumento

Lolly copre il lavoro creativo, da una singola conversione sul dispositivo fino alla produzione di asset di un'organizzazione governata. Queste pagine confrontano i flussi di lavoro supportati da ciascun prodotto, il modo in cui viene distribuito e i limiti che contano nella scelta di una soluzione.

_Ultima verifica: 28 settembre 2026._

## Un solo progetto, due parti distribuite separatamente

**Lolly** è il motore, le app e gli strumenti per creare, modificare, convertire ed esportare. Funziona sul tuo dispositivo, lavora offline una volta disponibili gli asset necessari e non richiede un account per l'uso autonomo.

**[lolly.work](https://lolly.work)** è il servizio per organizzazioni del progetto, mantenuto nel [repository lolly-work](https://github.com/lolly-tools/lolly-work). Offre SSO, provisioning SCIM, ruoli e policy, cataloghi e progetti condivisi, approvazioni, collaborazione di lavoro, report di utilizzo, registri di audit e rendering lato server. Entrambe le parti sono open source con licenza MPL-2.0. Un'organizzazione ospita lolly.work insieme a Lolly e decide quali servizi abilitare.

I confronti riguardano **Lolly + lolly.work**. Le funzionalità che richiedono il servizio per organizzazioni sono indicate esplicitamente. L'uso autonomo mantiene i file sul dispositivo; scegliere progetti condivisi, collaborazione di lavoro, rendering lato server o consegna invia i dati pertinenti ai servizi configurati. Il sito pubblico lolly.work è una sandbox; per una distribuzione in organizzazione consulta la [guida alla distribuzione](https://github.com/lolly-tools/lolly-work/blob/main/docs/install.md) e lo [stato attuale](https://github.com/lolly-tools/lolly-work/blob/main/docs/status.md).
