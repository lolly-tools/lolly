# Lolly e i convertitori di file online

_Ultima verifica: 28 settembre 2026._

Se di solito cerchi "da HEIC a JPG" o "comprimere PDF" e carichi il file sul primo sito che trovi, Lolly esegue la stessa conversione nel tuo browser, sul tuo dispositivo.

<!--i:eti-award-->
## Cosa può fare meglio un sito di conversione

Alcuni siti di conversione gestiscono formati che Lolly non supporta e non richiedono configurazione. Scegli un convertitore in base ai formati e alla fedeltà che ti servono e al luogo in cui elabora il file. Alcune conversioni mantengono la struttura modificabile e altre appiattiscono il risultato.

<!--i:eti-map-pin-->
## Dove avviene la conversione

Un convertitore basato su browser può caricare un file per elaborarlo oppure convertirlo localmente. Le utility di conversione di Lolly elaborano il file localmente, senza account, pubblicità o tracker. Non aggiungono filigrane Lolly né Content Credentials. Le utility funzionano offline una volta salvate le risorse necessarie alla conversione. La dimensione dei file è limitata dalla memoria del dispositivo e dal lettore del formato.

## Quando a un team serve di più

I membri di un'organizzazione che usa Lolly Work continuano a usare le utility sul dispositivo per le conversioni locali. I dati vanno al server dell'organizzazione solo per un caricamento condiviso, un rendering sul server o una consegna. [Cosa viene eseguito e dove](/info/compare.html#what-runs-where) spiega la separazione.
