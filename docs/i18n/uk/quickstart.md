## Додайте свій бренд

lolly.tools відкривається з **Lolly Demo**, власною зразковою дизайн-системою Lolly ([Знайомство з Lolly Demo](/info/lolly-demo.html)). Ваша дизайн-система замінює Lolly Demo. Це невеликий набір дизайн-токенів (кольори, шрифти й кілька правил), якими малює кожен інструмент. Налаштуйте його один раз, і все, що ви створюєте, відразу відповідатиме бренду.

Виберіть шлях відповідно до того, що маєте:

- <!--i:palette--> **Один колір.** Відкрийте вигляд **Design System Setup** (`#/start`), назвіть свою дизайн-систему й виберіть основний колір. Lolly виводить із цього кольору доступну палітру зі світлими й темними поверхнями, текстом і акцентами. Виберіть шрифт, і ви матимете робочий бренд.
- <!--i:upload--> **Файл токенів.** **Add from…** угорі Lolly Design System Setup приймає файл токенів DTCG, Tokens Studio чи Penpot, SVG або пакет `LollyBrand`. Палітра заповнюється з файлу. Поки дизайн-система порожня, **Start from a reference** на Board відкриває той самий вибірник.
- <!--i:pentool--> **Готовий дизайн.** У Lolly Design виберіть **Import a design** і перетягніть файл Figma, Penpot, Illustrator, InDesign, Affinity, Photoshop, PowerPoint або SVG ([усі формати](/info/design-import.html#what-comes-in-from-each-app)). Див. [Перенесіть те, що вже маєте](#bring-in-what-you-already-have) нижче.

Коли ви вперше відкриваєте галерею, привітання вгорі пропонує один наступний крок. На lolly.tools **Start making** відкриває Lolly Design із плакатом Launch. На новому встановленні **Make it yours** відкриває Lolly Design System Setup. Під цією кнопкою **Bring a file** відкриває вибірник файлу дизайну, а інший із цих двох варіантів показується посиланням. Будь-який із них або кнопка закриття назавжди прибирає привітання.

![Кімната Colours у Lolly Design System Setup для нової дизайн-системи: один живий зразок кольору, одне поле й усе для першого рішення](/t/url-shot?url=%2F%23%2Fstart%3Farea%3Dcolor&system=new-design-system&width=1440&height=740&dpi=192&waitMs=1800&format=svg&walker=1&dark=1&filename=bs-colours-new-system)

Вісім кімнат, якими можна користуватися в будь-якому порядку, розвивають дизайн-систему далі: **Board**, **Colours**, **Type**, **Logos**, **Tokens**, **Files**, **Rules** та **Skills**. Кожен попередній перегляд у застосунку оновлюється під час введення. [Lolly Design System Setup](/info/brand-studio.html) описує кожну кімнату.

Шрифти зберігаються на вашому пристрої. Вибраний шрифт Google Font зберігається як ресурс бренду, тож ваші шрифти працюють офлайн і нічого не завантажується, коли інструмент малює.

### Перегляд, перемикання й поширення дизайн-системи

- **Перегляньте активну.** **Налаштування → Система дизайну** показує активну дизайн-систему як обкладинку й сторінки лише для читання.
- **Перемикайтеся між ними.** **Налаштування → Preferences → Design systems** перелічує всі дизайн-системи на цьому пристрої. Одна організація може використовувати кілька дизайн-систем або одну з кількома колірними варіантами. [Архітектури брендів](/info/brand-architectures.html) показують ці схеми.
- **Поділіться однією.** Експортуйте дизайн-систему як пакет `LollyBrand`: один файл, який колега імпортує, щоб отримати ту саму палітру, шрифти й правила.

Дизайн-система, яку надає ваша збірка чи організація, є **керованою**: вона має значок замка й доступна лише для читання. Щоб змінити її, створіть редаговану копію в **Settings → Preferences → Design systems**.

![Вкладка дизайн-системи в Налаштуваннях: активна дизайн-система як обкладинка та сторінки](/t/url-shot?url=%2F%23%2Fd%3Ftab%3Dbrand&width=1440&height=900&dpi=192&waitMs=1800&format=svg&walker=1&localize=1&dark=1&filename=dashboard-brand&waitSelector=%5Bdata-issue-ready%5D)

Ваша дизайн-система складається з токенів DTCG у форматі, який Penpot читає й записує, а Tokens Studio переносить у Figma. Палітра, з якою ви створюєте дизайн, і палітра, яку застосовує Lolly, є одним документом. Докладніше про це в розділі [Токени дизайну](/info/design-tokens.html).

::: details Для розробників: створіть пакет бренду з командного рядка
`ingest:brand` створює багаторазовий пакет бренду в локальній копії репозиторію. Він приймає три контейнери, які експортують Penpot і Tokens Studio: один файл `tokens.json`, каталог файлів окремих наборів із `$metadata.json` або архів `project.penpot`.

```bash
pnpm run ingest:brand ./my-tokens.json --name acme --label "Acme" --activate
```

`--activate` реєструє бренд як профіль, створює та перевіряє його каталог. Він ніколи не змінює типовий профіль: запускайте з `LOLLY_PROFILE=acme`, щоб використовувати новий пакет. У розділі [Конфігурація](/info/configuration.html) пояснено, як пов'язані пакети бренду та профілі.
:::

## Імпортуйте те, що вже маєте

**Файли Lolly Design.** Готова робота з Figma, Penpot, Illustrator, InDesign чи будь-якого застосунку для SVG відкривається в Lolly Design як редагований макет. Текст залишається редагованим, фігури залишаються фігурами, а зображення потрапляють до вашої бібліотеки. Файл читається у вашому браузері й нікуди не надсилається. У розділі [Імпорт дизайну](/info/design-import.html) перелічено всі формати й те, що зберігається.

**Колоди.** Перетягніть файл PowerPoint `.pptx` у Lolly, щоб зберегти його слайди як ресурси. Створіть нову колоду з Markdown у **Lolly Markdown Slides**. [Ребрендинг колоди](/info/rebrand.html) переносить колоду на вашу дизайн-систему.

**Дані.** Вставте чи перетягніть таблицю CSV або JSON, щоб заповнити повторювані поля інструмента. [Lolly Batch](/info/batch.html#make-many-versions-of-one-design) створює один готовий файл на кожен рядок.

### Від разового макета до шаблону

Імпортований макет є звичайним сеансом Lolly Design. **Share with rules** перетворює сеанс на інструмент. Ви вибираєте, які частини можуть змінювати інші люди, а вони заповнюють лише їх.

## Створюйте багато, діліться й автоматизуйте

- <!--i:download--> **Експорт.** Інструменти створюють SVG, PDF, PNG, JPG, WebP, відео й інші формати, за потреби зі справжніми розмірами для друку. Кожен інструмент пропонує власний набір форматів. Див. [Експорт файлу](/info/exporting.html).
- <!--i:link--> **Поділіться посиланням.** Налаштування інструмента передаються в його посиланні, тому воно будь-де відкриває той самий файл.
- <!--i:layers--> **Створіть по одному на рядок.** Керуйте інструментом з електронної таблиці в [Lolly Batch](/info/batch.html#make-many-versions-of-one-design).
- <!--i:cpu--> **Автоматизуйте.** Той самий рендер запускається з [CLI](/info/cli.html) та через [ШІ-агента](/info/ai-agents.html).

Посилання є повним запитом. Тип, заголовок і таблицю даних наведеної нижче діаграми ввели в адресний рядок.
