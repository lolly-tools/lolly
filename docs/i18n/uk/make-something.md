# Створіть свій перший файл

Наприкінці цієї сторінки ви вже завантажите QR-код для веб-адреси та збережете копію, яку зможете відкрити й змінити пізніше. Вам не потрібен обліковий запис і нічого не треба налаштовувати заздалегідь.

::: note Перш ніж почати
Майте напоготові веб-адресу, яку має відкривати код, що починається з `https://`.
:::

## Створіть код

1. Відкрийте [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Елементи керування розташовані поряд із попереднім переглядом, або над ним на телефоні; те, що показує попередній перегляд, і буде файлом.
2. У полі **URL** замініть приклад адреси на свою, повністю. Попередній перегляд змінюється під час набору тексту.
3. Щоб відповідати вашим кольорам, задайте **Module colour** і **Фон**. Тримайте між ними сильний контраст, інакше телефонам буде важко зчитати код.
4. **Quiet zone**, у розділі **Modules**, починається з 4. Тримайте його на рівні 4 або більше: саме це поле й шукає камера телефону.

## Завантажте файл

1. Натисніть **Експорт** на пігулці **Експорт | Зберегти як** унизу елементів керування на комп'ютері або плаваючій знизу екрана на телефоні.
2. Відкрийте меню формату біля назви файлу (спочатку встановлено **SVG**) і виберіть **PNG** для екрана чи повідомлення. Для друку див. примітку нижче.
3. Натисніть **Завантажити**. Файл потрапляє до завантажень вашого браузера; якщо його там немає, див. [Знайдіть файл, який ви завантажили](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Скануйте код перед тим, як ділитися файлом
Відкрийте завантажений файл на екрані та відскануйте код камерою телефону. Якщо ви створили його на телефоні, відскануйте з другого телефону або з екрана комп'ютера. Телефон має запропонувати вашу веб-адресу.
:::

::: details Якщо код друкуватимуть або братимуть у руки
Оберіть **SVG** або **PDF**, щоб код лишався чітким за будь-якого розміру, і перевірте друк у тому розмірі, у якому його використовуватимуть. Якщо код може подряпатися або потрапити під дощ, встановіть **Error correction**, у розділі **Modules**, на **High (30%)**: пошкоджений код усе одно зчитується.
:::

## Збережіть редаговану копію

Завантажений файл готовий. Щоб пізніше змінити код, збережіть і свою роботу:

1. Натисніть **Зберегти як**, потім **Зберегти**. Коли панель експорту відкрита, **Зберегти як** розташоване в панелі; коли вона закрита, це галочка біля **Експорт**. Код потрапляє в **Моя бібліотека**, а повідомлення **Збережено** пропонує **Відкрити проєкти**.
2. Наступного разу натисніть **Головна** і відкрийте **Проєкти** (піктограма папки на телефоні). Ваш код там, названий **QR Code**. Відкрийте його, змініть що завгодно і експортуйте знову.

Збережена робота лишається на цьому пристрої, у браузері чи застосунку, який ви використали, якщо ви не увімкнете [синхронізацію](/info/sync.html). [Знайдіть і відновіть свою роботу](/info/find-your-work.html) охоплює папки, попередні версії та перенесення роботи на інший пристрій.

## Інші перші проєкти

- [Audiogram](/#/tool/audiogram) перетворює голосову нотатку на відео: рухома хвиля, ваші слова на обкладинці, ваші кольори. Перетягніть запис у поле **Аудіо**, додайте **Заголовок**, потім експортуйте **MP4**.
- [Filter](/#/tool/filter) обробляє фото для постера: друковані растрові точки, два плоскі кольори або кілька блоків тону. Виберіть фото в полі **Зображення**, оберіть **Ефект**, потім експортуйте **PNG**, або **SVG** для ефекту з позначкою *vector*.

## Далі

- **Надішліть посилання замість файлу.** Кожен елемент керування, якого ви торкнулися, записується в адресу сторінки, тож **Поділитися** в панелі експорту дає посилання, яке знову відкриває той самий дизайн на чужому екрані. Фото, яке ви завантажили зі свого пристрою, не подорожує разом із посиланням. Див. [Як поділитися роботою](/info/using.html#sharing-your-work).
- **Додайте свої кольори та шрифти один раз**, щоб кожен інструмент починав із ними: [Швидкий старт](/info/quickstart.html).
- [Використання Lolly](/info/using.html) - повний посібник із застосунку, а [Lolly для творців](/info/creators.html) показує, що ще він уміє створювати.
