# Розширення браузера

Вебсторінка не може читати пікселі іншого сайту. У браузері на основі Chromium (Chrome, Edge, Brave, Arc або Opera, починаючи з Chrome 111) безплатне розширення **Lolly URL Screenshot** дає вебзастосунку Lolly змогу робити знімок сторінки тим самим способом, що й настільний застосунок. З установленим розширенням:

- **[Lolly URL Screenshot](/t/url-shot)** зберігає скомпоновану вами сторінку як файл;
- вебадреса, вставлена в поле зображення, може стати знімком цієї сторінки через **Screenshot this page**;
- джерело **Website** у [Lolly Design System Setup](/info/brand-studio.html) може прочитати одну сторінку, щоб започаткувати дизайн-систему.

Ви схвалюєте кожен запит, а настільний застосунок виконує ті самі завдання без розширення.

## Перед установленням

Без розширення **Lolly URL Screenshot** усе одно відкривається, і ви можете скомпонувати знімок. Примітка над елементами керування інструмента пояснює, чого бракує.

Без розширення працює кожен елемент керування: цільовий URL, глибина прокручування, затримка для стабілізації, відступи обрізання й зміна кольорів. Розширення потрібне лише для знімка.

## Установлення

**Із Chrome Web Store:** незабаром. Після публікації розширення встановлюватиметься одним клацанням.

**Завантажте самостійно (для розробників).** Вихідний код розширення міститься в репозиторії в `shells/chrome-extension/`. Крок пакування збирає з цієї папки пакет для робочого середовища. Цей пакет працює лише з Lolly на `https://lolly.tools`.

1. Виконайте `pnpm run pack:chrome-extension`. Команда збирає пакет у `dist/chrome-extension/`.
2. Відкрийте `chrome://extensions`.
3. Увімкніть **Developer mode** (угорі праворуч).
4. Клацніть **Load unpacked** і виберіть папку `dist/chrome-extension/`.
5. Перезавантажте вкладку Lolly. Lolly виявляє розширення під час завантаження сторінки, і пропозиція «Get the extension» зникає. Тепер **Lolly URL Screenshot** (у розділі Утиліти) може зберігати знімки у файл і працює в режимі Lolly Batch.

::: details Для локального сервера розробки або папки вихідного коду
Для локального сервера розробки виконайте `pnpm run pack:chrome-extension:dev` і натомість завантажте `dist/chrome-extension-dev`. Цей пакет також приймає `http://localhost:5173` і має **Development** у назві.

Завантаження самої папки `shells/chrome-extension/` також працює для знімків PNG. Ця папка не має обходу сторінки, який додається під час пакування. SVG із цієї папки містить знімок екрана, а не фігури.
:::

## Що відбувається, коли Lolly надсилає запит

![Вкладка Lolly запитує одну сторінку, і ви натискаєте Approve once у вікні схвалення розширення. Фонова вкладка відкривається, читає сторінку й закривається. Потім вкладка Lolly отримує результат.](/info/diagrams/concepts/extension-request.svg)

1. **Lolly надсилає запит.** Невеликий скрипт повідомляє Lolly про наявність розширення, тож створення знімка чи читання сторінки може початися без додаткового налаштування.
2. **Ви схвалюєте.** Розширення відкриває власне вікно **Approve page request**. Воно показує сайт, що надіслав запит, чи потрібен йому знімок екрана або вміст сторінки, та адресу сторінки. Нічого не читається, доки ви не натиснете **Approve once**. **Скасувати** або закриття вікна завершує запит.
3. **Chrome запитує один раз для кожного сайту.** Коли ви вперше схвалюєте запит для сайту, Chrome також запитує, чи можна розширенню отримати доступ до нього. Chrome зберігає наданий вами доступ, але кожен наступний запит усе одно потребує окремого **Approve once**.
4. **Сторінка читається у фоновій вкладці.** Розширення відкриває цільову сторінку у фоновій вкладці, робить знімок через DevTools Protocol (той самий `Page.captureScreenshot`, який використовує настільний застосунок), закриває вкладку й повертає результат вкладці Lolly, що надіслала запит.

::: details Як створюється знімок SVG
Для **SVG** розширення обходить сторінку, замість того щоб фотографувати екран. Скрипт із пакета розширення читає макет сторінки у фоновій вкладці й перетворює сторінку на фігури та текст у контурах. Файл залишається чітким за будь-якого розміру, а кожна частина залишається редагованою. Зображення на сторінці залишаються зображеннями. Усе, що сторінка малює через canvas, відео чи ефект, який SVG не може відтворити, копіюється зі знімка екрана тієї самої миті. Lolly порівнює результат із цим знімком. Коли вони надто відрізняються, SVG натомість містить знімок екрана.

Щоб перетворити текст на контури у власній гарнітурі сторінки, розширення передає Lolly файли шрифтів, які завантажила сторінка. Chrome не зберігає байти шрифту там, де розширення може їх прочитати, тому розширення запитує кожен шрифт у сторінки ще раз. Ваш браузер зазвичай відповідає зі свого кешу, а власна політика безпеки сторінки й далі застосовується до цього запиту.
:::

Схвалення охоплює один запит і втрачає чинність через 30 секунд. Одночасно може очікувати чи виконуватися лише один запит, а схвалений запит зупиняється через 55 секунд. Якщо сторінка Lolly закривається чи змінюється або цільова сторінка переходить на інший сайт, запит скасовується.

::: warning Знімки використовують ваш сеанс браузера
Сторінка завантажується з вашим сеансом браузера, тож сторінка, на якій ви ввійшли в обліковий запис, може показати приватну інформацію в результаті.
:::

Знімок створюється у вашому браузері у вашій мережі, тож `localhost` і внутрішні сайти працюють. Знімок не надсилається на сервер. Єдиний мережевий трафік виникає, коли браузер завантажує запитану вами сторінку та, для SVG, удруге завантажує файли шрифтів цієї сторінки.

Під час створення знімка ви можете ненадовго побачити банер *«…почав налагодження цього браузера»* на тимчасовій вкладці. Банер з'являється через DevTools Protocol і зникає, коли знімок готовий.

## Читання сайту для Lolly Design System Setup

Джерело **Website** у Lolly Design System Setup започатковує дизайн-систему з вашого наявного сайту. У браузері Chromium сторінку читає розширення. У настільному застосунку сторінку отримує сам застосунок. У браузері без розширення плитка Website не пропонується.

- **Одна адреса, одна сторінка.** Після вашого схвалення розширення відкриває сторінку в такій самій фоновій вкладці, читає відрендерену розмітку, текст таблиць стилів і кілька зображень значків та логотипів, потім закриває вкладку. Розширення не переходить за посиланнями й не сканує сайт.
- **Таблиці стилів, розміщені деінде** (на CDN чи в сервісі шрифтів), теж завантажуються, бо містять кольори й типографіку сторінки. Запити до інших джерел надсилаються без ваших cookie. Запити до того самого джерела використовують ваші cookie, як і сама сторінка.
- **Усе має ліміти**: кількість таблиць стилів і зображень та обсяг байтів обмежено, тож ворожа чи частково несправна сторінка повертає неповний матеріал, а не спричиняє зависання.
- **Розбір відбувається на вашому пристрої.** Байти повертаються прямо до вкладки Lolly, що надіслала запит, і вона перетворює їх на кольори, типографіку й логотипи.

Вставлення адреси лише заповнює поле. Нічого не читається, доки ви не почнете читання й не натиснете **Approve once**.

## Дозволи

`manifest.json` розширення декларує чотири дозволи, а також доступ до сайтів, який воно запитує окремо для кожного сайту. Він задає `minimum_chrome_version: 111`, а поточна версія — 0.5.0.

| Дозвіл | Для чого потрібен | Коли надається |
|---|---|---|
| `debugger` | Керує фоновою вкладкою через DevTools Protocol, який робить знімок екрана та, для SVG, виконує обхід сторінки. | Під час установлення |
| `tabs` | Відкриває тимчасову фонову вкладку й потім закриває її, а також перевіряє, що ні сторінка Lolly, ні цільова сторінка не змінили адресу після вашого схвалення. | Під час установлення |
| `scripting` | Запускає читач однієї сторінки на вказаному вами сайті для джерела Website. | Під час установлення |
| `storage` | Записує id відкритої вкладки лише у сховище сеансу, щоб вкладка закрилася, навіть якщо браузер призупинить розширення під час читання. Очищується під час наступного запуску; жодні дані про вас не зберігаються. | Під час установлення |
| `optional_host_permissions: ["http://*/*", "https://*/*"]` | Доступ до сайту, який не надається під час установлення. Коли ви натискаєте **Approve once**, розширення просить Chrome надати доступ до одного сайту з цього запиту. | Коли ви вперше схвалюєте запит для цього сайту, після запиту Chrome |

Розширення читає лише схвалену вами сторінку. Воно не читає й не надсилає ваші дані перегляду.

## Усунення несправностей

- **Досі бачите «Get the extension»?** Перезавантажте вкладку Lolly.
- **На цьому сайті нічого не відбувається?** Розширення працює лише на `https://lolly.tools`, а в пакеті для розробки також на `http://localhost:5173`. Інше джерело, як-от самостійно розміщена копія Lolly, потребує власної збірки розширення, яка вказує це джерело і в `manifest.json`, і в `policy.js`. Редагування лише маніфесту не працює.
- **Не вдається зробити знімок?** Перевірте, що URL доступний і починається з `http://` або `https://`. Деякі сторінки блокують автоматизоване створення знімків. Якщо ви натиснули **Скасувати**, закрили вікно схвалення або чекали довше ніж 30 секунд, почніть створення знімка знову.
