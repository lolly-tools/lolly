# Lolly і API рендерингу

_Остання перевірка: 28 вересня 2026._

Якщо ви сьогодні генеруєте зображення з шаблонів через API, ця сторінка каже, як Lolly виконує те саме завдання на вашому власному пристрої, у CI або на вашому власному сервері.

## Що розміщені API рендерингу роблять краще

[Bannerbear](https://www.bannerbear.com/) та [Placid](https://placid.app/) пакують рендеринг як керовані сервіси з власною інфраструктурою, інтеграціями та підтримкою. Ви надсилаєте запит, а сервери запускає хтось інший.

## Де вони перетинаються

Обидва перетворюють шаблон плюс вхідні дані на медіа. Lolly бере вхідні дані з [посилання](/info/url-mode.html), [CLI](/info/cli.html), пакетної сітки чи кінцевої точки сервера.

## Як Lolly виконує спільне завдання

Той самий інструмент рендерить на ноутбуці, у завданні CI чи на сервері, з тих самих вхідних даних. Локальний рендеринг і рендеринг у CI взагалі не потребують сервісу.

![Налаштування пакетного експорту: назва файлу, формат за замовчуванням, одиниці, DPI та кількість рядків для рендерингу](/info/shots/use-batch-toolbar.svg)

На сервері [Lolly Work](/info/compare.html#what-runs-where) запускає рушій Lolly за API й застосовує видимість інструментів та політики вхідних даних. Його [відновлюваний сервіс рендерингу](/info/work-renders.html) підтримує окремі завдання та пакети, ідемпотентне подання, статус, обмежені повтори, скасування та збережені виводи, а перервана робота відновлюється після перезапуску, коли налаштовано постійне сховище.

Сервер має швидкий шлях SVG і PNG та необов'язковий робітник Chromium для інструментів, що потребують браузера. Автоматизація входить за сервісними токенами, готовий вивід може йти через [схвалену доставку](/info/work-delivery.html) до призначень організації, а налаштована ідентичність підпису додає Content Credentials до підтримуваного виводу.

## Хто запускає сервіс

З Lolly окрема людина рендерить локально, або команда запускає Lolly Work на власній інфраструктурі. Подання серверного завдання надсилає його вхідні дані та потрібні ресурси до цього екземпляра, що відрізняється від шляху на пристрої. Довговічний сервіс потребує постійної бази даних і сховища виводу, а інструменти, що залежать від браузера, потребують робітника Chromium; [Install Lolly Work](/info/work-install.html) описує обоє.

Bannerbear і Placid є торговими марками своїх власників. Ця сторінка описує, де продукти перетинаються, і не пов'язана з жодним із них.
