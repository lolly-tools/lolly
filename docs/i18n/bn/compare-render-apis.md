# Lolly ও রেন্ডারিং API

_সর্বশেষ যাচাই: 5 নভেম্বর 2026।_

আপনি API দিয়ে টেমপ্লেট থেকে ছবি তৈরি করলে এই পৃষ্ঠা জানায় সেই উৎপাদন নিজের ডিভাইসে, CI-তে বা আপনার নিয়ন্ত্রণে থাকা সার্ভারে চালালে কী বদলায়। [হোস্ট করা রেন্ডার API থেকে সরুন](/info/work-move-from-render-api.html)-এ ধাপগুলো আছে।

## হোস্ট করা রেন্ডারিং API যা ভালো করে

[Bannerbear](https://www.bannerbear.com/) ও [Placid](https://placid.app/) পরিচালিত সার্ভিস: আপনি অনুরোধ পাঠান, আর অন্য কেউ সার্ভার চালায়।

- **চালানোর কিছু নেই।** কোনো সার্ভার, ডেটাবেস, স্টোরেজ, আপডেট বা সক্ষমতার পরিকল্পনা নেই।
- **হোস্ট করা টেমপ্লেট এডিটর**, সঙ্গে নিজের মতো করে বদলানোর জন্য প্রস্তুত টেমপ্লেট।
- **একটি API থেকে আরও ধরনের আউটপুট।** দুটিই ভিডিও ও PDF এন্ডপয়েন্ট প্রকাশ করে, আর Bannerbear-এর ডকুমেন্টেশনে অ্যানিমেটেড আউটপুট, WebP ও AVIF, স্ক্রিনশট এবং AI দিয়ে ব্যাকগ্রাউন্ড সরানোর কথাও আছে।
- **তাদের নিজস্ব সংযোগ ও সহায়তা।**

আপনি এই ব্যবস্থাই চাইলে সার্ভিসগুলো ভালো পছন্দ।

## নিজে হোস্ট করলে যা পান

- **আপনার কনটেন্ট আপনার সিস্টেমেই থাকে।** ইনপুট, অ্যাসেট ও আউটপুট আপনার বেছে নেওয়া অবকাঠামোয় থাকে। ডিভাইসে বা CI-তে রেন্ডার করতে কোনো সার্ভিস লাগে না।
- **নিয়মগুলো টুলে থাকে।** রঙ, টাইপ, লোগো ও লক করা ইনপুট আপনার [ডিজাইন সিস্টেম](/info/brand-studio.html) থেকে আসে, তাই যে অনুরোধ করে সে শুধু আপনার অনুমতি দেওয়া অংশই বদলাতে পারে। [Lolly Work](/info/compare.html#what-runs-where) প্রতিটি অনুরোধে টুলের দৃশ্যমানতা ও ইনপুটের নীতি প্রয়োগ করে।
- **সব জায়গায় একই টুল।** ল্যাপটপে, CI জবে বা সার্ভারে টুল একই ইনপুট থেকে রেন্ডার করে। মানুষ অ্যাপে একই টুল সম্পাদনা করতে পারেন।
- **রেকর্ড আপনার হাতে।** [রেন্ডার রিসিপ্ট](/info/work-renders.html#evidence-and-identity), অডিটের ধারাবাহিক রেকর্ড এবং স্বাক্ষরের পরিচয় কনফিগার করলে Content Credentials।
- **ওপেন সোর্স এবং ব্যবহার মেপে খরচ নেই।** আপনি কোড চালান এবং শুধু নিজের অবকাঠামোর জন্য খরচ দেন।

এই সার্ভিসগুলো আপনার হয়ে যে কাজ করে সেই দায়িত্ব আপনি নেন। টেকসই সার্ভারের জন্য স্থায়ী ডেটাবেস ও আউটপুট স্টোরেজ লাগে। যে টুলের ব্রাউজার লাগে তার Chromium ওয়ার্কার লাগে। [Lolly Work ইনস্টল করুন](/info/work-install.html) দুটিই বর্ণনা করে।

## কাজগুলোর তুলনা

| কাজ | হোস্ট করা রেন্ডারিং API | Lolly |
|---|---|---|
| ডেটা থেকে টেমপ্লেট পূরণ | টেমপ্লেট ও তার লেয়ারের নামসহ API অনুরোধ | টুল ও তার ইনপুটের নামসহ [URL](/info/url-mode.html), [CLI](/info/cli.html) বা [সার্ভার API](/info/work-automation-api.html) |
| টেবিল থেকে অনেক ফাইল | ব্যাচ ও সংগ্রহ | আপনার ডিভাইসে [ব্যাচ](/info/batch.html), বা সার্ভারে [রেন্ডার ব্যাচ](/info/work-renders.html#batches-with-durable-rows) |
| ফলাফলের জন্য অপেক্ষা বা পোল করা | পোলিং, বা সিঙ্ক্রোনাস বিকল্প | স্থায়ী রেন্ডার যার জন্য আপনি পোল করেন, বা তাৎক্ষণিক রেন্ডার |
| শেষ হলে ওয়েবহুক কল করা | হ্যাঁ | আপনার অনুমতি দেওয়া অরিজিনে [স্বাক্ষর করা কলব্যাক](/info/work-renders.html) |
| ডায়নামিক ছবির URL | হ্যাঁ | [শেয়ার লিংক ও `/render` URL](/info/url-mode.html) |
| টেমপ্লেট সম্পাদনা | হোস্ট করা এডিটর | আপনার ডিভাইসে [Design](/info/using.html) |
| এজেন্ট | দুটিই MCP সার্ভার প্রকাশ করে | [MCP](/info/mcp.html), সঙ্গে Lolly Work-এ টোকেনের নীতির অধীনে প্রতিষ্ঠানের এন্ডপয়েন্ট |

Lolly-র নিজস্ব আউটপুটের ধরনগুলো [এক্সপোর্ট](/info/exporting.html)-এ তালিকাভুক্ত আছে। বর্তমানে Work সার্ভারে স্থায়ী রেন্ডার SVG, PNG, JPG ও PDF তৈরি করে, আর [ভিডিও ডিভাইস, CLI ও MCP-তেই থাকে](/info/work-renders.html#production-still-checks-and-permitted-repairs)।

| | Bannerbear V5 | Bannerbear V2 | Placid |
|---|---|---|---|
| আপনার অনুরোধ | Work-এর মাইগ্রেশন API একই কাঠামো গ্রহণ করে | একই | একই |
| আপনার টেমপ্লেট | নিশ্চিত স্কিমা নেই এমন লেয়ারের ধরন ছাড়া সম্পাদনাযোগ্য নথি হিসেবে **Import** করুন | শুধু ফিল্ডের নাম ও প্রিভিউ। প্রতিটি নতুন করে তৈরি করুন | শুধু ফিল্ডের নাম ও প্রিভিউ। প্রতিটি নতুন করে তৈরি করুন |
| বিদ্যমান ডায়নামিক URL | সমর্থিত নয় | সমর্থিত নয় | হোস্ট বদলানোর পরও আপনার পুরোনো ব্যক্তিগত টোকেন দিয়ে স্বাক্ষর করা URL কাজ করে |
| ওয়েবহুক | নিবন্ধিত ওয়েবহুক সমর্থিত নয় | `webhook_url` কাজ করে | `webhook_success` কাজ করে |
| WebP ও AVIF আউটপুট | নাম উল্লেখ করে প্রত্যাখ্যান করা হয় | দেওয়া হয় না | WebP নাম উল্লেখ করে প্রত্যাখ্যান করা হয় |
| অ্যানিমেশন, ভিডিও, সংগ্রহ, স্ক্রিনশট | মাইগ্রেশন API-তে নেই | মাইগ্রেশন API-তে নেই | মাইগ্রেশন API-তে নেই |

::: note প্রকাশ্য ডকুমেন্টেশন থেকে তৈরি
এটি প্রতিটি বিক্রেতার প্রকাশ্য ডকুমেন্টেশন থেকে তৈরি করা হয়েছে এবং কোনো চালু অ্যাকাউন্টে চালানো হয়নি। আপনার অ্যাকাউন্ট থাকলে [স্থানান্তরের নির্দেশিকায়](/info/work-move-from-render-api.html#check-it-on-your-own-account) একটি ছোট যাচাইয়ের তালিকা আছে।
:::

আপনি একটি টেমপ্লেট সরিয়ে বাকিগুলো যেখানে আছে সেখানেই রাখতে পারেন। [Lolly ছেড়ে যাওয়াও](/info/work-move-from-render-api.html#leave-lolly-too) একইভাবে উন্মুক্ত: টুলগুলো সাধারণ ফাইল, আর CLI কোনো সার্ভার ছাড়াই সেগুলো রেন্ডার করে।

## সার্ভিস কে চালায়

Lolly-তে একজন ব্যক্তি স্থানীয়ভাবে রেন্ডার করেন, বা একটি দল নিজেদের অবকাঠামোয় Lolly Work চালায়। সার্ভার জব তার ইনপুট ও প্রয়োজনীয় অ্যাসেট সেই ইনস্ট্যান্সে পাঠায়। ডিভাইসে চলার পথে তা হয় না।

Bannerbear ও Placid তাদের মালিকদের ট্রেডমার্ক। এই পৃষ্ঠা তাদের প্রকাশ্য ডকুমেন্টেশন থেকে পণ্যগুলোর কাজের মিল বর্ণনা করে এবং কোনোটির সঙ্গেই সংশ্লিষ্ট নয়।
