# Lolly 도구별 비교

Lolly는 기기 안에서 하는 단일 변환부터 거버넌스가 갖춰진 조직의 에셋 제작까지 크리에이티브 작업을 폭넓게 다뤄요. 이 페이지들은 각 제품이 지원하는 워크플로, 배포 방식, 솔루션을 고를 때 중요한 제약을 비교해요.

_최종 확인일: 2026년 9월 28일._

## 하나의 프로젝트, 따로 배포되는 두 부분

**Lolly**는 만들기, 편집, 변환, 내보내기를 위한 엔진, 앱, 도구예요. 사용자의 기기에서 실행되고, 필요한 에셋이 준비되면 오프라인에서도 작동하며, 단독으로 사용할 때는 계정이 필요 없어요.

**[lolly.work](https://lolly.work)**는 이 프로젝트의 조직용 서비스이며, [lolly-work 저장소](https://github.com/lolly-tools/lolly-work)에서 관리해요. SSO, SCIM 프로비저닝, 역할과 정책, 공유 카탈로그와 프로젝트, 승인, work 협업, 사용 현황 보고, 감사 기록, 서버 렌더링을 제공해요. 두 부분 모두 MPL-2.0 오픈 소스예요. 조직은 Lolly와 함께 lolly.work를 호스팅하고 어떤 서비스를 켤지 결정해요.

비교 대상은 **Lolly + lolly.work**예요. 조직용 서비스가 필요한 기능은 명시적으로 표시해요. 단독으로 사용하면 파일이 기기에 그대로 남아요. 공유 프로젝트, work 협업, 서버 렌더링, 전달을 선택하면 관련 데이터가 구성된 서비스로 전송돼요. 공개 lolly.work 사이트는 샌드박스예요. 조직 배포에 대해서는 [배포 가이드](https://github.com/lolly-tools/lolly-work/blob/main/docs/install.md)와 [현재 상태](https://github.com/lolly-tools/lolly-work/blob/main/docs/status.md)를 참고하세요.

- [Lolly와 Adobe](/info/compare-adobe.html) - 편집, 변환, 전문가용 출력, Content Credentials.
- [Lolly와 Figma](/info/compare-figma.html) - 디자인, 실시간 협업, 재사용 가능한 에셋 제작.
- [Lolly와 Penpot](/info/compare-penpot.html) - 오픈 소스 디자인, 공유 토큰, 조직 워크플로.
- [Lolly와 브랜드 포털](/info/compare-brand-portals.html) - 승인된 라이브러리, 잠긴 템플릿, ID, 검토, 보고.
- [Lolly와 렌더링 API](/info/compare-render-apis.html) - 사용자의 기기, CI, 또는 lolly.work를 통한 자동 생성.
- [Lolly와 온라인 파일 변환기](/info/compare-converters.html) - 사용자의 기기에서 하는 형식 변환.
