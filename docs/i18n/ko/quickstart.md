# 시작하기

도구를 나만의 색상과 글꼴로 설정하고, 이미 가진 작업물을 다시 활용하세요. 계정이 필요 없고, 만들기와 내보내기는 기기에서 실행돼요.

::: steps
- <!--i:eti-sparkles--> **[파일 하나 만들기](/info/make-something.html)** 몇 분 만에 QR 코드를 만들며, 모든 단계를 보여줘요.
- <!--i:eti-palette--> **[브랜드 적용하기](#put-your-brand-in)** 색상 하나, 토큰 파일, 완성된 디자인에서 시작하세요.
- <!--i:eti-folder-move--> **[작업물 가져오기](#bring-in-what-you-already-have)** 이미 가진 디자인, 덱, 데이터를 기기에서 읽어요.
- <!--i:eti-repeat--> **[같은 종류의 결과물 더 만들기](#make-many-share-and-automate)** 링크를 공유하거나, 스프레드시트를 채우거나, 스크립트에서 도구를 실행하세요.
:::

[Lolly란?](/info/what-is-lolly.html)은 5분 분량의 소개예요. [Lolly의 작동 방식](/info/how-lolly-works.html)은 누가 무엇을 하는지 보여줘요.

## 브랜드 적용하기

lolly.tools는 Lolly 자체의 샘플 디자인 시스템인 **Lolly Demo**로 열려요([Lolly Demo 알아보기](/info/lolly-demo.html)). 사용자의 디자인 시스템이 Lolly Demo를 대체해요. 디자인 시스템은 모든 도구가 그리는 데 쓰는 작은 디자인 토큰 모음(색상, 글꼴, 몇 가지 규칙)이에요. 한 번 설정하면 만드는 모든 것이 처음부터 브랜드에 맞아요.

가지고 있는 것에 맞는 경로를 고르세요.

- <!--i:palette--> **색상 하나.** **Design System Setup** 화면(`#/start`)을 열고 디자인 시스템의 이름을 정한 뒤 기본 색상을 고르세요. Lolly는 그 색상에서 밝고 어두운 배경, 텍스트, 강조색이 있는 접근성 높은 팔레트를 만들어요. 글꼴을 고르면 바로 쓸 수 있는 브랜드가 생겨요.
- <!--i:upload--> **토큰 파일.** Lolly Design System Setup 맨 위의 **Add from…**는 DTCG, Tokens Studio, Penpot 토큰 파일, SVG 또는 `LollyBrand` 팩을 받아요. 팔레트가 파일의 내용으로 채워져요. 디자인 시스템이 비어 있으면 Board의 **Start from a reference**가 같은 선택기를 열어요.
- <!--i:pentool--> **완성된 디자인.** Lolly Design에서 **Import a design**을 선택하고 Figma, Penpot, Illustrator, InDesign, Affinity, Photoshop, PowerPoint 또는 SVG 파일을 끌어다 놓으세요([모든 형식](/info/design-import.html#what-comes-in-from-each-app)). 아래의 [이미 가진 작업물 가져오기](#bring-in-what-you-already-have)를 참고하세요.

갤러리를 처음 열면 맨 위의 인사말이 다음 단계 하나를 제안해요. lolly.tools에서는 **Start making**이 Launch 포스터로 Lolly Design을 열어요. 새로 설치한 경우 **Make it yours**가 Lolly Design System Setup을 열어요. 그 버튼 아래의 **Bring a file**은 디자인용 파일 선택기를 열고, 앞의 두 선택 중 다른 하나는 링크로 표시돼요. 이 중 하나를 선택하거나 닫기 버튼을 누르면 인사말은 더 이상 나타나지 않아요.

![새 디자인 시스템의 Lolly Design System Setup Colours 공간: 실시간 색상 칩 하나, 입력란 하나, 첫 결정에 필요한 전부예요](/t/url-shot?url=%2F%23%2Fstart%3Farea%3Dcolor&system=new-design-system&width=1440&height=740&dpi=192&waitMs=1800&format=svg&walker=1&dark=1&filename=bs-colours-new-system)

**Board**, **Colours**, **Type**, **Logos**, **Tokens**, **Files**, **Rules**, **Skills**의 여덟 공간을 원하는 순서로 사용해 디자인 시스템을 더 발전시켜요. 입력하는 동안 앱의 모든 미리보기가 업데이트돼요. [Lolly Design System Setup](/info/brand-studio.html)에서 각 공간을 다뤄요.

글꼴은 기기에 보관돼요. 선택한 Google Font는 브랜드 에셋으로 저장되므로 서체가 오프라인에서 작동하고, 도구가 그릴 때는 아무것도 가져오지 않아요.

### 디자인 시스템 보기, 전환, 공유

- **활성 디자인 시스템 보기.** **Settings → Design system**은 활성 디자인 시스템을 표지와 페이지로 읽기 전용으로 보여줘요.
- **디자인 시스템 전환하기.** **Settings → Preferences → Design systems**는 이 기기의 모든 디자인 시스템을 나열해요. 한 조직이 여러 디자인 시스템을 운영하거나 여러 컬러웨이가 있는 하나를 운영할 수 있어요. [브랜드 구조](/info/brand-architectures.html)에서 구성을 보여줘요.
- **디자인 시스템 공유하기.** 디자인 시스템을 `LollyBrand` 팩으로 내보내세요. 동료가 파일 하나를 가져오면 같은 팔레트, 글꼴, 규칙을 얻어요.

빌드나 조직에서 제공한 디자인 시스템은 **관리 대상**이에요. 잠금 표시가 있고 읽기 전용으로 유지돼요. 바꾸려면 **Settings → Preferences → Design systems**에서 편집 가능한 사본을 만드세요.

![Settings의 Design system 탭: 표지와 페이지로 표시된 활성 디자인 시스템](/t/url-shot?url=%2F%23%2Fd%3Ftab%3Dbrand&width=1440&height=900&dpi=192&waitMs=1800&format=svg&walker=1&localize=1&dark=1&filename=dashboard-brand&waitSelector=%5Bdata-issue-ready%5D)

디자인 시스템은 Penpot이 읽고 쓰고 Tokens Studio가 Figma로 가져오는 형식인 DTCG 토큰으로 되어 있어요. 디자인에 쓰는 팔레트와 Lolly가 적용하는 팔레트는 하나의 문서예요. 자세한 내용은 [디자인 토큰](/info/design-tokens.html)을 참고하세요.

::: details 개발자용: 명령줄에서 브랜드 팩 만들기
`ingest:brand`는 체크아웃한 소스에서 재사용할 수 있는 브랜드 팩을 만들어요. Penpot과 Tokens Studio가 내보내는 세 가지 컨테이너를 받아요. 단일 `tokens.json`, `$metadata.json`이 있는 세트별 파일 디렉터리, `project.penpot` 아카이브예요.

```bash
pnpm run ingest:brand ./my-tokens.json --name acme --label "Acme" --activate
```

`--activate`는 브랜드를 프로필로 등록하고 카탈로그를 빌드하고 검증해요. 기본 프로필은 바꾸지 않아요. 새 팩을 쓰려면 `LOLLY_PROFILE=acme`로 실행하세요. [구성](/info/configuration.html)에서 브랜드 팩과 프로필이 어떻게 연결되는지 설명해요.
:::

## 이미 가진 작업물 가져오기

**Lolly Design 파일.** Figma, Penpot, Illustrator, InDesign이나 SVG 앱에서 완성한 작업물을 Lolly Design에서 편집 가능한 레이아웃으로 열 수 있어요. 텍스트는 다시 입력할 수 있고, 도형은 도형으로 유지되며, 이미지는 라이브러리에 들어가요. 파일은 브라우저에서 읽고 아무것도 업로드하지 않아요. [디자인 가져오기](/info/design-import.html)에서 각 형식과 유지되는 요소를 확인할 수 있어요.

**덱.** PowerPoint `.pptx`를 Lolly에 끌어다 놓으면 슬라이드를 에셋으로 보관해요. **Lolly Markdown Slides**에서 Markdown으로 새 덱을 작성하세요. [덱 리브랜딩하기](/info/rebrand.html)는 덱에 자신의 디자인 시스템을 적용해요.

**데이터.** CSV나 JSON 표를 붙여넣거나 끌어다 놓으면 도구의 반복 입력란이 채워져요. [Lolly Batch](/info/batch.html#make-many-versions-of-one-design)는 행마다 완성된 파일 하나를 만들어요.

### 일회성 작업물을 템플릿으로 만들기

가져온 레이아웃은 일반적인 Lolly Design 세션이에요. **Share with rules**는 세션을 도구로 바꿔요. 다른 사람이 바꿀 수 있는 부분을 정하면 그 사람은 그 부분만 채워요.

![Lolly Design 원본을 보관하고 제작용 사본에서 입력과 제한을 정한 뒤, 받는 사람이 채울 수 있는 재사용 가능한 .lolly 도구를 공유해요](/info/diagrams/concepts/share-with-rules.svg)

## 대량으로 만들고 공유하고 자동화하기

- <!--i:download--> **내보내기.** 도구는 SVG, PDF, PNG, JPG, WebP, 동영상 등을 만들고, 필요하면 실제 인쇄 크기로 만들어요. 도구마다 제공하는 형식이 달라요. [파일 내보내기](/info/exporting.html)를 참고하세요.
- <!--i:link--> **링크 공유하기.** 도구의 설정은 링크에 담겨 이동하므로 어디에서든 링크로 같은 파일을 다시 열 수 있어요.
- <!--i:layers--> **행마다 하나씩 만들기.** [Lolly Batch](/info/batch.html#make-many-versions-of-one-design)에서 스프레드시트로 도구를 실행하세요.
- <!--i:cpu--> **자동화하기.** [CLI](/info/cli.html)와 [AI 에이전트](/info/ai-agents.html)에서도 같은 렌더링을 실행해요.

링크는 완전한 요청이에요. 아래 차트의 유형, 제목, 데이터 표는 주소 표시줄에 입력한 것이에요.
