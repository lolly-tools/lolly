# Lolly와 온라인 파일 변환기

_최종 확인일: 2026년 9월 28일._

Lolly는 사용자의 기기에 있는 브라우저에서 파일을 변환해요. HEIC에서 JPG, PNG에서 SVG, PDF에서 이미지 등 다양한 조합을 지원해요. 지원되는 변환과 제약은 [Lolly가 열고 만들 수 있는 모든 형식](/info/formats.html)을 참고하세요.

## 변환이 이뤄지는 곳

브라우저 기반 변환기는 처리를 위해 파일을 업로드하기도 하고 로컬에서 변환하기도 해요. Lolly의 기기 안 유틸리티는 파일을 로컬에서 처리하며, 계정, 광고, 트래커가 없어요. Lolly 워터마크나 출처 메타데이터를 추가하지 않아요. 필요한 변환 에셋이 준비되면 오프라인에서도 작동할 수 있어요. 파일 크기는 기기의 메모리와 해당 형식 리더에 따라 제한돼요.

변환기는 파일을 어디서 처리하는지뿐 아니라 필요한 형식과 충실도를 기준으로 고르세요. 어떤 변환은 편집 가능한 구조를 유지하고, 어떤 변환은 결과를 평면화해요. Lolly의 형식 페이지에서 그 차이를 설명해요.

## 팀에 더 많은 것이 필요할 때

[lolly.work](https://lolly.work)는 Lolly 프로젝트에서 따로 배포되는 조직용 서비스예요. 지원되는 제작 워크플로를 위해 SSO, SCIM, 공유 카탈로그, 승인, 보고, 서버 렌더링을 더해요. 두 부분 모두 MPL-2.0 오픈 소스예요. 조직은 두 부분을 함께 사용하면서, 구성원은 로컬 변환에 계속 기기 안 유틸리티를 쓸 수 있어요.

이 차이는 데이터 처리에서 중요해요. 로컬 변환은 파일을 기기에 그대로 두지만, 공유 업로드, 서버 렌더링, 전달을 선택하면 관련 데이터가 구성된 서비스로 전송돼요. [통합 솔루션 개요](/info/compare.html)에서 이 분리를 설명해요.
