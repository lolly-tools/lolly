# Lolly와 온라인 파일 변환기

_마지막 확인: 2026년 9월 28일._

평소 "HEIC를 JPG로" 또는 "PDF 압축"을 검색하고 나오는 사이트에 파일을 업로드한다면, Lolly는 같은 변환을 자신의 기기에서 브라우저 안에서 처리해요.

<!--i:eti-award-->
## 변환 사이트가 더 잘할 수 있는 것

일부 변환 사이트는 Lolly가 다루지 않는 형식을 처리하고 설정이 필요 없어요. 필요한 형식과 재현 정확도, 파일을 처리하는 위치를 기준으로 변환기를 선택하세요. 어떤 변환은 편집 가능한 구조를 유지하고, 어떤 변환은 결과를 평탄화해요.

<!--i:eti-map-pin-->
## 변환이 일어나는 곳

브라우저 기반 변환기는 처리를 위해 파일을 업로드하거나 로컬에서 변환할 수 있어요. Lolly의 변환 유틸리티는 계정, 광고, 추적기 없이 파일을 로컬에서 처리해요. Lolly 워터마크나 Content Credentials를 추가하지 않아요. 변환에 필요한 에셋이 저장되면 유틸리티는 오프라인으로 작동해요. 파일 크기는 기기의 메모리와 형식 리더에 따라 제한돼요.

[Lolly가 열고 만들 수 있는 모든 형식](/info/formats.html)에 HEIC에서 JPG로, PNG에서 SVG로, PDF에서 이미지로의 변환을 포함해 지원되는 변환과 그 한계가 나열돼 있어요.

<!--i:eti-building-->
## 팀에 더 많은 기능이 필요할 때

Lolly Work를 운영하는 조직의 구성원도 로컬 변환에는 기기에서 실행되는 유틸리티를 사용해요. 데이터는 공유 업로드, 서버 렌더링, 전달을 할 때만 조직 서버로 전송돼요. [무엇이 어디에서 실행되나요](/info/compare.html#what-runs-where)에서 이 구분을 설명해요.
