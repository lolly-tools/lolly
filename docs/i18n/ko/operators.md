# 관리

Lolly는 각자의 기기에서 실행돼요. 팀에 로그인, 공유 프로젝트, 관리되는 에셋, 검토, 서버 작업이 필요하면 조직이 같은 프로젝트의 오픈 소스 조직 서버인 **Lolly Work**를 추가해요. 이 페이지들은 그 서버를 설정하고 돌보는 사람을 위한 것이에요.

구성원이 얻는 것은 [조직에서 Lolly 사용하기](/info/organisation.html)에서, 서버가 맡는 책임은 [Lolly Work 아키텍처](/info/work-overview.html)에서 확인하며 시작하세요.

## 접근과 정책 설정

- [도입 및 거버넌스](/info/adoption-governance.html)는 롤아웃과 브랜드 규칙의 역할을 다뤄요.
- [신원과 세션](/info/work-identity.html)은 로그인과 그룹 매핑을 다뤄요. [역할과 권한](/info/work-permissions.html)은 역할, 권한, 소유자 보호를 설명해요.
- [정책과 거버넌스](/info/work-governance.html)는 도구 오버레이, 잠긴 입력, 정책을 다뤄요. [조직 AI 정책 관리](/info/work-ai-policy.html)는 승인과 실행 한도를 다뤄요.
- [계정 데이터 제어](/info/work-account-lifecycle.html)와 [Work 저장소와 데이터 수명 주기](/info/work-data-lifecycle.html)는 내보내기, 오프보딩, 보관, 그 한계를 다뤄요.
- [프로필, 브랜드, 도구 구성](/info/configuration.html)은 Lolly 빌드가 어떤 도구와 디자인 시스템을 담는지 다뤄요.

## 에셋 연결과 작업 검토

- [디자인 시스템 관리](/info/work-design-system-administration.html)는 소스 목록, 검토된 변경, 롤백을 다뤄요.
- [카탈로그와 콘텐츠](/info/work-catalog.html)는 공유 에셋과 노출 규칙을 다뤄요. [공급자 가이드](/info/work-provider-guides.html)는 각 소스 플랫폼의 설정 및 검증 요구 사항을 알려줘요.
- [승인](/info/work-approvals.html)은 검토 체인과 업무 분리를 다뤄요. [렌더링과 공유](/info/work-sharing.html)는 링크와 서버 출력을 다뤄요.
- [문서에 에이전트 초대](/info/work-document-agents.html)는 범위가 제한된 문서 접근, 만료, 폐기를 다뤄요. 초대는 배포나 인프라 접근 권한을 부여하지 않아요.

## 다음 작업 찾기

- [만들기](/info/creators.html)에는 창작 작업과 팀 플레이북이 있어요.
- [배포](/info/operate.html)는 Lolly와 Lolly Work 서버의 설치와 유지 관리를 다뤄요. 인스턴스의 구성은 사람의 콘텐츠 프로필과 별개예요.
- [신뢰](/info/trust.html)는 데이터 흐름, 서명, 보안 경계를 설명해요.
