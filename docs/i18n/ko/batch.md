# Batch와 Multi-edit

같은 종류의 파일을 자주 만들다 보면 두 가지 작업이 생겨요. 한 디자인의 여러 버전이 필요할 때가 있어요. 열두 개 언어의 카드나 배너의 모든 크기 같은 것이에요. 서로 다른 저장된 디자인 여럿에 새 날짜나 새 제목 같은 하나의 변경을 모두 적용하고 싶을 때도 있어요.

**Batch**는 첫 번째 작업을, **Multi-edit**은 두 번째 작업을 해요. 둘 다 기기에서 실행되며 도구 자체와 같은 렌더 경로로 내보내요.

::: cols
## Batch

- 템플릿 하나, 여러 행. 각 행은 입력 한 세트이며 파일 하나를 만들어요.
- 직접 입력하거나, 스프레드시트에서 붙여넣거나, CSV를 가져와 행을 채워요.
- 행 수 제한이 없고, 페이지당 50개가 표시돼요.
- Projects 헤더의 **Batch**에서 열려요(`#/batch`).

## Multi-edit

- 서로 다른 저장된 디자인 2~8개가 실시간 카드로 나란히 놓여요.
- 사이드바 하나가 공유하는 입력을 편집한 뒤 각 카드의 고유 입력을 편집해요.
- 각 디자인은 원래 있던 곳에 다시 저장돼요.
- Projects 선택 막대의 **Edit together**에서 열려요.
:::

## 한 디자인의 여러 버전 만들기

**Projects**를 열고 헤더의 **Batch**를 누르세요. 그리드는 행 하나로 시작해요. 그 안에서 템플릿을 고른 뒤 행을 복제하거나 스프레드시트의 데이터를 붙여넣으세요. 폴더 안에서 열었다면 Batch는 그 폴더로 돌아가요.

![새 그리드의 Batch: 위쪽에 파일 이름과 행 도구가 있고, 첫 행의 템플릿 목록이 고를 수 있는 도구로 열려 있어요](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**행 채우기.** 셀에 입력하거나 Excel, Google Sheets 또는 다른 스프레드시트에서 블록을 그대로 붙여넣어요. **Import CSV**는 행을 추가하거나 배치를 대체해요. 내보내기 설정이 있는 셀에 붙여넣으면 Lolly가 붙여넣은 각 열이 어느 입력을 채울지 물어봐요. **Export CSV**는 그리드를 다시 내보내요. 그리드 아래의 **Columns**를 열면 더 많은 입력, 또는 행별 너비, 높이, 단위, DPI를 표시해요.

**출력 설정.** 도구 모음이 zip의 파일 이름, 모든 행의 **Default format**, 단위, DPI를 정해요. 형식 메뉴는 내보내기 패널의 그룹 목록으로, 카탈로그가 제공하고 브라우저가 지원하는 형식을 보여줘요. 자체 형식, 크기, 파일 이름이 있는 행은 자기 설정을 유지해요.

**렌더링.** **Render all**은 모든 행을 `.zip` 하나로 내보내요. 먼저 행을 선택하면 **Render selected**, **Export selected CSV**, **Print selected rows**가 그 행에만 작용하며, 선택을 해제하면 다시 배치 전체에 작업해요. **Print sheet**는 행을 인쇄 가능한 시트에 배치해요. **Batch activity**는 각 가져오기와 렌더링을 보고하며, 접으면 표에 더 많은 공간이 생겨요.

**배치 보관.** **Sessions**는 전체 그리드를 이름 붙은 배치 세션으로 저장하며 나중에 Projects에서 다시 열려요. Sessions는 선택과 상관없이 항상 모든 행을 저장해요. 같은 메뉴의 **Folders…**는 Projects 폴더 전체를 저장된 세션당 하나의 행으로 열고, 각 파일 이름에 폴더 경로가 붙어요.

::: details 행과 셀 선택
행은 체크박스로 선택하거나 체크박스를 Shift 클릭해 범위를 선택해요. 헤더 체크박스는 현재 페이지를 선택하고, **Select all *N* rows**는 다른 페이지의 행도 선택해요. 페이지를 이동해도 선택은 유지돼요. **Edit input**, **Duplicate**, **Remove**는 선택한 행에 작용하고, **Undo remove**는 마지막으로 제거한 행을 복원해요. 포커스된 셀에서 Shift+Space는 그 행을 선택하고 Escape는 선택을 지워요.

셀을 가로질러 끌거나, 셀을 Shift 클릭하거나, Shift+화살표 키로 사각형을 선택해요. **Copy cells** 또는 Ctrl+C / Command+C는 스프레드시트용 값을 복사해요. 포커스된 셀에서 Ctrl+A / Command+A는 모든 페이지의 보이는 모든 열을 선택하고, 행 체크박스에서는 같은 단축키가 모든 행을 선택해요. 셀을 선택해도 체크된 행은 체크된 채로 있어요. 셀을 더블클릭하거나 Enter를 누르면 텍스트를 편집해요. 클립보드의 사각형을 붙여넣거나, 값 하나를 붙여넣어 선택한 모든 셀을 채우세요. 빈 셀과 여러 줄 텍스트는 위치를 유지해요.
:::

### 행별 컬러웨이와 테마

각 행은 자체 테마 선택을 유지해요. 밝음 또는 어두움이며, 디자인 시스템에 있으면 컬러웨이도 포함돼요. Projects, 폴더, 저장된 배치에서 연 행은 세션이 저장된 선택으로 렌더링되고 미리보기도 그 선택으로 열려요. 인쇄 시트, 복제된 행, 채워진 행도 모두 이를 유지해요.

CSV는 크기 열 뒤의 `_themes` 열에 선택을 담으며, `_themes` 링크 매개변수와 같은 JSON이 들어가요. 예: `{"":"dark","colourway":"beach"}`. 빈 셀이나 `{}`는 디자인 시스템의 기본값을 뜻해요. 이 열은 일부 행에 선택이 있을 때만 쓰이므로 선택이 전혀 없는 배치는 이전과 같은 CSV를 내보내요. 가져올 때 유효한 테마 선택이 아닌 셀은 문제로 나열되고 그 행은 기본값으로 렌더링돼요. 그리드에는 아직 행의 선택을 바꾸는 컨트롤이 없으므로 CSV나 저장된 세션에서 설정하세요.

### Batch 또는 Render folder

Batch는 템플릿 하나의 여러 변형을 만들어요. 이미 저장한 세션을 다시 렌더링하려면 Projects에서 선택하고 **Render selection**을 쓰거나 폴더 전체에는 **Render folder**를 쓰세요. [작업물 찾기와 복구](/info/find-your-work.html#find-something-you-saved)가 둘 다 다뤄요.

## 저장된 여러 디자인 함께 편집하기

**Projects**에서 저장된 세션을 둘에서 여덟 개 선택하고 선택 막대에서 **Edit together**를 고르세요. 이들이 `#/multi?s=<slot>,<slot>…`에서 실시간 카드로 나란히 열려요. 각 카드는 세션의 실제 렌더링이므로 보이는 것이 내보내질 것이에요.

사이드바 하나가 모두를 구동해요.

- <!--i:sliders--> **Shared**가 먼저 와요. 둘 이상의 세션이 같은 방식으로 선언한 모든 입력(같은 ID, 같은 유형, 같은 제약, 배치 그리드가 열에 쓰는 규칙)이에요. 공유 컨트롤을 한 번 편집하면 그 입력을 선언한 모든 세션에 값이 반영되고 모든 카드에서 실시간으로 보여요. 같은 도구의 세션 둘은 모든 것을 공유하고, 서로 다른 도구 둘은 공통 입력만 공유해요.
- <!--i:document--> 그 아래의 **세션당 접힌 카드 하나**에는 해당 세션 고유의 모든 입력이 도구 자체 사이드바만큼 완전하게 들어 있고, **Format**, **W** / **H**, **Unit**, **DPI**, **Download**로 된 간결한 내보내기 블록이 있어요. 이 Download는 세션을 먼저 저장한 뒤 도구에서와 같은 파일 이름, 형식, Content Credentials로 파일을 렌더링해요.
- <!--i:search--> 맨 위의 **Filter inputs…**는 모든 카드의 컨트롤을 한꺼번에 좁혀서, 스크롤하지 않고 세션 여덟 개의 "제목"에 도달할 수 있어요.

카드를 아무거나 클릭하면(또는 카드에서 Enter를 누르면) 그 세션의 사이드바 카드가 열려요. **Save all**은 모든 세션을 각자의 슬롯에 다시 저장해요. **Download all**은 먼저 저장한 뒤 Projects의 **Render selection**과 같은 방식으로 전체 세트를 zip 하나로 렌더링하며, 도중에 선택적 비밀번호 잠금을 제안해요.

각 카드는 디자인 안에 놓인 도구를 포함해 자기 세션의 테마 선택으로 그려져요. 서로 다른 모습의 카드가 나란히 놓여도 주변 앱은 자체 색상을 유지하며, **Save all**, 다운로드, **Batch grid**, **Send to Print Sheet**는 각 세션의 선택을 유지해요.

### 한계

- **최대 여덟 개.** 모든 카드가 자체 실시간 런타임을 마운트하며, 여덟 개가 응답성이 유지되는 숫자예요. 더 많이 요청하거나 더 이상 없는 세션을 요청하는 링크는 반쯤 로드되지 않고 그렇다고 알려줘요.
- **링크는 로컬이에요.** 사용자 자신의 저장된 슬롯을 가리키므로 이 기기에서 그 세트를 다시 열어요. 공유 링크가 아니에요.
- **더 큰 규모에는** 같은 선택 막대에서 **Edit as sheet**를 선택하세요. 선택 전체를 배치 그리드(`#/batch?s=…`)의 행으로 열며, 크기 제한도 같은 도구 규칙도 없어요. 폴더는 둘 다에서 제외돼요. 그리드에서 **Sessions → Folders…**로 폴더를 열거나, Projects의 **Render folder**로 렌더링하세요.
- **검색은 Multi-edit에 닿지 않아요.** 검색 막대가 모르는 유일한 보기예요.
