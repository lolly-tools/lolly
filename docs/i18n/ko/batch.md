# Lolly Batch와 Lolly Multi-edit

<a id="batch-and-multi-edit"></a>

**Lolly Batch**는 열두 언어로 된 카드나 모든 크기의 배너처럼, 한 디자인의 여러 버전을 만들어요. **Lolly Multi-edit**는 새로운 날짜나 제목처럼 한 가지 변경을 서로 다른 여러 저장된 디자인에 적용해요.

둘 다 기기에서 실행되며 도구와 같은 렌더 경로로 내보내요.

::: cols
## Batch

- 템플릿 하나에 여러 행이 있어요. 각 행은 입력 한 묶음이며 파일 하나를 만들어요.
- 직접 입력하거나, 스프레드시트에서 붙여넣거나, CSV를 가져와 행을 채워요.
- 행 수에는 제한이 없고, 페이지마다 50개가 표시돼요.
- Projects 머리글의 **Lolly Batch**에서 열어요(`#/batch`).

<a id="multi-edit"></a>
## Lolly Multi-edit

- 서로 다른 저장된 디자인 두 개에서 여덟 개를 실시간 카드로 나란히 놓아요.
- 하나의 사이드바에서 공통 입력을 편집하고, 그다음 각 카드의 개별 입력을 편집해요.
- 각 디자인은 원래 있던 곳에 다시 저장돼요.
- Projects 선택 막대의 **Edit together**에서 열어요.
:::

## 한 디자인의 여러 버전 만들기

해당 **Projects** 보기를 열고 머리글에서 **Batch**를 누르세요. 격자는 행 하나로 시작해요. 그 행에서 템플릿을 고른 뒤 행을 복제하거나 스프레드시트의 데이터를 붙여넣으세요. 폴더 안에서 열었다면 Batch를 나갈 때 그 폴더로 돌아가요.

![새 격자의 Batch: 위쪽에 파일 이름과 행 도구가 있고, 첫 행의 템플릿 목록이 열려 고를 수 있는 도구를 보여줘요](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**행 채우기.** 셀에 입력하거나 Excel, Google Sheets, 다른 스프레드시트에서 블록을 붙여넣으세요. **Import CSV**는 행을 추가하거나 배치를 교체해요. 내보내기 설정이 있는 셀에 붙여넣으면 Lolly가 붙여넣은 각 열을 어떤 입력에 채울지 물어요. **Export CSV**는 격자를 파일로 써요. 격자 아래의 **Columns**를 열면 더 많은 입력이나 행별 너비, 높이, 단위, DPI를 표시할 수 있어요. 숫자, 텍스트, 선택 열의 **Fill** 팝오버에는 열의 여러 행에 토큰 하나를 연결하는 **Design token** 섹션도 있어요([여러 문서를 한 번에 연결하기](/info/token-workflows.html#link-many-documents-at-once)).

**출력 설정하기.** 도구 막대에서 zip의 파일 이름, 모든 행의 **Default format**, 단위, DPI를 설정해요. 형식 메뉴는 카탈로그가 제공하고 브라우저가 지원하는 형식을 그룹으로 묶은 내보내기 패널의 목록이에요. 자체 형식, 크기, 파일 이름이 있는 행은 그 설정을 유지해요.

**렌더링.** **Render all**은 모든 행을 `.zip` 하나로 내보내요. 행을 선택하면 **Render selected**, **Export selected CSV**, **Print selected rows**는 그 행에만 적용돼요. 전체 배치에서 다시 작업하려면 선택을 해제하세요. **Print sheet**는 인쇄할 수 있는 시트에 행을 배치해요. **Batch activity**는 각 가져오기와 렌더링을 알려주며 접어 둘 수 있어요.

**배치 보관하기.** **Sessions**는 무엇을 선택했든 격자의 모든 행을 이름 있는 배치 세션으로 저장해요. 세션은 Projects에서 다시 열어요. 같은 메뉴의 **Folders…**는 Projects 폴더를 저장된 세션당 행 하나로 열어요. 각 파일 이름에는 폴더 경로가 담겨요.

::: details 행과 셀 선택하기
체크박스로 행을 선택하거나, Shift를 누른 채 체크박스를 클릭해 범위를 선택하세요. 머리글 체크박스는 현재 페이지를 선택하고, **Select all *N* rows**는 다른 페이지의 행까지 선택해요. 페이지 사이를 이동해도 선택은 유지돼요. **Edit input**, **Duplicate**, **Remove**는 선택한 행에 적용되고, **Undo remove**는 마지막으로 지운 행을 복원해요. 셀에 포커스가 있을 때 Shift+Space는 그 행을 선택하고 Escape는 선택을 해제해요.

셀을 가로질러 끌거나, Shift를 누른 채 셀을 클릭하거나, Shift+방향키로 직사각형 영역을 선택하세요. **Copy cells** 또는 Ctrl+C / Command+C는 스프레드시트에 쓸 값을 복사해요. 셀에 포커스가 있을 때 Ctrl+A / Command+A는 모든 페이지의 표시된 열을 전부 선택하고, 행 체크박스에서는 같은 단축키가 모든 행을 선택해요. 셀을 선택해도 체크된 행은 그대로 체크돼 있어요. 셀을 더블클릭하거나 Enter를 눌러 텍스트를 편집하세요. 클립보드에서 직사각형 영역을 붙여넣거나 값 하나를 붙여넣어 선택한 모든 셀을 채우세요. 빈 셀과 여러 줄 텍스트도 위치를 유지해요.
:::

### 행별 컬러웨이와 테마

각 행은 자체 테마 선택을 유지해요. 밝음 또는 어두움, 그리고 디자인 시스템이 제공하면 컬러웨이도 있어요. Projects, 폴더, 저장된 배치에서 연 행은 세션을 저장할 때의 선택으로 렌더링되고 미리보기에 표시돼요. 인쇄 시트, 복제한 행, 채운 행도 그 선택을 유지해요.

CSV는 크기 열 다음의 `_themes` 열에 선택을 담아요. 이 열에는 `_themes` 링크 매개변수와 같은 JSON이 들어가요. 예를 들어 `{"":"dark","colourway":"beach"}`예요. 빈 셀이나 `{}`는 디자인 시스템의 기본값을 뜻해요. 선택이 있는 행이 하나라도 있을 때만 이 열을 써요. 가져올 때 유효한 테마 선택이 아닌 셀은 문제로 나열되며 해당 행은 기본값으로 렌더링돼요.

::: note CSV에서 행의 선택 설정하기
격자에는 아직 행의 선택을 바꾸는 컨트롤이 없으므로, CSV나 저장된 세션에서 설정하세요.
:::

### 행마다 언어 지정하기

Certificate처럼 자체 문구를 출력하는 도구에는 `language` 열에 `de`, `ja`, `ar` 같은 짧은 언어 코드를 넣을 수 있어요. 그러면 각 행의 문구와 날짜가 해당 언어로 출력돼요. 아랍어와 우르두어 행은 오른쪽에서 왼쪽으로 배치돼요. 빈 셀은 앱의 언어를 따라요. Lolly에 아직 번역이 없는 언어는 날짜를 포함해 영어로 출력되므로, 수료증이 반만 번역되는 일은 없어요.

### Batch 또는 Render folder

이미 저장한 세션을 다시 렌더링하려면 Projects에서 선택하고 **Render selection**을 쓰거나, 전체 폴더에 **Render folder**를 쓰세요. [작업물 찾기와 복구](/info/find-your-work.html#find-something-you-saved)에서 둘 다 다뤄요.

## 저장된 여러 디자인을 함께 편집하기

저장된 세션을 **Projects**에서 두 개에서 여덟 개까지 체크하고 선택 막대에서 **Edit together**를 고르세요. `#/multi?s=<slot>,<slot>…`에 실시간 카드로 나란히 열려요. 각 카드는 세션을 실제로 렌더링한 것이며 내보낼 결과를 보여줘요.

하나의 사이드바로 모두 제어해요.

- <!--i:sliders--> **Shared**가 먼저 나와요. 두 개 이상의 세션이 같은 방식으로 선언한 모든 입력이에요(id, 유형, 제약 조건이 같아야 하며, 배치 격자의 열에 쓰는 규칙과 같아요). 공통 컨트롤을 바꾸면 해당 입력을 선언한 모든 세션에 적용되어 모든 카드에 실시간으로 반영돼요. 같은 도구의 두 세션은 모든 입력을 공유하고, 서로 다른 두 도구는 공통 입력만 공유해요. Shared 카드의 **Input actions** 메뉴는 해당 입력을 선언한 모든 세션에 디자인 토큰을 연결해요.
- <!--i:document--> Shared 카드 아래에는 **세션마다 접힌 카드 하나**가 있으며, 도구 자체의 사이드바처럼 해당 세션의 모든 개별 입력을 담아요. 간결한 내보내기 블록도 있어요. **Format**, **W** / **H**, **Unit**, **DPI**, **Download**예요. 이 Download는 먼저 세션을 저장한 뒤, 도구에서 내보낼 때와 같은 파일 이름, 형식, Content Credentials로 파일을 렌더링해요.
- <!--i:search--> 위쪽의 **Filter inputs…**는 모든 카드의 컨트롤을 한 번에 필터링해요.

카드를 클릭하거나 카드에서 Enter를 누르면 그 세션의 사이드바 카드가 열려요. **Save all**은 모든 세션을 각각의 슬롯에 다시 저장해요. **Download all**은 먼저 저장한 뒤, Projects의 **Render selection**처럼 세트를 zip 하나로 렌더링하며 선택 사항으로 비밀번호 잠금을 제공해요.

각 카드는 디자인 안에 배치된 도구까지 포함해 자체 세션의 테마 선택으로 그려져요. 카드 주변의 앱은 자체 색상을 유지해요. **Save all**, 다운로드, **Batch grid**, **Send to Print Sheet**는 각 세션의 선택을 유지해요.

### 제한

- **최대 여덟 개예요.** 카드마다 자체 실시간 런타임을 띄우며, 여덟 개까지는 반응성을 유지해요. 더 많은 카드나 더 이상 없는 세션을 요청하는 링크는 이를 알려주고 일부만 불러오지 않아요.
- **이 링크는 기기 안에서만 쓰여요.** 사용자 자신의 저장 슬롯을 지정하고 이 기기에서 그 세트를 다시 열어요. 공유 링크가 아니에요.
- **규모가 더 크다면** 같은 선택 막대에서 **Edit as sheet**를 고르세요. 선택 항목이 배치 격자(`#/batch?s=…`)의 행으로 열리며, 개수 제한도 같은 도구여야 한다는 규칙도 없어요. 폴더는 둘 다에서 제외돼요. **Sessions → Folders…**로 격자에서 폴더를 열거나, Projects의 **Render folder**로 렌더링하세요.
- **검색은 Lolly Multi-edit에 닿지 않아요.** 검색 막대가 다루지 않는 유일한 보기예요.
