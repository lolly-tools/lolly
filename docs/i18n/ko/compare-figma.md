# Lolly와 Figma

_최종 확인일: 2026년 9월 28일._

디자이너가 Figma에서 일한다면, 이 페이지는 Lolly가 그 옆에 어떻게 놓이는지 알려줘요. Figma가 하지만 Lolly는 하지 않는 일과, Lolly가 반복 작업을 넘겨받는 곳이에요.

## Figma가 더 잘하는 것

[Figma Design](https://www.figma.com/design/)은 인터페이스 디자인, 컴포넌트, 인터랙티브 프로토타입, 개발자 핸드오프를 하나로 모아요. 팀이 애플리케이션 전체를 디자인하고 명세해야 할 때 확립된 제품 디자인 실무와 생태계가 중요하며, 실시간 편집은 Lolly의 업무 collab이 아직 도달하지 못한 규모에서 실행돼요.

## 겹치는 부분

둘 다 캔버스에 글꼴, 도형, 이미지를 배치하고 다른 사람과 작업할 수 있어요. Figma는 템플릿 기반 브랜드 제작도 다뤄요. [Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz)는 템플릿으로 에셋을 만들고 CSV나 XLSX 파일로 채워요. Lolly의 [디자인 가져오기](/info/design-import.html)는 Figma 파일을 편집 가능한 레이아웃으로 열어서 둘이 작업을 공유할 수 있어요.

## Lolly가 겹치는 작업을 하는 방법

Lolly는 디자인을 [규칙이 있는 재사용 가능한 도구](/info/create-a-tool.html)로 바꿔요. 도구는 브라우저나 CLI에서 실행되고 링크, 스크립트, 배치 그리드에서 입력을 받으므로, 하나의 템플릿이 파일 하나를 편집하는 사람과 많은 파일을 만드는 팀 모두에게 쓰여요.

![Design의 열린 캔버스: 도구 모음의 Lolly 메뉴에 Import a design이 있어요](/info/shots/design.svg)

[비공개 collab](/info/collaborate.html)은 두 기기를 직접 연결하며 계정도 필요 없고 공유 네트워크에서는 인터넷도 필요 없어요. 독립 실행형 Lolly는 오프라인으로 렌더링해요. 지원되는 내보내기에는 Content Credentials가 기본으로 켜져 있고 끌 수 있어요.

## 조직과 함께

Lolly Work는 공유 편집, 실시간 커서, 저장된 팀 세션이 있는 인증된 업무 collab과, 싱글 사인온, 공유 카탈로그, 프로젝트 권한, 승인, 서버 렌더링을 더해요. [어디서 무엇이 실행되는가](/info/compare.html#what-runs-where)가 두 부분을 나란히 비교해요.

Figma는 소유자의 상표예요. 이 페이지는 두 제품이 겹치는 곳을 설명하며 Figma와 제휴 관계가 아니에요.
