# Lolly와 Figma

_마지막 확인: 2026년 9월 28일._

디자이너가 Figma에서 작업한다면, 이 페이지에서 Figma는 할 수 있지만 Lolly는 못 하는 일과 Lolly가 반복 작업을 맡는 부분을 설명해요.

<!--i:eti-award-->
## Figma가 더 잘하는 것

[Figma Design](https://www.figma.com/design/)은 인터페이스 디자인, 컴포넌트, 인터랙티브 프로토타입, 개발자 인계를 결합해요. 팀이 애플리케이션 전체를 디자인하고 명세를 작성할 때는 Figma에 정착된 제품 디자인 작업 방식과 생태계가 중요해요. 실시간 편집은 Lolly의 업무용 collab이 아직 도달하지 못한 규모에서 운영돼요.

<!--i:eti-blend-->
## 겹치는 부분

둘 다 캔버스에 서체, 도형, 이미지를 배치하고 다른 사람과 함께 작업할 수 있어요. Figma는 템플릿 기반 브랜드 제작도 다뤄요. [Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz)는 템플릿으로 에셋을 만들고 CSV 또는 XLSX 파일에서 내용을 채워요. Lolly의 [디자인 가져오기](/info/design-import.html)는 Figma 파일을 편집 가능한 레이아웃으로 열므로 두 제품이 작업물을 공유할 수 있어요.

<!--i:eti-lolly-->
## 겹치는 작업을 Lolly가 처리하는 방식

Lolly는 디자인을 [규칙이 있는 재사용 가능한 도구](/info/create-a-tool.html)로 바꿔요. 도구는 브라우저나 CLI에서 실행돼요. 링크, 스크립트, 배치 그리드에서 입력을 받아요. 하나의 템플릿이 파일 하나를 편집하는 개인과 여러 파일을 만드는 팀 모두에게 쓰여요.

![도구 막대의 Lolly 메뉴에 Import a design이 있는 Lolly Design의 자유 캔버스](/info/shots/design.svg)

[비공개 collab](/info/collaborate.html)은 두 기기를 직접 연결하며, 계정이 필요 없고 같은 네트워크에서는 인터넷도 필요 없어요. 독립 실행형 Lolly는 오프라인으로 렌더링해요. 지원되는 내보내기에서는 Content Credentials가 기본으로 켜져 있으며, 끌 수 있어요.

<!--i:eti-building-->
## 조직에서 사용하기

Lolly Work는 공동 편집, 실시간 커서, 저장된 팀 세션을 갖춘 인증된 업무용 collab과 함께 통합 로그인, 공유 카탈로그, 프로젝트 권한, 승인, 서버 렌더링을 추가해요. [무엇이 어디에서 실행되나요](/info/compare.html#what-runs-where)에서 두 부분을 나란히 비교해요.

Figma는 해당 소유자의 상표예요. 이 페이지는 두 제품이 겹치는 부분을 설명하며 Figma와 제휴 관계가 없어요.
