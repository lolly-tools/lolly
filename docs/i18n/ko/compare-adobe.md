# Lolly와 Adobe

_최종 확인일: 2026년 9월 28일._

일상적인 파일에 Photoshop, Illustrator, InDesign을 쓰고 있다면, 이 페이지는 그중 어떤 작업을 Lolly가 대신할 수 있고 어떤 것이 Adobe에 남는지 알려줘요.

## Adobe가 더 잘하는 것

Adobe의 전문 애플리케이션은 깊이 있는 창작 작업을 다뤄요. 예를 들어 [Photoshop](https://www.adobe.com/products/photoshop.html)은 정교한 사진 편집, 선택, 마스킹, 합성을 제공해요. 복잡한 보정과 반복되는 브랜드 에셋은 필요한 것이 달라요. 작업을 옮기기 전에 작업에 필요한 편집 연산을 비교하세요.

## 겹치는 부분

둘 다 이미지 크기 조정, 레이아웃 구성, 전문 형식 내보내기를 해요. Lolly는 PDF/X, CMYK, 고비트 깊이 래스터 출력을 지원하며 [형식별 기능](/info/formats.html)이 있고, 기기 내 유틸리티는 파일을 업로드하지 않고 변환하고 정리해요.

## Lolly가 겹치는 작업을 하는 방법

독립 실행형 Lolly에는 Adobe 계정도 Lolly 계정도 필요 없으며 브라우저, 데스크톱 앱, CLI에서 같은 엔진을 실행해요. 템플릿과 디자인 토큰이 각 파일을 일관되게 유지하고, [Share with rules](/info/create-a-tool.html)는 디자인을 다른 사람이 채우는 도구로 바꿔요.

Lolly는 지원되는 내보내기에 기기에서 Content Credentials로 서명하며 기본으로 켜져 있고 끌 수 있어요. 기기 키는 서명된 이후 파일이 바뀌지 않았음을 증명해요. 조직은 자체 인증 기관을 쓸 수 있어서 검증자가 서명자를 신뢰해요. [Content Credentials 신원](/info/content-credentials-identity.html)이 차이를 설명해요. 기기 내 변환 유틸리티는 Lolly 워터마크나 Content Credentials를 추가하지 않아요.

## 조직과 함께

Lolly Work는 조직 로그인, 공유 에셋, 승인, 서버 제작을 더하며, 조직 인증서로 [서버 서명](/info/work-c2pa.html)을 해요. [어디서 무엇이 실행되는가](/info/compare.html#what-runs-where)가 두 부분을 나란히 비교해요.

Adobe, Photoshop, Creative Cloud는 Adobe의 상표예요. 이 페이지는 제품이 겹치는 곳을 설명하며 Adobe와 제휴 관계가 아니에요.
