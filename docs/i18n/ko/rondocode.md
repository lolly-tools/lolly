# Lolly Rondocode 곡

<a id="rondocode-songs"></a>

rondocode 곡은 코드로 작성하는 음악이에요. 신시사이저, 패턴, 믹스를 입력하는 동안 재생돼요. Lolly는 동영상의 배경으로 곡을 재생할 수 있고, **Rondocode** 유틸리티에서는 곡을 작성하고 오디오로 내보낼 수 있어요. 둘 다 파일의 Content Credentials에 곡을 기록해요.

<!--i:eti-music-->
## Lolly에서 곡 재생하기

에셋 선택기는 `.rondo` 또는 `.rondo.json` 파일이나 붙여넣은 `rondocode.com` 공유 링크로 곡을 받아요. 곡은 클립에서 요청한 길이만큼 재생돼요. 동영상 내보내기의 **배경 음악**이 되거나 Neurospicy Mode의 앰비언트 플레이어에서 재생될 수 있어요.

곡의 코드는 네트워크나 사용자 파일에 접근할 수 없는 Lolly의 샌드박스에서 실행돼요. 라이브 마이크나 음성 모델 없이 부르는 노래처럼 렌더링에서 재생할 수 없는 부분은 에셋 세부 정보에 나열돼요.

터미널에서는 `lolly mix`가 곡을 전체 사운드트랙으로 받아요. [CLI 렌더링](/info/cli-rendering.html)을 참고하세요.

## 곡 작성하고 내보내기

**Utilities**에서 **Rondocode** 도구를 열어 rondocode의 라이브 편집기에서 곡을 작성하고 입력하는 동안 들어 보세요. **WAV**, **MP3**, **M4A**, **Opus**, **FLAC**, 스템 ZIP, **MIDI** 또는 재생 중인 소리의 녹음으로 내보낼 수 있어요. 터미널에서는 `lolly rondocode --export=mid`가 같은 MIDI 파일을 만들어요. **Export length**는 내보낸 오디오의 길이를 초 단위로 정해요. 곡 파일(`.rondo.json`)은 아무것도 추가하지 않은, 작성한 그대로의 코드예요.

곡은 `sing()`으로 가사를 노래할 수 있어요. 내려받은 음성 모델이 기기에서 노래를 만들어요. 합성된 노래가 들어 있는 파일은 언제나 노래가 AI로 생성되었다고 선언해요([AI 기능](/info/ai-features.html) 참고).

## 자격 증명에 담긴 곡

rondocode 곡을 재생하는 동영상이나 오디오 내보내기는 각 곡을 Content Credentials에 소스로 기록해요.

- 곡의 이름;
- `.rondo.json` 파일의 SHA-256;
- 렌더링 방식: Lolly의 샌드박스, `vm` 실행 클래스, 렌더러 버전과 시드, 렌더링에서 재생할 수 없었던 부분.

곡의 코드로 계산한 음악은 알고리즘 미디어로 표시되므로 Lolly Verify는 이를 AI로 표시하지 않아요. 내보내기 전에 **Download** 아래의 줄이 자격 증명에 기록할 곡을 나열해요. 내보낸 뒤에는 같은 줄이 전달된 파일을 읽어 확인한 내용을 보고해요. 기록을 빼려면 **C2PA Credentials**를 해제하세요. 스틸 이미지에는 소리가 없어 곡을 기록하지 않아요. 스틸 이미지는 곡을 기록하지 않아요. `lolly mix`와 [MCP 서버](/info/mcp.html)도 같은 기록을 작성해요.

## Rondocode 유틸리티의 파일

기기에서 실행되는 대부분의 유틸리티는 이미 사용자가 가진 파일을 변환하므로 자격 증명을 작성하지 않아요. Lolly Rondocode는 새 오디오를 만들므로 작성하는 모든 오디오 파일에 곡을 소스로 기록하는 Content Credentials가 담겨요. WAV, MP3, M4A, Opus, FLAC, 스템 ZIP의 각 스템, 재생 중인 소리의 녹음이 해당돼요.

- 편집기 자체의 렌더링은 전용 프레임(`frame` 실행 클래스)에서 실행되고 편집기 버전을 기록해요.
- CLI나 공유 링크로 만든 렌더링은 `vm` 클래스에서 실행되고 렌더러 버전과 시드를 기록해요.
- WAV는 RIFF 주석에도 같은 내용을 명시해요.

곡이 노래를 부르면 AI 선언은 기계가 읽을 수 있는 형태로 기록돼요. 자격 증명의 디지털 소스 유형은 학습된 모델로 만든 복합 미디어이며, 기록에는 노래한 부분이 나열돼요. 모델마다 하나의 C2PA AI 공개 항목이 노래가 거친 각 모델을 식별해요. Supertonic-3 텍스트 음성 변환, wav2vec 2.0 음소 정렬기, ContentVec 인코더, RVC 음성과 Lolly가 이를 호스팅하는 데 사용한 저장소와 커밋이 포함돼요.

### MIDI 파일에 담기는 것

MIDI 파일은 Standard MIDI File의 format 1이에요. 첫 트랙에는 템포와 4/4 박자가 있고, 그 뒤에는 신시사이저마다 해당 이름이 붙은 트랙이 하나씩 있어요. 각 음표는 시작, 길이, 벨로시티를 유지해요. 베이스, 스트링, 패드, 피아노처럼 악기로 읽히는 이름의 신시사이저에는 해당 General MIDI 악기가 지정되고, 드럼 계열 이름은 채널 10에 배치돼요. 12음이 아닌 튜닝은 가장 가까운 반음으로 반올림하고 피치 벤드를 적용해요.

MIDI 파일은 신시사이저 설정, 필터, 효과, 버스, 샘플, 노래를 담을 수 없으므로 DAW가 자체 악기로 음표를 재생해요. 템포는 곡의 초당 사이클 수에서 읽으며 한 사이클을 4박자 한 마디로 간주해요. 렌더러가 반환하는 내용에 곡 자체의 박자표는 포함되지 않기 때문이에요.

MIDI 파일에는 자격 증명을 담을 곳이 없어 파일의 텍스트 이벤트에 선언을 담으며, 내보내기 패널이 이를 알려줘요. 패널은 내보내기 전에 이 모든 내용을 설명해요. 내보낼 때마다 편집기가 저장된 파일을 다시 읽고 그때 확인한 내용만 보고해요.

Content Credentials가 일반적으로 기록하는 내용은 [파일 내보내기](/info/exporting.html#content-credentials-c2pa)를 참고하세요.
