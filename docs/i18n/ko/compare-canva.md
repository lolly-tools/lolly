# Lolly와 Canva

_마지막 확인: 2026년 9월 28일._

팀에서 Canva로 소셜 게시물, 슬라이드, 전단을 만든다면, 이 페이지에서 Lolly가 같은 일을 하는 부분과 Canva가 더 잘 맞는 부분을 설명해요.

<!--i:eti-award-->
## Canva가 더 잘하는 것

Canva는 방대한 템플릿 및 스톡 라이브러리, 앱, 호스팅되는 팀 워크플로를 하나의 관리형 서비스로 결합해요. 오늘 바로 시작할 자료가 필요할 때 미리 만들어진 콘텐츠가 도움이 돼요. [Canva 템플릿](https://www.canva.com/templates/)과 [앱 마켓플레이스](https://www.canva.com/apps/)를 참고하세요. Canva의 실시간 편집은 Lolly의 업무용 collab이 아직 도달하지 못한 규모에서 오랫동안 운영돼 왔어요.

<!--i:eti-blend-->
## 겹치는 부분

둘 다 디자이너가 아닌 사람이 템플릿에서 시작해 완성된 그래픽을 만들 수 있게 해요. 둘 다 팀 작업과 브랜드 통제를 지원해요. [Canva는 이를 비즈니스 요금제에 묶어 제공해요](https://www.canva.com/canva-business/). Lolly는 창작 앱과 조직 서버를 분리해요.

<!--i:eti-lolly-->
## 겹치는 작업을 Lolly가 처리하는 방식

Lolly 도구는 사람들이 바꿀 수 있는 것을 정해요. 같은 도구가 브라우저, 데스크톱 앱, CLI에서 실행돼요. Lolly Design 캔버스에서 만든 레이아웃은 [규칙이 있는 도구](/info/create-a-tool.html)가 될 수 있어요. 도구 하나가 값이 담긴 표에서 여러 파일을 만들 수 있어요.

![디자인 시스템 자체의 색상, 서체, 에셋을 제공하는 Lolly Design의 자유 캔버스](/t/url-shot?url=%2F%23%2Ftool%2Fdesign%3Ftemplate%3D__blank__&width=1440&height=900&dpi=192&waitMs=2400&walker=1&format=svg&dark=1&filename=aud-open-canvas)

독립 실행형 Lolly는 계정 없이 기기에서 만들고 내보내요. 에셋이 저장되면 오프라인으로 작동해요. 두 사람이 기기 간 [비공개 collab](/info/collaborate.html)에서 실시간으로 편집할 수 있어요. 지원되는 내보내기에서는 Content Credentials가 기본으로 켜져 있으며, 끌 수 있어요.

<!--i:eti-building-->
## 조직에서 사용하기

조직의 자체 서버에서 실행하는 Lolly Work는 로그인, 공유 프로젝트, 실시간 업무용 collab, 승인된 에셋, 정책을 추가해요. [무엇이 어디에서 실행되나요](/info/compare.html#what-runs-where)에서 모든 비교가 공유하는 한계와 함께 두 부분을 나란히 비교해요.

Canva는 해당 소유자의 상표예요. 이 페이지는 두 제품이 겹치는 부분을 설명하며 Canva와 제휴 관계가 없어요.
