# 만들기

몇 가지 입력란을 채우면 글꼴, 색상, 레이아웃이 이미 정해진 완성 파일을 자신의 기기에서 얻을 수 있어요. 브랜드 규칙이 도구 안에 있으므로 자신의 이름이 붙은 파일이 브랜드에서 벗어나는 일은 없어요.

처음이라면 **[첫 파일 만들기](/info/make-something.html)**부터 시작하세요. [Lolly 작동 방식](/info/how-lolly-works.html)은 스크립트나 동료의 휴대폰에서도 도구를 실행하는 방법을 보여줘요. [질문과 답변](/info/faq.html)은 사람들이 무료 도구를 신뢰하기 전에 묻는 내용을 다뤄요.

<!--i:eti-pen-tool-->
## 제작하기

도구를 골라 입력란을 채우거나, Lolly Design 캔버스에서 페이지를 자유롭게 배치하세요.

- **[첫 파일 만들기](/info/make-something.html)** - 설정 없이 따라 하는 짧은 안내예요. QR 코드를 다운로드하고 편집 가능한 사본으로 저장해요.
- **[Lolly 사용하기](/info/using.html)** - 캔버스, 컨트롤, 저장, Projects, 휴대폰 사용법을 다뤄요.
- **[Lolly Design](/info/design.html)** - 어떤 템플릿에도 맞지 않는 레이아웃을 위한 자유 캔버스예요. 포스터, 덱, 모션 작품을 만들어요.
- **[템플릿](/info/templates.html)** - 빈 도구 대신 저장된 레이아웃으로 시작해요.
- **[Lolly Design의 텍스트](/info/text-composition.html)** - 제목, 이어지는 텍스트, 박스에 맞는 글자를 다뤄요.
- **[Lolly Chart](/info/chart.html)** - 붙여넣은 표를 벡터 차트, 통계 그래프, 3D 장면, 영화 같은 비행 장면으로 그려요.
- **[Lolly 3D Studio](/info/3d-studio.html)** - SVG 아트워크와 3D 모델을 배치하고 조명을 설정해 하나의 장면으로 렌더링해요.
- **[Lolly Darkroom](/info/darkroom.html)** - 사진과 동영상의 색감을 보정하고 그 모습을 LUT로 보관해요.
- **[Lolly Utilities](/info/utilities.html)** - 기기에서 파일을 손봐요. 안전하게 공유하고, 두 버전을 비교하고, 형식을 바꾸고, 글을 추출하거나 색상을 확인해요.
- **[브라우저 확장 프로그램](/info/extension.html)** - 웹 앱에서 실제 웹 페이지의 스크린샷을 찍거나, 사이트를 읽어 디자인 시스템 만들기를 시작해요.

## 자신에게 맞추기

모든 도구의 모습은 자신의 디자인 시스템이 정해요.

- **[Lolly Design System Setup](/info/brand-studio.html)** - 로고, 색상, 서체 등을 `#/start`에서 한 번 설정해요.
- **[Lolly Demo 사용하기](/info/lolly-demo-in-use.html)** - 실제 작업의 컬러웨이와 자신의 디자인 시스템으로 전환하는 방법을 다뤄요.
- **[브랜드 아키텍처](/info/brand-architectures.html)** - 한 조직에서 여러 디자인 시스템을 쓰거나 여러 컬러웨이를 가진 디자인 시스템 하나를 써요.
- **[파트너와 작업하기](/info/partners.html)** - 파트너에게 브랜드를 공유하고, 받은 브랜드로 작업하고, 후원사 로고 벽을 만들어요.
- **[디자인 가져오기](/info/design-import.html)** - Figma, Penpot, Illustrator, InDesign, Affinity, Photoshop, PowerPoint, SVG 파일을 단순한 그림이 아닌 편집 가능한 레이아웃으로 열어요([모든 형식](/info/design-import.html#what-comes-in-from-each-app)).
- **[덱 리브랜딩하기](/info/rebrand.html)** - 차트와 애니메이션을 유지하면서 PowerPoint 덱에 자신의 디자인 시스템을 적용해요.
- **[규칙을 정해 디자인 공유하기](/info/create-a-tool.html)** - 레이아웃을 다른 사람이 채워 넣는 도구로 바꿔요.

## 작업물 찾고 보관하기

- **[작업물 찾기와 복구](/info/find-your-work.html)** - 저장한 파일, 다운로드한 파일, 저장하지 않은 파일이 어디로 갔는지 찾아요.
- **[Lolly Search](/info/search.html)**와 **[Ask Lolly](/info/ask.html)** - 입력란 하나에서 도구, 저장된 작업물, 에셋, 설정을 찾고 이 가이드에서 답을 얻어요.
- **[Lolly Settings](/info/dashboard.html)** - 이 기기가 할 수 있는 일, 읽기 전용 디자인 시스템, 저장 공간을 확인해요.
- **[즐겨찾기](/info/favourites.html)**와 **[프로필](/info/profile.html)** - 별표를 붙인 도구, 도구가 미리 채워 넣는 데 쓰는 정보, 접근성 스위치를 다뤄요.
- **[기기 동기화하기](/info/sync.html)** - 직접 고른 저장소를 통해 컴퓨터와 휴대폰에서 같은 작업물을 사용해요.

## 애니메이션 만들기

움직이는 텍스트, 타임라인 위의 장면, 브랜드에 맞는 모션을 만들어요. 모션 내보내기는 화면을 녹화하지 않고 제어되는 시계를 기준으로 프레임마다 그리므로 같은 링크는 같은 클립을 만들어요.

- **[애니메이션 만들기](/info/animating.html)** - 키프레임, 깊이, 장면 카메라를 다뤄요.
- **[시퀀스 편집기](/info/sequence-editor.html)** - 클립, 오버레이 레인, 트리밍과 분할, 전환, 오디오 믹스를 다뤄요.
- **[광색역과 HDR](/info/hdr-editing.html)** - 더 넓은 범위를 표현할 수 있는 화면과 형식에서 일반적인 범위를 넘어서는 색상을 사용해요.

## 녹음·녹화하고 발표하기

시작 전 카운트와 레벨 미터로 깔끔하게 녹음·녹화하거나, 슬라이드 앞에 자신의 모습을 띄우세요.

- **[Lolly Design 타임라인](/info/design.html#timeline-sequence)** - 타임라인에 내레이션을 녹음해요.
- **[첫 파일 만들기](/info/make-something.html#other-first-projects)** - 카메라에 나오지 않고 목소리를 전하는 오디오그램을 만들어요.
- **[음악 생성기](/info/music-generator.html)** - 어느 장르든 자신의 곡을 만들고 크레딧을 표시해 무료로 사용해요. [무료 배경 음악](/info/background-music.html)에서는 모든 장르의 샘플을 들을 수 있어요. [생성된 음악](/info/generated-music.html)은 음악이 만들어지는 방식을 설명해요.
- **[카메라와 함께 발표하기](/info/presenting.html)** - 덱이나 Countdown 위에 카메라 영상, 로고, 이름을 띄우고 별도 창의 비공개 컨트롤로 조작해요.
- **[클리커로 조작하는 라이브 페이지](/info/interactive-pages.html)**와 **[Agenda 화면](/info/agenda.html)** - 현장에서 보여줄 페이지와 프로그램을 만들어요.

## 협업하기

계정도 중간 서버도 없이 두 사람이 두 기기에서 하나의 디자인을 실시간으로 편집해요.

- **[함께 작업하기](/info/collaborate.html)** - 기기 간의 비공개 collab과 조직의 Lolly Work를 통한 업무용 collab을 다뤄요.
- **[Lolly 사용하기](/info/using.html#sharing-your-work)** - 전체 상태를 담은 공유 링크나 `.lolly` 파일 하나로 공유해요.
- **[조직에서 Lolly 사용하기](/info/organisation.html)** - 조직이 Lolly Work를 운영할 때의 로그인, 팀 프로젝트, 관리되는 설정을 다뤄요.

## 게시하기

같은 원본에서 링크, 정확하게 인쇄되는 PDF, 동영상, 덱, 여러 변형을 담은 폴더를 보내세요.

- **[파일 내보내기](/info/exporting.html)** - 인쇄 단위, 도련과 재단선, 동영상, 배치 실행, 내보내기 패널을 다뤄요.
- **[Lolly가 열고 만들 수 있는 모든 형식](/info/formats.html)** - 전체 입출력 형식 목록이에요.
- **[창작물의 권리와 크레딧](/info/creative-rights.html)** - 사용한 것의 라이선스와 파일에 담겨 이동하는 크레딧을 다뤄요.
