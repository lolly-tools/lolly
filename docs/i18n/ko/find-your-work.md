# 작업 찾기 및 복구

Lolly에서 만든 모든 것은 [동기화](/info/sync.html)를 켜지 않는 한, 그것을 만든 브라우저나 앱 안에 그 기기에만 남아요. 저장한 작업은 **프로젝트**에 있어요. 다운로드한 파일은 브라우저나 시스템이 그것을 둔 곳에 있고, 보통 **애셋**에도 사본이 준비돼요. 9개 도구에서는 한 번도 저장하지 않은 작업도 함께 보관돼요. 이 페이지는 이 각각의 경우와 더불어, 탭을 닫은 경우, 브라우저 데이터를 지운 경우, 이전 버전, 삭제한 항목, 다른 기기로 옮기는 방법까지 다뤄요.

| 무엇을 했는지 | 어디를 볼지 |
|---|---|
| **다른 이름으로 저장** 또는 **저장**을 눌렀다 | **프로젝트** |
| **다운로드**를 눌렀다 | 브라우저의 다운로드 폴더, 그리고 **애셋**에도 사본 |
| 둘 다 아님, [작업하는 동안 저장되는 9개 도구](#the-nine-tools-that-save-as-you-work) 중 하나 | **프로젝트**와 **History** |
| 둘 다 아님, 그 밖의 도구 | 탭을 닫기 전까지 작업하던 탭에만 |
| 휴지통으로 옮겼다 | **프로젝트** 안의 **휴지통** 타일에 30일간 |

## 저장한 것 찾기

1. 도구 왼쪽 위의 **홈**을 누르세요.
2. 홈 화면 위쪽의 **프로젝트** 탭을 여세요(휴대폰에서는 폴더 아이콘).
3. 첫 화면을 보세요. **내 라이브러리**에 저장한 작업이 거기 있고, 각 프로젝트는 폴더예요. 모든 폴더를 한 번에 검색하려면 화면 아래쪽의 **모든 프로젝트 검색…**에 입력하세요.

항목은 내보내기 패널에서 입력한 파일 이름을 따서 붙여져요. 아무것도 입력하지 않았다면 **QR 코드**처럼 그 도구의 이름이 붙어요. 항목을 열면 모든 설정이 되돌아와 있어서 바로 바꾸고 다시 내보낼 수 있어요. 새 작업을 이런 식으로 남기려면 [저장하고 이어서 하기](/info/using.html#saving-continuing)를 참고하세요.

::: note 프로젝트에 없나요?
- **휴지통**에 있을 수 있어요: [삭제한 것 되찾기](#get-back-something-you-deleted)를 참고하세요.
- 다른 브라우저, 시크릿 창, 다른 기기는 [동기화](/info/sync.html)를 쓰거나 [작업을 옮기지](#move-your-work-to-another-device) 않는 한 비어 있는 상태로 시작해요.
- **다운로드**만 눌렀다면 [다운로드한 파일 찾기](#find-a-file-you-downloaded)를 참고하세요.
:::

- <!--i:checklist--> **다중 선택(데스크톱).** 타일의 체크박스를 켜거나, 빈 곳에서 선택 상자를 끌거나, **Shift/Cmd-click**하세요; 타일을 **오른쪽 클릭**하면 컨텍스트 메뉴가 나와요. 그러면 선택 바에서 **선택 항목 렌더링**, **이동…**, **새 폴더**, **삭제**(휴지통으로 이동해요), 같은 도구의 세션 2~8개를 하나의 사이드바 아래 나란히 여는 **함께 편집**, 그리고 크기나 종류에 상관없이 선택 항목을 배치 격자의 행으로 여는 **시트로 편집**을 제공해요.

- <!--i:link--> **저장한 세션을 공유하세요.** 세션을 오른쪽 클릭하고(휴대폰에서는 타일의 **•••**를 누르고) → **링크 공유**로 같은 설정으로 다시 열리는 링크를 복사하세요; 기기에 있는 사진은 링크에 함께 담기지 않아요(전체 공유 대화상자: [내 작업 공유하기](/info/using.html#sharing-your-work) 참고).
- <!--i:pentool--> **이름을 바꾸거나 복사하세요.** 세션을 오른쪽 클릭하면(휴대폰에서는 타일의 **•••**를 누르면) **이름 바꾸기**, **중복**(같은 폴더 안에 사본 생성), **이동…**이 나와요.

## 탭을 닫았거나 도구를 떠났을 때

무엇이 돌아오는지는 어떻게 나갔는지와 어떤 도구를 사용했는지에 따라 달라져요:

- **탭을 닫았거나 다른 때에 돌아온 경우.** 저장하지 않은 작업은 사라지지만, [9개 도구](#the-nine-tools-that-save-as-you-work)는 예외로, 작업하는 동안 편집 내용을 저장해요: **프로젝트**에서 여세요.
- **같은 탭에서 페이지를 새로고침한 경우.** 설정은 페이지 주소에서 복원돼요. 9개 도구가 아닌 다른 도구에서는 기기에서 추가한 사진과 파일, 150자를 넘는 한 줄 텍스트는 주소에 담기지 않으므로 복원되지 않아요.
- **홈을 눌렀거나 왼쪽 위의 뒤로 가기 버튼을 누른 경우.** 마지막으로 저장, 다운로드, 복사한 이후 무언가를 바꿨다면 **저장되지 않은 변경 사항** 대화상자가 먼저 저장할지 물어봐요. **Save & leave**는 작업을 저장하고 **프로젝트**, 또는 작업을 열었던 프로젝트 폴더로 이동해요. **저장하지 않고 나가기**는 그대로 나가요; 9개 도구에서는 편집 내용이 이미 저장되어 프로젝트에 남아 있어요. **취소**는 도구에 그대로 머물러요.

Lolly는 도구 안에서 **홈**이나 뒤로 가기 버튼을 눌렀을 때만 물어봐요. 탭을 닫거나, 새로고침하거나, 브라우저 자체의 뒤로 가기 버튼을 쓸 때는 절대 묻지 않아요. 확실히 하려면 도구를 떠나기 전에 **다른 이름으로 저장**을 누르거나 내보내기 패널에서 **저장**을 누르세요.

::: note 실수로 저장하지 않고 나갔나요?
9개 도구가 아닌 다른 도구에서는 바로 브라우저의 뒤로 가기 버튼을 누르세요. 페이지 주소의 설정은 돌아오지만, 기기에서 추가한 사진은 돌아오지 않아요. 그다음 다른 무엇을 하기 전에 **다른 이름으로 저장**과 **저장**을 누르세요: 이번에는 Lolly가 나가기 전에 묻지 않아요.
:::

::: details 작업하는 동안 저장되는 9개 도구
[디자인](/#/tool/design), [차트](/#/tool/chart), [QR 코드](/#/tool/qr-code), [그라데이션](/#/tool/gradient), [스니펫](/#/tool/snippet), [플로우 차트](/#/tool/org-chart), [가격](/#/tool/pricing-table), [워드마크](/#/tool/wordmark), [텍스트](/#/tool/text-helper). 자동 저장을 지원하는 도구는 앞으로 더 늘어나요.

이 도구들에서는 처음 변경한 순간 그 작업이 저장한 것처럼 **프로젝트**에 기록되고, 이후 변경 내용도 몇 초 안에 계속 저장돼요. 그래서 저장하지 않은 창작물도 탭을 닫은 뒤 프로젝트에 남아 있고, **저장하지 않고 나가기**를 선택해도 편집 내용이 사라지지 않아요. 홈 화면에서 그 도구를 다시 열면 새 창작물이 시작돼요; 이전 것은 프로젝트에서 여세요.

이 기능은 웹 앱에서만 동작하며, 데스크톱이나 모바일 앱에서는 동작하지 않아요. 그리고 다른 사람과 실시간으로 함께 작업하는 동안에도 동작하지 않아요.
:::

## 다운로드한 파일 찾기

브라우저에서는 **다운로드**를 누르면 파일이 브라우저로 넘어가고, 브라우저가 자신의 다운로드 폴더(보통 **다운로드**)에 저장하거나 저장 위치를 물어봐요. Lolly는 파일이 어디로 갔는지 알지 못하므로 브라우저의 다운로드 목록을 확인하세요.

파일이 나타나지 않았다면 아직 도구 안에 있는 동안 내보내기 패널을 확인하세요. **다운로드** 아래에 파일 이름과 시간을 알려주는 줄이 있고, **Retry download**와, Chrome, Edge 등 다른 Chromium 브라우저에서는 직접 폴더를 고를 수 있는 **Save file…**이 있어요. 이 줄과 그 파일은 도구를 떠나거나, 새로고침하거나, 다시 내보낼 때까지 남아 있어요.

Lolly는 다운로드할 때마다 두 가지를 더 보관해요:

- **파일 사본**이 **설정 → 내 렌더** 아래에서 **내 렌더를 라이브러리에 저장**이 켜져 있는 동안 **애셋**의 **내 업로드**에 저장돼요(**설정**은 홈 화면 아래쪽에 있어요). 이 설정은 기본으로 켜져 있어요. 동영상이나 50MB가 넘는 파일은 먼저 확인을 물어보고, zip은 복사되지 않아요.
- **사용한 설정**이 최근 24번의 다운로드에 대해 저장돼요. **프로젝트**의 저장한 작업 아래에 있는 **최근 내보내기**는 그 설정으로 도구를 다시 열어 파일을 다시 만들 수 있게 해주지만, 기기에서 추가한 사진과 파일은 포함되지 않아요. 같은 목록이 **설정 → 활동 및 통계 → 최근 내보내기**와 **History**의 **Changes** 탭에도 있어요. 이 목록은 설정을 보관할 뿐, 파일을 보관하지 않아요.

::: details 데스크톱과 모바일 앱에서는
- **데스크톱 앱:** **다운로드**는 대화상자 없이 **Downloads** 폴더 안의 **Lolly** 폴더로 바로 저장돼요. 메시지가 저장을 알려주고 파일을 보여주는 **드러내기**를 제공해요. **Window**나 **Exports** 메뉴에 있는 **Open Exports Folder**로 언제든 그 폴더를 열 수 있어요. 이전과 같은 이름의 파일은 "name (1)"로 저장돼요.
- **iPhone과 iPad:** 파일은 **Lolly** 아래의 **파일** 앱에 저장되고, 공유 시트가 열려서 바로 보낼 수 있어요.
- **Android:** 공유 메뉴가 열려서 파일을 보낼 곳을 고를 수 있어요.

iPhone, iPad, Android에서는 새 파일이 같은 이름의 이전 파일을 대체해요.
:::

## 이전 버전으로 돌아가기

- **이번 방문 동안은:** **실행 취소**는 도구를 떠나거나 새로고침할 때까지 최근 100번의 변경을 되돌릴 수 있어요. [실행 취소와 다시 실행](/info/using.html#undo-and-redo)을 참고하세요.
- **작업하는 동안 저장되는 9개 도구에서는:** 각 창작물의 이전 버전이 보관돼요. 아래 단계를 따르세요.
- **기기의 모든 것은:** [동기화](/info/sync.html)가 켜져 있으면 **설정 → 연결된 서비스** 아래의 **Restore an earlier copy**로 최근 7일치 일일 사본 중 하나, 또는 마지막 적용 이전의 사본을 되돌릴 수 있어요. 이 경우 디자인 하나가 아니라 이 기기의 모든 것이 그 사본과 일치하게 돼요.

9개 도구 중 하나에서 이전 버전을 열려면:

1. **실행 취소**와 **다시 실행** 옆의 시계 버튼인 **History**를 누르세요. Design에서는 **History**가 상단 바에 있어요; 휴대폰에서는 **•••**를 누른 다음 **History**를 누르세요.
2. 날짜와 시간으로 버전을 찾으세요. **Automatic checkpoint** 행은 작업하는 동안 자동으로 찍힌 것이고, **Saved version** 행은 저장한 시각이에요.
3. **Open as a copy**를 누르세요. 그 버전이 새 창작물로 열리고, 열려 있던 원래 작업은 그대로 남아요. 사본은 **프로젝트**에 있으며 이름 뒤에 "(copy)"가 붙어요.

이름을 붙여 버전을 남기려면 **Name version**을 누르고 이름을 입력한 다음 **Keep milestone**을 누르세요. 이름을 붙인 버전은 **History** 페이지의 **Milestones** 아래에 나열돼요.

::: details History 패널과 History 페이지
**History** 패널에는 **Recovered work** 행도 나열되고, **Protected drafts**는 체크포인트 사이의 최신 편집 내용을 보관하며 **Open draft as a copy**가 있어요. **Compare**와 **Check assets**는 사본을 열기 전에 선택하는 데 도움을 줘요. **This creation**을 **All history on this device**로 전환하면 모든 창작물을 볼 수 있어요.

자동 체크포인트는 오래될수록 줄어들어요: 최근 1시간은 1분마다, 최근 하루는 1시간마다, 최근 30일은 하루마다, 그 이후는 일주일마다예요. 저장된 버전은 모두 보관돼요. **설정 → 저장 공간**에서 창작물을 삭제하면 그 버전들도 함께 삭제돼요.

**History** 페이지(`#/history`, 또는 패널의 **Open app history**)는 이 브라우저 안의 모든 창작물을 다뤄요. 컴퓨터에서는 홈 화면이나 **프로젝트**의 오른쪽 위 시계 버튼에서 이 페이지를 열어요. 휴대폰에서는 홈 화면의 도구 갤러리로 가서 오른쪽 위의 둥근 로고 버튼을 누르고 **Saved sessions**를 고르면 History가 열려요. **프로젝트**에서의 그 항목은 아직 아무 동작도 하지 않아요.

- **Recent**은 창작물을 최신순으로 **Resume**과 함께 나열해요.
- **Changes**는 체크포인트, 다운로드, Convert 결과를 하나의 타임라인에 모아요. 다운로드에는 **Reopen settings**가 있어요.
- **Milestones**는 이름을 붙인 버전을 나열해요.

프로젝트, 도구, 날짜로 필터링할 수 있어요(휴대폰에서는 **Filters** 안에). History 페이지에는 삭제 버튼이 없어요; 항목을 지우려면 프로젝트를 사용하세요.
:::

## 다른 기기로 작업 옮기기

| 목적 | 사용할 기능 |
|---|---|
| 기기들을 맞춰 두기 | **설정 → 연결된 서비스** 아래의 **기기 간 동기화**: [기기 동기화하기](/info/sync.html) 참고 |
| 한 번에 모두 옮기기 | 아래의 **내 데이터 내보내기**와 **데이터 가져오기…** |
| 디자인 하나나 프로젝트 하나를 넘기기 | `.lolly` 파일: **내보내기**, 그다음 **공유**, 그다음 **Download .lolly**; 프로젝트 전체라면 폴더 메뉴의 **Download project (.lolly)**. 다른 기기에서 **열기**를 누르세요. [.lolly 파일](/info/using.html#the-lolly-file) 참고 |

공유 링크에는 설정이 담기지만, 기기에서 추가한 사진이나 파일은 담기지 않아요.

::: warning 가져오기는 폴더를 교체해요
다른 기기에 이미 작업이 있다면 먼저 이것을 읽어보세요. 가져오기는 파일이 담고 있는 내용을 추가하고, 일치하는 항목을 갱신하며, 저장된 항목을 삭제하지 않아요. 다만 프로필은 하나의 레코드라서, 그 기기의 폴더, 즐겨찾기, 템플릿, 세부 정보는 파일 안의 것으로 교체돼요. 그 기기에만 있던 저장된 항목은 **프로젝트** 최상위에 남아요. 동기화의 **Bring it to this device**도 똑같이 동작해요.
:::

한 번에 모두 옮기려면:

1. 이전 기기에서 **설정 → 저장 공간**을 열고, **다른 기기로 이동** 아래의 **내 데이터 내보내기**를 누르세요. Lolly가 이름이 `LollyTools-`로 시작하는 `.zip` 파일 하나를 다운로드해요.
2. USB, 자신에게 보내는 이메일, AirDrop, 또는 공유 폴더로 파일을 옮기세요.
3. 새 기기에서 **설정 → 저장 공간**을 열고 **데이터 가져오기…**를 눌러 파일을 고른 다음 **가져오기**를 누르세요.

::: note 남겨지는 것
로그인 정보, 키, 동기화 암호 문구는 각 기기에 남아요. 최근 다운로드 목록, 오프라인 다운로드, AI 모델은 어떤 방법으로도 이동하지 않아요. 버전 히스토리는 동기화나 `.lolly`가 아니라 **내 데이터 내보내기** 파일 안에서만 이동해요. 동기화가 저장소에 보관하는 사본은 **데이터 가져오기…**나 **열기**가 아니라 동기화를 통해서만 열려요.
:::

::: details 백업 파일이 담고 있는 것
파일은 `LollyTools-<First>-<Last>-<YYYY-MM-DD>-<n>.zip`이라는 이름을 가져요(이름 부분은 프로필에서 가져오며 설정되지 않으면 생략돼요; `<n>`은 일별 카운터라 같은 날의 내보내기가 충돌하지 않아요). 여기에는 폴더, 휴지통, 템플릿, 즐겨찾기를 포함한 프로필; 썸네일이 딸린 모든 저장된 세션; 업로드한 이미지, 폰트, 로고와 다운로드 사본; 디자인 시스템; 환경설정(테마, 사이드바 너비, 로컬 활동 통계); 저장된 버전과 Convert 결과; 그리고 웹 앱의 경우 창작물의 버전 히스토리가 담겨요.

카탈로그 캐시는 포함되지 않아요 - 새 기기에서 알아서 다시 내려받아요. 각 부분에 체크섬이 있어서 전송 중에 손상된 파일은 절반만 복원되는 대신 가져오는 시점에 걸러져요. 저장된 세션은 가져온 이미지에 자동으로 다시 연결돼요. 웹, 데스크톱, 모바일 앱은 같은 파일을 읽지만, 터미널 앱은 자체적으로 더 단순한 백업을 쓰며 이 형식은 그것을 읽지 못해요. **📦 Export my data & render everything**은 같은 파일에 더해, 저장된 모든 세션을 각각의 출력으로 렌더링한 두 번째 zip도 만들어요. (전체 형식 명세: [데이터 전송](/info/data-transfer.html).)
:::

## 브라우저 데이터를 지운 경우

웹 앱에서는 Lolly가 이 사이트용 브라우저 저장소에 모든 것을 보관해요: 저장한 작업, 사진, 폰트, 디자인 시스템, 버전 히스토리, 오프라인 다운로드예요. 브라우저에서 이 사이트의 데이터를 지우면 그 모두가 삭제되고, Lolly는 그중 무엇도 되찾을 수 없어요. 남는 것은 이미 브라우저 밖으로 나가 있던 것들이에요: 다운로드한 파일, **내 데이터 내보내기** 파일, [동기화](/info/sync.html) 사본, 그리고 공유한 링크예요.

::: warning 브라우저 데이터를 지우기 전에
**설정 → 저장 공간** 아래의 **내 데이터 내보내기**를 눌러 그 파일을 다른 곳에 보관하세요.
:::

앱이 시작되면 Lolly는 기기의 저장 공간이 부족해져도 자신의 저장소를 지우지 말아 달라고 브라우저에 요청해요. 판단은 브라우저가 해요. **설정 → 오프라인 사용 가능** 아래에서 **Protected**로 시작하는 줄이 있으면 브라우저가 동의한 것이고, "The browser may clear downloads if the device runs low on space"라면 동의하지 않은 것이며, **다운로드 보호**로 다시 요청할 수 있어요. 브라우저가 동의하지 않았다면 공간이 부족해질 때 다운로드뿐 아니라 저장한 작업도 지워질 수 있으니, 최근의 **내 데이터 내보내기** 파일을 보관해 두세요.

**설정 → 저장 공간**은 각 종류의 데이터가 얼마나 많은 공간을 쓰는지 보여줘요. **캐시 지우기**는 다운로드된 카탈로그 파일을 버려요. 필요할 때 다시 다운로드돼요. **내 데이터 모두 지우기**는 어떤 단어를 입력하도록 요청한 뒤 프로필, 저장된 세션, 업로드한 이미지, 애셋 캐시를 제거해요. 버전 히스토리, 최근 다운로드 목록, Convert 결과, 디자인 시스템, 다운로드한 AI 모델 등 다른 데이터는 남아요. 모든 것을 지우려면 브라우저에서 이 사이트의 데이터를 지우세요.

![휴대폰 너비 화면의 저장 공간 카드 - 기기에 있는 데이터의 모든 갈래가 이름과 함께 나오고, 맨 아래에 Clear all my data 버튼이 있어요](/t/url-shot?url=%2F%23%2Fprofile%3Ffocus%3Dstorage-section&width=430&height=1600&dpi=192&waitMs=2400&css=.welcome-dialog%2C.personalize-nudge%2C.store-manages%2C.storage-subsection%2C.store-selbar%2C.store-chip-val%2C%23store-hero-num%2C%23store-headroom%2C%23store-quota%2C%23store-reclaim%7Bdisplay%3Anone%7D&format=svg&walker=1&cropSelector=%23storage-section&dark=1&filename=pv-storage-clear)

데스크톱과 모바일 앱에서는 저장된 세션이 앱 자체의 데이터 폴더 안 파일이고, 나머지는 앱 자체의 저장소에 있어서 웹 브라우저를 지워도 영향을 받지 않아요.

::: details 데스크톱과 모바일 앱이 저장된 세션을 보관하는 위치
저장된 세션마다 파일 하나씩이 `saved-state` 폴더 안에 있어요:

- macOS: `~/Library/Application Support/tools.lolly.Desktop/saved-state/`
- Windows: `%APPDATA%\tools.lolly.Desktop\saved-state\`
- Linux: `~/.local/share/tools.lolly.Desktop/saved-state/`, 또는 `$XDG_DATA_HOME` 아래의 같은 경로
- iPhone, iPad, Android: 앱 자체의 저장소 안에 있으며, 파일 앱에는 표시되지 않아요

사진, 디자인 시스템, 최근 다운로드 목록은 이 폴더가 아니라 앱의 내부 저장소에 있어요. 터미널 앱과 명령줄은 같은 `saved-state` 폴더를 읽어요: [저장된 세션이 있는 곳](/info/cli-reference.html#where-saved-sessions-live)을 참고하세요.
:::

## 삭제한 것 되찾기

**프로젝트**에서 **휴지통으로 이동**하면 항목이 30일 동안 보관돼요. 폴더는 안의 모든 것을 포함해 하나의 항목으로 휴지통에 들어가요. 바로 직후에는 약 10초 동안 **실행 취소**를 제공하는 메시지가 떠요. 그 이후에는:

1. **프로젝트**를 열고 **휴지통** 타일을 누르세요. 이 타일은 휴지통에 무언가 있는 동안에만 나타나요.
2. 항목 옆의 **복원**을 누르세요.

**영구 삭제**와 **휴지통 비우기**는 묻지 않고 항목을 즉시 제거해요. 30일이 지난 항목은 다음에 프로젝트를 열 때 완전히 제거돼요.

::: warning 그 밖의 삭제는 영구적이에요
**설정 → 저장 공간** 아래에서, 또는 갤러리에서 도구의 저장된 세션 목록(도구 카드를 오른쪽 클릭한 다음 **저장된 세션 N개**)에서 세션을 삭제하면 버전 히스토리와 함께 완전히 삭제돼요. **내 이미지**에서 삭제한 사진은 묻지 않고 즉시 제거돼요.
:::

[동기화](/info/sync.html)가 켜져 있으면 **Restore an earlier copy**로 기기 전체의 이전 날짜 상태를 되돌릴 수 있고, **내 데이터 내보내기** 파일은 그 파일이 담고 있는 내용을 되돌려요.
