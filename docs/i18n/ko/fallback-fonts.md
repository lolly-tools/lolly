# 대체 글꼴

디자인 시스템의 글꼴이 글자를 그릴 수 없으면 Lolly는 개방형 Noto 글꼴로 그 글자를 그려요. 그래서 내보내기는 글자를 그림 대신 벡터 윤곽선으로 유지해요. Lolly Demo의 글꼴인 제목용 Outfit과 본문용 SUSE에는 키릴, 그리스, 아랍, 히브리, 데바나가리, 벵골, 태국, 중국어, 일본어, 한국어 문자가 없어요.

디자인 시스템의 글꼴이 항상 목록 순서대로 먼저 적용돼요. Outfit에는 베트남어 문자가 없으므로 베트남어 제목은 Lolly Demo 목록의 다음 글꼴인 SUSE에서 글자를 가져와요. 대체 글꼴은 그 글꼴 중 어느 것도 그릴 수 없는 문자만 그려요. 브랜드 글꼴은 자신에게 있는 모든 글자, 숫자, 기호를 한자까지 포함해 유지하며, 다른 문자 체계로 된 단어 안에서도 마찬가지예요.

## 번들에 포함된 것

고정된 커밋의 Google Fonts에서 가져온 글꼴 15개예요. 각 파일은 다운로드 크기와 함께 표시돼요.

| 문자 체계 | 글꼴 | 버전 | 다운로드 |
|---|---|---|---|
| 우르두어와 페르시아어 문자를 포함한 아랍 문자 | Noto Sans Arabic | 2.012 | 211 KB |
| 히브리 문자 | Noto Sans Hebrew | 3.001 | 37 KB |
| 데바나가리 문자(힌디어, 마라티어, 네팔어) | Noto Sans Devanagari | 2.007 | 151 KB |
| 벵골 문자 | Noto Sans Bengali | 3.011 | 139 KB |
| 태국 문자 | Noto Sans Thai | 2.002 | 62 KB |
| 키릴 문자 | Noto Sans, 키릴 문자 | 2.015 | 115 KB, 이탤릭 132 KB |
| 그리스 문자 | Noto Sans, 그리스 문자 | 2.015 | 77 KB, 이탤릭 83 KB |
| 베트남어 및 다른 악센트 문자를 포함한 라틴 문자 | Noto Sans, 라틴 문자 | 2.015 | 316 KB, 이탤릭 350 KB |
| 중국어 간체, GB 2312 문자 | Noto Sans SC | 2.004 | 2.0 MB |
| 중국어 번체, Big5 문자 | Noto Sans TC | 2.004 | 3.8 MB |
| 일본어, Shift_JIS 문자 | Noto Sans JP | 2.004 | 2.2 MB |
| 한국어, 모든 한글 음절과 KS X 1001 문자 | Noto Sans KR | 2.004 | 2.5 MB |

각 글꼴은 굵기 축의 모든 굵기를 유지하므로 중국어, 일본어, 한국어의 굵은 제목도 굵게 표시돼요. Noto Sans 글꼴은 너비 축을 보통으로 고정해 각 파일 크기를 절반으로 줄여요. 중국어, 일본어, 한국어 글꼴에는 너비 축이 없어요. Noto Sans는 문자 체계별로 나뉘므로 키릴 문자 단어가 있으면 키릴 문자만 내려받아요. 윤곽선은 업스트림 원본과 같아요.

::: details 글꼴의 위치와 빌드 방식
글꼴은 하나의 공유 폴더인 `community/fallback-fonts`에 있으며, 이모지 세트처럼 `/catalog/packs/fallback-fonts/`에서 모든 디자인 시스템에 제공돼요. `scripts/import-fallback-fonts.ts`는 `scripts/data/fallback-fonts.json`에 고정된 업스트림 글꼴로 파일을 빌드하고, 각 업스트림 파일을 기록된 SHA-256과 대조한 뒤 글꼴 옆에 라이선스 텍스트를 작성해요.
:::

## 중국어, 일본어, 한국어

줄이지 않은 중국어, 일본어, 한국어 글꼴은 9.6~17.8 MB예요. 각 글꼴은 해당 국가 문자 집합과 본문에 쓰이는 문장 부호, 가나, 전각 형태, 기호만 남겨 줄여요.

- 중국어 간체: GB 2312의 상용 한자 6,763자와 기호로, 모두 7,522자예요.
- 중국어 번체: Big5의 한자 13,053자와 기호로, 모두 13,629자예요. 홍콩 보충 문자 집합은 포함되지 않아요.
- 일본어: Windows와 웹에서 읽는 Shift_JIS로, JIS X 0208에 髙와 﨑 같은 이름에 필요한 NEC와 IBM 추가 문자, 모든 가나와 반각 가타카나를 더해 모두 7,432자예요.
- 한국어: 한글 음절 11,172자 전체와 한자 4,888자를 포함하는 KS X 1001로, 모두 17,082자예요.

이 네 글꼴에는 라틴, 그리스, 키릴 문자가 빠져 있으며, 이 문자는 디자인 시스템의 글꼴과 위의 글꼴이 그려요. 문자 집합은 고정된 커밋의 Encoding Standard 인덱스 파일에서 가져오므로 다시 빌드해도 같은 파일이 나와요.

중국어, 일본어, 한국어는 대부분의 문자를 공유하지만 많은 문자를 서로 다르게 그려요. 예를 들어 直은 중국어와 일본어에서 다르게 써요. 하나의 텍스트 구간은 공유 문자를 모두 이 글꼴 중 하나에서만 가져오며 두 글꼴을 섞지 않아요. Lolly는 다음 순서로 글꼴을 골라요.

1. 텍스트 구간의 언어로, 해당 요소나 문서에서 이를 감싸는 가장 가까운 요소의 `lang`에서 가져와요. 수료증의 Language 같은 도구의 언어 설정이 이 값을 정해요. Lolly 자체 인터페이스의 언어나 디자인 시스템의 언어는 적용되지 않으므로 누구나 문서를 똑같이 내보내요.
2. 텍스트 구간의 문자 체계예요. 가나가 있으면 일본어, 한글이 있으면 한국어예요. 둘 다 없으면 Lolly가 문서를 읽으므로 일본어 문서에서 한자로만 된 제목도 일본어로 그려져요. 문서에 가나와 한글이 모두 있으면 이 단계에서는 결정하지 않아요.
3. 텍스트 구간에, 또는 그 안에 없으면 문서에 體나 說처럼 중국어 번체에서만 쓰는 문자가 있으면 중국어 번체로 정해요. 단, 같은 텍스트에 중국어 간체에서만 쓰는 문자도 있으면 그렇지 않아요.
4. 그 밖의 경우는 중국어 간체예요.

선택한 글꼴에 없는 문자는 나머지 세 글꼴에서 가져오지 않아요. 그림으로 남아요. 일본어로 표시된 줄에 있는 한국어 단어처럼 선택한 글꼴에 없는 가나나 한글은 일본어 또는 한국어 글꼴에서 가져올 수 있어요. 다만 그 글꼴이 해당 줄의 공유 문자를 하나도 그리지 않는 경우에만 가능해요.

페이지에서 이 언어 중 두 가지가 있는 캔버스는 두 글꼴을 모두 나열하고 브라우저는 첫 번째 글꼴로 공유 문자를 그려요. 내보내기는 각 텍스트 구간을 해당 구간의 글꼴로 그려요.

## 글꼴을 내려받는 시점

문서에 디자인 시스템의 어떤 글꼴도 그릴 수 없는 문자가 들어오기 전에는 아무것도 내려받지 않아요. 영어 줄에 있는 ★나 ※ 같은 기호로는 중국어, 일본어, 한국어 글꼴을 내려받지 않아요.

문서에 대체 글꼴이 처음 필요해지면 Lolly는 그 글꼴 하나를 내려받아 기기에 보관해요. 일본어 문서는 2.2 MB의 일본어 글꼴만, 중국어 번체 문서는 3.8 MB의 번체 글꼴만 내려받아요. 그다음부터는 해당 문자 체계를 오프라인에서 그릴 수 있고 카탈로그를 정리해도 글꼴이 남아요. 글꼴은 카탈로그 파일과 함께 보관되며 업로드한 글꼴 사이에 들어가지 않고 브랜드 글꼴 목록에도 나타나지 않아요.

명령줄, 터미널 앱, MCP 서버는 디스크에서 같은 파일을 읽으므로 내려받을 필요가 없어요.

## 페이지와 내보내기에서

페이지는 내보내기와 같은 대체 글꼴을 쓰므로 이런 글자가 있는 줄은 양쪽에서 너비가 같아요. Lolly는 해당 캔버스에만 디자인 시스템의 자체 글꼴 뒤, 시스템 글꼴 앞에 대체 글꼴을 추가해요. 스타일이나 요소에 자체 글꼴 목록을 설정하는 도구도 같은 위치에 대체 글꼴이 추가돼요. 디자인 시스템이 모든 문자를 지원하는 캔버스는 글꼴 목록을 그대로 유지해요.

글꼴 목록이 `system-ui`나 Helvetica 같은 시스템 글꼴로 시작하면 페이지는 목록을 그대로 둬요. 내보내기는 그 텍스트를 디자인 시스템의 글꼴로 그리지만 페이지는 그렇지 않기 때문이에요.

PDF에서는 텍스트 설정에 관계없이 글자가 대체 글꼴의 윤곽선이 돼요. 라이브 PDF 텍스트는 임베드된 글꼴에 없는 문자 체계를 담을 수 없기 때문이에요. SVG, EMF, EPS, DXF, WMF에서는 텍스트를 윤곽선으로 변환할 때마다 글자가 윤곽선이 돼요. 텍스트를 라이브 상태로 유지하면 리더의 자체 글꼴이 그려요. 대체 글꼴이 내보내기의 일부를 그리면 내보내기 패널은 다음과 같은 안내를 보여줘요.

> 이 디자인 시스템의 글꼴에 일본어 문자가 없어 일본어 텍스트는 Noto Sans JP로 그려요.

명령줄도 같은 문장을 안내로 출력해요.

## 그림으로 남는 것

𠮷이나 홍콩 보충 문자처럼 네 국가 문자 집합에 없는 문자에는 대체 글꼴이 없어요. 𠮷 같은 드문 문자, 홍콩 보충 문자 집합에서 추가된 문자, 타밀, 에티오피아, 시리아 문자처럼 대체 글꼴이 없는 문자 체계는 모두 같은 방식으로 처리돼요. 타밀, 에티오피아, 시리아 같은 문자 체계에도 대체 글꼴이 없어요. PDF에서는 이런 텍스트가 있는 줄이 300 dpi 그림으로 들어가며, 내보내기 패널이 문자 체계를 나열해요. SVG에서는 해당 구간이 라이브 텍스트로 남고 리더의 자체 글꼴이 그려요.

::: details EPS, WMF, EMF 내보내기에서
**Outline fonts**를 켠 EPS, WMF, EMF에는 대체할 라이브 텍스트가 없으므로 해당 구간도 300 dpi 그림으로 들어가요. 그림은 글자가 있는 곳에만 텍스트 색상을 칠하므로 배경이 비쳐 보여요. 내보내기 패널은 문자 체계를 나열해요. 그림은 똑바로 선 상태로만 그려지므로 회전하거나 기울어진 구간이 있으면 해당 구간을 인용하는 메시지와 함께 내보내기가 중단돼요. WMF나 EMF에서 그림은 마스크와 칠하기라는 한 쌍의 비트맵 연산이에요. Microsoft Office와 LibreOffice는 의도한 대로 그려요. Inkscape처럼 이 연산을 무시하는 앱은 흰 상자 위에 글자를 보여줘요.

**Outline fonts**를 끈 EMF는 이런 구간을 라이브 텍스트로 유지하며 리더의 자체 글꼴이 그려요. 자간이 있는 텍스트처럼 라이브 EMF 텍스트가 담을 수 없는 구간은 예외예요. Lolly는 해당 구간을 윤곽선으로 바꾸므로 어떤 글꼴도 그릴 수 없는 구간은 여기서도 그림으로 들어가요.
:::

::: warning 어떤 글꼴도 그릴 수 없는 텍스트가 있으면 DXF 내보내기가 중단돼요
DXF는 윤곽선이 필요한 커팅 머신과 CAD 소프트웨어로 전달되므로 어떤 글꼴도 그릴 수 없는 구간이 있으면 DXF 내보내기가 중단돼요. 메시지는 해당 구간을 인용하고 문자 체계를 알려줘요. 그 문자가 있는 글꼴을 추가하거나 SVG나 PDF로 내보내세요.
:::

## 내보내기 전 확인

Lolly Design의 **Before you export** 카드와 `lolly check`의 `render` 검사는 어떤 글꼴도 그릴 수 없는 텍스트를 보고해요. 내보내기처럼 같은 글꼴별 문자 목록을 바탕으로 대체 글꼴도 고려하므로 대체 글꼴이 그리는 텍스트는 보고하지 않아요. 타밀 문자처럼 대체 글꼴이 없는 문자 체계와 국가 문자 집합에 없는 중국어, 일본어, 한국어 문자는 여전히 보고돼요. 내보내기가 이를 그림이나 라이브 텍스트로 그리고, DXF 내보내기는 이 문자에서 중단되기 때문이에요. 검사는 카탈로그에서 이 목록을 읽으며 글꼴은 내려받지 않아요.

## 라이선스와 크레딧

모든 대체 글꼴에는 SIL Open Font License 1.1이 적용돼요. 각 카탈로그 항목은 라이선스 텍스트의 해시와 함께 라이선스를 기록하므로 [창작물의 권리와 크레딧](/info/creative-rights.html)의 권리 규칙은 다른 글꼴과 똑같이 라이선스를 읽어요. 라이선스 텍스트는 글꼴 옆에 있어요. Noto Sans 파일은 Reserved Font Name을 선언하지 않아요. 중국어, 일본어, 한국어 글꼴은 Adobe 소유이며 Source라는 이름을 예약해요. 줄인 파일은 그 이름을 쓰지 않는 Noto 이름을 유지해요.

라이선스는 해당 글꼴로 만든 문서에는 약관이 적용되지 않는다고 명시해요. 내보낸 파일에는 디자인 시스템 자체 글꼴과 마찬가지로 사용한 글자의 윤곽선만 들어가요. Lolly는 대체 글꼴을 위한 글꼴 프로그램, 크레딧 문구, 새 콘텐츠 자격 증명 항목을 추가하지 않아요.
