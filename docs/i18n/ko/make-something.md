# 첫 파일 만들기

웹 주소를 여는 QR 코드를 다운로드하고, 나중에 열어서 바꿀 수 있는 사본을 저장하세요. 계정도 사전 설정도 필요 없어요. 계정도 설정도 필요 없어요.

::: note 시작하기 전에
코드가 열어야 할 `https://`로 시작하는 웹 주소를 준비하세요.
:::

::: steps
- <!--i:eti-pen--> **[코드 만들기](#make-the-code)** Lolly QR Code에 주소를 넣고 색상을 정하세요.
- <!--i:eti-download--> **[파일 다운로드하기](#download-the-file)** 화면용으로는 PNG를, 인쇄용으로는 SVG나 PDF를 내보내세요.
- <!--i:eti-folder-plus--> **[편집 가능한 사본 보관하기](#keep-an-editable-copy)** 나중에 코드를 바꿀 수 있도록 작업물을 저장하세요.
:::

<!--i:eti-pen-->
## 코드 만들기

1. [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)를 여세요. 컨트롤은 미리보기 옆에 있고, 휴대폰에서는 미리보기 위에 있어요. 미리보기는 파일이 어떻게 나올지 보여줘요.
2. **URL**에서 예시 주소 전체를 자신의 주소로 바꾸세요. 입력할 때마다 미리보기가 바뀌어요.
3. 자신의 색상에 맞추려면 **Module colour**와 **Background**를 설정하세요. 두 색상의 대비가 뚜렷해야 해요. 그렇지 않으면 휴대폰이 코드를 읽기 어려워요.
4. **Modules** 아래의 **Quiet zone**은 처음에 4로 설정돼 있어요. 4 이상으로 유지하세요. 휴대폰 카메라는 그 빈 여백을 찾아요.

<!--i:eti-download-->
## 파일 다운로드하기

1. **Export | Save as** 알약에서 **Export**를 누르세요. 컴퓨터에서는 컨트롤 맨 아래에 있고, 휴대폰에서는 화면 아래쪽에 떠 있어요.
2. 파일 이름 옆의 형식 메뉴를 열고(처음에는 **SVG**예요) 화면이나 메시지에 쓸 **PNG**를 고르세요. 인쇄하려면 아래 참고 사항을 보세요.
3. **Download**를 누르세요. 파일은 브라우저의 다운로드 위치에 저장돼요. 거기에 없다면 [다운로드한 파일 찾기](/info/find-your-work.html#find-a-file-you-downloaded)를 참고하세요.

::: check 파일을 공유하기 전에 코드를 스캔하세요
다운로드한 파일을 화면에 열고 휴대폰 카메라로 코드를 스캔하세요. 휴대폰에서 만들었다면 다른 휴대폰이나 컴퓨터 화면에 띄워 스캔하세요. 휴대폰에 자신의 웹 주소가 표시되어야 해요.
:::

::: note 코드를 인쇄하거나 손으로 만지는 곳에 쓸 때
어떤 크기에서도 코드가 선명하도록 **SVG**나 **PDF**를 고르세요. 실제 사용할 크기로 인쇄해 테스트하세요. 코드가 긁히거나 젖을 수 있다면 **Modules** 아래의 **Error correction**을 **High (30%)**로 설정해 손상된 코드도 읽을 수 있게 하세요.
:::

## 편집 가능한 사본 보관하기

나중에 코드를 바꾸려면 작업물도 저장하세요.

1. **Save as**를 누르고 **Save**를 누르세요. Export 패널이 열려 있으면 **Save as**는 패널 안에 있어요. 패널이 닫혀 있으면 **Export** 옆의 체크 표시를 쓰세요. 코드는 **My library**에 저장되고 **Saved** 메시지에 **Open Projects**가 나타나요.
2. 다음에는 **Home**을 누르고 **Projects** 보기를 여세요(휴대폰에서는 폴더 아이콘이에요). **QR Code**라는 이름으로 코드가 있어요. 열어서 원하는 대로 바꾸고 다시 내보내세요.

[Sync](/info/sync.html)를 켜지 않으면 저장한 작업물은 이 기기에서 사용한 브라우저나 앱에 남아요. [작업물 찾기와 복구](/info/find-your-work.html)에서 폴더, 이전 버전, 다른 기기로 작업물 옮기기를 다뤄요.

## 처음 해볼 다른 프로젝트

- [Lolly Audiogram](/#/tool/audiogram)은 음성 메모를 움직이는 파형, 표지의 글, 자신의 색상이 담긴 동영상으로 바꿔요. 녹음 파일을 **Audio**에 끌어다 놓고 **Title**을 넣은 다음 **MP4**로 내보내세요.
- [Lolly Filter](/#/tool/filter)는 포스터에 쓸 사진에 효과를 줘요. 인쇄된 하프톤 점, 두 가지 단색, 몇 개의 명암 덩어리 등이에요. **Image**에서 사진을 고르고 **Effect**를 선택한 다음 **PNG**로 내보내세요. *vector* 배지가 붙은 효과는 **SVG**로도 내보낼 수 있어요.
- [음악 생성기](/#/music)는 장르와 시드로 곡을 만들어요. 재생되는 곡이 마음에 들 때까지 둥근 셔플 버튼을 누른 다음 **Render**를 열어 M4A나 WAV 파일을 다운로드하세요. 만든 음악은 **Lolly로 만든 음악 (https://lolly.tools), CC BY 4.0**이라는 크레딧을 표시하면 상업적 용도를 포함해 무료로 사용할 수 있어요. [음악 생성기 가이드](/info/music-generator.html)에서 모든 컨트롤을 안내하고, [무료 배경 음악](/info/background-music.html)에서는 모든 장르의 샘플을 들을 수 있어요.

## 다음 단계

- **파일 대신 링크를 보내세요.** 조작한 모든 컨트롤이 페이지 주소에 담겨 있어요. 내보내기 패널의 **Share**는 다른 사람의 화면에서 같은 디자인을 여는 링크를 제공해요. 자신의 기기에서 업로드한 사진은 링크에 담겨 이동하지 않아요. [작업물 공유하기](/info/using.html#sharing-your-work)를 참고하세요.
- **색상과 글꼴을 한 번 추가하세요.** 그러면 모든 도구가 그 색상과 글꼴로 시작해요. [빠른 시작](/info/quickstart.html)을 참고하세요.
- [Lolly 사용하기](/info/using.html)는 앱 전체 가이드예요. [만드는 사람을 위한 Lolly](/info/creators.html)에서는 Lolly로 만들 수 있는 다른 결과물을 보여줘요.
