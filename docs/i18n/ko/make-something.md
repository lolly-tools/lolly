# 첫 파일 만들기

이 페이지를 다 읽을 즈음이면 웹 주소 하나를 담은 QR 코드를 다운로드하고, 나중에 열어서 바꿀 수 있는 사본도 저장해 두었을 거예요. 계정도 필요 없고 미리 설정할 것도 없어요.

::: note 시작하기 전에
코드가 열어야 할, `https://`로 시작하는 웹 주소를 준비하세요.
:::

## 코드 만들기

1. [QR 코드](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)를 여세요. 컨트롤은 미리보기 옆(휴대폰에서는 위)에 있고, 미리보기에 보이는 것이 곧 파일이 돼요.
2. **URL**에서 예시 주소를 자신의 주소로, 전체를 그대로 바꿔 넣으세요. 입력하는 대로 미리보기가 바뀌어요.
3. 원하는 색상에 맞추려면 **모듈 색상**과 **배경**을 설정하세요. 둘 사이의 대비를 강하게 유지하지 않으면 휴대폰이 코드를 읽기 어려워해요.
4. **모듈** 아래의 **여백 영역**은 4에서 시작해요. 4 이상으로 유지하세요: 이 여백이 바로 휴대폰 카메라가 찾는 부분이에요.

## 파일 다운로드하기

1. 컴퓨터에서는 컨트롤 아래쪽에, 휴대폰에서는 화면 아래에 떠 있는 **Export | Save as** 알약에서 **Export**를 누르세요.
2. 파일 이름 옆의 형식 메뉴(처음에는 **SVG**)를 열고, 화면이나 메시지용이면 **PNG**를 고르세요. 인쇄용이면 아래 노트를 참고하세요.
3. **다운로드**를 누르세요. 파일은 브라우저의 다운로드 폴더로 들어가요. 거기 없다면 [다운로드한 파일 찾기](/info/find-your-work.html#find-a-file-you-downloaded)를 확인하세요.

::: check 파일을 공유하기 전에 코드를 스캔하세요
다운로드한 파일을 화면에서 열고 휴대폰 카메라로 코드를 스캔하세요. 휴대폰에서 만들었다면 다른 휴대폰이나 컴퓨터 화면으로 스캔하세요. 휴대폰에 사용자의 웹 주소가 떠야 해요.
:::

::: details 코드를 인쇄하거나 사람 손을 탈 예정이라면
어떤 크기에서도 선명함을 유지하도록 **SVG**나 **PDF**를 선택하고, 실제로 사용할 크기로 인쇄 테스트를 해 보세요. 코드가 긁히거나 비에 젖을 수 있다면 **모듈** 아래의 **오류 정정**을 **높음 (30%)**으로 설정하세요: 손상된 코드도 여전히 인식돼요.
:::

## 편집 가능한 사본 남기기

다운로드한 파일은 이걸로 완성이에요. 나중에 코드를 바꾸려면 작업물도 함께 저장해 두세요:

1. **다른 이름으로 저장**을 누른 다음 **저장**을 누르세요. 내보내기 패널이 열려 있으면 **다른 이름으로 저장**은 그 패널 안에 있어요. 닫혀 있으면 **내보내기** 옆의 체크 표시가 그거예요. 코드는 **내 라이브러리**로 들어가고, **저장됨** 메시지가 **프로젝트 열기**를 제안해요.
2. 다음에는 **홈**을 누르고 **프로젝트**(휴대폰에서는 폴더 아이콘)를 여세요. 코드는 **QR 코드**라는 이름으로 거기 있어요. 열어서 무엇이든 바꾸고 다시 내보내세요.

[동기화](/info/sync.html)를 켜지 않는 한, 저장한 작업은 사용한 브라우저나 앱 안에서 이 기기에만 남아요. [작업 찾기 및 복구](/info/find-your-work.html)에서 폴더, 이전 버전, 다른 기기로 작업을 옮기는 방법을 다뤄요.

## 다른 첫 프로젝트

- [오디오그램](/#/tool/audiogram)은 음성 메모를 동영상으로 바꿔요: 움직이는 파형, 커버에 실리는 말, 사용자의 색상. **오디오**에 녹음을 넣고 **제목**을 추가한 다음 **MP4**로 내보내세요.
- [필터](/#/tool/filter)는 포스터용으로 사진을 가공해요: 인쇄용 망점, 두 가지 단색, 또는 몇 단계의 톤. **Image** 아래에서 사진을 고르고 **Effect**를 선택한 다음 **PNG**로, *vector* 표시가 붙은 효과라면 **SVG**로 내보내세요.

## 다음으로

- **파일 대신 링크를 보내세요.** 사용자가 손댄 모든 컨트롤이 페이지 주소에 기록되므로, 내보내기 패널의 **공유**를 쓰면 같은 디자인을 다른 사람의 화면에서 다시 여는 링크를 얻을 수 있어요. 자신의 기기에서 업로드한 사진은 그 링크와 함께 이동하지 않아요. [작업물 공유하기](/info/using.html#sharing-your-work)를 참고하세요.
- **색상과 폰트를 한 번만 설정해 두면** 모든 도구가 그것으로 시작해요: [빠른 시작](/info/quickstart.html).
- [Lolly 사용하기](/info/using.html)는 앱의 전체 가이드이고, [크리에이터를 위한 Lolly](/info/creators.html)는 그 밖에 무엇을 만들 수 있는지 둘러봐요.
