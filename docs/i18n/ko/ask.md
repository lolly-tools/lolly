# Ask Lolly

Ask Lolly는 질문에 맞는 가이드 섹션을 한 글자도 바꾸지 않고 인용해 답해요. 해당 페이지의 출처와 그 섹션으로 가는 **Open in docs** 링크도 있어요. 생성하는 것은 없어요. 기기에서 답을 찾아 인용해요.

인용된 섹션 아래에는 질문과 맞는 앱 안의 위치가 있어요. 도구, 유틸리티, 저장된 프로젝트, 카탈로그 에셋, 설정, 앱의 페이지 등이에요. 각 행은 이동만 해요. 답변의 어떤 부분도 설정을 바꾸거나, 파일을 열거나, 사용자를 대신해 동작하지 않아요. [Lolly Search](/info/search.html)와 같은 규칙이에요.

## 질문하기

보기 아래쪽의 질문 입력란에 입력하고 Enter를 누르세요. 두 글자보다 짧은 입력은 무시해요. 답변은 입력란 위에 쌓이며 가장 새 답변이 맨 아래에 있어요.

![열려 있는 빈 Ask Lolly: 보기 아래쪽에 질문 입력란이 있고, 문서에서 답변을 가져온다는 안내가 있어요](/t/url-shot?url=%2F%23%2Fask&width=1200&height=820&waitMs=2200&format=svg&walker=1&filename=ask-view)

::: note 각 질문은 독립적이에요
앞선 질문의 맥락은 다음 질문으로 이어지지 않아요. 따라서 내보내기를 물은 뒤 "PDF는요?"라고 물으면 PDF만 묻는 질문으로 읽어요. 매번 질문 전체를 물어보세요.
:::

질문의 첫 단어가 답변에서 먼저 나올 것을 정해요.

| 시작하는 말 | 먼저 나오는 것 |
|---|---|
| *where*, *find*, *open*, *show*, *go to*, *goto*, *take*, *jump*, *navigate*, *switch* | 일치하는 앱 안의 위치 |
| *make*, *create*, *generate*, *build*, *design*, *convert*, *resize*, *compress*, *remove*, *strip*, *export*, *render*, *add* | 일치하는 도구 |
| 그 밖의 모든 말 - *how do I*와 *what is* 포함 | 기본값인 문서 섹션 |

두 부분은 항상 모두 검색되므로, 질문을 잘못 읽어도 답변의 순서만 바뀌어요.

매칭에서는 흔한 질문 단어(*how*, *do*, *I*, *the*, *my*)를 빼요. 나머지 단어가 얼마나 많이 포함돼 있는지, 그다음 어디에서 일치했는지로 섹션 순위를 매겨요. 제목은 본문보다 비중이 커요. 매칭은 대소문자와 악센트를 구분하지 않는 부분 문자열 방식이므로 오타를 고치지는 않아요. 일치하는 것이 없으면 Ask가 이를 알리고 문서 색인으로 안내해요.

**Better matching**은 선택 사항이에요. 첫 답변 뒤에 Ask가 작은 매칭 모델과 다운로드 크기를 제시할 수 있어요. 이 모델은 같은 것을 다른 말로 설명하는 가이드에 질문을 연결해요. 동의할 때만 다운로드하고, 이 기기에서 실행되며, 어떤 섹션이 먼저 나오는지만 바꿔요. 답변은 여전히 문서의 원래 문구예요. **Settings → Preferences → Available offline** 아래의 **Ask matching model**로도 다운로드할 수 있어요([오프라인에서 사용 가능](/info/dashboard.html#available-offline)).

## 답변에 담기는 것

답변 카드의 순서는 정해져 있어요.

1. 문서 원본에서 렌더링한 **섹션 자체**예요. 단락, 목록, 표, 코드, 인용문이 있고, 앱 안의 링크와 `/info` 링크는 작동해요. 긴 섹션 끝에는 **Show more**가 있어 나머지를 그 자리에서 펼쳐요. 이미지는 빠지고, 다른 사이트로 가는 링크는 일반 텍스트로 표시돼요.
2. **출처** - *페이지 › 제목* - 와 정확히 그 섹션으로 가는 **Open in docs** 링크예요.
3. **More in the docs** - 일치하는 다른 섹션 최대 네 개를 링크로 보여줘요.
4. Search와 같은 그룹 제목 아래에 있는 **앱 안의 항목 행**이에요.

전체 텍스트는 각 문서 페이지가 `/info/<slug>.md`에 게시하는 Markdown 사본에서 가져와요. 이 사본은 영어만 있어요. 다른 언어이거나 Markdown으로 만들지 않은 소수의 페이지라면, 대신 검색 색인의 짧은 발췌문을 답변으로 보여줘요. 출처와 **Open in docs** 링크는 여전히 사용자의 언어로 된 페이지로 가요.

## 어디서 여나요

경로는 `#/ask`예요. 탭도 없고 Utilities 격자의 타일도 없어요. 검색 막대나 주소로 보기에 들어가요.

- <!--i:search--> **검색에서.** 모든 결과 패널은 다른 그룹의 결과 아래에 있는 **Ask Lolly: *검색어*** 행으로 끝나요. 이 행은 `#/ask?q=…`를 열고, 보기가 열리면 질문을 한 번 물어요. 단어는 문장 부호 없이 소문자로 전달되므로, 필요하면 질문 입력란에서 다듬으세요.
- <!--i:link--> **링크에서.** `#/ask?q=how%20do%20I%20export%20a%20transparent%20png`는 해당 질문을 이미 물은 상태로 보기를 열어요. 해시는 첫 질문만 채워요. 이후에 입력하는 질문은 그 자리에서 답변되며 주소를 바꾸지 않아요.

이 보기에서는 질문 입력란이 Enter를 사용하므로 검색 막대가 숨겨져요. 뒤로 가기 알약은 원래 있던 곳으로 돌려보내요.

답변은 이번 세션 동안 유지돼요. 나갔다 돌아와도 그대로 있고, 새로고침하면 지워져요. 저장소에 아무것도 쓰지 않으므로 관리할 기록도 없어요.

## 오프라인

답변은 문서 사이트가 게시하는 두 정적 파일에서 가져와요. 언어별 검색 색인과 페이지의 Markdown 사본이에요. 둘 다 이름으로 가져오므로 한 번 캐시되면 Ask는 연결 없이도 동작해요. 앱에서 가이드를 읽으면 캐시돼요. [오프라인에서 사용 가능](/info/dashboard.html#available-offline) 아래의 **Guides & docs**는 스크린샷을 포함한 전체 사이트를 한 번에 다운로드해요.

이 파일들이 없으면 답변에서 문서 부분이 나타나지 않고 오류도 표시되지 않아요. 앱 안의 항목 행은 기기에 이미 있는 데이터와 매칭하므로 계속 나타나요.

## 개인정보 보호

질문은 기기를 벗어나지 않아요. 매칭은 이름으로 가져온 파일을 대상으로 기기에서 실행되므로, 입력한 내용은 어떤 요청에도 포함되지 않아요. 어떤 서버도 질문을 보지 않고, 어떤 계정에도 질문이 담기지 않으며, 새로고침한 뒤에는 기록도 남지 않아요. [개인정보 처리방침](/info/privacy.html)에 앱이 가져오거나 보내는 모든 것이 나열돼 있어요.
