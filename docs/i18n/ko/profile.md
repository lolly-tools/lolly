# 프로필

이름, 연락처, 인물 사진을 한 번 설정하면 이메일 서명, 배지, 발표자 카드처럼 이 정보를 사용하도록 만들어진 모든 도구가 자동으로 채워 넣어요. 이 기록이 **프로필**이며, 기기에 저장돼요.

프로필에는 저장된 세션, 업로드한 이미지, 로컬 활동 집계도 담겨요. **Settings → Preferences**에서 관리하세요. 도구는 미리 채우도록 만들어진 필드만 읽어요. 독립적으로 사용할 때는 계정이 필요 없어요. 선택적 Sync, 공유, 조직 서비스에는 각각 별도의 데이터 흐름이 있어요.

<!--i:eti-user-check-->
## 프로필에 담긴 내용

| 항목 | 내용 |
|---|---|
| **Name** | 이름과 성이에요. |
| **Contact** | 이메일과 전화번호예요. |
| **Location** | 도시와 국가예요. |
| **Headshot** | 이메일 서명, 인용 카드, 조직도 같은 도구를 위한 선택적 사진이에요. 정사각형으로 잘라 로컬 이미지로 보관해요. |
| **Use my details to create** | 직접 선택해서 켜는 스위치로, 켜면 **Using my details**로 표시돼요. 내보낸 파일과 Lolly Batch 실행에 작성자 표시로 개인 정보를 넣을지 정해요. [도구가 프로필을 사용하는 방식](#how-tools-use-your-profile)을 참고하세요. |
| **Preferences** | 테마, 디자인 시스템별 컬러웨이, 접근성 설정, **Feature flags**에서 켠 앱 기능이에요. |
| **Your work** | [Lolly Projects](/info/find-your-work.html)에 정리된 썸네일이 있는 저장 세션, 업로드한 이미지, 로컬 활동 통계예요. |

필수 항목은 없으며 빈 프로필로도 사용할 수 있어요.

[Lolly 설정](/info/dashboard.html)에서는 모양과 이모지부터 저장소와 오프라인 다운로드까지 Preferences의 나머지 내용을 다뤄요.

## 나, 팀, 역할

Lolly에서 프로필은 무언가를 만드는 동안 누구로 작업하는지를 뜻해요. 자신일 수도, 팀일 수도, 역할일 수도 있어요. Lolly는 셋을 같은 방식으로 다뤄요.

::: cols
## 나로서

기본은 자신의 이름, 이메일, 인물 사진이에요. 서명, 배지, 콘퍼런스 로고 조합에 이 정보가 채워져요.

## 팀으로서

팀의 공통 이름, `events@…` 같은 그룹 받은편지함, 부서, 팀의 마크를 써요. 한 사람이 프로필을 설정하고 파일로 내보내요. 다른 사람들도 같은 프로필을 로드하므로 팀의 파일에는 같은 정보가 담겨요. 공용 키오스크나 데모 노트북에서 하나의 팀 프로필을 사용할 수 있어요.

## 역할에 따라

행사 담당자는 1년에 사흘 동안 배지와 안내 표지에 행사 받은편지함과 하위 브랜드를 써야 하고, 그 뒤에는 평소 신원으로 돌아가야 해요. 역할을 프로필 파일로 저장해 두고 행사 때 파일을 로드한 다음 끝나면 따로 보관하세요.
:::

::: details Lolly Work를 사용하는 조직의 프로필
[조직의 Lolly](/info/organisation.html)에 로그인하면 Lolly Work는 ID 공급자로부터 확인된 프로필 필드를 제공하고 조직 정책에 따라 필드나 환경설정을 고정할 수 있어요. 관리되는 필드는 앱에 표시돼요.

그 로그인은 공유 프로젝트와 에셋의 접근도 제어해요. 팀 프로필 파일은 로컬 파일이에요. 조직 구성원 자격을 부여하거나 업무용 계정을 대신하지 않아요. **Use my details to create**는 내보내기에 들어가는 작성자 표시를 제어하며, 조직의 로그인이나 감사 기록은 제어하지 않아요. [개인정보 보호](/info/privacy.html#organisation-services-with-lolly-work)를 참고하세요.
:::

## 여러 개를 보관하고 하나를 사용하기

설치 환경 하나에서는 한 번에 프로필 하나만 활성화되며, 앱 내 전환 기능은 없어요. 각 프로필은 이동 가능한 파일이며, 작업물을 새 기기로 옮기는 백업 파일과 같아요. 작업 상황을 바꾸려면:

::: timeline
- <!--i:download--> **Settings → Storage → Move to another device**의 **Export my data**는 현재 프로필을 하나의 `.zip`으로 저장해요.
- <!--i:trash--> **Clear all my data**는 이 설치 환경을 비워요.
- <!--i:upload--> **Import data…**는 전환하려는 작업 상황에 맞는 프로필 파일을 로드해요.
:::

::: note 먼저 지우지 않고 가져오면 병합돼요
가져온 세션과 이미지가 추가돼요. 양쪽에 사본이 있으면 더 최근에 저장한 것을 보관해요. 폴더, 즐겨찾기, 템플릿은 기존 항목 옆에 추가돼요. 자신의 정보는 유지되지만 빈 필드는 파일의 값으로 채워져요. 병합은 팀의 세션을 자신의 환경으로 가져올 때 적합하지만, 역할을 완전히 분리해서 전환하는 데는 맞지 않아요.
:::

두 작업 상황을 동시에 쓰려면 별도의 브라우저 프로필, 사용자 계정 또는 따로 설치한 웹 앱을 사용하세요. 각각 자체 Lolly 프로필을 가져요.

::: note 작업 상황마다 파일 하나를 보관하세요
`LollyTools-events-2026.zip`, `LollyTools-me.zip`처럼 용도에 맞게 파일 이름을 붙이세요. 파일이 곧 프로필이에요.

## 도구가 프로필을 사용하는 방식

**미리 채우기.** 도구 작성자는 입력이 프로필에서 값을 가져오도록 표시해요(`bindToProfile: "firstname"`, `"email"`, `"headshot"` 등). 도구가 열리면 그 입력이 프로필에서 채워져요. 조직 정책이 입력을 잠그지 않은 한, 프로필을 바꾸지 않고 한 세션의 값만 덮어쓸 수 있어요. 미리 채우기는 로컬에서 이뤄지며 **Use my details**가 켜져 있는지와 관계없이 동작해요.

**작성자 표시.** 내보낼 때 개인 정보가 파일의 메타데이터(PNG, PDF, SVG 등)에 작성자 표시로 담길 수 있어요. **Use my details to create**는 이 표시와 Lolly Batch 실행의 작성자를 제어해요. 스위치를 꺼도 내보낸 파일에는 Lolly로 만들었다는 표시가 남지만, 개인 작성자나 연락처 줄은 들어가지 않아요.

도구 작성자는 [`bindToProfile`](/info/tool-inputs.html#bindtoprofile)과 [`host.profile`](/info/host-api.html#host-profile)을 참고하세요.

## 프로필, 디자인 시스템, 기능

Settings에는 서로 가까이 있어 혼동하기 쉬운 세 가지가 있어요:

- <!--i:people--> **Profile** - 자신, 팀 또는 현재 맡은 역할: 이름, 연락처, 인물 사진, 저장된 작업물이에요. 개인용으로 기기에 보관되며 파일로 옮길 수 있어요.
- <!--i:palette--> **Design system** - 브랜드: 모든 도구가 렌더링에 쓰는 색상, 글꼴, 설정이에요. 개인용이 아닌 공유 항목이에요. [Lolly Design System Setup](/info/brand-studio.html)을 참고하세요.
- <!--i:sliders--> **Capabilities** - 앱이 할 수 있는 것: 사용할 수 있는 기능과 도구예요.

Lolly에서 이 단어는 세 가지 다른 뜻으로도 쓰여요. **콘텐츠 프로필**은 배포에 포함할 도구와 카탈로그를 고르는 빌드 설정이에요. [용어집](/info/glossary.html)에 정의가 있어요. 링크 매개변수 `profile`은 CMYK 인쇄 조건 같은 내보내기용 색상 프로필을 골라요. [예약된 URL 매개변수](/info/url-parameters.html#print)를 참고하세요. **확인된 ID**는 이메일을 서명된 내보내기 파일과 연결하는 선택적 서명 인증서예요. 개인 정보와는 별개지만 **Use my details to create**가 둘 중 어느 것이든 임베드할지 결정해요. [Content Credentials](/info/content-credentials-identity.html)를 참고하세요.

## 개인정보 보호

개인 프로필은 로컬에 저장돼요. 개인 정보는 백업이나 Sync 사본, 공유하거나 내보내는 콘텐츠에 담겨 이동할 수 있으며, 선택적 Content Credentials 등록 중에도 전송될 수 있어요. Lolly Work 인스턴스에서는 로그인, 공유 작업, 텔레메트리 정책, 감사 기록이 이 로컬 프로필과 별개예요. **Settings → Preferences → Clear all my data**는 이 기기를 지우며, 저장소 제공업체나 조직이 보관한 사본은 지우지 않아요. [개인정보 처리방침](/info/privacy.html)을 참고하세요.
