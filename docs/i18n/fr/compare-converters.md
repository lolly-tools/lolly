# Lolly et les convertisseurs de fichiers en ligne

_Dernière vérification : 28 septembre 2026._

Lolly convertit les fichiers dans le navigateur, sur ton propre appareil : HEIC vers JPG, PNG vers SVG, PDF vers images et de nombreuses autres combinaisons. Consulte [tous les formats que Lolly peut ouvrir et produire](/info/formats.html) pour les conversions prises en charge et leurs limites.

## Où a lieu la conversion

Un convertisseur dans le navigateur peut téléverser un fichier pour le traiter, ou convertir en local. Les utilitaires de Lolly sur l'appareil traitent le fichier localement, sans compte, sans publicités ni traqueurs. Ils n'ajoutent ni filigrane Lolly ni métadonnées de provenance. Une fois les ressources de conversion nécessaires disponibles, ils peuvent fonctionner hors ligne ; la taille des fichiers est limitée par la mémoire de l'appareil et par le lecteur du format concerné.

Choisis un convertisseur selon les formats et la fidélité dont tu as besoin, ainsi que selon l'endroit où il traite le fichier. Certaines conversions préservent la structure modifiable, d'autres aplatissent le résultat ; les pages de formats de Lolly décrivent ces différences.

## Quand une équipe a besoin de plus

[lolly.work](https://lolly.work) est le service d'organisation du projet Lolly, déployé séparément. Il ajoute le SSO, SCIM, les catalogues partagés, les validations, les rapports et le rendu serveur pour les workflows de production pris en charge. Les deux parties sont open source sous MPL-2.0. Une organisation peut les utiliser ensemble pendant que ses membres continuent d'utiliser les utilitaires sur l'appareil pour les conversions locales.

La distinction compte pour le traitement des données : une conversion locale garde le fichier sur l'appareil, tandis que choisir un téléversement partagé, un rendu serveur ou une livraison envoie les données concernées aux services configurés. La [vue d'ensemble de la solution combinée](/info/compare.html) explique cette séparation.
