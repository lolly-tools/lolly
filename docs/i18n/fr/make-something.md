# Créer ton premier fichier

Télécharge un code QR pour une adresse web et enregistre une copie que tu pourras rouvrir et modifier plus tard. Tu n'as besoin ni de compte ni de configuration préalable. Tu n'as besoin ni de compte ni de configuration.

::: note Avant de commencer
Prépare l'adresse web que le code doit ouvrir, en commençant par `https://`.
:::

::: steps
- <!--i:eti-pen--> **[Créer le code](#make-the-code)** Saisis ton adresse dans Lolly QR Code et règle ses couleurs.
- <!--i:eti-download--> **[Télécharger le fichier](#download-the-file)** Exporte un PNG pour un écran, ou un SVG ou PDF pour l'impression.
- <!--i:eti-folder-plus--> **[Garder une copie modifiable](#keep-an-editable-copy)** Enregistre ton travail pour pouvoir modifier le code plus tard.
:::

<!--i:eti-pen-->
## Créer le code

1. Ouvre [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Les contrôles sont à côté de l'aperçu, ou au-dessus sur un téléphone. L'aperçu montre ce que sera le fichier.
2. Dans **URL**, remplace toute l'adresse d'exemple par la tienne. L'aperçu change à mesure que tu tapes.
3. Pour utiliser tes propres couleurs, règle **Module colour** et **Background**. Garde un contraste fort entre les deux, sinon les téléphones ont du mal à lire le code.
4. **Quiet zone**, sous **Modules**, vaut 4 au départ. Garde cette valeur à 4 ou plus. L'appareil photo d'un téléphone cherche cette marge unie.

<!--i:eti-download-->
## Télécharger le fichier

1. Appuie sur **Export** dans la pastille **Export | Save as**, au pied des contrôles sur un ordinateur ou flottant en bas de l'écran sur un téléphone.
2. Ouvre le menu de format à côté du nom de fichier (réglé sur **SVG** au départ) et choisis **PNG** pour un écran ou un message. Pour l'impression, consulte la note ci-dessous.
3. Appuie sur **Download**. Le fichier arrive dans les téléchargements de ton navigateur. S'il n'y est pas, consulte [Retrouver un fichier téléchargé](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scanne le code avant de partager le fichier
Ouvre le fichier téléchargé sur un écran et scanne le code avec l'appareil photo d'un téléphone. Si tu l'as créé sur ton téléphone, scanne-le depuis un second téléphone ou un écran d'ordinateur. Le téléphone doit te proposer ton adresse web.
:::

::: note Si le code sera imprimé ou manipulé
Choisis **SVG** ou **PDF** pour que le code reste net à toute taille. Teste une impression à la taille prévue. Si le code risque d'être abîmé ou mouillé, règle **Error correction**, sous **Modules**, sur **High (30%)** pour qu'il reste lisible même endommagé.
:::

<!--i:eti-folder-plus-->
## Garder une copie modifiable

Pour modifier le code plus tard, enregistre aussi ton travail :

1. Appuie sur **Save as**, puis sur **Save**. Quand le panneau Export est ouvert, **Save as** se trouve dans ce panneau. Quand il est fermé, utilise la coche à côté de **Export**. Le code est enregistré dans **My library** et un message **Saved** propose **Open Projects**.
2. La prochaine fois, appuie sur **Home** et ouvre la vue **Projects** (l'icône de dossier sur un téléphone). Ton code s'y trouve, sous le nom **QR Code**. Ouvre-le, modifie ce que tu veux et exporte-le à nouveau.

Le travail enregistré reste sur cet appareil, dans le navigateur ou l'application que tu as utilisé, sauf si tu actives [Sync](/info/sync.html). [Retrouver et récupérer ton travail](/info/find-your-work.html) explique les dossiers, les versions antérieures et le transfert de ton travail sur un autre appareil.

## D'autres premiers projets

- [Lolly Audiogram](/#/tool/audiogram) transforme une note vocale en vidéo avec une forme d'onde animée, tes mots sur la couverture et tes couleurs. Dépose l'enregistrement dans **Audio**, ajoute un **Title**, puis exporte en **MP4**.
- [Lolly Filter](/#/tool/filter) traite une photo pour une affiche : points de trame d'impression, deux aplats de couleur ou quelques blocs de tons. Choisis la photo sous **Image**, sélectionne un **Effect**, puis exporte en **PNG**, ou en **SVG** pour un effet marqué *vector*.
- Le [générateur de musique](/#/music) compose un morceau à partir d'un genre et d'une graine. Appuie sur le bouton rond de lecture aléatoire jusqu'à ce que le résultat te plaise, puis ouvre **Render** et télécharge un fichier M4A ou WAV. La musique que tu crées est libre d'utilisation, même commerciale, avec la mention **Musique créée avec Lolly (https://lolly.tools), CC BY 4.0**. Le [guide du générateur de musique](/info/music-generator.html) présente chaque contrôle et [Musique de fond gratuite](/info/background-music.html) propose un extrait de chaque genre.

## La suite

- **Envoie un lien plutôt qu'un fichier.** Chaque contrôle que tu as modifié se retrouve dans l'adresse de la page. **Share**, dans le panneau d'export, fournit un lien qui rouvre le même design sur l'écran d'une autre personne. Une photo que tu as importée depuis ton appareil n'est pas incluse dans le lien. Voir [Partager ton travail](/info/using.html#sharing-your-work).
- **Ajoute tes couleurs et tes polices une fois**, pour que chaque outil les utilise dès l'ouverture : le [Démarrage rapide](/info/quickstart.html).
- [Utiliser Lolly](/info/using.html) est le guide complet de l'application. [Lolly pour les créateurs](/info/creators.html) montre ce que Lolly permet aussi de créer.
