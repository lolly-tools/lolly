# Crée ton premier fichier

D'ici la fin de cette page, tu auras téléchargé un code QR pour une adresse web et enregistré une copie que tu pourras rouvrir et modifier plus tard. Tu n'as besoin d'aucun compte ni de rien à configurer au préalable.

::: note Avant de commencer
Aie sous la main l'adresse web que le code doit ouvrir, commençant par `https://`.
:::

## Créer le code

1. Ouvre [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Les contrôles se trouvent à côté de l'aperçu, ou au-dessus sur un téléphone ; ce que montre l'aperçu est ce que sera le fichier.
2. Dans **URL**, remplace toute l'adresse d'exemple par la tienne. L'aperçu change au fur et à mesure que tu tapes.
3. Pour reprendre tes propres couleurs, règle **Module colour** et **Background**. Garde un fort contraste entre les deux, sinon les téléphones ont du mal à lire le code.
4. **Quiet zone**, sous **Modules**, commence à 4. Garde-le à 4 ou plus : cette marge unie est ce qu'une caméra de téléphone recherche.

## Télécharger le fichier

1. Appuie sur **Exporter** sur la pastille **Export | Save as**, au pied des contrôles sur un ordinateur ou flottante en bas de l'écran sur un téléphone.
2. Ouvre le menu de format à côté du nom de fichier (il commence sur **SVG**) et choisis **PNG** pour un écran ou un message. Pour l'impression, voir la note ci-dessous.
3. Appuie sur **Télécharger**. Le fichier part dans les téléchargements de ton navigateur ; s'il n'y est pas, voir [Retrouver un fichier téléchargé](/info/find-your-work.html#find-a-file-you-downloaded).

::: check Scanne le code avant de partager le fichier
Ouvre le fichier téléchargé sur un écran et scanne le code avec une caméra de téléphone. Si tu l'as fait sur ton téléphone, scanne-le depuis un second téléphone ou un écran d'ordinateur. Le téléphone devrait proposer ton adresse web.
:::

::: details Si le code sera imprimé ou manipulé
Choisis **SVG** ou **PDF** pour que le code reste net à toute taille, et teste une impression à la taille réelle d'utilisation. Si le code risque d'être éraflé ou mouillé par la pluie, règle **Error correction**, sous **Modules**, sur **High (30%)** : un code endommagé reste lisible.
:::

## Garder une copie modifiable

Le fichier que tu as téléchargé est terminé. Pour modifier le code plus tard, enregistre aussi ton travail :

1. Appuie sur **Enregistrer sous**, puis **Enregistrer**. Avec le panneau d'export ouvert, **Enregistrer sous** se trouve dans le panneau ; fermé, c'est la coche à côté d'**Exporter**. Le code va dans **Ma bibliothèque**, et un message **Enregistré** propose **Ouvrir les projets**.
2. La prochaine fois, appuie sur **Accueil** et ouvre **Projets** (l'icône de dossier sur un téléphone). Ton code est là, nommé **QR Code**. Ouvre-le, change ce que tu veux et exporte à nouveau.

Le travail enregistré reste sur cet appareil, dans le navigateur ou l'application que tu as utilisé, sauf si tu actives la [synchronisation](/info/sync.html). [Retrouver et récupérer ton travail](/info/find-your-work.html) couvre les dossiers, les versions antérieures et le transfert de ton travail vers un autre appareil.

## Autres premiers projets

- [Audiogram](/#/tool/audiogram) transforme une note vocale en vidéo : une forme d'onde animée, tes mots sur la couverture, tes couleurs. Dépose l'enregistrement dans **Audio**, ajoute un **Titre**, puis exporte en **MP4**.
- [Filter](/#/tool/filter) traite une photo pour une affiche : points de trame imprimés, deux couleurs plates ou quelques blocs de ton. Choisis la photo sous **Image**, choisis un **Effet**, puis exporte en **PNG**, ou en **SVG** sur un effet marqué *vector*.

## Où aller ensuite

- **Envoyer un lien plutôt qu'un fichier.** Chaque contrôle que tu as touché est écrit dans l'adresse de la page, donc **Partager** dans le panneau d'export donne un lien qui rouvre le même design sur l'écran de quelqu'un d'autre. Une photo que tu as importée depuis ton propre appareil ne voyage pas avec le lien. Voir [Partager ton travail](/info/using.html#sharing-your-work).
- **Ajoute tes couleurs et polices une fois**, pour que chaque outil parte avec elles : le [Démarrage rapide](/info/quickstart.html).
- [Utiliser Lolly](/info/using.html) est le guide complet de l'application, et [Lolly pour les créateurs](/info/creators.html) fait le tour de ce qu'elle sait faire d'autre.
