# 初めてのファイルを作る

ウェブアドレス用のQRコードをダウンロードし、後で開いて変更できるコピーを保存します。アカウントも、事前の設定も必要ありません。アカウントや設定は不要です。

::: note 始める前に
コードで開くウェブアドレスを、`https://`から始まる形で用意してください。
:::

::: steps
- <!--i:eti-pen--> **[コードを作る](#make-the-code)** Lolly QR Codeにアドレスを入力し、色を設定します。
- <!--i:eti-download--> **[ファイルをダウンロードする](#download-the-file)** 画面用ならPNG、印刷用ならSVGまたはPDFを書き出します。
- <!--i:eti-folder-plus--> **[編集可能なコピーを残す](#keep-an-editable-copy)** 後でコードを変更できるように、作品を保存します。
:::

<!--i:eti-pen-->
## コードを作る

1. [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)を開きます。コントロールはプレビューの横に、スマートフォンではプレビューの上にあります。プレビューには、ファイルになる内容が表示されます。
2. **URL**で、例のアドレス全体を自分のアドレスに置き換えます。入力に合わせてプレビューが変わります。
3. 自分の色に合わせるには、**Module colour**と**Background**を設定します。両者のコントラストを強く保ってください。弱いとスマートフォンでコードを読み取りにくくなります。
4. **Modules**内の**Quiet zone**の初期値は4です。4以上に保ってください。スマートフォンのカメラは、この何もない余白を探します。

<!--i:eti-download-->
## ファイルをダウンロードする

1. **Export | Save as**ピルの**Export**を押します。パソコンではコントロールの下部に、スマートフォンでは画面下部に浮かんで表示されます。
2. ファイル名の横の形式メニュー(初期値は**SVG**)を開き、画面やメッセージ用には**PNG**を選びます。印刷については、下の注記をご覧ください。
3. **Download**を押します。ファイルはブラウザのダウンロード先に入ります。そこにない場合は、[ダウンロードしたファイルを探す](/info/find-your-work.html#find-a-file-you-downloaded)をご覧ください。

::: check ファイルを共有する前にコードを読み取る
ダウンロードしたファイルを画面で開き、スマートフォンのカメラでコードを読み取ります。スマートフォンで作った場合は、別のスマートフォンやパソコンの画面から読み取ります。スマートフォンに自分のウェブアドレスが表示されることを確認してください。
:::

::: note コードを印刷する場合や手に取って使う場合
どのサイズでも鮮明に保つため、**SVG**か**PDF**を選びます。実際に使うサイズで印刷して試してください。コードがこすれたり濡れたりする可能性がある場合は、**Modules**内の**Error correction**を**High (30%)**に設定し、損傷しても読み取れるようにします。
:::

<!--i:eti-folder-plus-->
## 編集可能なコピーを残す

後でコードを変更するには、作品も保存してください。

1. **Save as**を押してから、**Save**を押します。書き出しパネルが開いている場合、**Save as**はパネル内にあります。閉じている場合は、**Export**の横のチェックマークを使います。コードは**My library**に入り、**Saved**メッセージに**Open Projects**が表示されます。
2. 次回は、**Home**を押して**Projects**ビュー(スマートフォンではフォルダアイコン)を開きます。コードは**QR Code**という名前で保存されています。開いて内容を変更し、もう一度書き出します。

[同期](/info/sync.html)をオンにしない限り、保存した作品は、このデバイスの使用したブラウザやアプリ内に残ります。[作品を探して復元する](/info/find-your-work.html)では、フォルダ、以前のバージョン、別のデバイスへの作品の移動を説明しています。

## 初めて作る作品の別の例

- [Lolly Audiogram](/#/tool/audiogram)は、音声メモを、動く波形、カバー上のテキスト、自分の色を備えた動画に変えます。録音を**Audio**にドロップし、**Title**を加えて、**MP4**を書き出します。
- [Lolly Filter](/#/tool/filter)は、写真をポスター向けに加工します。印刷の網点、2色のべた塗り、少数の階調の面などです。**Image**で写真を選び、**Effect**を選択して**PNG**を書き出します。*vector*のバッジが付いたエフェクトでは**SVG**も書き出せます。
- [音楽ジェネレーター](/#/music)は、ジャンルとシードから曲を作ります。気に入った曲が再生されるまで丸いシャッフルボタンを押し、**Render**を開いてM4AまたはWAVファイルをダウンロードします。作った音楽は、**Music made with Lolly (https://lolly.tools), CC BY 4.0**とクレジットを記載すれば、商用でも無料で使えます。[音楽ジェネレーターのガイド](/info/music-generator.html)ではすべてのコントロールを説明し、[無料のBGM](/info/background-music.html)には全ジャンルのサンプルがあります。

## 次へ

- **ファイルの代わりにリンクを送る。** 操作したすべてのコントロールは、ページのアドレスに含まれます。書き出しパネルの**Share**で、相手の画面でも同じデザインを開けるリンクを取得できます。自分のデバイスからアップロードした写真は、リンクには含まれません。[作品を共有する](/info/using.html#sharing-your-work)をご覧ください。
- **色とフォントを一度追加**すれば、すべてのツールがそれらを使って始まります。[クイックスタート](/info/quickstart.html)をご覧ください。
- [Lollyを使う](/info/using.html)は、アプリ全体のガイドです。[クリエイター向けLolly](/info/creators.html)では、他にどのようなものを作れるか紹介しています。
