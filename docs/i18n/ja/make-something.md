# 最初のファイルを作る

このページを読み終える頃には、あるWebアドレス用のQRコードをダウンロードし、あとで開いて変更できるコピーも保存できているはずです。アカウントは不要で、事前の準備も一切要りません。

::: note 始める前に
`https://`から始まる、コードが開くべきWebアドレスを用意してください。
:::

## コードを作る

1. [QRコード](/#/tool/qr-code?url=https%3A%2F%2Fexample.com)を開きます。コントロールはプレビューの横(スマートフォンでは上)にあり、プレビューに表示されているものがそのままファイルになります。
2. **URL**で、サンプルのアドレスを自分のものに、省略せず全体を置き換えます。入力するそばからプレビューが変わります。
3. 自分の色に合わせるには、**モジュールの色**と**背景**を設定します。両者のコントラストは強く保ってください。そうしないとスマートフォンがコードを読み取りにくくなります。
4. **モジュール**の下にある**クワイエットゾーン**は4から始まります。4以上を保ってください。この余白こそ、スマートフォンのカメラが探しているものです。

## ファイルをダウンロードする

1. コントロールの下端(スマートフォンでは画面下部に浮かぶ)にある**Export | Save as**ピルの**Export**を押します。
2. ファイル名の横のフォーマットメニュー(初期状態は**SVG**)を開き、画面やメッセージ用なら**PNG**を選びます。印刷の場合は下の注記を参照してください。
3. **ダウンロード**を押します。ファイルはブラウザのダウンロード先に入ります。見当たらない場合は[ダウンロードしたファイルを見つける](/info/find-your-work.html#find-a-file-you-downloaded)をご覧ください。

::: check ファイルを共有する前にコードをスキャンする
ダウンロードしたファイルを画面で開き、スマートフォンのカメラでコードをスキャンします。スマートフォンで作った場合は、別のスマートフォンかパソコンの画面からスキャンしてください。スマートフォンにはあなたのWebアドレスが表示されるはずです。
:::

::: details コードを印刷したり手に取られたりする場合
どんなサイズでも鮮明さを保てるよう**SVG**または**PDF**を選び、実際に使うサイズで試し刷りをしてください。コードがこすれたり雨に濡れたりする可能性がある場合は、**モジュール**の下の**誤り訂正レベル**を**最高 (30%)**に設定してください。傷んだコードでも読み取れます。
:::

## 編集できるコピーを残す

ダウンロードしたファイルはこれで完成です。あとでコードを変更できるように、作業内容も保存しておきましょう。

1. **名前を付けて保存**、続けて**保存**を押します。エクスポートパネルが開いているときは**名前を付けて保存**はパネルの中にあります。閉じているときは、**エクスポート**の隣にあるチェックマークがそれです。コードは**マイライブラリ**に入り、**保存しました**というメッセージに**プロジェクトを開く**が表示されます。
2. 次回は**ホーム**を押して**プロジェクト**(スマートフォンではフォルダーのアイコン)を開きます。あなたのコードはそこに**QRコード**という名前で入っています。開いて何かを変更し、もう一度エクスポートしてください。

[同期](/info/sync.html)をオンにしない限り、保存した作業は、使用したブラウザまたはアプリの中で、このデバイスだけに残ります。[作業を見つけて復元する](/info/find-your-work.html)では、フォルダー、以前のバージョン、別のデバイスへの移動について説明しています。

## ほかの最初のプロジェクト

- [オーディオグラム](/#/tool/audiogram)は音声メモを動画に変えます。動く波形、カバーに表示される言葉、あなたの色です。**オーディオ**に録音をドロップし、**タイトル**を追加してから**MP4**でエクスポートします。
- [フィルター](/#/tool/filter)はポスター用に写真を加工します。印刷用のハーフトーンドット、2色のベタ、あるいは数段階のトーンです。**Image**の下で写真を選び、**Effect**を選んでから**PNG**で、*vector*と表示されたエフェクトなら**SVG**でエクスポートします。

## 次に

- **ファイルの代わりにリンクを送る。** 触ったすべてのコントロールはページのアドレスに書き込まれるので、エクスポートパネルの**共有**を使うと、同じデザインを相手の画面で再現するリンクが手に入ります。自分のデバイスからアップロードした写真は、そのリンクと一緒には運ばれません。[作ったものを共有する](/info/using.html#sharing-your-work)をご覧ください。
- **色とフォントを一度だけ設定しておく**と、どのツールもそこから始まります。[クイックスタート](/info/quickstart.html)をご覧ください。
- [Lollyの使い方](/info/using.html)はアプリの完全ガイドで、[クリエイター向けLolly](/info/creators.html)はほかに何を作れるかを紹介します。
