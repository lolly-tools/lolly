# Lolly BatchとLolly Multi-edit

<a id="batch-and-multi-edit"></a>

**Lolly Batch**は、12言語のカードやあらゆるサイズのバナーなど、1つのデザインの多くのバリエーションを作ります。**Lolly Multi-edit**は、日付や見出しの更新など、1つの変更を複数の異なる保存済みデザインに適用します。

どちらもお使いのデバイス上で動作し、ツールと同じレンダリング経路で書き出します。

::: cols
## Batch

- 1つのテンプレートに多くの行を使います。各行が1組の入力となり、1つのファイルを作ります。
- 入力、スプレッドシートからの貼り付け、CSVのインポートで行を埋めます。
- 行数に制限はなく、1ページに50行が表示されます。
- Projectsのヘッダーにある**Lolly Batch**から開きます(`#/batch`)。

<a id="multi-edit"></a>
## Lolly Multi-edit

- 2〜8個の異なる保存済みデザインが、ライブのカードとして横に並びます。
- 1つのサイドバーで共通の入力を編集し、次に各カード固有の入力を編集します。
- 各デザインは元の場所に保存されます。
- Projectsの選択バーにある**Edit together**から開きます。
:::

## 1つのデザインの多くのバリエーションを作る

**Projects**ビューを開き、ヘッダーの**Batch**を押します。グリッドは1行から始まります。その行でテンプレートを選び、行を複製するか、スプレッドシートからデータを貼り付けます。フォルダ内から開いた場合、Batchはそのフォルダに戻ります。

![新しいグリッドのBatch: 上部にファイル名と行のツールが並び、最初の行のテンプレート一覧に選択できるツールが表示されている](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**行を埋める。** セルに入力するか、Excel、Google Sheetsなどのスプレッドシートから範囲を貼り付けます。**Import CSV**は行を追加するか、バッチを置き換えます。書き出し設定が入っているセルに貼り付けると、貼り付けた各列をどの入力に対応させるかをLollyが尋ねます。**Export CSV**はグリッドを書き出します。グリッドの下の**Columns**を開くと、さらに多くの入力や、行ごとの幅、高さ、単位、DPIを表示できます。数値、テキスト、選択肢の列の**Fill**ポップオーバーには**Design token**セクションもあり、その列の各行に1つのトークンをリンクできます([多くのドキュメントを一度にリンクする](/info/token-workflows.html#link-many-documents-at-once))。

**出力を設定する。** ツールバーでは、zipのファイル名と、全行の**Default format**、単位、DPIを設定します。形式メニューは書き出しパネルと同じグループ分けされた一覧で、カタログが提供し、お使いのブラウザが対応する形式が並びます。独自の形式、サイズ、ファイル名を持つ行は、その設定を保ちます。

**レンダリングする。** **Render all**は、すべての行を1つの`.zip`に書き出します。行を選択している場合、**Render selected**、**Export selected CSV**、**Print selected rows**はその行だけに作用します。選択を解除すると、再びバッチ全体を操作できます。**Print sheet**は、印刷可能なシートに行を配置します。**Batch activity**は各インポートとレンダリングを報告し、折りたためます。

**バッチを保存する。** **Sessions**は、選択状態に関係なく、グリッドのすべての行を名前付きのバッチセッションとして保存します。セッションはProjectsから開き直せます。同じメニューの**Folders…**は、Projectsのフォルダを、保存済みセッションごとに1行として開きます。各ファイル名にはフォルダのパスが含まれます。

::: details 行とセルを選択する
チェックボックスで行を選択するか、Shiftを押しながらチェックボックスをクリックして範囲を選択します。ヘッダーのチェックボックスは現在のページを選択し、**Select all *N* rows**は他のページの行も選択します。ページ間を移動しても選択は保たれます。**Edit input**、**Duplicate**、**Remove**は選択した行に作用し、**Undo remove**は最後に削除した行を復元します。セルにフォーカスがある状態でShift+Spaceを押すとその行を選択し、Escapeを押すと選択を解除します。

セルをまたいでドラッグするか、Shiftを押しながらセルをクリックするか、Shift+矢印キーを使うと、長方形の範囲を選択できます。**Copy cells**、またはCtrl+C / Command+Cは、スプレッドシート用に値をコピーします。セルにフォーカスがある状態でCtrl+A / Command+Aを押すと、全ページの表示されているすべての列を選択します。行のチェックボックスから同じショートカットを使うと、すべての行を選択します。セルを選択しても、行のチェックは外れません。セルをダブルクリックするかEnterを押すと、そのテキストを編集できます。クリップボードから長方形の範囲を貼り付けるか、1つの値を貼り付けて選択したすべてのセルを埋めます。空のセルや複数行のテキストは、その位置を保ちます。
:::

### 行ごとのカラーウェイとテーマ

各行は独自のテーマの選択を保持します。ライトかダーク、そしてデザインシステムが提供する場合はカラーウェイです。Projects、フォルダ、保存したバッチから開いた行は、そのセッションが保存されたときの選択でレンダリングされ、プレビューされます。印刷シート、複製した行、一括入力した行も、その選択を保ちます。

CSVは、サイズの列の後にある`_themes`列に選択を含めます。この列には、`_themes`リンクパラメーターと同じJSONが入ります。たとえば`{"":"dark","colourway":"beach"}`です。空のセル、または`{}`は、デザインシステムの既定値を意味します。この列は、いずれかの行に選択がある場合だけ書き出されます。インポート時に有効なテーマの選択ではないセルがあると、問題として一覧に表示され、その行は既定値でレンダリングされます。

::: note 行の選択をCSVで設定する
グリッドには、行の選択を変更するコントロールがまだないため、CSVまたは保存済みセッションで設定します。
:::

### 行ごとの言語

Certificateのように独自の文言を印字するツールは、`language`列に`de`、`ja`、`ar`などの短い言語コードを受け取れます。各行は、その言語で文言と日付を印字します。アラビア語とウルドゥー語の行は、右から左に配置されます。空のセルはアプリの言語に従います。Lollyにまだ翻訳がない言語では、日付も含めて英語で印字するため、証明書の一部だけが翻訳された状態にはなりません。

### BatchとRender folder

保存済みのセッションを再レンダリングするには、Projectsで選択して**Render selection**を使うか、フォルダ全体には**Render folder**を使います。[作品を探して復元する](/info/find-your-work.html#find-something-you-saved)で両方を説明しています。

## 複数の保存済みデザインを一緒に編集する

**Projects**で2〜8個の保存済みセッションにチェックを入れ、選択バーから**Edit together**を選びます。`#/multi?s=<slot>,<slot>…`で、ライブのカードとして横に並んで開きます。各カードはそのセッションを実際にレンダリングし、書き出される内容を表示します。

1つのサイドバーですべてを操作します。

- <!--i:sliders--> 最初に**Shared**があります。2つ以上のセッションが同じ形で宣言しているすべての入力です(ID、型、制約が同じで、バッチグリッドが列に使うルールと同じです)。共通のコントロールを変更すると、その入力を宣言しているすべてのセッションに反映され、各カードですぐに確認できます。同じツールの2つのセッションはすべてを共有し、異なる2つのツールは共通の入力だけを共有します。Sharedカードの**Input actions**メニューは、その入力を宣言するすべてのセッションにデザイントークンをリンクします。
- <!--i:document--> Sharedカードの下には、**セッションごとに1枚の折りたたまれたカード**があり、ツール自身のサイドバーと同じように、そのセッション固有のすべての入力を収めています。コンパクトな書き出しブロックには、**Format**、**W** / **H**、**Unit**、**DPI**、**Download**があります。このDownloadは、まずセッションを保存し、その後ツールから書き出す場合と同じファイル名、形式、Content Credentialsでファイルをレンダリングします。
- <!--i:search--> 上部の**Filter inputs…**は、すべてのカードのコントロールを一度に絞り込みます。

カードをクリックするか、カード上でEnterを押すと、そのセッションのサイドバーカードが開きます。**Save all**は、各セッションをそれぞれのスロットに保存します。**Download all**は、まず保存してから、Projectsの**Render selection**と同じように、全体を1つのzipにレンダリングします。必要に応じてパスワードでロックできます。

各カードは、デザイン内に配置したツールも含め、それぞれのセッションのテーマの選択で描画されます。カードの周りのアプリは独自の色を保ちます。**Save all**、ダウンロード、**Batch grid**、**Send to Print Sheet**は、各セッションの選択を保ちます。

### 制限

- **最大8個。** 各カードは独自のライブランタイムを起動し、8枚なら応答性を保てます。それより多い数や、すでに存在しないセッションを指定するリンクは、その旨を表示し、一部だけを読み込むことはありません。
- **リンクはローカルです。** 自分の保存済みスロットを指定し、このデバイスでその組み合わせを開き直します。共有リンクではありません。
- **それより多い場合は、**同じ選択バーで**Edit as sheet**を選びます。選択したセッションをバッチグリッド(`#/batch?s=…`)の行として開き、数の制限も同じツールでなければならないというルールもありません。フォルダはどちらにも含まれません。グリッドでフォルダを開くには**Sessions → Folders…**を使い、レンダリングするにはProjectsの**Render folder**を使います。
- **検索はLolly Multi-editに届きません。** 検索バーの対象外となる唯一のビューです。
