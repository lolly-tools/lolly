# BatchとMulti-edit

同じ種類のファイルを頻繁に作るようになると、2つの作業が出てきます。1つのデザインの多数のバージョンが必要な場合があります。12言語のカードや、バナーのすべてのサイズなどです。また、保存した複数の異なるデザインに、新しい日付や新しい見出しのような1つの変更を行き渡らせたい場合もあります。

**Batch**は1つ目の作業を、**Multi-edit**は2つ目の作業を行います。どちらもお使いのデバイス上で動作し、ツール自体と同じレンダリング経路で書き出されます。

::: cols
## Batch

- 1つのテンプレートに多数の行。各行は入力の1セットで、ファイルを1つ作ります。
- 入力、スプレッドシートからの貼り付け、CSVのインポートで行を埋めます。
- 行数の上限はなく、1ページに50行が表示されます。
- Projectsヘッダーの**Batch**(`#/batch`)から開きます。

## Multi-edit

- 保存した2〜8個の異なるデザインを、ライブカードとして並べて表示します。
- 1つのサイドバーで、共通する入力を編集し、次に各カード固有の入力を編集します。
- 各デザインは、元の場所に保存し直されます。
- Projectsの選択バーの**Edit together**から開きます。
:::

## 1つのデザインの多数のバージョンを作る

**Projects**を開き、ヘッダーの**Batch**を押します。グリッドは1行から始まります。その行でテンプレートを選び、行を複製するか、スプレッドシートのデータを貼り付けます。フォルダの中から開いた場合、Batchはそのフォルダに戻ります。

![新しいグリッドのBatch: 上部にファイル名と行のツール、最初の行のテンプレート一覧が選べるツールで開いている](/t/url-shot?url=%2F%23%2Fbatch&width=1440&height=900&dpi=192&waitMs=3500&walker=1&format=svg&dark=1&filename=use-batch-toolbar)

**行を埋める。** セルに入力するか、Excel、Googleスプレッドシート、その他のスプレッドシートからブロックをそのまま貼り付けます。**Import CSV**は行を追加するか、バッチを置き換えます。書き出し設定を持つセルに貼り付けると、Lollyは貼り付けた各列がどの入力を埋めるかを尋ねます。**Export CSV**はグリッドを書き出し直します。グリッドの下の**Columns**を開くと、より多くの入力、または行ごとの幅、高さ、単位、DPIが表示されます。

**出力を設定する。** ツールバーでは、zipのファイル名、すべての行の**Default format**、単位、DPIを設定します。形式メニューは書き出しパネルのグループ化された一覧で、カタログが提供し、ブラウザが対応する形式が表示されます。独自の形式、サイズ、ファイル名を持つ行は、その設定を保ちます。

**レンダリング。** **Render all**は、すべての行を1つの`.zip`に書き出します。先に行を選択すると、**Render selected**、**Export selected CSV**、**Print selected rows**がそれらの行だけに作用します。選択を解除すると、再びバッチ全体を対象にします。**Print sheet**は、行を印刷可能なシートに配置します。**Batch activity**は各インポートとレンダリングを報告し、折りたたんで表にスペースを譲れます。

**バッチを保存する。** **Sessions**はグリッド全体を名前付きのバッチセッションとして保存し、後でProjectsから開き直せます。Sessionsは、選択に関係なく常にすべての行を保存します。同じメニューの**Folders…**は、Projectsのフォルダ全体を、保存済みセッション1つにつき1行として開き、各ファイル名にはフォルダのパスが付きます。

::: details 行とセルの選択
行はチェックボックスで選択し、Shiftを押しながらチェックボックスをクリックすると範囲を選べます。ヘッダーのチェックボックスは現在のページを選択し、**Select all *N* rows**は他のページの行も含めます。ページを移動しても選択は保たれます。**Edit input**、**Duplicate**、**Remove**は選択した行に作用し、**Undo remove**は直前に削除した行を復元します。フォーカスしたセルからShift+Spaceでその行を選択し、Escapeで選択を解除します。

セルをまたいでドラッグするか、セルをShiftクリックするか、Shift+矢印キーで、長方形を選択します。**Copy cells**またはCtrl+C / Command+Cは、スプレッドシート向けに値をコピーします。フォーカスしたセルからのCtrl+A / Command+Aは、すべてのページのすべての表示列を選択し、行のチェックボックスからの同じショートカットは、すべての行を選択します。セルを選択しても、チェック済みの行はチェックされたままです。セルをダブルクリックするかEnterを押すと、そのテキストを編集できます。クリップボードから長方形を貼り付けるか、1つの値を貼り付けて選択したすべてのセルを埋められ、空白のセルと複数行のテキストはその位置を保ちます。
:::

### 行ごとのカラーウェイとテーマ

各行は、ライトまたはダーク、デザインシステムにある場合はカラーウェイという、独自のテーマの選択を保持します。Projects、フォルダ、保存済みバッチから開いた行は、そのセッションが保存された選択でレンダリングされ、プレビューもその選択で開きます。印刷シート、複製した行、埋めた行もそれらを保ちます。

CSVは、サイズの列の後ろにある`_themes`列に選択を持ちます。これには`_themes`リンクパラメーターと同じJSON、たとえば`{"":"dark","colourway":"beach"}`が入ります。空白のセル、または`{}`は、デザインシステムの既定値を意味します。この列が書き込まれるのは、いずれかの行に選択がある場合だけなので、選択のないバッチは、以前と同じCSVを書き出します。インポート時、有効なテーマの選択ではないセルは問題として一覧に出され、その行は既定値でレンダリングされます。グリッドには、行の選択を変更するコントロールがまだないため、CSVか保存済みセッションで設定してください。

### Batch、またはRender folder

Batchは、1つのテンプレートの多数のバリエーションを作ります。すでに保存したセッションを再レンダリングするには、Projectsでそれらを選択して**Render selection**を、フォルダ全体なら**Render folder**を使います。どちらも[作品を探して復元する](/info/find-your-work.html#find-something-you-saved)で扱っています。

## 保存した複数のデザインをまとめて編集する

**Projects**で2〜8個の保存済みセッションにチェックを入れ、選択バーから**Edit together**を選びます。それらは`#/multi?s=<slot>,<slot>…`で、ライブカードとして並んで開きます。各カードはそのセッションの実際のレンダリングなので、見たものがそのまま書き出されます。

1つのサイドバーがすべてを操作します。

- <!--i:sliders--> **Shared**が最初に表示されます。2つ以上のセッションが同じ方法(同じID、同じ種類、同じ制約。バッチグリッドが列に使う規則)で宣言しているすべての入力です。共通のコントロールを一度編集すると、その入力を宣言しているすべてのセッションに値が届き、すべてのカードにライブで反映されます。同じツールの2つのセッションはすべてを共有し、異なるツールの2つのセッションは共通する入力だけを共有します。
- <!--i:document--> その下には、**セッションごとに1つの折りたたみカード**があり、そのセッション自身のすべての入力が、ツール自身のサイドバーと同じだけ完全に入っています。コンパクトな書き出しブロックは、**Format**、**W** / **H**、**Unit**、**DPI**、**Download**です。そのDownloadはまずセッションを保存し、その後、ツールから書き出す場合と同じファイル名、形式、Content Credentialsでファイルをレンダリングします。
- <!--i:search--> 上部の**Filter inputs…**は、すべてのカードのコントロールを一度に絞り込むため、8つのセッションの「見出し」まで、スクロールせずに到達できます。

任意のカード(またはそれにフォーカスしてEnter)をクリックすると、そのセッションのサイドバーカードが開きます。**Save all**はすべてのセッションを、それぞれのスロットに書き戻します。**Download all**はまず保存し、その後、Projectsの**Render selection**と同じように、セット全体を1つのzipにレンダリングし、その途中で任意のパスワードロックを提案します。

各カードは、デザインの中に配置されたツールを含め、そのセッション自身のテーマの選択で描画されます。異なる見た目のカードが並んでも、周りのアプリは独自の色を保ち、**Save all**、ダウンロード、**Batch grid**、**Send to Print Sheet**は、各セッションの選択を保ちます。

### 制限

- **最大8つです。** 各カードは独自のライブランタイムをマウントし、応答性が保たれるのは8つまでです。それ以上を求めるリンクや、もう存在しないセッションを求めるリンクは、中途半端に読み込まれるのではなく、そのことが示されます。
- **リンクはローカルのものです。** ご自身の保存済みスロットを指すため、このデバイスで同じセットを開き直します。共有リンクではありません。
- **それより大きな場合は、** 同じ選択バーの**Edit as sheet**を選びます。選択範囲全体をバッチグリッドの行として開き(`#/batch?s=…`)、サイズの上限も同じツールという制約もありません。フォルダはどちらからも除外されます。フォルダは**Sessions → Folders…**でグリッドに開くか、Projectsの**Render folder**でレンダリングしてください。
- **検索はMulti-editには届きません。** 検索バーが認識しない唯一のビューです。
