# LollyとレンダリングAPI

_最終確認日: 2026年11月5日。_

APIを通じてテンプレートから画像を生成している場合、このページでは、その制作を自分のデバイス、CI、自分で管理するサーバーで行うと何が変わるかを説明します。[ホスティング型のレンダリングAPIから移行する](/info/work-move-from-render-api.html)に手順があります。

<!--i:eti-award-->
## ホスティング型のレンダリングAPIが優れている点

[Bannerbear](https://www.bannerbear.com/)と[Placid](https://placid.app/)は、マネージドサービスです。リクエストを送ると、サービス側がサーバーを運用します。

- **運用するものがありません。** サーバー、データベース、ストレージ、更新、容量計画は不要です。
- **ホスティング型のテンプレートエディター**に、変更して使えるテンプレートが用意されています。
- **1つのAPIから、より多くの種類の出力を得られます。** どちらも動画とPDFのエンドポイントを公開しています。Bannerbearは、アニメーション出力、WebPとAVIF、スクリーンショット、AIによる背景除去も文書化しています。
- **独自の連携機能とサポート。**

その仕組みが希望に合うなら、それらのサービスは適切な選択肢です。

## セルフホストで得られるもの

- **コンテンツは自分のシステム内にとどまります。** 入力、アセット、出力は、自分で選んだインフラストラクチャ上に置かれます。デバイスやCIでのレンダリングには、サービスは不要です。
- **ルールはツール内にあります。** 色、書体、ロゴ、ロックされた入力は[デザインシステム](/info/brand-studio.html)に由来するため、呼び出し側が変更できるのは、あなたが許可した部分だけです。[Lolly Work](/info/compare.html#what-runs-where)は、すべてのリクエストにツールの表示範囲と入力のポリシーを適用します。
- **どこでも同じツールを使えます。** ツールは、ノートパソコン、CIジョブ、サーバーのいずれでも、同じ入力からレンダリングします。利用者は、アプリで同じツールを編集できます。
- **記録は自分で保持します。** [レンダリングの受領記録](/info/work-renders.html#evidence-and-identity)、監査証跡、署名用のIDを設定した場合のContent Credentialsです。
- **オープンソースで、従量課金はありません。** コードをご自身で実行し、支払うのは自分のインフラストラクチャの費用だけです。

それらのサービスが代行する作業を、ご自身で引き受けます。継続運用するサーバーには、永続的なデータベースと出力ストレージが必要です。ブラウザを必要とするツールには、Chromiumワーカーが必要です。[Lolly Workのインストール](/info/work-install.html)では、その両方を説明しています。

## 作業ごとの対応

| 作業 | ホスティング型のレンダリングAPI | Lolly |
|---|---|---|
| データをテンプレートに入力する | テンプレートとそのレイヤーを指定するAPIリクエスト | ツールとその入力を指定する[URL](/info/url-mode.html)、[CLI](/info/cli.html)、[サーバーAPI](/info/work-automation-api.html) |
| 表から多数のファイルを作る | バッチとコレクション | デバイス上の[Batch](/info/batch.html)、またはサーバー上の[レンダリングバッチ](/info/work-renders.html#batches-with-durable-rows) |
| 結果を待つ、またはポーリングする | ポーリング、または同期処理のオプション | 永続化されるレンダリングをポーリング、または即時レンダリング |
| 完了時にWebhookを呼び出す | 対応 | 許可したオリジンへの[署名付きコールバック](/info/work-renders.html) |
| 動的な画像URL | 対応 | [共有リンクと`/render` URL](/info/url-mode.html) |
| テンプレートを編集する | ホスティング型のエディター | デバイス上の[Design](/info/using.html) |
| エージェント | どちらもMCPサーバーを公開 | [MCP](/info/mcp.html)。Lolly Workでは、トークンのポリシーに従う組織のエンドポイントを提供 |

Lolly自体の出力の種類は、[書き出し](/info/exporting.html)に一覧があります。現在のWorkサーバーでは、永続化されるレンダリングでSVG、PNG、JPG、PDFを作成し、[動画は引き続きデバイス、CLI、MCPで扱います](/info/work-renders.html#production-still-checks-and-permitted-repairs)。

## 引き継げるものと、引き継げないもの

| | Bannerbear V5 | Bannerbear V2 | Placid |
|---|---|---|---|
| リクエスト | Workの移行APIが同じ構造を受け付けます | 同じです | 同じです |
| テンプレート | スキーマが確認されていないレイヤータイプを除き、編集可能なドキュメントとして**Import**できます | フィールド名とプレビューのみです。1つずつ作り直してください | フィールド名とプレビューのみです。1つずつ作り直してください |
| 既存の動的URL | 未対応 | 未対応 | 以前のプライベートトークンを使えば、ホストを変更しても署名付きURLは動作し続けます |
| Webhook | 登録済みのWebhookは未対応です | `webhook_url`が動作します | `webhook_success`が動作します |
| WebPとAVIFの出力 | 名前を指定すると拒否されます | 提供されません | WebPは名前を指定すると拒否されます |
| アニメーション、動画、コレクション、スクリーンショット | 移行APIでは未対応 | 移行APIでは未対応 | 移行APIでは未対応 |

::: note 公開ドキュメントに基づいて構築
これは各ベンダーの公開ドキュメントに基づいて構築されており、実際のアカウントに対しては実行していません。アカウントをお持ちの場合、[移行ガイド](/info/work-move-from-render-api.html#check-it-on-your-own-account)に短いチェックリストがあります。
:::

1つのテンプレートだけを移し、残りを今の場所に置いておけます。[Lollyからの移行](/info/work-move-from-render-api.html#leave-lolly-too)も同じように自由です。ツールは通常のファイルで、CLIはサーバーなしでレンダリングします。

## サービスを運用するのは誰か

Lollyでは、個人がローカルでレンダリングするか、チームが自分たちのインフラストラクチャでLolly Workを運用します。サーバーのジョブは、入力と必要なアセットをそのインスタンスに送ります。デバイス上の経路では送りません。

BannerbearとPlacidは、それぞれの所有者の商標です。このページは、公開ドキュメントに基づいて製品間で共通する範囲を説明するものであり、いずれとも提携していません。
