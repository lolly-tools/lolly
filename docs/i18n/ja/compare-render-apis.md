# Lolly とレンダリング API

_最終確認日: 2026年11月5日。_

現在、APIでテンプレートから画像を生成している場合、このページは、その制作をご自身で運用すると何が変わるかを示します。対象は、ご自身のデバイス、CI、ご自身が管理するサーバーのいずれかです。手順は[ホスト型レンダリングAPIから移行する](/info/work-move-from-render-api.html)にあります。

## ホスト型レンダリングAPIがより優れている点

[Bannerbear](https://www.bannerbear.com/)と[Placid](https://placid.app/)はマネージドサービスであり、これは確かな利点です。リクエストを送れば、サーバーの運用、稼働の維持、負荷の処理は他の誰かが行います。

- **運用するものがありません。** サーバー、データベース、ストレージ、アップデート、キャパシティ計画のいずれも不要です。
- **ホスト型のテンプレートエディタ**があり、すぐに調整できるテンプレートが用意されています。
- **1つのAPIでより多くの出力種類に対応します。** どちらも動画とPDFのエンドポイントを公開しており、Bannerbearはさらにアニメーション出力、WebPとAVIF、スクリーンショット、AIによる背景除去も文書化しています。
- **独自の連携とサポートがあります。**

その形態をお望みであれば、これらのサービスは適切な選択です。

## セルフホスティングで得られるもの

- **コンテンツはご自身のシステムに留まります。** 入力、アセット、出力は、ご自身が選んだインフラ上に置かれます。デバイス上やCIでのレンダリングには、サービスは一切不要です。
- **ルールはツールの中にあります。** 色、書体、ロゴ、ロックされた入力は[デザインシステム](/info/brand-studio.html)から来るため、呼び出し側は許可された項目しか変更できません。[Lolly Work](/info/compare.html#what-runs-where)は、すべてのリクエストにツールの表示と入力のポリシーを適用します。
- **どこでも同じツールです。** ツールは、同じ入力から、ノートパソコン、CIジョブ、サーバーでレンダリングされ、同じツールをアプリ内で編集することもできます。
- **手元に残る記録があります。** [レンダリングレシート](/info/work-renders.html#evidence-and-identity)、監査証跡、そして署名アイデンティティを設定した場合はContent Credentialsです。
- **オープンソースで、従量課金はありません。** コードはご自身で実行し、支払うのはご自身のインフラ費用です。

これらのサービスが代わりに行っている作業は、ご自身で引き受けることになります。耐久性のあるサーバーには、永続的なデータベースと出力ストレージが必要で、ブラウザを必要とするツールにはChromiumワーカーが必要です。どちらも[Lolly Workをインストールする](/info/work-install.html)で説明しています。

## 作業の対応関係

| 作業 | ホスト型レンダリングAPI | Lolly |
|---|---|---|
| データからテンプレートを埋める | テンプレートとそのレイヤーを指定するAPIリクエスト | ツールとその入力を指定する[URL](/info/url-mode.html)、[CLI](/info/cli.html)、[サーバーAPI](/info/work-automation-api.html) |
| 表から多数のファイルを作る | バッチとコレクション | ご自身のデバイス上の[Batch](/info/batch.html)、またはサーバー上の[レンダリングバッチ](/info/work-renders.html#batches-with-durable-rows) |
| 結果を待つ、またはポーリングする | ポーリング、または同期オプション | ポーリングする復旧可能なレンダリング、または即時レンダリング |
| 完了時にWebhookを呼び出す | あり | 許可したオリジンへの[署名付きコールバック](/info/work-renders.html) |
| 動的な画像URL | あり | [共有リンクと`/render` URL](/info/url-mode.html) |
| テンプレートを編集する | ホスト型エディタ | ご自身のデバイス上の[Design](/info/using.html) |
| エージェント | どちらもMCPサーバーを公開 | [MCP](/info/mcp.html)。Lolly Workでは、トークンのポリシーの下に組織のエンドポイントがあります |

Lolly自身の出力の種類は[書き出し](/info/exporting.html)に一覧があります。現在のWorkサーバーでは、復旧可能なレンダリングがSVG、PNG、JPG、PDFを作成し、[動画はデバイス、CLI、MCPに留まります](/info/work-renders.html#production-still-checks-and-permitted-repairs)。

## 引き継がれるものと引き継がれないもの

| | Bannerbear V5 | Bannerbear V2 | Placid |
|---|---|---|---|
| リクエスト | Workの移行APIが同じ形式を受け付けます | 同じ | 同じ |
| テンプレート | 確認済みのスキーマがないレイヤー種類を除き、編集可能なドキュメントとして**インポート**されます | フィールド名とプレビューのみ。1つずつ作り直します | フィールド名とプレビューのみ。1つずつ作り直します |
| 既存の動的URL | 非対応 | 非対応 | ホストを変更しても、以前の非公開トークンで署名付きURLは引き続き動作します |
| Webhook | 登録済みWebhookは非対応 | `webhook_url`は動作します | `webhook_success`は動作します |
| WebPとAVIFの出力 | 名前を指定して拒否されます | 提供なし | WebPは名前を指定して拒否されます |
| アニメーション、動画、コレクション、スクリーンショット | 移行APIでは非対応 | 移行APIでは非対応 | 移行APIでは非対応 |

これらはすべて各ベンダーの公開ドキュメントをもとに作成したもので、実際のアカウントに対して実行したことはありません。アカウントをお持ちの場合は、[移行ガイド](/info/work-move-from-render-api.html#check-it-on-your-own-account)に短いチェックリストがあります。

移行は、すべてか無かではありません。1つのテンプレートだけ移して残りはそのままにでき、[Lollyから離れる](/info/work-move-from-render-api.html#leave-lolly-too)ことも同じように自由です。ツールはただのファイルで、CLIはサーバーなしでそれをレンダリングします。

## サービスを運用するのは誰か

Lollyでは、個人がローカルでレンダリングするか、チームが自らのインフラでLolly Workを運用します。サーバージョブを送信すると、その入力と必要なアセットがそのインスタンスに送られ、これはデバイス上の経路とは異なります。

BannerbearとPlacidは、それぞれの所有者の商標です。このページは、両製品が重なる部分を公開ドキュメントに基づいて説明するもので、どちらとも提携していません。
