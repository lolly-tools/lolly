# Lolly と Figma

_最終確認日: 2026年9月28日。_

デザイナーがFigmaで作業している場合、このページは、Lollyがそれとどう並ぶかを示します。FigmaにできてLollyにできないこと、そして繰り返しの作業をLollyが引き受ける場面です。

## Figmaがより優れている点

[Figma Design](https://www.figma.com/design/)は、インターフェースデザイン、コンポーネント、インタラクティブなプロトタイプ、開発者への引き渡しをまとめています。アプリケーション全体をデザインして仕様化する必要があるチームにとって、その確立されたプロダクトデザインの実践とエコシステムは重要であり、そのライブ編集は、Lollyのワークコラボがまだ到達していない規模で動作しています。

## 重なる部分

どちらも、キャンバス上で文字、図形、画像を配置し、他の人と共同作業できます。Figmaはテンプレートに基づくブランド制作もカバーします。[Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz)は、テンプレートからアセットを作り、CSVやXLSXファイルから内容を埋めます。Lollyの[デザインを取り込む](/info/design-import.html)はFigmaファイルを編集可能なレイアウトとして開くため、両者は作業を共有できます。

## 重なる作業をLollyがどう行うか

Lollyは、デザインを[ルール付きの再利用可能なツール](/info/create-a-tool.html)に変えます。ツールはブラウザまたはCLIで動作し、入力をリンク、スクリプト、バッチグリッドから受け取るため、1つのテンプレートが、1つのファイルを編集する個人にも、多くのファイルを作るチームにも役立ちます。

![Designのオープンキャンバス。ツールバーのLollyメニューにImport a designがある](/info/shots/design.svg)

[プライベートコラボ](/info/collaborate.html)は、2台のデバイスを直接つなぎ、アカウントも、共有ネットワーク上ではインターネットも不要です。単独のLollyはオフラインでレンダリングします。Content Credentialsは対応する書き出しで既定でオンですが、オフにもできます。

## 組織で使う場合

Lolly Workは、共有編集、ライブカーソル、保存されたチームセッションを備えた認証付きのワークコラボに加え、シングルサインオン、共有カタログ、プロジェクトの権限、承認、サーバーレンダリングを加えます。この2つの部分の対比は、[どこで何が動くか](/info/compare.html#what-runs-where)にあります。

Figmaは、その所有者の商標です。このページは2つの製品が重なる部分を説明するもので、Figmaとは提携していません。
