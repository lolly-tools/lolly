# Lolly と Figma

_最終確認日: 2026年9月28日。_

Lolly は、デザイン、リアルタイム編集、再利用可能なアセット制作に対応します。[lolly.work](https://lolly.work) は、その作業を取り巻く組織向けサービス、つまり ID、共有プロジェクト、アクセス制御、承認を追加します。

## 重なる部分

どちらも、キャンバス上にテキスト、図形、画像を配置し、他の人と共同で作業できます。Lolly の[デザインのインポート](/info/design-import.html)は、Figma ファイルを編集可能なレイアウトとして読み込みます。Figma もテンプレートベースのブランド制作に対応しています。[Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz) はテンプレートからアセットを作成し、CSV または XLSX ファイルから値を入力します。

Lolly は、デザインを[ルール付きの再利用可能なツール](/info/create-a-tool.html)に変えます。そのツールはブラウザまたは CLI で動作し、URL、スクリプト、バッチグリッドから入力を受け付けます。同じテンプレートで、1つのアセットを編集する個人も、多数のバリエーションを制作するチームも対応できます。

## コラボレーションとプロダクトデザイン

[Figma Design](https://www.figma.com/design/) は、インターフェースデザイン、コンポーネント、インタラクティブなプロトタイプ、開発者へのハンドオフをまとめています。チームが完全なアプリケーションをデザインし仕様化する必要がある場合には、その確立されたプロダクトデザインのワークフローとエコシステムが重要になります。

Lolly は2種類のリアルタイムコラボレーションを提供します。[プライベート collab](/info/collaborate.html) は2台のデバイスを直接ペアリングし、アカウントは不要で、共有ネットワーク上ではインターネットも不要です。work collab は、認証付きアクセス、共有編集、ライブカーソル、保存されたチームセッションのために lolly.work を使用します。work コラボレーションは Lolly クライアントと lolly.work サーバーの両方に実装されていますが、現在の単一ノードのデプロイでは、Figma の運用規模との同等性は確立されていません。

## デプロイと制作

Lolly のクリエイティブアプリと lolly.work は、同じオープンソースプロジェクトの別々にデプロイされる部分です。単体の Lolly は、アカウントなしでオフラインでもレンダリングできます。lolly.work は、組織が管理するインフラストラクチャ上で、SSO、SCIM、共有カタログ、プロジェクト権限、承認、監査記録、サーバーレンダリングを提供します。

チームセッションと work collab の編集はそのインスタンスに届きます。ローカルでのレンダリングはデバイス上に留められます。Content Credentials は、対応する書き出しでは任意であり、サーバー署名には設定済みの組織 ID が使用されます。分離については[統合ソリューションの概要](/info/compare.html)を、検証者が署名者をどのように信頼するかについては [Content Credentials の ID](/info/content-credentials-identity.html)を参照してください。

Figma はその所有者の商標です。このページは2つのソリューションが重なる部分を説明するものであり、Figma とは提携していません。
