# Rondocodeの曲

rondocodeの曲は、コードとして書かれた音楽です。シンセ、パターン、ミックスを、入力しながら再生します。Lollyは動画の下で曲を再生でき、**Rondocode**ユーティリティでは曲を書いて音声として書き出せます。どちらも曲をファイルのContent Credentialsに記録するため、音楽は自らの出どころを示します。

## Lollyで曲を再生する

アセットピッカーは、曲を`.rondo`または`.rondo.json`ファイル、あるいは貼り付けた`rondocode.com`の共有リンクとして受け付けます。曲は自らの音を作るコードなので、クリップが求めるどんな長さでも再生されます。動画の書き出しの**ミュージックベッド**にも、Neurospicy Modeのアンビエントプレーヤーでの再生にも使えます。

曲のコードは、ネットワークなし、ファイルへのアクセスなしで、Lollyのサンドボックス内で実行されます。ライブのマイクや、音声モデルなしの歌唱など、レンダリングで再生できない部分は、アセットの詳細に一覧されます。

ターミナルからは、`lolly mix`が曲をサウンドトラック全体として取り込みます。[CLIでのレンダリング](/info/cli-rendering.html)をご覧ください。

## 曲を書いて書き出す

**Utilities**から**Rondocode**を開き、rondocodeのライブエディターで曲を書き、入力しながら聞きます。**WAV**、**MP3**、**M4A**、**Opus**、**FLAC**、ステムのZIP、**MIDI**、または再生中の音の録音として書き出せます。**Export length**は、音声の書き出しが何秒続くかを設定します。曲ファイル自体(`.rondo.json`)は、書いたとおりのコードで、何も追加されません。

曲は、`sing()`で歌詞を歌わせることができます。歌唱はダウンロードした音声モデルによってお使いのデバイス上で生成され、合成された歌唱を含むファイルは、必ず歌唱をAI生成として宣言します([AI機能](/info/ai-features.html)をご覧ください)。

## クレデンシャル内の曲

rondocodeの曲を再生する動画または音声の書き出しは、各曲をソースとして、Content Credentialsに記録します。

- 曲の名前
- その`.rondo.json`ファイルのSHA-256
- レンダリングの方法: Lollyのサンドボックス内の、`vm`実行クラスで、レンダラーのバージョンとシード、およびレンダリングで再生できなかった部分

曲のコードから計算された音楽はアルゴリズム生成メディアとして記されるため、VerifyがそれをAIとしてフラグ付けすることはありません。書き出す前に、**Download**の下の1行が、クレデンシャルが記録する曲を一覧にし、書き出した後には、同じ行が、配信されたファイルを読み取って見つかったものを報告します。記録を省くには、**C2PA Credentials**のチェックを外します。静止画は音を持たないため、曲を記録しません。`lolly mix`と[MCPサーバー](/info/mcp.html)も、同じ記録を書きます。

## Rondocodeユーティリティのファイル

デバイス上のほとんどのユーティリティは、すでにお持ちのファイルを変換するため、クレデンシャルを書きません。Rondocodeは新しい音声を作るため、書き出すすべての音声ファイルが、曲をソースとして記録するContent Credentialsを持ちます。その名前、`.rondo.json`ファイルのSHA-256、コードが実行された場所です。対象は、WAV、MP3、M4A、Opus、FLAC、ステムZIP内の各ステム、再生中の音の録音です。

- エディター自身のレンダリングは、その非公開フレーム(`frame`実行クラス)で実行され、エディターのバージョンを記録します。
- CLIまたは共有リンクによるレンダリングは、`vm`クラスで実行され、レンダラーのバージョンとシードを記録します。
- WAVは、そのRIFFコメントにも同じ内容を記します。
- 曲のコードから計算された音楽はアルゴリズム生成メディアであり、AIとしては記されません。

曲が歌う場合、ファイルは、その歌唱がAI生成であることを機械可読な形で宣言します。クレデンシャルのデジタルソースタイプは、学習済みモデルで作られた合成メディアで、記録には歌われた部分が一覧され、歌唱が通ったモデルごとに1つのC2PA AI開示が、そのモデルを識別します。Supertonic-3のテキスト読み上げ、wav2vec 2.0の音素アライナー、ContentVecエンコーダー、RVCの声で、Lollyがそれらをホストするリポジトリとコミットが含まれます。合成された歌唱を含むファイルが、その宣言なしで保存されることはありません。

MIDIファイルにはクレデンシャルを入れる場所がないため、代わりにファイル内のテキストイベントがその記述を運び、書き出しパネルもそのことを伝えます。パネルは書き出す前にこれらすべてを説明し、書き出した後は、エディターが保存したファイルを読み戻して、その読み取りで見つかったものだけを報告します。

Content Credentialsが一般に何を記録するかは、[ファイルを書き出す](/info/exporting.html#content-credentials-c2pa)をご覧ください。
