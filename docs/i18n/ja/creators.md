# クリエイター向けLolly

いくつかの項目を入力するだけで、フォントも色もレイアウトもすでに決まった状態の完成ファイルが、あなた自身のデバイス上で出来上がります。数分で仕上げても何時間もかけたように見え、ブランドルールがツール自体に組み込まれているため、ブランドから外れたファイルにあなたの名前が付くことは決してありません。今日やろうとしていることに合ったレーンを、以下から選んでください。

あなたはリレーの一走者です。開発者はあなたが使うツールをパイプラインへと拡張でき、同僚はそれをセルフサービスで実行できます。そこで[キャンペーンのライフサイクル](/info/overview.html#the-lifecycle-of-a-campaign)は、1つのアセットがこの3組の手をすべて経ていく様子を追います。

初めての方へ。まずは**[60秒で何かを作る](/info/make-something.html)**から始めて、どの部分を深掘りしたいか分かったら戻ってきてください。[よくある質問](/info/faq.html)は、無料ツールを信用する前に人々が尋ねることをまとめたものです。[Lollyとの比較](/info/positioning.html)は、他のツールに切り替えるべき場面についての率直な説明です。

## 作る

ツールを選び、いくつかの項目を入力して、完成ファイルをダウンロードします。あるいはDesignキャンバスを開いて自由にレイアウトすることもできます。どちらの方法でも、色・書体・間隔は記憶に頼るのではなくあなたのブランドから決まり、いずれもアカウントは不要です。

- **[60秒で何かを作る](/info/make-something.html)** - Lollyを開いたことがない方向けの、準備不要な3つの短いウォークスルーです。
- **[Lollyの使い方](/info/using.html)** - キャンバス、コントロール、保存、Projects、スマートフォンでの利用など、アプリ自体の振る舞いです。
- **[ブランドスタジオ](/info/brand-studio.html)** - ロゴ・色・書体を初期値ではなく自分のものにしたい時に。
- **[デザインをインポート](/info/design-import.html)** - すでに`.fig`、`.penpot`、`.ai`、`.idml`またはSVGファイルとして存在する作品を、平坦化せず編集可能な状態で取り込みたい時に。
- **[ユーティリティビュー](/info/utilities.html)** - スプレッドシート、コンバーター、Colour Lab、PDF抽出、Script audioなど、ツールのレンダリングではない作業のために。
- **[ブラウザ拡張機能](/info/extension.html)** - 稼働中のWebページをキャプチャし、自分のデザインの中でアセットとして再利用します。
- **[検索](/info/search.html)** - ツール、保存済みの作業、カタログ、設定に一括でアクセスできる1つの入力欄です。
- **[Ask Lolly](/info/ask.html)** - 質問を入力すると、これらのガイドの該当箇所がリンク付きで返ってきます。
- **[ダッシュボード](/info/dashboard.html)** - このデバイスでできること、読み取り専用のデザインシステム、ストレージの概況です。
- **[お気に入り](/info/favourites.html)** - よく使うものにスターを付けると、グリッドの上に専用のタイルが表示されます。
- **[プロフィール](/info/profile.html)** - ツールが事前入力する際に参照する項目と、書き出す内容を1ピクセルも動かさずにアプリを落ち着かせる4つのアクセシビリティ切り替えです。

## アニメーション

動くテキスト、タイムライン上のシーン、そしてブランドを保ったモーション。モーションの書き出しは画面を録画するのではなく、駆動クロックからフレームごとに合成されるため、タイミングがずれることはなく、同じリンクは何回でも同じクリップをレンダリングします。

- **[アニメーション](/info/animating.html)** - キーフレーム、実際の奥行き、そして結果の上を飛ぶシーンカメラです。
- **[シーケンスエディタ](/info/sequence-editor.html)** - タイムラインそのもの: クリップ、オーバーレイレーン、トリムと分割、トランジション、オーディオミックスです。
- **[書き出しとフォーマット](/info/exporting.html)** - モーションが仕上がった後の、動画・GIF・アニメーションPNG側のエクスポートパネルです。

## 録音・録画

カウントイン、レベルメーター、やさしいコーチングを使って、きれいなテイクを録音できます。あるいは音声メモを、音に合わせて動く完成した動画に変えることもできます。専用のRecordページはまだなく、Lollyの使い方のタイムラインのセクションでこれを扱っています。

- **[Lollyの使い方](/info/using.html#timeline-sequence-studio)** - タイムラインへ直接ナレーションを録音する方法、テイクの保存先、それがミックスに反映される仕組みです。
- **[60秒で何かを作る](/info/make-something.html#make)** - 姿を見せるより声を届けたい時のためのオーディオグラムシーンです。
- **[ユーティリティビュー](/info/utilities.html)** - 言葉を先に決めて後から声を当てる、Script audioです。

## 共同作業

2人、2台のデバイス、1つのセッションを、リアルタイムで編集します。テーブル越しにコードをスキャンするだけで、両方の画面に同じ作業内容が表示されます。アカウントも間に入るサーバーも不要で、両方のデバイスが同じネットワーク上にあればインターネット接続すら不要です。

- **[一緒に作業する](/info/collaborate.html)** - セッションの開始方法、デバイス間で何がやり取りされるか、ネットワークが切れたときに何が起きるかです。
- **[Lollyの使い方](/info/using.html#sharing-your-work)** - もっと静かに作業を引き継ぐ方法: 状態全体を保持する共有リンク、または1つの`.lolly`ファイルです。

## 公開・送付

求められた形式でそのまま送り出せます: デザインを保持したリンク、印刷に忠実なPDF、動画、デッキ、あるいはバリエーションのフォルダです。これらすべてが同じソースから作られるため、作るのは一度きりで済みます。

- **[書き出しとフォーマット](/info/exporting.html)** - 印刷単位、DPI、塗り足しとトンボ、動画、バッチ実行、そしてエクスポートパネル自体です。
- **[Lollyが開ける・作れるすべてのフォーマット](/info/formats.html)** - 入出力の全リストと、各チップの裏にあるわかりやすい説明カードです。
- **[データ移行](/info/data-transfer.html)** - 作成したものすべてを別のデバイスへ移すためのバックアップバンドルです。
