# 作る

いくつかのフィールドに入力するだけで、フォント、色、レイアウトが決まった完成ファイルが、自分のデバイス上でできあがります。ブランドのルールはツールに組み込まれているため、ブランドに合わないファイルに自分の名前が付くことはありません。

初めての方は、**[初めてのファイルを作る](/info/make-something.html)**から始めてください。[Lollyの仕組み](/info/how-lolly-works.html)では、スクリプトや同僚のスマートフォンからもツールを実行できる仕組みを説明しています。[質問 & 回答](/info/faq.html)では、無料のツールを信頼して使う前によく寄せられる質問を扱っています。

## 制作する

ツールを選んで入力するか、Lolly Designのキャンバスでページを自由にレイアウトします。

- **[初めてのファイルを作る](/info/make-something.html)** - 設定不要の短いレッスン。QRコードをダウンロードし、編集可能なコピーとして保存します。
- **[Lollyを使う](/info/using.html)** - キャンバス、コントロール、保存、Projects、スマートフォンでの使い方。
- **[Lolly Design](/info/design.html)** - テンプレートでは対応できないレイアウトのための自由なキャンバス。ポスター、デッキ、モーション作品を作れます。
- **[テンプレート](/info/templates.html)** - 空のツールではなく、保存したレイアウトから始めます。
- **[Lolly Designのテキスト](/info/text-composition.html)** - 見出し、流し込みテキスト、ボックスに収まる文字。
- **[Lolly Chart](/info/chart.html)** - 貼り付けた表を、ベクターのグラフ、統計プロット、3Dシーン、映画のような飛行映像として描きます。
- **[Lolly 3D Studio](/info/3d-studio.html)** - SVGアートワークと3Dモデルを配置し、照明を当て、1つのシーンとしてレンダリングします。
- **[Lolly Darkroom](/info/darkroom.html)** - 写真や動画の色を調整し、ルックをLUTとして保存します。
- **[Lolly Utilities](/info/utilities.html)** - デバイス上でファイルを整えます。安全な共有、2つのバージョンの比較、形式の変更、文字の抽出、色の確認に使います。
- **[ブラウザ拡張機能](/info/extension.html)** - ウェブアプリから実際のウェブページのスクリーンショットを撮るか、サイトを読み込んでデザインシステムを作り始めます。

## 自分用に整える

すべてのツールの見た目は、デザインシステムが決めます。

- **[Lolly Design System Setup](/info/brand-studio.html)** - ロゴ、色、書体などを、`#/start`で一度設定します。
- **[Lolly Demoを使う](/info/lolly-demo-in-use.html)** - 実際の作品でのカラーウェイと、独自のデザインシステムへの切り替え。
- **[ブランドの構成](/info/brand-architectures.html)** - 1つの組織で複数のデザインシステムを使うか、複数のカラーウェイを持つ1つのデザインシステムを使います。
- **[パートナーと作業する](/info/partners.html)** - ブランドをパートナーと共有し、受け取ったブランドで作業し、スポンサーのロゴを並べたウォールを作ります。
- **[デザインをインポートする](/info/design-import.html)** - Figma、Penpot、Illustrator、InDesign、Affinity、Photoshop、PowerPoint、SVGのファイルを、1枚の画像ではなく編集可能なレイアウトとして開きます([すべての形式](/info/design-import.html#what-comes-in-from-each-app))。
- **[デッキのブランドを変更する](/info/rebrand.html)** - グラフとアニメーションを保ったまま、PowerPointのデッキに自分のデザインシステムを適用します。
- **[ルール付きでデザインを共有する](/info/create-a-tool.html)** - レイアウトを、他の人が入力できるツールに変えます。

## 作品を探して残す

- **[作品を探して復元する](/info/find-your-work.html)** - 保存したファイル、ダウンロードしたファイル、未保存のファイルの行き先。
- **[Lolly Search](/info/search.html)**と**[Ask Lolly](/info/ask.html)** - 1つの欄からツール、保存した作品、アセット、設定を探し、これらのガイドから回答を得られます。
- **[Lolly Settings](/info/dashboard.html)** - このデバイスでできること、読み取り専用のデザインシステム表示、ストレージ。
- **[お気に入り](/info/favourites.html)**と**[プロフィール](/info/profile.html)** - 星を付けたツール、ツールの自動入力に使う情報、アクセシビリティの切り替え。
- **[デバイスを同期する](/info/sync.html)** - 選んだストレージを通じて、パソコンとスマートフォンで同じ作品を使います。

## アニメーションを作る

動くテキスト、タイムライン上のシーン、ブランドに沿ったモーション。モーションの書き出しは画面の録画ではなく、制御された時計に従って1フレームずつ描画されるため、同じリンクから同じクリップが作られます。

- **[アニメーション](/info/animating.html)** - キーフレーム、奥行き、シーンカメラ。
- **[シーケンスエディター](/info/sequence-editor.html)** - クリップ、オーバーレイレーン、トリミングと分割、トランジション、オーディオミックス。
- **[広色域とHDR](/info/hdr-editing.html)** - 広い色域に対応する画面と形式で、通常の範囲を超えた色を使います。

## 録音・録画とプレゼンテーション

カウントインとレベルメーターを使ってきれいに収録したり、スライドの手前に自分の映像を重ねたりできます。

- **[Lolly Designのタイムライン](/info/design.html#timeline-sequence)** - タイムラインにナレーションを録音します。
- **[初めてのファイルを作る](/info/make-something.html#other-first-projects)** - カメラに映らず声を届けるためのオーディオグラム。
- **[音楽ジェネレーター](/info/music-generator.html)** - 好きなジャンルで自分の曲を作り、クレジットを記載して無料で使えます。[無料のBGM](/info/background-music.html)には全ジャンルのサンプルがあります。[生成された音楽](/info/generated-music.html)では、音楽の作り方を説明しています。
- **[カメラを使ったプレゼンテーション](/info/presenting.html)** - デッキやCountdownにカメラ映像、ロゴ、名前を重ね、非公開のコントロールを別ウィンドウで操作します。
- **[クリッカーで操作できるライブページ](/info/interactive-pages.html)**と**[アジェンダ画面](/info/agenda.html)** - 会場向けのページとプログラム。

## 一緒に作業する

2人が2台のデバイスで、1つのデザインをライブ編集します。アカウントも、中継サーバーも不要です。

- **[一緒に作業する](/info/collaborate.html)** - デバイス間のプライベートなコラボと、組織のLolly Workを通じた組織のコラボ。
- **[Lollyを使う](/info/using.html#sharing-your-work)** - 状態全体を含む共有リンク、または1つの`.lolly`ファイル。
- **[組織でLollyを使う](/info/organisation.html)** - 組織がLolly Workを運用している場合のサインイン、チームプロジェクト、管理対象の設定。

## 発信する

リンク、印刷寸法どおりのPDF、動画、デッキ、バリエーションをまとめたフォルダを、すべて同じ元データから送れます。

- **[ファイルを書き出す](/info/exporting.html)** - 印刷の単位、塗り足しとトンボ、動画、バッチ処理、書き出しパネル。
- **[Lollyで開ける形式と作れる形式のすべて](/info/formats.html)** - 入出力形式の全一覧。
- **[制作物の権利とクレジット](/info/creative-rights.html)** - 使用したもののライセンスと、ファイルに付随するクレジット。
