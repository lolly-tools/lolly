# フォールバックフォント

デザインシステムのフォントで文字を描けない場合、LollyはオープンなNotoフォントでその文字を描き、書き出しでは画像ではなくベクターのアウトラインとして保持します。Lolly Demoのフォントである見出し用のOutfitと本文用のSUSEには、キリル文字、ギリシャ文字、アラビア文字、ヘブライ文字、デーヴァナーガリー文字、ベンガル文字、タイ文字、中国語、日本語、韓国語の文字がありません。

デザインシステムのフォントが、常に一覧の順に優先されます。Outfitにはベトナム語の文字がないため、ベトナム語の見出しは、Lolly Demoの一覧で次にあるSUSEから文字を取ります。フォールバックフォントが描くのは、それらのフォントのどれでも描けない文字だけです。ブランドフォントは、漢字を含め、自分が持つすべての文字、数字、記号を担当します。別の文字体系の単語の中でも同じです。

## 同梱されるもの

15のフォントがあり、すべて固定したコミットのGoogle Fontsから取得しています。各ファイルには、ダウンロードサイズが表示されます。

| 文字体系 | フォント | バージョン | ダウンロード |
|---|---|---|---|
| ウルドゥー語とペルシャ語の文字を含むアラビア文字 | Noto Sans Arabic | 2.012 | 211 KB |
| ヘブライ文字 | Noto Sans Hebrew | 3.001 | 37 KB |
| デーヴァナーガリー文字 (ヒンディー語、マラーティー語、ネパール語) | Noto Sans Devanagari | 2.007 | 151 KB |
| ベンガル文字 | Noto Sans Bengali | 3.011 | 139 KB |
| タイ文字 | Noto Sans Thai | 2.002 | 62 KB |
| キリル文字 | Noto Sans、キリル文字 | 2.015 | 115 KB、イタリック132 KB |
| ギリシャ文字 | Noto Sans、ギリシャ文字 | 2.015 | 77 KB、イタリック83 KB |
| ベトナム語などのアクセント付き文字を含むラテン文字 | Noto Sans、ラテン文字 | 2.015 | 316 KB、イタリック350 KB |
| 簡体字中国語、GB 2312の文字 | Noto Sans SC | 2.004 | 2.0 MB |
| 繁体字中国語、Big5の文字 | Noto Sans TC | 2.004 | 3.8 MB |
| 日本語、Shift_JISの文字 | Noto Sans JP | 2.004 | 2.2 MB |
| 韓国語、すべてのハングル音節とKS X 1001の文字 | Noto Sans KR | 2.004 | 2.5 MB |

各フォントはウェイト軸のすべての太さを保持するため、中国語、日本語、韓国語の太字の見出しは太字になります。Noto Sansフォントは字幅軸を標準に固定し、各ファイルのサイズを半分にしています。中国語、日本語、韓国語のフォントには字幅軸がありません。Noto Sansは文字体系ごとに分割されているため、キリル文字の単語にはキリル文字だけがダウンロードされます。アウトラインは配布元から変更していません。

::: details フォントの保存場所とビルド方法
フォントは1つの共有フォルダ`community/fallback-fonts`にあり、絵文字セットと同じように、`/catalog/packs/fallback-fonts/`からすべてのデザインシステムに配信されます。`scripts/import-fallback-fonts.ts`は、`scripts/data/fallback-fonts.json`で固定された配布元のフォントからファイルをビルドし、各配布元ファイルを記録済みのSHA-256と照合して、フォントの横にライセンス文を書き出します。
:::

## 中国語、日本語、韓国語

文字を削減していない中国語、日本語、韓国語のフォントは、9.6 MBから17.8 MBです。それぞれ、各国の文字集合に加えて、通常の文章で使う句読点、かな、全角形、記号を残すように削減されています。

- 簡体字中国語: GB 2312の一般的な漢字6,763字と記号で、合計7,522文字です。
- 繁体字中国語: Big5の漢字13,053字と記号で、合計13,629文字です。香港増補字符集は含まれません。
- 日本語: WindowsやWebで解釈されるShift_JISです。JIS X 0208に、髙や﨑などの名前に必要なNECとIBMの拡張、すべてのかなと半角カタカナを含め、合計7,432文字です。
- 韓国語: 全11,172ハングル音節と、漢字4,888字を含むKS X 1001で、合計17,082文字です。

この4つのフォントには、ラテン文字、ギリシャ文字、キリル文字は含まれません。これらはデザインシステムのフォントと上記のフォントが描きます。文字集合は、固定したコミットのEncoding Standardのインデックスファイルから取得するため、再ビルドしても同じファイルになります。

中国語、日本語、韓国語は文字の多くを共有していますが、その多くで字形が異なります。たとえば「直」は、中国語と日本語で書き方が異なります。ひと続きのテキストの共有文字は、必ずこれらのフォントの1つから取り、2つにまたがることはありません。Lollyは次の順でフォントを選びます。

1. ひと続きのテキストの言語です。ドキュメント内で、その要素、またはそれを囲む最も近い要素の`lang`から取得します。証明書のLanguageなど、ツールの言語設定がこれを設定します。Lolly自体のインターフェイスの言語やデザインシステムの言語は考慮しないため、ドキュメントは誰が書き出しても同じになります。
2. ひと続きのテキストの文字体系です。かながあれば日本語、ハングルがあれば韓国語です。どちらもない場合、Lollyはドキュメントを調べるため、日本語のドキュメント内の漢字だけの見出しは、日本語の字形で描かれます。かなとハングルの両方があるドキュメントでは、この段階では決まりません。
3. ひと続きのテキスト、なければドキュメント内に、體や說などの繁体字中国語だけで使う文字があれば、繁体字中国語になります。ただし、同じテキストに簡体字中国語だけで使う文字も含まれる場合は除きます。
4. それ以外は簡体字中国語です。

選んだフォントにない文字を、他の3つのフォントから取ることはありません。その文字は画像のままです。日本語と指定された行の韓国語の単語など、選んだフォントにないかなやハングルは、日本語や韓国語のフォントから取れます。ただし、そのフォントが行内の共有文字を1文字も描かない場合に限ります。

ページ上では、これらの言語を2つ含むキャンバスのフォント一覧には両方のフォントが入り、ブラウザは先頭のフォントで共有文字を描きます。書き出しでは、ひと続きのテキストごとにそれぞれのフォントで描きます。

## フォントがダウンロードされるタイミング

ドキュメントに、デザインシステムのどのフォントでも描けない文字が現れるまで、何もダウンロードされません。英語の行内の★や※などの記号のために、中国語、日本語、韓国語のフォントがダウンロードされることはありません。

ドキュメントで初めてフォールバックフォントが必要になると、Lollyはそのフォントだけをダウンロードし、デバイス上に保持します。日本語のドキュメントは2.2 MBの日本語フォントだけを、繁体字中国語のドキュメントは3.8 MBの繁体字フォントだけをダウンロードします。それ以降、その文字体系はオフラインで描画でき、カタログを整理してもフォントは残ります。フォントはカタログのファイルとともに保持され、アップロードしたフォントの中には入らず、ブランドのフォント一覧にも表示されません。

コマンドライン、ターミナルアプリ、MCPサーバーは、ディスクから同じファイルを読むため、ダウンロードは不要です。

## ページ上と書き出しでの表示

ページは書き出しと同じフォールバックフォントを使うため、そうした文字を含む行の幅は両方で同じになります。Lollyは、そのキャンバスでのみ、デザインシステム独自のフォントの後、システムフォントの前にフォールバックフォントを追加します。スタイルや要素に独自のフォント一覧を設定するツールでも、同じ位置にフォールバックフォントが入ります。デザインシステムで対応できるキャンバスのフォント一覧は変わりません。

`system-ui`やHelveticaなどのシステムフォントで始まるフォント一覧は、ページ上では変更されません。そのテキストは、書き出しではデザインシステムのフォントで描かれますが、ページ上ではそうではないためです。

PDFでは、テキスト設定にかかわらず、文字はフォールバックフォントのアウトラインになります。ライブのPDFテキストでは、埋め込みフォントにない文字体系を保持できないためです。SVG、EMF、EPS、DXF、WMFでは、テキストをアウトラインに変換すると、これらの文字もアウトラインになります。テキストをライブのまま保持した場合、閲覧する側のフォントが描きます。フォールバックフォントで書き出しの一部を描いた場合、書き出しパネルには次のような注記が表示されます。

> このデザインシステムのフォントには日本語の文字がないため、日本語のテキストはNoto Sans JPで描画されます。

コマンドラインでも、同じ文を注記として表示します。

## 画像のままになるもの

𠮷や香港増補字符集の文字など、4つの国別の文字集合に含まれない文字には、フォールバックフォントがありません。𠮷などの珍しい文字、香港増補字符集で追加された文字、タミル文字、エチオピア文字、シリア文字など、フォールバックフォントがない文字体系は、すべて同じように扱われます。タミル文字、エチオピア文字、シリア文字などの文字体系にも、フォールバックフォントはありません。PDFでは、そのようなテキストを含む行が300 dpiの画像として入り、書き出しパネルに文字体系が一覧表示されます。SVGでは、ひと続きのテキストはライブテキストのまま残り、閲覧する側のフォントで描かれます。

::: details EPS、WMF、EMFの書き出しでは
**Outline fonts**がオンのEPS、WMF、EMFには、代わりに使えるライブテキストがないため、ひと続きのテキストも300 dpiの画像として入ります。画像は文字のある部分だけをテキストの色で塗るため、背景は透けて見えます。書き出しパネルには文字体系が一覧表示されます。画像は正立でしか描画できないため、回転や傾斜のあるひと続きのテキストがあると、書き出しが停止し、そのテキストを引用したメッセージが表示されます。WMFやEMFでは、画像はマスクと描画という2つのビットマップ操作です。Microsoft OfficeとLibreOfficeは意図どおりに描画します。Inkscapeなど、それらを無視するアプリでは、文字が白いボックスの上に表示されます。

**Outline fonts**がオフのEMFは、そのようなひと続きのテキストをライブテキストとして保持し、閲覧する側のフォントで描きます。例外は、字間を指定したテキストなど、ライブのEMFテキストでは保持できないものです。Lollyはそのテキストをアウトライン化するため、どのフォントでも描けないテキストは、ここでも画像として入ります。
:::

::: warning どのフォントでも描けないテキストがあるとDXFの書き出しは停止します
DXFは、アウトラインを必要とするカッティングマシンやCADソフトウェアに渡すため、どのフォントでも描けないひと続きのテキストがあると、DXFの書き出しは停止します。メッセージはそのテキストを引用し、文字体系を示します。その文字を持つフォントを追加するか、SVGまたはPDFを書き出してください。
:::

## 書き出し前の確認

Lolly Designの**Before you export**カードと`lolly check`の`render`チェックは、どのフォントでも描けないテキストを報告します。書き出しと同じように、同じフォント別の文字一覧からフォールバックフォントも考慮するため、フォールバックフォントで描けるテキストは報告されません。タミル文字などのフォールバックフォントがない文字体系や、国別の文字集合に含まれない中国語、日本語、韓国語の文字は、引き続き報告されます。書き出しでは画像やライブテキストとして描かれ、DXFの書き出しでは停止するためです。このチェックはカタログから文字一覧を読み、フォントはダウンロードしません。

## ライセンスとクレジット

すべてのフォールバックフォントには、SIL Open Font License 1.1が適用されます。カタログの各項目には、ライセンス文のハッシュとともにそのライセンスが記録されるため、[創作物の権利とクレジット](/info/creative-rights.html)の権利規則は、他のフォントと同じようにライセンスを読み取ります。ライセンス文はフォントの横にあります。Noto SansファイルはReserved Font Nameを宣言していません。中国語、日本語、韓国語のフォントはAdobeのもので、Sourceという名前を予約しています。文字を削減したファイルは、その名前を使わないNotoの名前を保持します。

ライセンスには、その条項はフォントを使って作ったドキュメントには適用されないと記されています。書き出しに含まれるのは、デザインシステム独自のフォントと同じように、使われた文字のアウトラインだけです。Lollyは、フォールバックフォントのために、フォントプログラム、クレジット行、新たなコンテンツクレデンシャルの項目を追加することはありません。
