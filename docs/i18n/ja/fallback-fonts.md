# フォールバックフォント

デザインシステムのフォントがカバーするのは、世界の文字体系の一部だけであることがよくあります。Lolly Demoは見出しにOutfit、本文にSUSEを使っていますが、どちらのフォントにも、キリル文字、ギリシャ文字、アラビア文字、ヘブライ文字、デーヴァナーガリー文字、ベンガル文字、タイ文字、中国語、日本語、韓国語の文字がありません。ドキュメントに、デザインシステムのフォントで描けない文字が含まれる場合、Lollyはその文字をオープンなNotoフォントで描くため、書き出しでは、単語を画像にせず、ベクターのアウトラインとして保てます。

デザインシステムのフォントが常に最優先で、デザインシステムが並べた順に使われます。Outfitにはベトナム語の文字がないため、ベトナム語の見出しでは、Lolly Demoのリストで次にあるSUSEから取ります。フォールバックフォントが描くのは、それらのフォントのどれも描けない文字だけです。そのため、ほかの文字体系の単語の中にあっても、ブランドフォントは自身が持つすべての文字、数字、記号を保ちます。ブランドフォントに漢字があれば、その漢字も保たれます。

各フォントのウェイト軸はそのまま保たれるため、デザインが求めるどのウェイトも描け、太字の中国語、日本語、韓国語の見出しも太字になります。Noto Sansフォントの幅の軸は標準に固定されており、各ファイルが半分のサイズになります。中国語、日本語、韓国語のフォントには幅の軸がありません。Noto Sansは文字体系ごとに分割されているため、キリル文字の単語では、キリル文字だけをダウンロードします。アウトラインは上流のアウトラインのままで、変更はありません。

## 中国語、日本語、韓国語

中国語、日本語、韓国語のフォント1つ分の全体は9.6 MBから17.8 MBあります。そこで、これらの各フォントは、読み手が日常的に使う国の文字集合に、句読点、かな、全角形、本文で使う記号を加えたところまで切り詰められています。

- 簡体字中国語: GB 2312。よく使われる6,763字の漢字とその記号で、合計7,522字。
- 繁体字中国語: Big5。13,053字の漢字とその記号で、合計13,629字。香港補足文字集合は含まれません。
- 日本語: WindowsとWebが読むShift_JIS。JIS X 0208に、髙や﨑のような名前に必要なNECとIBMの追加分を加えたもので、すべてのかなと半角カタカナを含み、合計7,432字。
- 韓国語: 11,172字のハングル音節すべてとKS X 1001(4,888字の漢字を含む)で、合計17,082字。

ラテン文字、ギリシャ文字、キリル文字は、デザインシステムのフォントと上記のフォントが描くため、これら4つのフォントには含まれません。文字集合は、Encoding Standardのインデックスファイルを固定されたコミットから読み取っているため、再ビルドしても同じファイルになります。

中国語、日本語、韓国語は文字の多くを共有していますが、それぞれが多くの文字を異なる形で描きます。たとえば同じ文字の「直」は、中国語と日本語で書き方が違います。そのため、1つのテキストの連なりは、共有される文字のすべてを、これらのフォントのうちの1つから取り、2つから取ることはありません。Lollyは次の順序でそのフォントを選びます。

1. 連なりの言語。その要素、またはドキュメント内でそれを囲む最も近い要素の`lang`から取ります。証明書のLanguageのような、ツールの言語設定がそれを決めます。Lolly自身のインターフェースの言語とデザインシステムの言語は数えないため、ドキュメントは誰が書き出しても同じになります。
2. 連なりの文字体系。かなは日本語、ハングルは韓国語を意味します。連なり自体にどちらもない場合は、ドキュメント全体を読むため、日本語のドキュメントで漢字だけの見出しは、日本語で描かれます。かなとハングルの両方を含むドキュメントでは、ここでは何も決まりません。
3. 連なり、またはなければドキュメント内に、「體」や「說」のような、繁体字中国語だけが使う文字がある場合は、繁体字中国語を意味します。ただし、同じテキストに簡体字中国語だけが使う文字もある場合は除きます。
4. それ以外は、簡体字中国語。

選ばれたフォントにない文字を、ほかの3つのフォントから取ることはありません。その文字は、後述のとおり画像のままになります。選ばれたフォントにないかなやハングル(日本語と指定された行にある韓国語の単語など)は、日本語または韓国語のフォントから取れる場合がありますが、それは、そのフォントが、その行の共有文字を1つも描かない場合に限ります。

ページ上では、これらの言語を2つ含むキャンバスは両方のフォントを並べ、ブラウザは共有文字を最初のフォントで描きます。書き出しでは、各連なりをそれぞれのフォントで描きます。

## フォントをダウンロードするとき

ドキュメントに、デザインシステムのどのフォントでも描けない文字が含まれるまで、何もダウンロードされません。英語のドキュメント、またはデザインシステムがカバーするどの言語のドキュメントも、フォールバックフォントをダウンロードすることはありません。英語の行にある★や※のような記号が、中国語、日本語、韓国語のフォントをダウンロードすることもありません。

ドキュメントが初めてフォールバックフォントを必要としたとき、Lollyはその1つの文字体系のためにその1つのフォントをダウンロードし、お使いのデバイスに保存します。日本語のドキュメントは日本語のフォントだけ(2.1 MB)、繁体字中国語のドキュメントは3.6 MBの繁体字のフォントをダウンロードします。それ以降、その文字体系はオフラインでも描け、カタログを整理してもフォントは残ります。フォントはカタログ自身のファイルと一緒に保管され、アップロードしたフォントには入らないため、ブランドのフォント一覧には表示されません。

コマンドライン、ターミナルアプリ、MCPサーバーは、同じファイルをディスクから読むため、ダウンロードは不要です。

## ページ上と書き出しで

ページは、書き出しと同じフォールバックフォントを使います。これがないと、ブラウザはそうした文字をシステムフォントで描く一方、書き出しではNotoを使うため、それらを含む行の幅が両者で変わってしまいます。Lollyは、そのキャンバスに限り、デザインシステムのフォントリストの末尾、つまりデザインシステム自身のフォントの後で、どのシステムフォントよりも前に、フォールバックフォントを加えます。ツールが、スタイルや要素で独自のフォントリストを指定している場合も、フォールバックフォントは同じ位置に入ります。つまり、そのリストが示すフォントの後で、どのシステムフォントよりも前です。デザインシステムがカバーするキャンバスは、フォントリストがこれまでとまったく同じままです。

ページは、フォントリストが`system-ui`やHelveticaのようなシステムフォントで始まる場合は、そのリストに手を加えません。書き出しはそのテキストをデザインシステムのフォントで描くのに対し、ページは描かないためです。

PDFでは、どのテキスト設定を選んでも、単語はフォールバックフォントで描かれたアウトラインになります。ライブのPDFテキストは、埋め込まれたフォントにない文字体系を運べないためです。SVG、EMF、EPS、DXF、WMFでは、テキストがアウトラインに変換されるときは常にアウトラインになり、テキストをライブのままにした場合は、従来どおり、閲覧する側のフォントで描かれます。フォールバックフォントが書き出しの一部を描いた場合、書き出しパネルには次のような注記が表示されます。

> 日本語のテキストは、このデザインシステムのフォントにその文字がないため、Noto Sans JPで描かれています。

コマンドラインは、同じ文を注記として出力します。

## 画像のままになるもの

4つの国の文字集合の外にある文字には、フォールバックフォントがありません。𠮷のような珍しい文字、香港補足文字集合が加えた香港向けの文字、タミル文字、エチオピア文字、シリア文字のようにフォールバックフォントのない文字体系は、すべて同じ扱いです。PDFでは、それを含む行が300 dpiの画像として入り、書き出しパネルにその文字体系が一覧されます。SVGでは、その連なりはライブテキストのままで、閲覧する側のフォントで描かれます。

## 書き出し前のチェック

Lolly Designの**Before you export**カードと、`lolly check`の`render`チェックは、どのフォントでも描けないテキストを報告します。どちらも、書き出しと同じように、各フォントが持つ文字の同じ一覧からフォールバックフォントを数えるため、フォールバックフォントが描くテキストは報告されません。タミル文字のようにフォールバックフォントのない文字体系や、国の文字集合の外にある中国語、日本語、韓国語の文字は、書き出しが画像またはライブテキストとして描くため、引き続き報告されます。チェックはそれらの一覧をカタログから読み、フォントはダウンロードしません。

## ライセンスとクレジット

すべてのフォールバックフォントはSIL Open Font License 1.1の下にあり、各カタログエントリはそのライセンスを、ライセンス文のハッシュとともに記録します。そのため、[クリエイティブの権利とクレジット](/info/creative-rights.html)の権利ルールは、そのライセンスをほかのフォントのものと同じように読みます。ライセンス文はフォントの隣にあります。Noto Sansのファイルは、予約フォント名を宣言していません。中国語、日本語、韓国語のフォントはAdobeのもので、Sourceという名前を予約していますが、切り詰めたファイルはNotoの名前を保っており、その名前は使っていません。

ライセンスには、その条件がフォントで作ったドキュメントには適用されないと書かれています。書き出しが保持するのは、使った文字の描画済みアウトラインだけで、これはデザインシステム自身のフォントの場合と同じです。Lollyは、フォールバックフォントについて、フォントプログラムも、クレジット行も、新しいコンテンツクレデンシャルのエントリも加えません。
