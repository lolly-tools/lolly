# 私たちのAIに対する姿勢

Lollyは、印刷機以来、メディアの作られ方における最大の変化のさなかに、AIに慌てることも、その技術に浮かれることもない人々によって作られました。これがプロジェクトの立場であり、それぞれの約束の背後にある仕組みとともに示しているため、信頼するのではなく検証できます。

> 「私たちは、まるで蛇口が今にも枯れるかのように水を飲んでいます。そんなことは起きません - 今日のAIは、これから先で最も出来の悪いAIなのです。もし私たちがこの洪水を生き延びるとしたら、それは丘の下にある錆びた、堆積物だらけの貯水タンクの中身を溜め込むことによってではありません。それは***私たちの***土地に水を引き、豊かな未来のために取り戻すことによってです。」
>
> - Andy Fitzsimon, Lolly Contributor

Andyの描く絵では、AIに対する希少性の姿勢とは、洪水が平原を駆け抜けているのに、傷んだタンクの水を飲むことです。生成されたコンテンツは、事実上無限になろうとしています。何かが無限になると、その価値は周囲に残る希少なものに移ります。信頼、来歴、ブランドの一貫性、人間の判断です。Lollyは洪水のためのより大きなバケツではありません。灌漑です。水を導く水路と、実際に物が育つ土壌です。

## このスタンスを5つのコミットメントで

- <!--i:layers--> **AIは入力としては歓迎されるが、なりすましは認めない。** エージェントはLollyのファーストクラスのユーザーです。[MCPサーバー](/info/mcp.html)と[URLモード](/info/url-mode.html)を通して、人と同じツールを、まったく同じ制約の中で実行します。エージェントに許されないのは、出力を、そうでないものとして通用させることです。[入力であって、なりすましではない](/info/input-not-impersonation.html)が、その線を引いています。
- <!--i:shieldcheck--> **AIは自らを明示する。** AIがピクセルを生成した場合、書き出しはそう述べます。ファイルのContent Credentialsにある機械可読なアサーションと、誰かがファイルを検証したときの目に見えるGEN AIバッジです。AI製と宣言されたメディアがデザインに配置されると、書き出し自身のクレデンシャルもそう述べます。複合的な出所の印と、署名された機械可読なAI開示です。Lollyは他の場所で作られたファイルのAI宣言も読み取って表示し、SynthIDの透かしが含まれていそうな場合にはフラグを立てます。読み取るのは透かし自体ではなく、宣言です。同じルールは、Lolly自身のデバイス上のリライターにも課されます。それが書くすべての文は、語の選び方に公開された統計的な透かしを持ち、ここでもツールの中でも開示されるため、モデルが書いたテキストは、プレーンテキストにコピーしても自らを示し続け、誰でもそのテキストを[Verify](/#/verify)で確認できます([確認の仕組み](/info/what-verify-checks.html#text-reworded-by-lolly))。この方式は意図的に公開されています。すべての人に検証を、誰にも秘密を与えないためです。受け手には、メディアがどのように作られたかを知る権利があります。
- <!--i:check--> **来歴は既定でオン。** 書き出しには、埋もれた設定としてではなく、既定で[Content Credentials](/info/content-credentials-identity.html)が付きます。連鎖は編集と素材をカバーするため、作品の履歴が作品とともに運ばれます。Lollyが作成した任意のファイルで、[ご自身で検証](/info/verify-yourself.html)できます。
- <!--i:people--> **作者は人のまま。** 言葉、画像、パレット、判断が必要だった決定。ツールはその判断を拡大するものであり、人の代わりをするものではありません。自動化されるのは、面倒な部分です。ブランドの確認、すべてのサイズでの再書き出し、手作業のローカライズ。そして残るのが、作者であることです。
- <!--i:globe--> **バケツではなく水路。** 今日のモデルは天井ではなく床なので、モデルへのアクセスを抱え込むことに価値が依存するものは、何も作りません。エンジンはオープンソースで、お使いのデバイス上でレンダリングし、オフラインで動作します。モデルの堀も、使用量メーターも、洪水そのものに付随する希少性のビジネスもありません。持続的な投資は水の周りのインフラであり、そのインフラこそ、私たちが無償で提供するものです。

## 人間の意思決定こそが要点です

個人が地球と私たちの歴史を形作ります。一つひとつなされる彼らの選択が、残りの私たちが生きる世界になります。彼らの行動がその世界を作ります。物事はいつも、そうして起こってきました。

だから私たちは人間の決定を力づけ、それを決して妥協しません。選ぶ権利。主体性。自律。決めて行動する力、そしてその行動があなたのものであること。

ここにあるツールは、人が決めたことを拡張します。人に代わって決めることはなく、ひそかに人の代わりを務めることもありません。決定が自動化によって運ばれる場合でも、記録は必ず、それを引き起こした人物へとたどり着きます。途中でいくつのシステムや紆余曲折を経たとしても変わりません。

私たちはそれを最初から最後まで尊重し、記録します。歴史のために、説明責任のために、信頼のために、そして未来のために。

## AIは、あなたの条件で

ここでAIを使う必要は一切ありません。もし使うと選んだ場合、次の3つが常に成り立ちます:

- <!--i:people--> **主導権はあなたにあります。** AIが手を貸すのは、お客様が求めたときだけ、お客様が指し示した部分についてだけです。何も、お客様の代わりに決められることはありません。
- <!--i:check--> **コストがかからなくなります。** AIが一度何かを作る手助けをしたなら、その結果はお客様のものです。もう一度使うことは、その結果が何度必要でも無料です。
- <!--i:shieldcheck--> **正直なままです。** AIが作った作品はそう述べ、お客様が作るものは、他の誰かのふりをするのではなく、お客様の名前を運びます。組み込みのヘルプもこのように動作します。[Ask Lolly](/info/ask.html)は、マニュアル自身の文とリンクで答え、作り物の答えを返すことはありません。

## これが意味しないこと

- <!--i:check--> **禁止ではありません。** ツールは作業に役立つ場面でAIを使用でき、エージェントもサポート対象のオーディエンスです - 詳しくは[AIエージェント](/info/ai-agents.html)をご覧ください。
- <!--i:seal--> **純粋性を主張するものではありません。** Lollyは来歴を広く読み取り、正直に書き込みますが、インターネット上のすべての生成ピクセルを検出できるふりはしません。
- <!--i:sunburst--> **モラルパニックではありません。** 敵は洪水ではありません。出所不明の水こそが敵です。
