# AIに対する私たちの立場

Lollyは、印刷機以来最大となるメディア制作方法の変化のさなかに、AIに慌てることも、その技術に熱狂することもない人々によって作られました。信じるだけでなく検証できるよう、各約束を支える仕組みとともに、このプロジェクトの立場を示します。

> 「私たちは、今にも蛇口の水が尽きるかのように飲んでいます。尽きることはありません。今日のAIは、これから先で最も性能が低いAIです。もし私たちが洪水を生き延びるとしても、それは丘の下にある、沈殿物でいっぱいのさびた水槽の中身をため込むことによってではありません。豊かな未来のために、***私たちの***土地を灌漑し、開墾することによってです。」
>
> - Andy Fitzsimon, Lolly Contributor

## 5つの約束に示す立場

- <!--i:layers--> **AIを入力として歓迎しますが、偽装には使いません。** エージェントは、Lollyにおいて人と同等のユーザーです。[MCPサーバー](/info/mcp.html)と[URLモード](/info/url-mode.html)を通じて、人と同じツールを、まったく同じ制約の中で使います。どのエージェントにも許されないのは、出力を実際とは別のものとして装うことです。[入力として使い、偽装には使わない](/info/input-not-impersonation.html)で、その線を引いています。
- <!--i:shieldcheck--> **AIは自らを明示します。** AIがピクセルを生成した場合、書き出しはその事実を示します。ファイルのContent Credentials内の機械可読の表明と、誰かがファイルを検証したときに見えるGEN AIバッジです。AI製と申告したメディアをデザインに配置した場合は、書き出し自体のクレデンシャルにも、合成の出自を示すマークと、署名付きで機械可読のAI開示が記録されます。Lollyは、他で作られたファイルのAI宣言も読み取って表示し、SynthIDの透かしがある可能性が高い場合は、その旨を示します。読み取るのは宣言であり、透かしそのものではありません。同じルールは、Lolly自身のデバイス上のリライト機能にも適用されます。書いた文はすべて、語の選び方に公開の統計的透かしを含み、そのことをここでもツール内でも開示しています。そのため、モデルが書いたテキストは、プレーンテキストのコピーになっても自らを明示し続け、誰でも[Lolly Verify](/#/verify)で確認できます([確認の仕組み](/info/what-verify-checks.html#text-reworded-by-lolly))。この仕組みは、設計上公開されています。誰でも検証でき、誰も秘密を持ちません。受け手には、メディアがどう作られたかを知る権利があります。
- <!--i:check--> **来歴は既定で有効です。** 書き出しには、埋もれた設定としてではなく、既定で[Content Credentials](/info/content-credentials-identity.html)が付与されます。連鎖には編集と素材が含まれるため、作品の履歴が作品とともに移動します。Lollyが作るどのファイルでも、[ご自身で検証できます](/info/verify-yourself.html)。
- <!--i:people--> **作者は人のままです。** 言葉、画像、配色、判断が必要だった決定。ツールは、その判断を大きな規模に広げ、人の代わりになることはありません。自動化するのは、ブランドの確認、サイズごとの再書き出し、手作業のローカライズといった手間のかかる部分です。作者であることは、その人に残ります。
- <!--i:globe--> **バケツではなく、水路です。** 今日のモデルは到達点ではなく出発点なので、私たちはモデルへのアクセスを囲い込むことに価値が依存するものを作りません。エンジンはオープンソースで、お使いのデバイス上でレンダリングし、オフラインでも動作します。モデルによる参入障壁も、利用量のメーターも、洪水そのものの希少性に頼るビジネスもありません。長く価値を持つ投資は、水の周囲のインフラです。そして、そのインフラこそを、私たちは無償で提供します。

## 人間の決定こそが大切です

一人ひとりが、地球と私たちの歴史を形作ります。一つずつ積み重ねる選択が、他の人々の暮らす世界になります。その行動が、その世界を作ります。これまで何事も、そうして起きてきました。

だから私たちは、人間の決定を力づけ、決してそこを妥協しません。選ぶ権利。主体性。自律性。決めて行動する力と、その行動が自分自身のものであることです。

ここにあるツールは、人が決めたことを広げ、人に代わってひそかに決めることはありません。判断が自動化によって実行される場合も、途中でいくつのシステムを通り、どれだけ回り道をしても、記録はそれを開始した人までたどれます。

私たちは、その原則を最初から最後まで守り、記録します。歴史、説明責任、信頼、そして明日のために。

## AIは、あなたの意思で

ここではAIを使う必要はありません。使う場合も、次の3つは変わりません。

- <!--i:people--> **主導権はあなたにあります。** AIが手伝うのは、あなたが頼んだときに、指定した部分だけです。あなたに代わって決めることはありません。
- <!--i:check--> **費用はかかり続けません。** AIが一度何かを作るのを手伝えば、その成果はあなたのものです。何度必要になっても、再利用は無料です。
- <!--i:shieldcheck--> **偽りません。** AIが作ったものにはそう表示され、あなたが作ったものには、誰かになりすますことなくあなたの名前が付きます。組み込みのヘルプも同じです。[Ask Lolly](/info/ask.html)は、マニュアルそのものの文とリンクで答え、回答を作り上げることはありません。

<!--i:eti-info-->
## この方針が意味しないこと

- <!--i:check--> **禁止ではありません。** 作業に役立つならツールはAIを使えますし、エージェントも対応する利用者です。[AIエージェント](/info/ai-agents.html)をご覧ください。
- <!--i:seal--> **AIを一切含まないという主張ではありません。** Lollyは幅広く来歴を読み、正直に記録します。インターネット上で生成されたすべてのピクセルを検出できるとは言いません。
- <!--i:sunburst--> **過剰な恐れではありません。** 押し寄せるコンテンツが問題なのではありません。出所のわからないコンテンツが問題です。
