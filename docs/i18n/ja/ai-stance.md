# 私たちのAIに対するスタンス

Lollyは、印刷機の登場以来メディアの作られ方における最大の変化の只中で、AIにパニックを起こすこともなく、AIに浮かれることもない人々によって作られました。このページはプロジェクトの立場を率直に述べ、すべての主張にそれを強制するメカニズムを対応させています。信じるのではなく、確認できるように。

> 「私たちは、まるで蛇口が今にも枯れるかのように水を飲んでいます。そんなことは起きません - 今日のAIは、これから先で最も出来の悪いAIなのです。もし私たちがこの洪水を生き延びるとしたら、それは丘の下にある錆びた、堆積物だらけの貯水タンクの中身を溜め込むことによってではありません。それは***私たちの***土地に水を引き、豊かな未来のために取り戻すことによってです。」
>
> - Andy Fitzsimon, Lolly Contributor

## このスタンスを5つのコミットメントで

- <!--i:layers--> **AIは入力としては歓迎するが、なりすましとしては決して認めない。** エージェントはLollyの第一級のユーザーです。[MCPサーバー](/info/mcp.html)や[URLモード](/info/url-mode.html)を通じて、人間とまったく同じツールを、まったく同じ制約の中で実行します。あるツールが人のためにオフブランドなアセットを出力できないなら、エージェントのためにもそれを出力できません - ガードレールは誰がボールを投げているかを気にしません。エージェントに許されていないのは、その出力を、それではない何かであるかのように見せかけることです。
- <!--i:shieldcheck--> **AIは自らを宣言する。** AIがピクセルを生成した場合、書き出しはそれを明示します:ファイルのContent Credentialsに機械可読なアサーションが含まれ、誰かが検証すれば目に見えるGEN AIバッジが表示されます。Lollyは他所で作られたファイルのAI宣言も読み取って表示し、SynthID透かしが存在する可能性がある場合はフラグを立てます - これは透かし自体ではなく宣言を読み取るものです。同じ規則はLolly自身のデバイス上リライターにも適用されます:モデルが書くすべての文には、語の選択の中に公開された統計的な透かしが含まれ、こことツール内の両方で開示されるため、モデルが書いたテキストはプレーンテキストのコピーになっても自己申告的であり続け、誰でも[Verify](/info/verify-yourself.html)ページで確認できます。この仕組みは設計上公開されています:検証は誰にでも、秘密は誰にもありません。オーディエンスにはメディアがどう作られたかを知る権利がある - この一文は[インクルーシブデザイン](/info/inclusive-design.html)ページに倫理的コミットメントとして掲げられており、これがそれを現実のものにしています。そして、あなたがAI制作と宣言したメディアがデザインに配置されると、書き出し自身のクレデンシャルもそれを示します:合成物であることを示す出自マークと、署名済みの機械可読なAI開示です。
- <!--i:check--> **来歴はデフォルトでオンです。** 書き出しには、隠された設定としてではなく、デフォルトで[Content Credentials](/info/content-credentials-identity.html)が付与されます。このチェーンは編集とイングリディエントを網羅するため、作品の履歴はその作品とともに移動します。Lollyが生成したどのファイルでも、[自分で検証](/info/verify-yourself.html)できます。
- <!--i:people--> **著者は常に人間です。** すべての入力は、ここに至るまでにいくつのシステムや紆余曲折を経ていようと、最終的にはどこかで人間が下した決定です。エージェントは決定を遠くまで運ぶことはできますが、それを生み出すことはできません。言葉、画像、パレット、判断を要する選択 - ツールはその判断を拡張するのであって、置き換えるのではありません。自動化されるのは面倒な部分です:ブランドチェック、あらゆるサイズへの再書き出し、手作業でのローカライズなど。残るのは著作性です。
- <!--i:globe--> **バケットではなく、チャネルを。** 今日のモデルは天井ではなく床であり、その価値がモデルへのアクセスを独占することに依存するようなものは何も作らないと私たちは決めています。エンジンはオープンソースで、あなた自身のデバイス上でレンダリングし、オフラインでも動作します。モデルの堀もなく、利用量メーターもなく、この奔流そのものに希少性ビジネスを結びつけることもありません。持続する投資先は水そのものではなくその周りのインフラであり、私たちが無償で提供するのはそのインフラです。

## 人間の意思決定こそが要点です

上記のすべてのコミットメントの根底にあるものを、はっきりさせておきましょう。

個人が地球と私たちの歴史を形作ります。一つひとつ下された彼らの選択が、私たちの残りが生きる世界になります。彼らの行動がそれを作るのです。これは感傷ではなく、単に物事がこれまで起きてきた仕組みそのものです。

だから私たちは人間の意思決定に力を与え、それを損なうことはしません。選ぶ権利。主体性。自律性。決定し行動する能力、そしてその行動があなた自身のものであること。

ここにあるツールは、人が決めたことを拡張します。人に代わって決めることはなく、ひそかに人の代わりを務めることもありません。決定が自動化によって運ばれる場合でも、記録は必ず、それを引き起こした人物へとたどり着きます。途中でいくつのシステムや紆余曲折を経たとしても変わりません。

私たちはそれを最初から最後まで尊重し、記録します。歴史のために、説明責任のために、信頼のために、そして未来のために。

## AIは、あなたの条件で

ここでAIを使う必要は一切ありません。もし使うと選んだ場合、次の3つが常に成り立ちます:

- <!--i:people--> **主導権はあなたにあります。** AIはあなたが求めたときにだけ、あなたが指定した部分にだけ手を貸します。何もあなたの代わりに決められることはありません。
- <!--i:check--> **コストがかかり続けることはありません。** AIが一度何かを作る手助けをしたら、その結果はあなたのものです。再び使うのは無料で、何度必要であっても同じです。
- <!--i:shieldcheck--> **常に正直であり続けます。** AIが作った部分はその旨を示し、あなたが作るものは誰か別人になりすますのではなく、あなたの名前を掲げます。組み込みのヘルプでさえこの方式です: [Ask Lolly](/info/ask.html)はマニュアルそのものの文章とリンクで答え、でっち上げの回答は決して返しません。

## これが意味しないこと

- <!--i:check--> **禁止ではありません。** ツールは作業に役立つ場面でAIを使用でき、エージェントもサポート対象のオーディエンスです - 詳しくは[AIエージェント](/info/ai-agents.html)をご覧ください。
- <!--i:seal--> **純粋性を主張するものではありません。** Lollyは来歴を広く読み取り、正直に書き込みますが、インターネット上のすべての生成ピクセルを検出できるふりはしません。
- <!--i:sunburst--> **モラルパニックではありません。** 敵は洪水ではありません。出所不明の水こそが敵です。
