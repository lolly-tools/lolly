# ブラウザ拡張機能

Webページは、別のWebサイトのピクセルを読み取れません。Chromiumベースのブラウザ(Chrome、Edge、Brave、Arc、Opera。Chrome 111以降)では、無料の**Lolly URL Screenshot**拡張機能により、Lolly Webアプリがデスクトップアプリと同じキャプチャ機能でページのスクリーンショットを撮れます。拡張機能をインストールすると、次のことができます。

- **[Lolly URL Screenshot](/t/url-shot)**で、構成したページをファイルとして保存できます。
- 画像スロットに貼り付けたWebアドレスを、**Screenshot this page**で、そのページのスクリーンショットにできます。
- [Lolly Design System Setup](/info/brand-studio.html)の**Website**ソースで、1ページを読み取ってデザインシステムを作り始められます。

リクエストは毎回ご自身で承認します。デスクトップアプリは、拡張機能なしで同じ作業を行います。

## インストール

**Chrome Web Storeから:** 近日公開予定です。公開後は、ワンクリックでインストールできます。

**ご自身で読み込む(開発者向け)。** 拡張機能のソースは、リポジトリの`shells/chrome-extension/`にあります。パッケージ化のステップで、そのフォルダから本番用パッケージをビルドします。このパッケージは、`https://lolly.tools`のLollyでのみ動作します。

1. `pnpm run pack:chrome-extension`を実行します。`dist/chrome-extension/`にパッケージをビルドします。
2. `chrome://extensions`を開きます。
3. **Developer mode**(右上)をオンにします。
4. **Load unpacked**をクリックし、`dist/chrome-extension/`フォルダを選びます。
5. Lollyのタブを再読み込みします。Lollyはページの読み込み時に拡張機能を検出し、「Get the extension」の案内が消えます。その後、**Lolly URL Screenshot**(Utilities内)でキャプチャをファイルに保存でき、Lolly Batchモードでも動作します。

::: details ローカル開発サーバーまたはソースフォルダを使う場合
ローカル開発サーバーでは、代わりに`pnpm run pack:chrome-extension:dev`を実行し、`dist/chrome-extension-dev`を読み込みます。このパッケージは`http://localhost:5173`も受け付け、名前に**Development**が含まれます。

PNGのスクリーンショットなら、`shells/chrome-extension/`フォルダ自体を読み込んでも動作します。このフォルダには、パッケージ化のステップで組み込まれるページ走査機能がありません。このフォルダから作ったSVGには、図形ではなくスクリーンショットが入ります。
:::

## Lollyがリクエストするときの流れ

![Lollyのタブが1ページをリクエストし、拡張機能の承認ウィンドウでApprove onceを押す。バックグラウンドのタブが開き、ページを読み取って閉じる。その後、Lollyのタブが結果を受け取る。](/info/diagrams/concepts/extension-request.svg)

1. **Lollyがリクエストします。** 小さなスクリプトが拡張機能の存在をLollyに伝えるため、追加の設定なしでキャプチャやページの読み取りを始められます。
2. **ご自身で承認します。** 拡張機能が独自の**Approve page request**ウィンドウを開きます。リクエスト元のサイト、要求しているのがスクリーンショットかページの内容か、ページのアドレスが表示されます。**Approve once**を押すまで、何も読み取りません。**Cancel**を押すかウィンドウを閉じると、リクエストが終了します。
3. **Chromeはサイトごとに1回確認します。** あるサイトへのリクエストを初めて承認すると、Chromeも、そのサイトへのアクセスを拡張機能に許可するかを尋ねます。Chromeは一度許可したアクセス権を保持しますが、それ以降のリクエストにも、毎回個別に**Approve once**が必要です。
4. **バックグラウンドのタブでページを読み取ります。** 拡張機能は対象ページをバックグラウンドのタブで開き、DevTools Protocol(デスクトップアプリと同じ`Page.captureScreenshot`)を通じてキャプチャし、タブを閉じて、リクエストしたLollyのタブに結果を返します。

::: details SVGキャプチャの仕組み
**SVG**の場合、拡張機能は画面を撮影する代わりにページを走査します。拡張機能に同梱されたスクリプトが、バックグラウンドのタブでページのレイアウトを読み取り、ページを図形とアウトライン化したテキストに変換します。ファイルはどのサイズでもくっきりしたままで、どの部分も編集できます。ページ内の画像は画像のままです。ページがキャンバス、動画、SVGでは表現できないエフェクトで描いているものは、同じ瞬間のスクリーンショットからコピーします。Lollyは、そのスクリーンショットと結果を照合します。両者の違いが大きすぎる場合は、SVGに代わりにスクリーンショットを入れます。

ページ本来の書体でテキストをアウトライン化するため、拡張機能はページが読み込んだフォントファイルをLollyに渡します。Chromeは拡張機能が読み取れる場所にフォントのバイト列を保持しないため、拡張機能はページに各フォントをもう一度要求します。通常、ブラウザはキャッシュから応答し、そのリクエストにもページ自身のセキュリティポリシーが適用されます。
:::

承認は1つのリクエストに適用され、30秒で期限切れになります。待機中または実行中にできるリクエストは一度に1つだけで、承認済みのリクエストは55秒で停止します。Lollyのページが閉じるか切り替わる場合、または対象のページが別のサイトへ移動する場合、リクエストはキャンセルされます。

::: warning キャプチャはお使いのブラウザのセッションを使います
ページはブラウザのセッションで読み込まれるため、サインインしているページでは、結果に非公開の情報が表示される場合があります。
:::

キャプチャは、お使いのネットワーク上のブラウザで実行されるため、`localhost`や内部サイトも使えます。キャプチャはアップロードされません。ネットワーク通信は、ブラウザが要求したページを読み込むときと、SVGの場合にそのページのフォントファイルをもう一度読み込むときだけです。

キャプチャの実行中、一時タブに*「…がこのブラウザのデバッグを開始しました」*というバナーが短時間表示される場合があります。このバナーはDevTools Protocolによるもので、撮影が終わると消えます。

## Lolly Design System Setup用にサイトを読み取る

Lolly Design System Setupの**Website**ソースでは、既存のサイトをもとにデザインシステムを作り始められます。Chromiumブラウザでは、拡張機能がページを読み取ります。デスクトップアプリでは、アプリ自身がページを取得します。拡張機能がないブラウザでは、Websiteタイルは表示されません。

- **1つのアドレス、1つのページ。** 承認すると、拡張機能は同じ種類のバックグラウンドタブでページを開き、レンダリングされたマークアップ、スタイルシートのテキスト、いくつかのアイコンやロゴの画像を読み取り、タブを閉じます。拡張機能はリンクをたどらず、クロールもしません。
- **別の場所にホストされているスタイルシート**(CDNやフォントサービス)も、ページの色や書体が含まれているため取得します。クロスオリジンのリクエストにはCookieを付けません。同一オリジンのリクエストでは、ページと同じようにCookieを使います。
- **すべてに上限があります。** スタイルシートと画像の数、バイト数に制限があるため、悪意のあるページや一部が壊れたページでも、ハングせずに取得できた素材を返します。
- **解析はお使いのデバイス上で行います。** バイト列は、要求したLollyのタブに直接戻り、そのタブで色、書体、ロゴに変換します。

アドレスを貼り付けるだけでは、欄に入力されるだけです。読み取りを開始して**Approve once**を押すまで、何も読み取りません。

## 権限

拡張機能の`manifest.json`は4つの権限を宣言し、それに加えてサイトごとにアクセス権を要求します。`minimum_chrome_version: 111`が設定されており、現在のバージョンは0.5.0です。

| 権限 | 用途 | 付与されるタイミング |
|---|---|---|
| `debugger` | DevTools Protocolを通じてバックグラウンドのタブを操作し、スクリーンショットを撮影します。SVGの場合は、ページの走査も実行します。 | インストール時 |
| `tabs` | 一時的なバックグラウンドのタブを開いて後で閉じ、承認後にLollyのページも対象のページも移動していないことを確認します。 | インストール時 |
| `scripting` | Websiteソース用に、指定したサイト内で単一ページのリーダーを実行します。 | インストール時 |
| `storage` | 開いたタブのIDをセッションストレージだけに記録し、読み取り中にブラウザが拡張機能を停止してもタブを閉じられるようにします。次回の起動時に消去します。ユーザーに関する情報は何も保存しません。 | インストール時 |
| `optional_host_permissions: ["http://*/*", "https://*/*"]` | サイトへのアクセス権で、インストール時には付与されません。**Approve once**を押すと、拡張機能はそのリクエストに含まれる1つのサイトへのアクセスをChromeに要求します。 | そのサイトへのリクエストを初めて承認し、Chromeが確認した後 |

拡張機能が読み取るのは、承認したページだけです。閲覧データを読み取ったり送信したりすることはありません。

## トラブルシューティング

- **「Get the extension」がまだ表示されますか？** Lollyのタブを再読み込みしてください。
- **このサイトで何も起こりませんか？** 拡張機能は`https://lolly.tools`でのみ動作し、開発用パッケージでは`http://localhost:5173`でも動作します。自己ホストしたLollyなど、別のオリジンでは、`manifest.json`と`policy.js`の両方にそのオリジンを記載した独自の拡張機能ビルドが必要です。マニフェストを編集するだけでは動作しません。
- **キャプチャが失敗しますか？** URLにアクセスでき、`http://`または`https://`で始まっていることを確認してください。自動キャプチャをブロックするページもあります。**Cancel**を押した場合、承認ウィンドウを閉じた場合、30秒を超えて待った場合は、キャプチャをやり直してください。
