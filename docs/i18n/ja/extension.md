# ブラウザ拡張機能

Webページは他のウェブサイトのピクセルを読み取れないため、LollyのWebアプリがページのスクリーンショットを撮るには助けが必要です。Chromiumベースのブラウザ(Chrome 111以降のChrome、Edge、Brave、Arc、Opera)では、無料の拡張機能**Lolly URL Screenshot**が、デスクトップアプリが使うのと同じキャプチャでその助けを提供します。インストールすると、次のことができます。

- **[URL Screenshot](/t/url-shot)**は、作成したページをファイルとして保存します。
- 画像スロットに貼り付けたWebアドレスは、**Screenshot this page**で、そのページのスクリーンショットにできます。
- [Design System Setup](/info/brand-studio.html)の**Website**ソースは、1ページを読み取って、デザインシステムを始められます。

すべてのリクエストをお客様が承認し、デスクトップアプリは拡張機能なしで同じ作業を行います。

## インストールする前に

拡張機能がインストールされるまでは、**URL Screenshot**は引き続き開くため、ショットを作成できます。ツールのコントロールの上部にあるメモが、何が足りないかを伝えます。

![capture to file を実行するホストがない場合に表示される URL Screenshot ツールの、拡張機能を案内する注記](/t/url-shot?url=%2F%23%2Ftool%2Furl-shot&width=1440&height=900&dpi=192&waitMs=2400&walker=1&format=svg&cropSelector=%23capture-hint-notice&dark=1&filename=exp-url-shot-notice)

待っている間も、すべてのコントロールが動作します。対象URL、スクロールの深さ、待機の遅延、切り抜きの余白、再着色です。拡張機能が必要なのは、キャプチャそのものだけです。

## インストール

**Chrome Web Storeから:** 近日公開予定です。拡張機能が公開されれば、ワンクリックでインストールできます。

**ご自身で読み込む(開発者向け)。** 拡張機能は、リポジトリの`shells/chrome-extension/`にあります。そのフォルダは本番ビルドで、`https://lolly.tools`のLollyでのみ動作します。

1. `chrome://extensions`を開きます。
2. **Developer mode**(右上)をオンにします。
3. **Load unpacked**をクリックし、`shells/chrome-extension/`フォルダを選びます。
4. Lollyのタブを再読み込みします。検出はページの読み込み時に行われるため、「Get the extension」のプロンプトは消えます。これで**URL Screenshot**(Utilitiesの下)はキャプチャをファイルに保存でき、Batchモードでも使えるようになります。

ローカルの開発サーバーを使う場合は、`pnpm run pack:chrome-extension:dev` を実行し、代わりに `dist/chrome-extension-dev` を読み込みます。このパッケージは `http://localhost:5173` も受け付け、名前に **Development** が付きます。

## Lollyが依頼したときに起こること

![Lollyのタブが1つのページを求め、拡張機能の承認ウィンドウでApprove onceを押す。バックグラウンドタブが開き、ページを読み取って閉じる。その後Lollyのタブが結果を受け取る。](/info/diagrams/concepts/extension-request.svg)

1. **Lollyが依頼する。** 小さなスクリプトが、拡張機能があることをLollyに伝えるため、キャプチャやページの読み取りを、それ以上の設定なしで開始できます。
2. **お客様が承認する。** 拡張機能が専用の**Approve page request**ウィンドウを開きます。リクエスト元のサイト、スクリーンショットとページ内容のどちらが目的か、ページのアドレスが表示されます。**Approve once**を押すまでは、何も読み取られません。**Cancel**かウィンドウを閉じると、リクエストが終了します。
3. **Chromeはサイトごとに一度だけ尋ねる。** サイトのリクエストを初めて承認するとき、Chromeは拡張機能がそのサイトにアクセスしてよいかも尋ねます。許可すればChromeはそのアクセスを保持しますが、以降のリクエストにもそれぞれ**Approve once**が必要です。
4. **ページはバックグラウンドタブで読み取られる。** 拡張機能は対象ページをバックグラウンドタブで開き、DevTools Protocol(デスクトップアプリが使うのと同じ`Page.captureScreenshot`)でキャプチャし、タブを閉じて、結果を依頼したLollyのタブに返します。

承認は1つのリクエストに対するもので、30秒で期限が切れます。待機または実行できるリクエストは同時に1つだけで、承認済みのリクエストは55秒後に停止します。Lollyのページが閉じられたり変わったり、対象のページが別のサイトに移動したりすると、リクエストはキャンセルされます。

キャプチャはお使いのブラウザ上で、お使いのネットワークで実行されるため、`localhost`や社内サイトも動作します。ページはお使いのブラウザのセッションで読み込まれるため、サインイン済みのページが結果に非公開の情報を含めることがあります。キャプチャはアップロードされません。ネットワーク上の通信は、依頼したページをお使いのブラウザが読み込む通信だけです。

キャプチャの実行中、一時的なタブに*「…started debugging this browser」*というバナーが短く表示されることがあります。これはDevTools Protocolが動作している印で、ショットが終わるとバナーは消えます。

## Design System Setup向けにサイトを読み取る

Design System Setupの**Website**ソースは、すでにお持ちのサイトからデザインシステムを始めます。Chromiumブラウザでは拡張機能がページを読み取ります。デスクトップアプリでは、アプリ自身がページを取得します。拡張機能のないブラウザでは、Websiteタイルは表示されません。

- **1つのアドレスで1つのページ。** 承認すると、拡張機能は同じ種類のバックグラウンドタブでページを開き、レンダリングされたマークアップ、スタイルシートのテキスト、いくつかのアイコンとロゴの画像を読み取って、タブを閉じます。リンクをたどることも、クロールすることもありません。
- **他の場所でホストされるスタイルシート**(CDNやフォントサービス)も、ページの色と書体がそこにあるため、取得されます。クロスオリジンのリクエストはCookieなしで送られ、同一オリジンのリクエストは、ページ自身と同じようにCookieを使います。
- **すべてに上限があり、** スタイルシートと画像の数、およびバイト数が制限されているため、悪意のある、または半壊したページでも、フリーズせずに部分的な素材が返ります。
- **解析はお使いのデバイス上で行われます。** バイト列は、依頼したLollyのタブにそのまま返され、Lollyがそれを色、書体、ロゴに変換します。

アドレスを貼り付けても、入力欄が埋まるだけです。読み取りを開始して**Approve once**を押すまで、何も読み取られません。

## 権限

拡張機能の`manifest.json`は、4つの権限と、サイトごとに求めるサイトアクセスを宣言しています。`minimum_chrome_version: 111`を設定しており、現在のバージョンは0.4.0です。

| 権限 | 用途 | 付与されるタイミング |
|---|---|---|
| `debugger` | DevTools Protocolを通じてバックグラウンドタブを操作し、スクリーンショットを撮る。 | インストール時 |
| `tabs` | 一時的なバックグラウンドタブを開き、その後閉じ、承認してからLollyのページも対象のページも移動していないことを確認する。 | インストール時 |
| `scripting` | Websiteソース向けに、指定したサイトの中で1ページのリーダーを実行する。 | インストール時 |
| `storage` | 開いたタブのIDを、セッションストレージにのみ記録し、読み取りの途中でブラウザが拡張機能を停止してもタブが閉じるようにする。次回の起動時に消去され、お客様に関することは何も保存されない。 | インストール時 |
| `optional_host_permissions: ["http://*/*", "https://*/*"]` | サイトアクセス。インストール時には付与されない。**Approve once**を押すと、拡張機能はそのリクエストの1つのサイトへのアクセスをChromeに求める。 | そのサイトのリクエストを初めて承認するとき、Chromeがお客様に尋ねた後 |

拡張機能が読み取るのは、承認した1つのページだけです。閲覧データを読み取ることも送信することもなく、何もアップロードされません。

## トラブルシューティング

- **まだ「Get the extension」と表示される?** Lollyのタブを再読み込みしてください。
- **このサイトで何も起こらない?** 拡張機能は`https://lolly.tools`と、開発用パッケージの`http://localhost:5173`でのみ動作します。Lollyのセルフホスト版など別のオリジンには、そのオリジンを`manifest.json`と`policy.js`の両方に記載した、専用の拡張機能ビルドが必要です。マニフェストだけを編集しても動作しません。
- **キャプチャが失敗する?** URLに到達でき、`http://`か`https://`で始まっていることを確認してください。自動キャプチャをブロックするページもあります。**Cancel**を押した、承認ウィンドウを閉じた、30秒以上待った場合は、もう一度キャプチャを開始してください。
