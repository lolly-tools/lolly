# Lolly と Canva

_最終確認日: 2026年9月28日。_

チームが現在、Canvaでソーシャル投稿、スライド、チラシを作っている場合、このページは、Lollyが同じ作業をする場面と、Canvaのほうが適している場面を示します。

## Canvaがより優れている点

Canvaは、大規模なテンプレートとストックのライブラリ、アプリ、ホスト型のチームワークフローを、1つのマネージドサービスにまとめています。そうしてすぐに使えるコンテンツと体験は、今日すぐに出発点が必要なときに役立ちます。[Canvaのテンプレート](https://www.canva.com/templates/)と[アプリマーケットプレイス](https://www.canva.com/apps/)をご覧ください。そのライブ編集にも、Lollyのワークコラボがまだ到達していない規模での長い運用実績があります。

## 重なる部分

どちらも、テンプレートから始めて、デザイナーでなくても完成したグラフィックを作れます。どちらもチームでの作業とブランド管理に対応しています。[Canvaはこれらをビジネスプランにまとめており](https://www.canva.com/canva-business/)、Lollyはクリエイティブアプリと組織向けサーバーを分けて提供します。

## 重なる作業をLollyがどう行うか

Lollyのツールは、人が行ってよい変更を符号化し、同じツールがブラウザ、デスクトップアプリ、CLIで動作します。Designキャンバスで作ったレイアウトは[ルール付きのツール](/info/create-a-tool.html)にでき、1つのツールが、値の表から多くのファイルを作れます。

![Designの自由なキャンバス: 提供される色、書体、アセットは、デザインシステム自身のもの](/t/url-shot?url=%2F%23%2Ftool%2Fdesign%3Ftemplate%3D__blank__&width=1440&height=900&dpi=192&waitMs=2400&walker=1&format=svg&dark=1&filename=aud-open-canvas)

単独のLollyは、作成と書き出しをアカウントなしでデバイス上に保ち、アセットを保存すればオフラインでも動作します。2人が[プライベートコラボ](/info/collaborate.html)で、デバイス間でライブ編集できます。Content Credentialsは対応する書き出しで既定でオンですが、オフにもできます。

## 組織で使う場合

組織自身のサーバーで運用されるLolly Workは、サインイン、共有プロジェクト、ライブのワークコラボ、承認済みアセット、ポリシーを加えます。この2つの部分の対比と、すべての比較に共通する制限は、[どこで何が動くか](/info/compare.html#what-runs-where)にあります。

Canvaは、その所有者の商標です。このページは2つの製品が重なる部分を説明するもので、Canvaとは提携していません。
