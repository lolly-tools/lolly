# Lolly と Canva

_最終確認日: 2026年9月28日。_

Lolly は、ブランドに沿ったグラフィック、ソーシャル投稿、プレゼンテーション、レイアウトをブラウザで作成します。[lolly.work](https://lolly.work) と併せて、共有プロジェクト、リアルタイムの work コラボレーション、承認済みアセット、組織のポリシーにも対応します。

## 重なる部分

どちらも、テンプレートから始めて、デザイナーでなくても完成したグラフィックを作れます。どちらもチームのワークフローとブランド管理に対応しています。[Canva はこれらをビジネスプランにまとめています](https://www.canva.com/canva-business/)が、Lolly はクリエイティブアプリと組織向けサービスを分けています。

Lolly は、アカウントなしでお使いのデバイス上で単体動作します。組織が必要とするときに、lolly.work が SSO、SCIM プロビジョニング、ロール、共有カタログ、承認、利用状況レポートを追加します。これは Lolly プロジェクトの一部であり、別個にデプロイされ、Lolly 自体と同様に MPL-2.0 でオープンソース化されています。

## テンプレートとチームワーク

Canva は、大規模なテンプレートとストックのライブラリ、アプリ、ホスト型のチームワークフローを1つのサービスにまとめています。そのような既成のコンテンツとマネージドな体験は、出発点を選ぶ際に役立つ場合があります。[Canva のテンプレート](https://www.canva.com/templates/)と[アプリマーケットプレイス](https://www.canva.com/apps/)を参照してください。

Lolly のツールは許可された変更内容を組み込んでおり、ブラウザ、デスクトップアプリ、CLI で再利用できます。デザインを[ルール付きのツール](/info/create-a-tool.html)にでき、同じツールで値の表から多数の出力を生成できます。lolly.work は、それらのツールに関するアクセス、共有された作業、ポリシーを管理します。

リアルタイム編集は、2台のデバイスを直接接続する[プライベート collab](/info/collaborate.html)と、組織の lolly.work インスタンスを介した work collab の両方で利用できます。work collab には、共有編集、カーソル、保存されたチームセッションが含まれます。現在のサーバーデプロイは単一のコラボレーションノードを使用しており、そのスケールと運用実績は Canva の確立されたサービスとは異なります。

## 作業の置き場所

単体の Lolly は、制作と書き出しをデバイス上に保ち、アセットが揃えばオフラインでも動作します。work コラボレーション、チームストレージ、サーバーレンダリングは、組織が設定したサービスを使用します。このデプロイの選択が相違点です。組織は Lolly の両方の部分を自ら運用でき、ユーザー数あたりのソフトウェアライセンス料はかかりませんが、自らのホスティングと管理の費用は負担します。

Content Credentials は、対応する書き出しでは任意です。lolly.work は、設定済みの組織 ID でサーバー出力に署名できます。検証者は、署名者を信頼済みとして表示する前に、その ID を信頼している必要があります。[Content Credentials の ID](/info/content-credentials-identity.html)と[統合ソリューションの概要](/info/compare.html)を参照してください。

Canva はその所有者の商標です。このページは2つのソリューションが重なる部分を説明するものであり、Canva とは提携していません。
