# LollyとCanva

_最終確認日: 2026年9月28日。_

チームがCanvaでSNSの投稿、スライド、チラシを作っている場合、このページでは、Lollyで同じ作業ができる範囲と、Canvaのほうが適している範囲を説明します。

<!--i:eti-award-->
## Canvaが優れている点

Canvaは、豊富なテンプレートとストック素材のライブラリ、アプリ、ホスティング型のチームワークフローを、1つのマネージドサービスにまとめています。今すぐ出発点が必要なとき、用意されたコンテンツが役立ちます。[Canvaのテンプレート](https://www.canva.com/templates/)と[アプリのマーケットプレイス](https://www.canva.com/apps/)をご覧ください。Canvaのライブ編集には、Lolly Workのコラボが達していない規模での長い運用実績があります。

<!--i:eti-blend-->
## 共通する範囲

どちらも、デザイナーでない人がテンプレートから始めて、完成したグラフィックを作れます。どちらもチームでの作業とブランド管理に対応しています。[Canvaはこれらをビジネスプランで提供しています](https://www.canva.com/canva-business/)。Lollyは、制作アプリと組織向けサーバーを分けています。

<!--i:eti-lolly-->
## 共通する作業をLollyで行う方法

Lollyのツールは、利用者が変更できる範囲を定めます。同じツールがブラウザ、デスクトップアプリ、CLIで動作します。Lolly Designのキャンバスで作ったレイアウトは、[ルール付きのツール](/info/create-a-tool.html)にできます。1つのツールが、値の表から多数のファイルを作れます。

![Lolly Designの自由なキャンバス。選べる色、書体、アセットは、デザインシステム自体のものです](/t/url-shot?url=%2F%23%2Ftool%2Fdesign%3Ftemplate%3D__blank__&width=1440&height=900&dpi=192&waitMs=2400&walker=1&format=svg&dark=1&filename=aud-open-canvas)

単独で使うLollyは、アカウントなしで、デバイス上で作成と書き出しを行います。アセットを保存すれば、オフラインでも動作します。[プライベートコラボ](/info/collaborate.html)では、2人がデバイス同士をつないでライブ編集できます。対応する書き出しではContent Credentialsが既定でオンになっており、オフにできます。

<!--i:eti-building-->
## 組織で使う場合

組織自身のサーバーで動作するLolly Workは、サインイン、共有プロジェクト、ライブコラボ、承認済みアセット、ポリシーを追加します。[何がどこで動くか](/info/compare.html#what-runs-where)では、すべての比較に共通する制限とともに、この2つの部分を並べて示しています。

Canvaはその所有者の商標です。このページは両製品で共通する範囲を説明するものであり、Canvaとは提携していません。
