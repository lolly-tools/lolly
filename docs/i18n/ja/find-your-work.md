# 作業を見つけて復元する

Lollyで作ったものはすべて、[同期](/info/sync.html)をオンにしない限り、それを作ったブラウザやアプリの中に、そのデバイス上だけに残ります。保存した作業は**プロジェクト**にあります。ダウンロードしたファイルは、ブラウザやシステムがそれを置いた場所にあり、通常は**アセット**にもコピーが用意されます。9つのツールでは、一度も保存していない作業も保持されます。このページでは、それぞれについて、さらにタブを閉じた場合、ブラウザのデータを消去した場合、以前のバージョン、削除した項目、別のデバイスへの移動についても扱います。

| どうしたか | どこを見るか |
|---|---|
| **名前を付けて保存**または**保存**を押した | **プロジェクト** |
| **ダウンロード**を押した | ブラウザのダウンロード先、そして**アセット**にもコピー |
| どちらも押していない、[作業しながら保存する9つのツール](#the-nine-tools-that-save-as-you-work)の場合 | **プロジェクト**と**History** |
| どちらも押していない、それ以外のツールの場合 | タブを閉じるまで、作業していたタブのみ |
| ゴミ箱に移動した | **プロジェクト**内の**ゴミ箱**タイルに30日間 |

## 保存したものを見つける

1. ツールの左上にある**ホーム**を押します。
2. ホーム画面の上部にある**プロジェクト**タブを開きます(スマートフォンではフォルダーのアイコン)。
3. 最初の画面を見てください。**マイライブラリ**に保存した作業はそこにあり、各プロジェクトはフォルダーです。すべてのフォルダーを一度に検索するには、画面下部の**すべてのプロジェクトを検索…**に入力します。

項目は、書き出しパネルで入力したファイル名で呼ばれます。何も入力していなければ、**QRコード**のようにツールの名前になります。項目を開けばすべての設定が復元され、変更してもう一度書き出す準備ができています。新しい作業をこの方法で残すには、[保存と再開](/info/using.html#saving-continuing)をご覧ください。

::: note プロジェクトに見当たりませんか？
- **ゴミ箱**に入っているかもしれません: [削除したものを取り戻す](#get-back-something-you-deleted)をご覧ください。
- 別のブラウザ、プライベートウィンドウ、別のデバイスは、[同期](/info/sync.html)を使うか[作業を移動](#move-your-work-to-another-device)しない限り、空の状態から始まります。
- **ダウンロード**しか押していない場合は、[ダウンロードしたファイルを見つける](#find-a-file-you-downloaded)をご覧ください。
:::

- <!--i:document--> **新しい作業をそのまま取り込む。** **新しいアセット**を押すと共有ピッカーが開きます。**テンプレート**を選べば保存済みのテンプレートから始められます: 開いて編集するか、**+ 追加**で新しい作品をすぐに保存できます。
- <!--i:checklist--> **複数選択(デスクトップ)。** タイルのチェックボックスをオンにする、空白部分をドラッグして選択ボックスを描く、**Shift/Cmd-click**する、のいずれかで選べます。タイルを**右クリック**するとコンテキストメニューが開きます。選択バーには**選択範囲をレンダリング**、**移動…**、**新しいフォルダ**、**削除**(ゴミ箱に移動します)、同一ツールのセッション2〜8件を1つのサイドバーの下に横並びで開く**まとめて編集**、そして選択したものをサイズや種類を問わずバッチグリッドの行として開く**シートとして編集**が並びます。
- <!--i:download--> **フォルダーや選択範囲をまとめてレンダリング。** **フォルダをレンダリング**は、サブフォルダーも含めてフォルダー内の保存済みセッションをすべて、入れ子構造の1つの`.zip`として書き出します。**選択範囲をレンダリング**は任意の複数選択に対して同じことを行い、セッションが1つならそのまま自分のファイルとしてレンダリングされます。Batch/Proは不要です。

- <!--i:link--> **保存したセッションを共有する。** セッションを右クリック(スマートフォンではタイルの**•••**を押す) → **共有リンク**で、まったく同じ設定で開き直せるリンクをコピーします。デバイスからの画像はリンクと一緒には運ばれません(共有ダイアログの全体については[作業を共有する](/info/using.html#sharing-your-work)を参照)。
- <!--i:pentool--> **名前を変更するか複製する。** セッションを右クリックすると(スマートフォンではタイルの**•••**を押すと)、**名前を変更**、**重複**(同じフォルダー内にコピーを作成)、**移動…**が表示されます。

## タブを閉じた場合やツールを離れた場合

何が戻ってくるかは、どのように離れたか、どのツールを使っていたかによって決まります:

- **タブを閉じた場合、または別の機会に戻ってきた場合。** 保存していない作業は失われますが、[9つのツール](#the-nine-tools-that-save-as-you-work)は例外で、作業しながら編集内容を保存します: **プロジェクト**から開いてください。
- **同じタブでページをリロードした場合。** 設定はページのアドレスから復元されます。9つのツール以外では、デバイスから追加した画像やファイル、150文字を超える1行のテキストは、アドレスに保持されていないため復元されません。
- **ホームを押した場合、または左上の戻るボタンを押した場合。** 前回の保存・ダウンロード・コピー以降に何かを変更していた場合、**未保存の変更**ダイアログが先に保存するかどうかを尋ねます。**Save & leave**は作業を保存し、**プロジェクト**、または作業を開いた元のプロジェクトフォルダーへ移動します。**保存せずに離れる**はそのまま離れます。9つのツールでは編集内容はすでに保存済みで、プロジェクトに残ります。**キャンセル**はツールにとどまります。

Lollyが尋ねるのは、ツール内で**ホーム**または戻るボタンを押したときだけです。タブを閉じる、リロードする、ブラウザ自体の戻るボタンを使う場合は、決して尋ねません。確実にするには、ツールを離れる前に**名前を付けて保存**を押すか、書き出しパネルで**保存**を押してください。

::: note 保存せずに誤って離れてしまいましたか？
9つのツール以外では、すぐにブラウザの戻るボタンを押してください。ページのアドレスからの設定は復元されますが、デバイスから追加した画像は復元されません。次に、他の何かをする前に**名前を付けて保存**と**保存**を押してください: 今度はLollyは離れる前に尋ねません。
:::

::: details 作業しながら保存する9つのツール
[Design](/#/tool/design)、[チャート](/#/tool/chart)、[QRコード](/#/tool/qr-code)、[グラデーション](/#/tool/gradient)、[スニペット](/#/tool/snippet)、[フローチャート](/#/tool/org-chart)、[料金表](/#/tool/pricing-table)、[ワードマーク](/#/tool/wordmark)、[テキスト](/#/tool/text-helper)。対応するツールは今後も増えていきます。

これらのツールでは、最初の変更を加えた時点で、保存したのと同じように作業が**プロジェクト**に記録され、それ以降の変更も数秒以内に保持されます。そのため、保存していない作品もタブを閉じた後にプロジェクトに残り、**保存せずに離れる**を選んでも編集内容が失われることはありません。ホーム画面からもう一度そのツールを開くと新しい作品が始まります。以前のものはプロジェクトから開いてください。

これはWebアプリでのみ機能し、デスクトップアプリやモバイルアプリでは動作しません。また、誰かとライブで共同作業している間も機能しません。
:::

## ダウンロードしたファイルを見つける

ブラウザでは、**ダウンロード**を押すとファイルがブラウザに渡され、ブラウザがそのダウンロードフォルダー(通常は**ダウンロード**)に保存するか、保存先を尋ねます。Lollyにはファイルがどこへ行ったかは伝わらないため、ブラウザのダウンロード一覧を確認してください。

ファイルが現れなかった場合は、まだツールの中にいる間に書き出しパネルを確認してください。**ダウンロード**の下に、ファイル名と時刻を示す行があり、**Retry download**、そしてChrome、Edgeなど他のChromium系ブラウザでは自分でフォルダーを選べる**Save file…**が表示されます。この行とそのファイルは、ツールを離れる、リロードする、もう一度書き出すまで残ります。

Lollyはダウンロードのたびに、さらに2つのものを保持します:

- **ファイルのコピー**が、**設定 → あなたのレンダリング**の下で**レンダリングをライブラリに保存する**がオンになっている間、**アセット**の**アップロードしたファイル**に保存されます(**設定**はホーム画面の下部にあります)。この設定は既定でオンです。動画や50MBを超えるファイルは事前に確認され、zipはコピーされません。
- **使用した設定**が、直近24回分のダウンロードについて保存されます。**プロジェクト**の保存済み作業の下にある**最近のエクスポート**は、その設定でツールを開き直し、もう一度ファイルを作れるようにしますが、デバイスから追加した画像やファイルは含まれません。同じ一覧は**設定 → アクティビティと統計 → 最新のエクスポート**と、**History**の**Changes**タブにもあります。この一覧が保持するのは設定であり、ファイルそのものではありません。

::: details デスクトップアプリとモバイルアプリでは
- **デスクトップアプリ:** **ダウンロード**はダイアログなしで、**Downloads**フォルダーの中の**Lolly**フォルダーへ直接保存されます。メッセージが保存を知らせ、ファイルを表示する**表示**を提供します。**Window**または**Exports**メニューにある**Open Exports Folder**で、いつでもそのフォルダーを開けます。以前と同じ名前のファイルは「name (1)」として保存されます。
- **iPhoneとiPad:** ファイルは**Lolly**の下にある**ファイル**アプリに保存され、共有シートが開くのでそのまま送信できます。
- **Android:** 共有メニューが開き、ファイルの送り先を選べます。

iPhone、iPad、Androidでは、新しいファイルが同じ名前の以前のファイルを置き換えます。
:::

## 以前のバージョンに戻る

- **この訪問中は:** **元に戻す**は直近100件の変更を、ツールを離れるかリロードするまで遡れます。[元に戻す／やり直す](/info/using.html#undo-and-redo)を参照してください。
- **作業しながら保存する9つのツールでは:** それぞれの作品の以前のバージョンが保持されます。以下の手順に従ってください。
- **デバイス上のすべては:** [同期](/info/sync.html)がオンの場合、**設定 → 接続済みサービス**の下にある**Restore an earlier copy**で、直近7日分の日次コピーのいずれか、または前回の適用より前のコピーを復元できます。この場合、1つのデザインだけでなく、このデバイス上のすべてがそのコピーと一致するようになります。

9つのツールのいずれかで以前のバージョンを開くには:

1. **元に戻す**と**やり直し**の隣にある時計ボタン、**History**を押します。Designでは**History**は上部のバーにあります。スマートフォンでは**•••**を押してから**History**を押します。
2. 日付と時刻でバージョンを見つけます。**Automatic checkpoint**の行は作業中に自動で取られたもので、**Saved version**の行は保存した時刻です。
3. **Open as a copy**を押します。そのバージョンが新しい作品として開き、開いていた元の作品はそのまま残ります。コピーは**プロジェクト**にあり、名前の後ろに「(copy)」が付きます。

名前を付けてバージョンを残すには、**Name version**を押して名前を入力し、**Keep milestone**を押します。名前を付けたバージョンは、**History**ページの**Milestones**の下に一覧表示されます。

::: details Historyパネルとhistoryページ
**History**パネルには**Recovered work**の行も表示され、**Protected drafts**はチェックポイントの間の最新の編集内容を保持し、**Open draft as a copy**があります。**Compare**と**Check assets**は、コピーを開く前に選ぶ助けになります。**This creation**を**All history on this device**に切り替えると、すべての作品を確認できます。

自動チェックポイントは古くなるにつれて間引かれます: 直近1時間は1分ごと、直近1日は1時間ごと、直近30日は1日ごと、それ以降は1週間ごとになります。保存済みバージョンはすべて保持されます。**設定 → ストレージ**から作品を削除すると、そのバージョンも削除されます。

**History**ページ(`#/history`、またはパネルの**Open app history**)は、このブラウザ内のすべての作品を対象とします。パソコンでは、ホーム画面または**プロジェクト**の右上にある時計ボタンからこのページを開きます。スマートフォンでは、ホーム画面のツールギャラリーに移動し、右上の丸いロゴボタンを押して**Saved sessions**を選ぶとHistoryが開きます。**プロジェクト**からのその項目は、まだ何も行いません。

- **Recent**は、あなたの作品を新しい順に、**Resume**とともに一覧表示します。
- **Changes**は、チェックポイント、ダウンロード、Convertの結果を1つのタイムラインにまとめます。ダウンロードには**Reopen settings**があります。
- **Milestones**は、名前を付けたバージョンを一覧表示します。

プロジェクト、ツール、日付で絞り込めます(スマートフォンでは**Filters**の中)。Historyページには削除ボタンがありません。項目を削除するにはプロジェクトを使ってください。
:::

## 作業を別のデバイスに移す

| 目的 | 使う機能 |
|---|---|
| デバイス同士をそろえておく | **設定 → 接続済みサービス**の下にある**デバイス間で同期**: [デバイスを同期する](/info/sync.html)を参照 |
| 一度にすべてを移動する | 下記の**自分のデータをエクスポート**と**データをインポート…** |
| 1つのデザインや1つのプロジェクトを渡す | `.lolly`ファイル: **エクスポート**、続けて**共有**、続けて**Download .lolly**。プロジェクト全体の場合は、フォルダーのメニューにある**Download project (.lolly)**。もう一方のデバイスで**開く**を押してください。[.lollyファイル](/info/using.html#the-lolly-file)を参照 |

共有リンクには設定が含まれますが、デバイスから追加した画像やファイルは含まれません。

::: warning インポートはフォルダーを置き換えます
もう一方のデバイスにすでに作業がある場合は、まずこれを読んでください。インポートはファイルが持つ内容を追加し、一致する項目を更新し、保存済みの項目を削除することはありません。ただしプロフィールは1つのレコードであるため、そのデバイス上のフォルダー、お気に入り、テンプレート、詳細情報はファイル内のものに置き換えられます。そのデバイスにしかなかった保存済みの項目は、**プロジェクト**の最上位に残ります。同期の**Bring it to this device**も同じことを行います。
:::

一度にすべてを移動するには:

1. 古いデバイスで**設定 → ストレージ**を開き、**別の端末へ移動**の下にある**自分のデータをエクスポート**を押します。Lollyが、名前が`LollyTools-`で始まる1つの`.zip`ファイルをダウンロードします。
2. USB、自分宛のメール、AirDrop、または共有フォルダーでファイルを移します。
3. 新しいデバイスで**設定 → ストレージ**を開き、**データをインポート…**を押してファイルを選び、**インポート**を押します。

::: note 残されるもの
サインイン情報、鍵、同期用パスフレーズは各デバイスにとどまります。最近のダウンロード一覧、オフラインダウンロード、AIモデルは、どの方法でも移動しません。バージョン履歴は、同期や`.lolly`ではなく、**自分のデータをエクスポート**のファイルの中でのみ移動します。同期がストレージに保持するコピーは、**データをインポート…**や**開く**ではなく、同期を通じてのみ開けます。
:::

::: details バックアップファイルが保持する内容
ファイルは`LollyTools-<First>-<Last>-<YYYY-MM-DD>-<n>.zip`という名前になります(名前の各部分はプロフィールから取られ、未設定の場合は省かれます。`<n>`は日単位のカウンターで、同じ日のエクスポート同士が衝突しないようにします)。含まれるのは、フォルダー、ゴミ箱、テンプレート、お気に入りを含むプロフィール、サムネイル付きの保存済みセッションすべて、アップロードした画像・フォント・ロゴとダウンロードのコピー、デザインシステム、環境設定(テーマ、サイドバー幅、ローカルのアクティビティ統計)、保存済みバージョンとConvertの結果、そしてWebアプリからは、作品のバージョン履歴です。

カタログキャッシュは含まれません - 新しいデバイスで自動的に再ダウンロードされます。各部分にはチェックサムが付いているため、転送中に壊れたファイルは中途半端に復元されるのではなく、インポート時に検出されます。保存済みセッションは、インポートした画像に自動的に再リンクされます。Web、デスクトップ、モバイルの各アプリは同じファイルを読み取りますが、ターミナルアプリは独自のよりシンプルなバックアップを書き出し、この形式では読み取れません。**📦 Export my data & render everything**は、同じファイルに加えて、保存済みセッションすべてをそれぞれの出力にレンダリングした2つ目のzipも作成します。(完全なフォーマット仕様: [Data Transfer](/info/data-transfer.html)。)
:::

## ブラウザのデータを消去した場合

Webアプリでは、Lollyはこのサイト用のブラウザのストレージにすべてを保持します: 保存した作業、画像、フォント、デザインシステム、バージョン履歴、オフラインダウンロードです。ブラウザでこのサイトのデータを消去すると、それらはすべて削除され、Lollyはどれも取り戻せません。残るのは、すでにブラウザの外に出ていたもの、つまりダウンロードしたファイル、**自分のデータをエクスポート**のファイル、[同期](/info/sync.html)のコピー、そして共有したリンクです。

::: warning ブラウザのデータを消去する前に
**設定 → ストレージ**の下にある**自分のデータをエクスポート**を押し、そのファイルを別の場所に保管してください。
:::

アプリが起動すると、Lollyはデバイスの空き容量が少なくなってもそのストレージを消去しないようブラウザに依頼します。判断するのはブラウザです。**設定 → オフラインで利用可能**の下で、**Protected**から始まる行があればブラウザが同意したことを意味し、「The browser may clear downloads if the device runs low on space」であれば同意していないことを意味し、**ダウンロードを保護**でもう一度依頼できます。ブラウザが同意していない場合、容量が少なくなるとダウンロードだけでなく保存した作業も消去されることがあるため、最近の**自分のデータをエクスポート**ファイルを保管しておいてください。

**設定 → ストレージ**は、各種データがどれだけの容量を使っているかを示します。**キャッシュを消去**は、ダウンロード済みのカタログファイルを破棄します。これらは必要になれば再びダウンロードされます。**すべてのデータを消去**は、ある単語の入力を求めたうえで、プロフィール、保存済みセッション、アップロードした画像、アセットキャッシュを削除します。バージョン履歴、最近のダウンロード一覧、Convertの結果、デザインシステム、ダウンロード済みのAIモデルなど、それ以外のデータは残ります。すべてを削除するには、ブラウザでこのサイトのデータを消去してください。

![スマートフォン幅の画面でのストレージカード。デバイス上のデータの分類がすべて示され、下部に Clear all my data ボタンがある](/t/url-shot?url=%2F%23%2Fprofile%3Ffocus%3Dstorage-section&width=430&height=1600&dpi=192&waitMs=2400&css=.welcome-dialog%2C.personalize-nudge%2C.store-manages%2C.storage-subsection%2C.store-selbar%2C.store-chip-val%2C%23store-hero-num%2C%23store-headroom%2C%23store-quota%2C%23store-reclaim%7Bdisplay%3Anone%7D&format=svg&walker=1&cropSelector=%23storage-section&dark=1&filename=pv-storage-clear)

デスクトップアプリとモバイルアプリでは、保存済みセッションはアプリ自身のデータフォルダー内のファイルであり、それ以外はアプリ自身のストレージにあるため、Webブラウザを消去してもそれらには影響しません。

::: details デスクトップアプリとモバイルアプリが保存済みセッションを保管する場所
保存済みセッション1つにつき1つのファイルが、`saved-state`フォルダーの中にあります:

- macOS: `~/Library/Application Support/tools.lolly.Desktop/saved-state/`
- Windows: `%APPDATA%\tools.lolly.Desktop\saved-state\`
- Linux: `~/.local/share/tools.lolly.Desktop/saved-state/`、または`$XDG_DATA_HOME`の下の同じパス
- iPhone、iPad、Android: アプリ自身のストレージの中にあり、ファイルアプリには表示されません

画像、デザインシステム、最近のダウンロード一覧は、これらのフォルダーではなくアプリの内部ストレージにあります。ターミナルアプリとコマンドラインは同じ`saved-state`フォルダーを読み取ります: [保存済みセッションの保存場所](/info/cli-reference.html#where-saved-sessions-live)を参照してください。
:::

## 削除したものを取り戻す

**プロジェクト**では、**ゴミ箱に移動**すると項目は30日間保持されます。フォルダーは、中身をすべて含んだ1つの項目としてゴミ箱に入ります。直後には、約10秒間**元に戻す**を提供するメッセージが表示されます。それ以降は:

1. **プロジェクト**を開き、**ゴミ箱**タイルを押します。このタイルは、ゴミ箱に何か入っている間だけ表示されます。
2. 項目の隣にある**復元**を押します。

**完全に削除**と**ゴミ箱を空にする**は、確認なしに項目を即座に削除します。30日を過ぎた項目は、次にプロジェクトを開いたときに完全に削除されます。

::: warning その他の削除は取り消せません
**設定 → ストレージ**の下、またはギャラリー内のツールの保存済みセッション一覧(ツールのカードを右クリックして**N件の保存済みセッション**)からセッションを削除すると、そのバージョン履歴とともに完全に削除されます。**自分の画像**から削除した画像は、確認なしに即座に削除されます。
:::

[同期](/info/sync.html)がオンの場合、**Restore an earlier copy**でデバイス全体の以前の日の状態を復元でき、**自分のデータをエクスポート**ファイルはそのファイルが保持する内容を復元します。
