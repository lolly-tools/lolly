# 組織でLollyを使う

あなたの組織は、自分たちのLollyを運用できます。選んだツールとデザインシステムを備えた同じアプリで、サインインが必要になることもあります。このページでは、それにアクセスする方法と、アクセスすると何が変わるかを説明します。

::: note 組織から必要なもの
組織のLollyのWebアドレス、または組織が作成した`.lolly`セットアップファイルです。lolly.tools単体は組織に接続しません。
:::

## ブラウザで

組織から渡されたアドレスを開きます。サインインを求められたら**サインイン**を押し、開いたサインインページの指示に従います。それ以降は、組織のツールとデザインシステムを備えた、普通のLollyと同じように動作します。

ブラウザには別のLollyに切り替える設定がないため、lolly.toolsではなく組織自身のアドレスを開いてください。

## デスクトップ・モバイルアプリで

アプリを初めて起動すると、**Lollyはどこからツールを取得すべきですか?**と尋ねられます。

1. **Lollyインスタンスに接続**を選びます。
2. 組織のWebアドレスを入力し、**確認して接続**を押します。
3. **このインスタンスを使う**を押します。次の画面**データをインポート(任意)**は、Lollyのバックアップから保存済みの作業を持ち込みます。何もなければ**スキップ**を押します。
4. アプリから求められたらサインインします。

接続したインスタンスのツールは、アプリ自身のツールと同じ信頼のもとで実行されるため、信頼できるインスタンスにのみ接続してください。組織によっては、代わりにアプリを接続してくれる`.lolly`セットアップファイルを送ってくる場合もあります。

あとで切り替えるには、**設定**を開きます。**Lollyインスタンス**カードに**変更**と**退出**があります。

## コードでサインインする

このデバイスでのサインインが難しく、組織のLollyがこの方法を提供している場合は、**別のデバイスでコードを使ってサインイン**を押します。Lollyが短いコードとアドレスを表示するので、すでにサインイン済みのスマートフォンやパソコンでそのアドレスを開き、コードを入力してください。コードの有効期限は約10分です。

## そこでの違い

- **一部のコントロールは、あなたの代わりに設定されています。** 組織が管理するコントロールには、組織名を添えて**「~によって管理されています」**と表示されるか、**組織によって管理されています**と表示されます。固定されたコントロールは変更できず、メニューには選択肢の一部しか表示されないことがあり、**「~により設定」**で始まる行が、どのルールが適用され、その理由が何かを伝えることがあります。まったく表示されないコントロールもあります。
- **組織のツールだけが表示されます。** 組織が提供していないツールは、一切表示されません。
- **共有プロジェクト。** 組織があなたとプロジェクトを共有している場合、**プロジェクト**に**チームプロジェクト**タイルが表示されます。
- **一部の書き出しには承認が必要な場合があります。** 組織が承認を求める場面では、**ダウンロード**の代わりに**承認をリクエスト**が表示され、ツールが提供するフォーマットが少なくなることもあります。
- **自分自身の保存内容**は、Lollyのどこでもそうであるように、[同期](/info/sync.html)をオンにしない限りこのデバイスに残ります。

## 退出する

**設定**の**Lollyインスタンス**カードにある**退出**は、組織のデザインシステム、ツール、カタログを取り除きます。あなた自身の作業内容はそのまま残ります。組織のツールで作ったものは、再接続するまで開けなくなり、組織に保存したものは組織のもとに残ります。組織自身のアドレスにいるブラウザでは、退出するものは何もありません。別のアドレスを開いてください。

## 誰に尋ねるか

何が組織のサーバーに届くか、誰が組織の共有プロジェクトを見られるか、どの設定が固定されているかは、組織の判断です。組織のLollyを運用している人に尋ねてください。[プライバシー](/info/privacy.html)には、Lolly自身があなたのデータをどう扱うかが記載されています。
