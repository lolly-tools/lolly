# Lolly と Adobe

_最終確認日: 2026年9月28日。_

Lolly は、画像の編集と変換、レイアウト、繰り返し可能なブランド制作、印刷出力、Content Credentials に対応します。[lolly.work](https://lolly.work) は、そのクリエイティブなワークフローに、組織の ID、共有アセット、承認、自動化されたサーバー制作を加えます。

## 重なる部分

どちらも、画像のリサイズ、レイアウトの構成、プロフェッショナル向けフォーマットでの書き出しといった作業に対応します。Lolly は PDF/X、CMYK、高ビット深度のラスター出力に対応しており、[フォーマットごとの機能](/info/formats.html)があります。デバイス上のユーティリティは、ファイルをアップロードすることなく変換とクリーンアップを行います。

Adobe の専門アプリケーションは、広範なクリエイティブワークフローをカバーします。たとえば [Photoshop](https://www.adobe.com/products/photoshop.html) は、詳細な写真編集、選択、マスキング、合成のツールを提供します。作業に必要な編集操作を Lolly のツールと照らし合わせて比較してください。繰り返し使うブランドアセットと複雑なレタッチでは、要件が異なる場合があります。

## 制作と組織向けサービス

単体の Lolly は、Adobe アカウントも Lolly アカウントも不要で動作し、ブラウザ、デスクトップアプリ、CLI で同じエンジンを使用します。テンプレートとデザイントークンにより出力を繰り返し再現でき、[ルール付きで共有](/info/create-a-tool.html)すると、デザインを他の人が入力できるツールに変えられます。

lolly.work は Lolly プロジェクト内の別個のサービスで、クリエイティブアプリと同様に MPL-2.0 でオープンソース化されています。SSO、SCIM、共有カタログとプロジェクト、承認、アクセスポリシー、監査記録、サーバーレンダリングを提供します。組織は両方の部分を自ら運用し、既存のアセットライブラリを接続できます。ローカルでの制作はデバイス上に留まり、共有された作業とサーバージョブは設定済みのサービスを使用します。

## Content Credentials と ID

Lolly は、ユーザーが Content Credentials を有効にすることで、対応する書き出しにデバイス上で署名できます。デバイスで生成された鍵はファイルの署名の完全性を証明しますが、検証済みの ID を提示するには、検証者が署名者を信頼している必要があります。組織は独自の認証局を使用し、そのルートを検証者に配布できます。lolly.work は、設定済みの組織の証明書と鍵によるサーバー署名にも対応しています。

これにより、Lolly ソリューションの中で個人による署名と組織による署名の両方が利用できます。[Content Credentials の ID](/info/content-credentials-identity.html)、[lolly.work 署名ガイド](https://github.com/lolly-tools/lolly-work/blob/main/docs/c2pa.md)、[統合ソリューションの概要](/info/compare.html)を参照してください。デバイス上の変換ユーティリティは、Lolly の透かしや来歴メタデータを追加しません。

Adobe、Photoshop、Creative Cloud は Adobe の商標です。このページはソリューションが重なる部分を説明するものであり、Adobe とは提携していません。
