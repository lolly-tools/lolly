# Lolly と Adobe

_最終確認日: 2026年9月28日。_

日常的なファイルのためにPhotoshop、Illustrator、InDesignを使っている場合、このページは、それらの作業のうちLollyが引き受けられるものと、Adobeに残るものを示します。

## Adobeがより優れている点

Adobeの専門的なアプリケーションは、奥深い創作作業をカバーします。たとえば[Photoshop](https://www.adobe.com/products/photoshop.html)は、詳細な写真編集、選択、マスク、合成を提供します。複雑なレタッチと繰り返し使うブランドのアセットでは、必要なものが異なります。作業を移す前に、必要な編集操作を比較してください。

## 重なる部分

どちらも、画像のリサイズ、レイアウトの構成、プロ向けの形式での書き出しができます。LollyはPDF/X、CMYK、高ビット深度のラスター出力に対応し([形式ごとの機能](/info/formats.html))、そのデバイス上のユーティリティは、アップロードせずにファイルを変換、クリーンアップします。

## 重なる作業をLollyがどう行うか

単独のLollyは、Adobeのアカウントも、Lollyのアカウントも不要で、ブラウザ、デスクトップアプリ、CLIで同じエンジンを実行します。テンプレートとデザイントークンが各ファイルの一貫性を保ち、[Share with rules](/info/create-a-tool.html)は、デザインを他の人が入力するツールに変えます。

Lollyは、対応する書き出しに、デバイス上でContent Credentialsを署名し、既定でオンですが、オフにもできます。デバイスの鍵は、ファイルが署名されてから変更されていないことを証明します。組織は独自の認証局を使えるため、検証者はその署名者を信頼できます。その違いは[Content Credentialsのアイデンティティ](/info/content-credentials-identity.html)で説明しています。デバイス上の変換ユーティリティは、Lollyの透かしもContent Credentialsも追加しません。

## 組織で使う場合

Lolly Workは、組織のサインイン、共有アセット、承認、サーバーでの制作を加え、組織の証明書による[サーバー署名](/info/work-c2pa.html)を行います。この2つの部分の対比は、[どこで何が動くか](/info/compare.html#what-runs-where)にあります。

Adobe、Photoshop、Creative CloudはAdobeの商標です。このページは製品が重なる部分を説明するもので、Adobeとは提携していません。
