# LollyとAdobe

_最終確認日: 2026年9月28日。_

日常のファイル作成にPhotoshop、Illustrator、InDesignを使っている場合、このページでは、Lollyに任せられる作業と、Adobeで行う作業を説明します。

<!--i:eti-award-->
## Adobeが優れている点

Adobeの専門アプリケーションは、高度な創作作業に対応しています。[Photoshop](https://www.adobe.com/products/photoshop.html)は、細かな写真編集、選択、マスク、合成を提供します。複雑なレタッチと、繰り返し作るブランドアセットでは、必要なものが異なります。作業を移す前に、その作業に必要な編集操作を比較してください。

<!--i:eti-blend-->
## 共通する範囲

どちらも画像をリサイズし、レイアウトを組み、プロ向けの形式で書き出します。LollyはPDF/X、CMYK、高ビット深度のラスター出力に対応し、[形式ごとの機能](/info/formats.html)があります。デバイス上のユーティリティは、ファイルをアップロードせずに変換し、不要なデータを除去します。[デザインのインポート](/info/design-import.html)は、Photoshop、Illustrator、InDesignのファイルを、編集可能なレイアウトとしてデバイス上で開きます。

<!--i:eti-lolly-->
## 共通する作業をLollyで行う方法

単独で使うLollyには、AdobeのアカウントもLollyのアカウントも必要ありません。ブラウザ、デスクトップアプリ、CLIで同じエンジンを実行します。テンプレートとデザイントークンが、各ファイルの一貫性を保ちます。[ルール付きで共有する](/info/create-a-tool.html)は、デザインを、他の人が入力して使えるツールに変えます。

Lollyは、対応する書き出しにデバイス上でContent Credentialsの署名を付けます。署名は既定でオンになっており、オフにできます。デバイスの鍵は、署名後にファイルが変更されていないことを証明します。組織は独自の認証局を使うことで、自組織の検証側が署名者を信頼するようにできます。[Content CredentialsのID](/info/content-credentials-identity.html)で、その違いを説明しています。デバイス上の変換ユーティリティは、Lollyの透かしもContent Credentialsも追加しません。

## 組織で使う場合

Lolly Workは、組織でのサインイン、共有アセット、承認、サーバーでの制作に加えて、組織の証明書による[サーバー署名](/info/work-c2pa.html)を提供します。[何がどこで動くか](/info/compare.html#what-runs-where)では、この2つの部分を並べて示しています。

Adobe、Photoshop、Creative CloudはAdobeの商標です。このページは製品間で共通する範囲を説明するものであり、Adobeとは提携していません。
