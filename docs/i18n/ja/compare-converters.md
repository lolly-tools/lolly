# Lolly とオンラインファイルコンバーター

_最終確認日: 2026年9月28日。_

Lolly は、お使いのデバイス上のブラウザでファイルを変換します。HEIC から JPG、PNG から SVG、PDF から画像など、さまざまな組み合わせに対応します。対応する変換とその制約については、[Lolly が開ける・作れるすべてのフォーマット](/info/formats.html)を参照してください。

## 変換が行われる場所

ブラウザベースのコンバーターは、処理のためにファイルをアップロードする場合もあれば、ローカルで変換する場合もあります。Lolly のデバイス上のユーティリティはファイルをローカルで処理し、アカウント、広告、トラッカーはありません。Lolly の透かしや来歴メタデータは追加されません。必要な変換用アセットが揃えば、オフラインでも動作します。ファイルサイズは、デバイスのメモリと個々のフォーマットリーダーによって制限されます。

コンバーターは、ファイルをどこで処理するかに加えて、必要なフォーマットと忠実度で選んでください。変換によっては編集可能な構造が保持され、結果がフラット化されるものもあります。Lolly のフォーマットページでそれらの違いを説明しています。

## チームがさらに必要とするとき

[lolly.work](https://lolly.work) は、Lolly プロジェクトの別個にデプロイされる組織向けサービスです。対応する制作ワークフロー向けに、SSO、SCIM、共有カタログ、承認、レポート、サーバーレンダリングを追加します。どちらの部分も MPL-2.0 のオープンソースです。組織はこれらを併用でき、メンバーはローカルでの変換にこれまでどおりデバイス上のユーティリティを使い続けられます。

この違いはデータの取り扱いに関わります。ローカルでの変換ではファイルはデバイス上に保たれますが、共有アップロード、サーバーレンダリング、配信を選択すると、該当するデータが設定済みのサービスに送信されます。この分離については、[統合ソリューションの概要](/info/compare.html)で説明しています。
