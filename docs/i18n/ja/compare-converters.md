# Lollyとオンラインのファイル変換サービス

_最終確認日: 2026年9月28日。_

普段「HEICをJPGに変換」や「PDFを圧縮」で検索し、表示されたサイトにファイルをアップロードしているなら、Lollyは同じ変換を、お使いのデバイス上のブラウザ内で行います。

<!--i:eti-award-->
## 変換サイトが優れている点

変換サイトの中には、Lollyが対応しない形式を扱え、セットアップも不要なものがあります。必要な形式と再現性、そしてどこでファイルを処理するかを基準に選んでください。変換によって、編集可能な構造を保つものも、結果を平坦化するものもあります。

<!--i:eti-map-pin-->
## 変換が行われる場所

ブラウザで使う変換サービスには、処理のためにファイルをアップロードするものと、ローカルで変換するものがあります。Lollyの変換ユーティリティは、アカウント、広告、トラッカーなしで、ファイルをローカルで処理します。Lollyの透かしもContent Credentialsも追加しません。変換に必要なアセットを保存すれば、ユーティリティはオフラインでも動作します。扱えるファイルサイズは、デバイスのメモリと形式の読み取り処理によって制限されます。

## チームに追加の機能が必要な場合

Lolly Workを運用する組織のメンバーも、ローカルの変換には、引き続きデバイス上のユーティリティを使います。データが組織のサーバーに送られるのは、共有のためのアップロード、サーバーレンダリング、配信の場合だけです。[何がどこで動くか](/info/compare.html#what-runs-where)で、その分担を説明しています。
