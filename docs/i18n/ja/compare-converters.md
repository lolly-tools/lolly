# Lolly とオンラインファイルコンバーター

_最終確認日: 2026年9月28日。_

いつも「HEIC to JPG」や「compress PDF」と検索して、最初に出てきたサイトにファイルをアップロードしているなら、Lollyは同じ変換を、ご自身のデバイス上のブラウザで行います。

## 変換サイトがより優れている点

Lollyが扱わない形式を扱う変換サイトもあり、事前の設定も不要です。変換サービスは、ファイルをどこで処理するかだけでなく、必要な形式と忠実度で選んでください。編集可能な構造を保つ変換もあれば、結果を平坦化するものもあります。

## 変換が行われる場所

ブラウザベースの変換サービスは、処理のためにファイルをアップロードする場合も、ローカルで変換する場合もあります。Lollyの変換ユーティリティは、アカウント、広告、トラッカーなしでファイルをローカルで処理し、Lollyの透かしもContent Credentialsも追加しません。変換に必要なアセットを保存すれば、オフラインでも動作します。ファイルサイズは、デバイスのメモリと個々の形式のリーダーによって制限されます。

## チームがさらに必要とするとき

組織のメンバーは、組織がLolly Workを運用していても、ローカルでの変換にはデバイス上のユーティリティを使い続けます。共有アップロード、サーバーレンダリング、配信が、データがサーバーに行く時点です。この区別は[どこで何が動くか](/info/compare.html#what-runs-where)で説明しています。
