# Lolly at mga online file converter

_Huling sinuri: 28 Setyembre 2026._

Kino-convert ng Lolly ang mga file sa browser sa sarili mong device: HEIC to JPG, PNG to SVG, PDF to images at marami pang ibang kombinasyon. Tingnan ang [bawat format na kayang buksan at gawin ng Lolly](/info/formats.html) para sa mga sinusuportahang conversion at ang mga limitasyon ng mga ito.

## Kung saan nangyayari ang conversion

Ang browser-based na converter ay maaaring mag-upload ng file para iproseso o mag-convert nang lokal. Lokal na pinoproseso ng mga on-device utility ng Lolly ang file, nang walang account, ad o tracker. Hindi sila nagdaragdag ng Lolly watermark o provenance metadata. Kapag available na ang mga kinakailangang conversion asset, maaari silang gumana offline; nililimitahan ng memory ng device at ng partikular na format reader ang laki ng file.

Pumili ng converter ayon sa mga format at fidelity na kailangan mo, at kung saan pinoproseso ang file. Ang ilang conversion ay nagpapanatili ng nae-edit na istruktura, habang ang iba ay nag-fa-flatten ng resulta; inilalarawan ng mga format page ng Lolly ang mga pagkakaibang iyon.

## Kapag kailangan pa ng team

Ang [lolly.work](https://lolly.work) ang hiwalay na dine-deploy na organisation service ng proyektong Lolly. Nagdaragdag ito ng SSO, SCIM, shared na catalogue, mga approval, reporting at server rendering para sa mga sinusuportahang production workflow. Parehong open source sa ilalim ng MPL-2.0 ang dalawang bahagi. Maaaring gamitin ng organisasyon ang mga ito nang magkasama habang patuloy na ginagamit ng mga miyembro nito ang mga on-device utility para sa mga lokal na conversion.

Mahalaga ang pagkakaiba para sa paghawak ng data: ang lokal na conversion ay nagpapanatili ng file sa device, habang ang pagpili ng shared upload, server render o delivery ay nagpapadala ng kaugnay na data sa mga naka-configure na serbisyo. Ipinapaliwanag ng [pangkalahatang-ideya ng pinagsamang solusyon](/info/compare.html) ang paghihiwalay.
