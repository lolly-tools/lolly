# Gamitin ang Lolly sa iyong organisasyon

Puwedeng patakbuhin ng organisasyon mo ang sarili nitong Lolly: ang parehong app, may mga tool at design system na pinili nito, at kung minsan ay may sign-in. Ipinapakita ng page na ito kung paano ito maaabot at ano ang nagbabago kapag ginawa mo iyon.

::: note Ang kailangan mo mula sa iyong organisasyon
Ang web address ng Lolly nito, o isang `.lolly` na setup file na ginawa ng organisasyon mo. Hindi kumokonekta sa isang organisasyon ang lolly.tools mismo.
:::

## Sa isang browser

Buksan ang address na ibinigay ng organisasyon mo. Kung hihilingin sa iyo ng page na mag-sign in, pindutin ang **Mag-sign in** at sundan ang sign-in page na bubuksan nito. Pagkatapos noon, gagana ito tulad ng kahit anong Lolly, na may mga tool at design system ng organisasyon mo.

Walang setting ang browser para lumipat sa ibang Lolly, kaya buksan ang sarili ng address ng organisasyon mo sa halip na ang lolly.tools.

## Sa desktop o mobile app

Sa unang pagkakataong magsimula ang app, tinatanong nito, **Saan dapat kunin ni Lolly ang mga tool nito?**

1. Piliin ang **Kumonekta sa isang Lolly instance**.
2. Ilagay ang web address ng organisasyon mo at pindutin ang **I-check at kumonekta**.
3. Pindutin ang **Gamitin ang instance na ito**. Ang susunod na screen, **I-import ang data mo (opsyonal)**, ay naghahatid ng naka-save na gawa mula sa isang Lolly backup; pindutin ang **Laktawan** kung wala ka nito.
4. Mag-sign in kung tatanungin ka ng app.

Tumatakbo ang mga tool mula sa isang connected instance nang may parehong tiwala gaya ng sariling app, kaya kumonekta lang sa isang pinagkakatiwalaan mo. Puwede ring magpadala sa iyo ang organisasyon mo ng isang `.lolly` na setup file na kumokonekta sa app para sa iyo.

Para lumipat sa ibang pagkakataon, buksan ang **Mga Setting**: may **Baguhin** at **Umalis** ang **Lolly instance** card.

## Pag-sign in gamit ang code

Kung hirap mag-sign in sa device na ito at inaalok ito ng Lolly ng organisasyon mo, pindutin ang **Mag-sign in gamit ang code sa ibang device**. Magpapakita si Lolly ng maikling code at isang address: buksan ang address sa isang telepono o computer kung saan naka-sign in ka na, at ilagay ang code doon. Tumatagal ang code nang mga sampung minuto.

## Ano ang naiiba doon

- **Naka-set na para sa iyo ang ilang control.** Ang isang control na pinamamahalaan ng organisasyon mo ay nagpapakita ng **Managed by** at ang pangalan ng organisasyon, o **Pinamamahalaan ng iyong organisasyon**. Hindi mababago ang isang naka-fix na control, puwedeng ilan lang sa mga choice nito ang ialok ng isang menu, at maaaring sabihin ng isang linyang nagsisimula sa **Set by** kung aling rule ang naaangkop at bakit. May mga control na hindi ipinapakita nang tuluyan.
- **Ang mga tool lang nito ang nakalista.** Ang isang tool na hindi inaalok ng organisasyon mo ay hindi ipinapakita nang tuluyan.
- **Mga shared project.** Kung ibinabahagi sa iyo ng organisasyon mo ang mga project, nagpapakita ang **Mga Project** ng isang **Mga team project** tile.
- **Ang ilang export ay maaaring mangailangan ng approval.** Kung saan humihiling ng approval ang organisasyon mo, pumapalit ang **Humiling ng approval** sa **I-download**, at maaaring mag-alok ang isang tool ng mas kaunting format.
- **Nananatili ang sarili mong mga save** sa device na ito maliban kung i-on mo ang [Sync](/info/sync.html), gaya ng kahit saan sa Lolly.

## Pag-alis

Aalisin ng **Umalis**, sa **Lolly instance** card sa **Mga Setting**, ang design system, mga tool at catalogue ng organisasyon mo. Nananatili ang sarili mong gawa. Anumang ginawa mo gamit ang mga tool nito ay hindi na muling magbubukas hangga't hindi ka muling kumokonekta, at anumang na-save mo sa organisasyon ay mananatili sa organisasyon. Sa isang browser sa sariling address ng organisasyon mo, walang dapat alisin: magbukas na lang ng ibang address.

## Sino ang tatanungin

Ang naaabot sa server ng organisasyon mo, kung sino ang makakakita ng mga shared project nito at kung aling mga setting ang naka-fix ay mga desisyon ng organisasyon mo. Tanungin ang sinumang nagpapatakbo ng Lolly ng organisasyon mo. Sinasaklaw ng [Privacy](/info/privacy.html) kung ano ang ginagawa ni Lolly mismo sa data mo.
