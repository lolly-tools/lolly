# Lolly at Adobe

_Huling sinuri: 28 Setyembre 2026._

Kung gumagamit ka ng Photoshop, Illustrator o InDesign para sa pang-araw-araw na mga file, sinasabi ng pahinang ito kung aling mga gawain ang kayang akuin ng Lolly at alin ang mananatili sa Adobe.

<!--i:eti-award-->
## Ang mas mahusay na ginagawa ng Adobe

Sinasaklaw ng mga espesyalistang application ng Adobe ang masusing malikhaing gawain. Nagbibigay ang [Photoshop](https://www.adobe.com/products/photoshop.html) ng detalyadong pag-edit ng larawan, pagpili, masking at compositing. Magkaiba ang pangangailangan ng komplikadong retouch at paulit-ulit na brand asset. Bago ka maglipat ng gawain, ihambing ang mga operasyong pang-edit na kailangan ng gawain.

<!--i:eti-blend-->
## Saan sila magkapareho

Parehong nagre-resize ng mga larawan, bumubuo ng mga layout at nag-e-export ng mga propesyonal na format. Sinusuportahan ng Lolly ang PDF/X, CMYK at raster output na may mataas na bit depth, na may [mga kakayahan para sa bawat format](/info/formats.html). Nagko-convert at naglilinis ng mga file ang mga utility nito sa device nang hindi ina-upload ang mga ito. Binubuksan ng [Mag-import ng design](/info/design-import.html) ang mga file ng Photoshop, Illustrator at InDesign sa device bilang mga layout na mae-edit mo.

<!--i:eti-lolly-->
## Paano ginagawa ng Lolly ang kaparehong gawain

Hindi kailangan ng standalone na Lolly ng Adobe account o Lolly account. Pinapatakbo nito ang parehong engine sa browser, desktop app at CLI. Pinananatiling pare-pareho ng mga template at design token ang bawat file. Ginagawang tool na pinupunan ng iba ang isang design sa [Magbahagi na may mga patakaran](/info/create-a-tool.html).

Pinipirmahan ng Lolly ang mga sinusuportahang export gamit ang Content Credentials sa device. Naka-on bilang default ang pagpirma at puwedeng i-off. Pinatutunayan ng device key na hindi nagbago ang file mula nang pirmahan ito. Puwedeng gumamit ang organisasyon ng sarili nitong certificate authority para pagkatiwalaan ng mga verifier nito ang pumirma. Ipinapaliwanag ng [Pagkakakilanlan sa Content Credentials](/info/content-credentials-identity.html) ang pagkakaiba. Walang idinaragdag na Lolly watermark o Content Credentials ang mga transform utility sa device.

## Kasama ang isang organisasyon

Idinaragdag ng Lolly Work ang sign-in ng organisasyon, mga pinagsasaluhang asset, approval at paggawa sa server, na may [pagpirma sa server](/info/work-c2pa.html) sa ilalim ng certificate ng organisasyon. Inilalagay ng [Ano ang tumatakbo saan](/info/compare.html#what-runs-where) ang dalawang bahagi nang magkatabi.

Mga trademark ng Adobe ang Adobe, Photoshop at Creative Cloud. Inilalarawan ng pahinang ito kung saan magkapareho ang mga produkto at hindi ito kaanib ng Adobe.
