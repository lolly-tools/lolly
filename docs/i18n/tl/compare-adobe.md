# Lolly at Adobe

_Huling sinuri: 28 Setyembre 2026._

Kung inaabot mo ang Photoshop, Illustrator o InDesign para sa pang-araw-araw na file, sinasabi ng pahinang ito kung alin sa mga trabahong iyon ang kayang akuin ng Lolly at alin ang nananatili sa Adobe.

## Ang mas mahusay na ginagawa ng Adobe

Sinasaklaw ng mga espesyalistang application ng Adobe ang malalim na creative na gawa. Ang [Photoshop](https://www.adobe.com/products/photoshop.html), halimbawa, ay nagbibigay ng detalyadong photo editing, selection, masking at compositing. Magkaiba ang pangangailangan ng kumplikadong retouch at ng umuulit na brand asset: ihambing ang mga editing operation na kailangan ng gawa mo bago mo ilipat ang gawang iyon.

## Kung saan sila nagtatagpo

Parehong nagre-resize ng larawan, nag-compose ng layout at nag-e-export ng propesyonal na format. Sinusuportahan ng Lolly ang PDF/X, CMYK at high-bit-depth na raster output, na may [mga kakayahang partikular sa format](/info/formats.html), at ang mga on-device utility nito ay nagko-convert at naglilinis ng file nang walang upload.

## Paano ginagawa ng Lolly ang magkapatong na trabaho

Ang standalone na Lolly ay hindi nangangailangan ng Adobe account at Lolly account, at pinapatakbo ang parehong engine sa browser, desktop app at CLI. Pinananatiling pare-pareho ng mga template at design token ang bawat file, at ginagawang tool ng [Share with rules](/info/create-a-tool.html) ang design na pupunan ng ibang tao.

Pinipirmahan ng Lolly ang mga sinusuportahang export gamit ang Content Credentials sa device, naka-on bilang default; puwede mo itong i-off. Pinatutunayan ng device key na hindi nagbago ang file mula nang pirmahan. Ang organisasyon ay maaaring gumamit ng sarili nitong certificate authority, kaya pinagkakatiwalaan ng mga verifier nito ang pumirma; ipinapaliwanag ng [Content Credentials Identity](/info/content-credentials-identity.html) ang pagkakaiba. Ang mga on-device transform utility ay hindi nagdaragdag ng Lolly watermark o Content Credentials.

## Sa isang organisasyon

Nagdaragdag ang Lolly Work ng organisation sign-in, shared asset, approval at server production, na may [server signing](/info/work-c2pa.html) sa ilalim ng organisation certificate. Inilalagay ng [Ano ang tumatakbo saan](/info/compare.html#what-runs-where) ang dalawang bahagi nang magkatabi.
