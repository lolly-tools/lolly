# Gumawa ng iyong unang file

Sa pagtatapos ng page na ito, makakapag-download ka na ng QR code para sa isang web address at makakapag-save ng kopyang puwede mong buksan at baguhin sa ibang pagkakataon. Hindi ka kailangang mag-account at wala kang kailangang i-set up muna.

::: note Bago ka magsimula
Ihanda ang web address na dapat buksan ng code, nagsisimula sa `https://`.
:::

## Gumawa ng code

1. Buksan ang [QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Nasa tabi ng preview ang mga control, o sa itaas nito sa telepono; ang ipinapakita ng preview ang magiging file.
2. Sa **URL**, palitan ang halimbawang address ng sarili mo, nang buo. Nagbabago ang preview habang nagta-type ka.
3. Para itugma ang sarili mong mga kulay, itakda ang **Kulay ng module** at **Background**. Panatilihing malakas ang contrast sa pagitan nila, o mahihirapang basahin ng mga telepono ang code.
4. Nagsisimula sa 4 ang **Tahimik na sona**, sa ilalim ng **Modules**. Panatilihin itong 4 o higit pa: ang plain margin na iyon ang hinahanap ng camera ng telepono.

## I-download ang file

1. Pindutin ang **I-export** sa **I-export | I-save bilang** pill, sa ilalim ng mga control sa computer o lumulutang sa ibaba ng screen sa telepono.
2. Buksan ang format menu sa tabi ng pangalan ng file (nagsisimula ito sa **SVG**) at piliin ang **PNG** para sa screen o mensahe. Para sa print, tingnan ang note sa ibaba.
3. Pindutin ang **I-download**. Napupunta ang file sa mga download ng browser mo; kung wala ito doon, tingnan ang [Hanapin ang file na na-download mo](/info/find-your-work.html#find-a-file-you-downloaded).

::: check I-scan ang code bago ibahagi ang file
Buksan ang na-download na file sa isang screen at i-scan ang code gamit ang camera ng telepono. Kung ginawa mo ito sa telepono mo, i-scan ito mula sa ikalawang telepono o sa screen ng computer. Dapat mag-alok ang telepono ng web address mo.
:::

::: details Kung ipi-print o hahawakan ang code
Piliin ang **SVG** o **PDF** para manatiling matalas ang code sa kahit anong sukat, at subukang mag-print sa sukat na gagamitin dito. Kung baka magaspang o mabasa ng ulan ang code, itakda ang **Pagwawasto ng error**, sa ilalim ng **Modules**, sa **Mataas (30%)**: nababasa pa rin ang isang sirang code.
:::

## Panatilihin ang isang nae-edit na kopya

Tapos na ang file na na-download mo. Para baguhin ang code sa ibang pagkakataon, i-save mo rin ang gawa mo:

1. Pindutin ang **I-save bilang**, tapos **I-save**. Kapag bukas ang Export panel, nasa loob ng panel ang **I-save bilang**; kapag sarado ito, ito ang tick sa tabi ng **I-export**. Napupunta ang code sa **Aking library**, at nag-aalok ang mensaheng **Na-save** ng **Buksan ang Projects**.
2. Sa susunod, pindutin ang **Home** at buksan ang **Mga Project** (ang folder icon sa telepono). Nandoon ang code mo, na pinangalanang **QR Code**. Buksan ito, baguhin ang kahit ano at mag-export ulit.

Nananatili ang naka-save na gawa sa device na ito, sa browser o app na ginamit mo, maliban kung i-on mo ang [Sync](/info/sync.html). Sinasaklaw ng [Hanapin at bawiin ang gawa mo](/info/find-your-work.html) ang mga folder, mas naunang bersyon at paglipat ng gawa mo sa ibang device.

## Iba pang unang project

- Ginagawang video ng [Audiogram](/#/tool/audiogram) ang isang voice note: isang gumagalaw na waveform, ang mga salita mo sa cover, ang mga kulay mo. Ilagay ang recording sa **Audio**, magdagdag ng **Pamagat**, pagkatapos ay mag-export ng **MP4**.
- Ginagawan ng [Filter](/#/tool/filter) ang isang larawan para sa isang poster: naka-print na halftone dots, dalawang flat na kulay o ilang blocks ng tono. Piliin ang larawan sa ilalim ng **Larawan**, pumili ng **Epekto**, pagkatapos ay mag-export ng **PNG**, o **SVG** sa isang effect na may badge na *vector*.

## Susunod

- **Magpadala ng link sa halip na file.** Bawat control na ginalaw mo ay nakasulat sa address ng page, kaya nagbibigay ang **Ibahagi** sa export panel ng link na nagbubukas-muli ng parehong disenyo sa screen ng ibang tao. Hindi kasama sa link ang larawang in-upload mo mula sa sarili mong device. Tingnan ang [Pagbabahagi ng gawa mo](/info/using.html#sharing-your-work).
- **Idagdag ang mga kulay at font mo nang minsan lang**, para magsimula ang bawat tool nang mayroon na ang mga ito: ang [Quickstart](/info/quickstart.html).
- Ang [Paggamit ng Lolly](/info/using.html) ang buong gabay sa app, at ang [Lolly para sa mga Creator](/info/creators.html) ay naglalakbay sa iba pang nagagawa nito.
