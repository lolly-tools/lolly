# Gawin ang una mong file

Mag-download ng QR code para sa isang web address at mag-save ng kopyang puwede mong buksan at baguhin sa ibang pagkakataon. Hindi mo kailangan ng account o anumang paunang setup. Hindi mo kailangan ng account o setup.

::: note Bago ka magsimula
Ihanda ang web address na bubuksan ng code, na nagsisimula sa `https://`.
:::

::: steps
- <!--i:eti-pen--> **[Gawin ang code](#make-the-code)** Ilagay ang address mo sa Lolly QR Code at itakda ang mga kulay nito.
- <!--i:eti-download--> **[I-download ang file](#download-the-file)** Mag-export ng PNG para sa screen, o SVG o PDF para sa print.
- <!--i:eti-folder-plus--> **[Magtabi ng mae-edit na kopya](#keep-an-editable-copy)** I-save ang gawa mo para mabago mo ang code sa ibang pagkakataon.
:::

<!--i:eti-pen-->
## Gawin ang code

1. Buksan ang [Lolly QR Code](/#/tool/qr-code?url=https%3A%2F%2Fexample.com). Nasa tabi ng preview ang mga kontrol, o nasa itaas ng preview kapag sa phone. Ipinapakita ng preview ang magiging file.
2. Sa **URL**, palitan ang buong halimbawang address ng sarili mong address. Nagbabago ang preview habang nagta-type ka.
3. Para tumugma sa sarili mong mga kulay, itakda ang **Module colour** at **Background**. Panatilihing mataas ang contrast ng mga ito, kung hindi ay mahihirapang basahin ng mga phone ang code.
4. Nagsisimula sa 4 ang **Quiet zone**, sa ilalim ng **Modules**. Panatilihin ito sa 4 o higit pa. Hinahanap ng camera ng phone ang blangkong margin na iyon.

<!--i:eti-download-->
## I-download ang file

1. Pindutin ang **Export** sa **Export | Save as** pill, sa ilalim ng mga kontrol sa computer o nakalutang sa ibaba ng screen sa phone.
2. Buksan ang format menu sa tabi ng pangalan ng file (nagsisimula ito sa **SVG**) at piliin ang **PNG** para sa screen o mensahe. Para sa print, tingnan ang tala sa ibaba.
3. Pindutin ang **Download**. Mapupunta ang file sa mga download ng browser mo. Kung wala roon ang file, tingnan ang [Hanapin ang na-download mong file](/info/find-your-work.html#find-a-file-you-downloaded).

::: check I-scan ang code bago mo ibahagi ang file
Buksan ang na-download na file sa screen at i-scan ang code gamit ang camera ng phone. Kung ginawa mo ito sa phone mo, i-scan ito mula sa isa pang phone o screen ng computer. Dapat ialok ng phone ang web address mo.
:::

::: note Kung ipi-print o hahawakan ang code
Piliin ang **SVG** o **PDF** para manatiling matalas ang code sa anumang sukat. Subukan ang print sa sukat na gagamitin dito. Kung posibleng magasgas o mabasa ang code, itakda ang **Error correction**, sa ilalim ng **Modules**, sa **High (30%)** para mabasa pa rin ang code kahit masira ito.
:::

<!--i:eti-folder-plus-->
## Magtabi ng mae-edit na kopya

Para mabago ang code sa ibang pagkakataon, i-save din ang gawa mo:

1. Pindutin ang **Save as**, saka ang **Save**. Kapag bukas ang Export panel, nasa panel ang **Save as**. Kapag sarado ang panel, gamitin ang tsek sa tabi ng **Export**. Mapupunta ang code sa **My library**, at may **Open Projects** sa mensaheng **Saved**.
2. Sa susunod, pindutin ang **Home** at buksan ang **Projects** view (ang folder icon sa phone). Naroon ang code mo, na may pangalang **QR Code**. Buksan ito, baguhin ang anumang gusto mo at mag-export muli.

Nananatili ang na-save na gawa sa device na ito, sa browser o app na ginamit mo, maliban kung i-on mo ang [Sync](/info/sync.html). Sinasaklaw ng [Hanapin at ibalik ang gawa mo](/info/find-your-work.html) ang mga folder, naunang bersyon at paglilipat ng gawa mo sa ibang device.

## Iba pang panimulang proyekto

- Ginagawang video ng [Lolly Audiogram](/#/tool/audiogram) ang isang voice note, na may gumagalaw na waveform, mga salita mo sa cover at mga kulay mo. I-drop ang recording sa **Audio**, magdagdag ng **Title**, saka mag-export ng **MP4**.
- Pinoproseso ng [Lolly Filter](/#/tool/filter) ang litrato para sa poster: mga naka-print na halftone dot, dalawang solidong kulay o ilang bloke ng tono. Piliin ang litrato sa ilalim ng **Image**, pumili ng **Effect**, saka mag-export ng **PNG**, o **SVG** sa epektong may markang *vector*.
- Bumubuo ang [music generator](/#/music) ng track mula sa genre at seed. Pindutin ang bilog na shuffle button hanggang magustuhan mo ang tumutugtog, saka buksan ang **Render** at mag-download ng M4A o WAV file. Libreng gamitin ang musikang ginagawa mo, kahit sa komersyal na gamit, na may credit na **Musikang ginawa gamit ang Lolly (https://lolly.tools), CC BY 4.0**. Ipinapakita ng [gabay sa music generator](/info/music-generator.html) ang bawat kontrol, at may sample ng bawat genre ang [Libreng background music](/info/background-music.html).

## Susunod

- **Magpadala ng link sa halip na file.** Nasa address ng page ang bawat kontrol na binago mo. Nagbibigay ang **Share** sa export panel ng link na muling nagbubukas ng parehong design sa screen ng ibang tao. Hindi kasama sa link ang litratong in-upload mo mula sa sarili mong device. Tingnan ang [Pagbabahagi ng gawa mo](/info/using.html#sharing-your-work).
- **Idagdag nang isang beses ang mga kulay at font mo**, para iyon ang gamitin ng bawat tool sa simula: ang [Mabilis na pagsisimula](/info/quickstart.html).
- Ang [Paggamit ng Lolly](/info/using.html) ang buong gabay sa app. Ipinapakita ng [Lolly para sa mga Creator](/info/creators.html) kung ano pa ang nagagawa ng Lolly.
