# Mamahala

Tumatakbo ang Lolly sa device ng bawat tao. Kapag kailangan ng team ng sign-in, shared project, governed asset, review at server job, nagdaragdag ang organisasyon ng **Lolly Work**, ang open-source na organisation server ng parehong proyekto. Ang mga pahinang ito ay para sa sinumang nagse-setup at nag-aalaga ng server na iyon.

Magsimula sa [Gamitin ang Lolly sa organisasyon mo](/info/organisation.html) para makita kung ano ang nakukuha ng mga miyembro, o sa [Arkitektura ng Lolly Work](/info/work-overview.html) para sa responsibilidad ng server.

## Magtakda ng access at policy

- Sinasaklaw ng [Adoption & Governance](/info/adoption-governance.html) ang rollout at ang papel ng mga brand rule.
- Sinasaklaw ng [Identity at mga session](/info/work-identity.html) ang sign-in at group mapping. Ipinapaliwanag ng [Mga papel at grant](/info/work-permissions.html) ang mga papel, grant at ang owner guard.
- Sinasaklaw ng [Policy at governance](/info/work-governance.html) ang mga tool overlay, naka-lock na input at policy. Sinasaklaw ng [Pamahalaan ang AI policy ng organisasyon](/info/work-ai-policy.html) ang mga approval at limitasyon sa pagpapatupad.
- Sinasaklaw ng [Mga kontrol sa data ng account](/info/work-account-lifecycle.html) at [Work storage at data lifecycle](/info/work-data-lifecycle.html) ang mga export, offboarding, retention at mga limitasyon ng mga ito.
- Sinasaklaw ng [Mga profile, brand at configuration ng tool](/info/configuration.html) kung aling mga tool at design system ang dala ng build ng Lolly.

## Ikonekta ang mga asset at i-review ang gawa

- Sinasaklaw ng [Design-system administration](/info/work-design-system-administration.html) ang source inventory, mga reviewed na pagbabago at rollback.
- Sinasaklaw ng [Catalog at nilalaman](/info/work-catalog.html) ang mga shared asset at exposure rule. Ibinibigay ng [Provider guides](/info/work-provider-guides.html) ang setup at verification requirement ng bawat source platform.
- Sinasaklaw ng [Mga approval](/info/work-approvals.html) ang mga review chain at paghihiwalay ng tungkulin. Sinasaklaw ng [Rendering at pagbabahagi](/info/work-sharing.html) ang mga link at server output.
- Sinasaklaw ng [Mag-imbita ng agent sa dokumento](/info/work-document-agents.html) ang scoped na access sa dokumento, expiry at revocation. Ang imbitasyon ay hindi nagbibigay ng access sa deployment o infrastructure.

## Hanapin ang susunod na gawain

- Ang [Gumawa](/info/creators.html) ay may mga creative na gawain at team playbook.
- Sinasaklaw ng [I-deploy](/info/operate.html) ang pag-install at pagpapanatili ng Lolly at Lolly Work server. Hiwalay ang configuration ng instance sa content profile ng tao.
- Ipinapaliwanag ng [Tiwala](/info/trust.html) ang mga daloy ng data, signature at security boundary.
