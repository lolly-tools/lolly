# Pamahalaan

Tumatakbo ang Lolly sa device ng bawat tao. Para ang mga pahinang ito sa sinumang nagpapatakbo ng **Lolly Work**, ang open-source na server ng proyekto para sa organisasyon, para sa sign-in, mga pinagsasaluhang proyekto, pinamamahalaang asset, review at server job.

Magsimula sa [Gamitin ang Lolly sa organisasyon mo](/info/organisation.html) para makita kung ano ang makukuha ng mga miyembro, o sa [Arkitektura ng Lolly Work](/info/work-overview.html) para malaman kung ano ang ginagawa ng server.

<!--i:eti-lock-->
## Itakda ang access at policy

- Sinasaklaw ng [Pagsisimulang gumamit & Pamamahala](/info/adoption-governance.html) ang rollout at papel ng mga patakaran ng brand.
- Sinasaklaw ng [Pagkakakilanlan at mga session](/info/work-identity.html) ang sign-in at group mapping. Ipinapaliwanag ng [Mga role at pahintulot](/info/work-permissions.html) ang mga role, pahintulot at proteksyon para sa may-ari.
- Sinasaklaw ng [Policy at pamamahala](/info/work-governance.html) ang mga tool overlay, naka-lock na input at policy. Sinasaklaw ng [Pamahalaan ang AI policy ng organisasyon](/info/work-ai-policy.html) ang mga approval at limitasyon sa pagpapatakbo.
- Sinasaklaw ng [Mga kontrol sa data ng account](/info/work-account-lifecycle.html) at [Storage at lifecycle ng data ng Lolly Work](/info/work-data-lifecycle.html) ang mga export, pag-alis ng miyembro, pagpapanatili ng data at mga limitasyon ng mga ito.
- Sinasaklaw ng [Mga profile, brand at configuration ng tool](/info/configuration.html) kung aling mga tool at design system ang kasama sa build ng Lolly.

## Ikonekta ang mga asset at i-review ang gawa

- Ipinapaliwanag ng [Gamitin ang Lolly sa umiiral mong DAM](/info/use-with-dam.html) ang awtoridad ng pinagmulan at konektadong paggawa. Itinatala ng [Salaysay ng SUSE Brandfolder](/info/suse-brandfolder.html) ang isang karanasan sa pagsisimulang gumamit. Sinasaklaw ng [Magplano ng paglipat ng DAM](/info/dam-transition.html) ang opsyonal na paglipat sa hinaharap.

- Sinasaklaw ng [Pangangasiwa ng design system](/info/work-design-system-administration.html) ang imbentaryo ng mga pinagmulan, mga na-review na pagbabago at rollback.
- Sinasaklaw ng [Catalog at nilalaman](/info/work-catalog.html) ang mga pinagsasaluhang asset at mga patakaran sa pagpapakita. Ibinibigay ng [Mga gabay sa provider](/info/work-provider-guides.html) ang mga kinakailangan sa setup at pag-verify ng bawat pinagmulang platform.
- Sinasaklaw ng [Mga approval](/info/work-approvals.html) ang sunod-sunod na review at paghihiwalay ng mga tungkulin. Sinasaklaw ng [Pag-render at pagbabahagi](/info/work-sharing.html) ang mga link at server output.
- Sinasaklaw ng [Mag-imbita ng agent sa dokumento](/info/work-document-agents.html) ang access sa dokumento na limitado ang saklaw, pag-expire at pagbawi. Hindi nagbibigay ng access sa deployment o imprastraktura ang imbitasyon.

## Hanapin ang susunod na gawain

- Nasa [Gumawa](/info/creators.html) ang mga malikhaing gawain at playbook ng team.
- Sinasaklaw ng [Mag-deploy](/info/operate.html) ang pag-install at pagpapanatili ng Lolly at Lolly Work server. Hiwalay ang configuration ng instance sa content profile ng tao.
- Ipinapaliwanag ng [Tiwala](/info/trust.html) ang mga daloy ng data, lagda at hangganan ng seguridad.
