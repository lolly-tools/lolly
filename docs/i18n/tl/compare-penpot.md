# Lolly at Penpot

_Huling sinuri: 28 Setyembre 2026._

Kung nagdidisenyo ang team mo sa Penpot, gumagana ang Lolly kasabay ng Penpot. Parehong open source at bumabasa ng parehong mga design token ang mga ito. Sinasabi ng pahinang ito kung para saang gawain ang bawat isa.

<!--i:eti-award-->
## Ang mas mahusay na ginagawa ng Penpot

Nagbibigay ang [Penpot](https://penpot.app/) ng interface design, mga component, flexible na layout, interactive na prototype at inspeksyon para sa developer, na may real-time na pag-edit at live na cursor. Nag-aalok ito ng hosted at self-hosted na deployment, na may [mga opsyon sa pag-install gamit ang Docker at Kubernetes](https://help.penpot.app/technical-guide/getting-started/). Para sa pagdisenyo ng application, Penpot ang tool.

<!--i:eti-blend-->
## Saan sila magkapareho

Gumagamit ang [mga design token ng Penpot](https://help.penpot.app/user-guide/design-systems/design-tokens/) ng DTCG format, na binabasa rin ng Lolly, kaya naililipat sa pagitan ng dalawa ang mga kulay, type at iba pang value ng token. Binubuksan ng [Mag-import ng design](/info/design-import.html) ng Lolly ang `.penpot` export bilang mae-edit na layout, at ipinapadala pabalik ng **Send to Penpot** sa Lolly ang isang design bilang `.penpot` archive. Pinapanatili rin ng Lolly ang [Lolly Export plugin para sa Penpot](https://github.com/lolly-tools/lolly-plugins-penpot-export), na gumagamit ng engine ng Lolly para magdagdag ng Content Credentials sa device kapag pinili mo ito.

<!--i:eti-lolly-->
## Paano ginagawa ng Lolly ang kaparehong gawain

Gumagawa ang canvas ng Lolly Design ng mga mae-edit na asset at kayang gawing [tool na may mga patakaran](/info/create-a-tool.html) ang layout. Nagre-render ang parehong tool sa browser, desktop app o CLI at gumagawa ng mga variant mula sa data. Nagre-render at pumipirma ang standalone na Lolly sa device, na walang account o server. Direktang nagpapares ng dalawang device ang [pribadong collab](/info/collaborate.html).

<!--i:eti-building-->
## Kasama ang isang organisasyon

Idinaragdag ng Lolly Work ang single sign-on, SCIM provisioning, mga pinagsasaluhang catalog at proyekto, role, approval, audit record, work collab at pag-render sa server. Parehong MPL-2.0 ang mga repository at puwedeng patakbuhin ng isang organisasyon ang dalawa. Inilalagay ng [Ano ang tumatakbo saan](/info/compare.html#what-runs-where) ang dalawang bahagi nang magkatabi.

Puwede mong gamitin ang dalawa: Penpot para sa interface design at prototyping, Lolly para sa mga file na paulit-ulit na ginagawa.
