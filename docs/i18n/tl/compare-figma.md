# Lolly at Figma

_Huling sinuri: 28 Setyembre 2026._

Kung gumagana sa Figma ang mga designer mo, sinasabi ng pahinang ito kung paano nakaupo ang Lolly sa tabi nito: ano ang ginagawa ng Figma na hindi ginagawa ng Lolly, at kung saan inaako ng Lolly ang paulit-ulit na gawain.

## Ang mas mahusay na ginagawa ng Figma

Pinagsasama ng [Figma Design](https://www.figma.com/design/) ang interface design, mga component, interactive prototype at developer handoff. Mahalaga ang itinatag nitong product-design na kasanayan at ecosystem kapag kailangan ng team na magdisenyo at magspecify ng buong application, at ang live editing nito ay tumatakbo sa laking hindi pa naaabot ng mga work collab ng Lolly.

## Kung saan sila nagtatagpo

Parehong hinahayaan kang mag-ayos ng type, hugis at larawan sa canvas at makipagtulungan sa ibang tao. Sinasaklaw din ng Figma ang template-based na brand production: ang [Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz) ay gumagawa ng asset mula sa mga template at pinupunan ang mga ito mula sa CSV o XLSX file. Binubuksan ng [Import a design](/info/design-import.html) ng Lolly ang mga Figma file bilang mae-edit na layout, kaya maibabahagi ng dalawa ang gawa.

## Paano ginagawa ng Lolly ang magkapatong na trabaho

Ginagawang [magagamit muling tool na may mga patakaran](/info/create-a-tool.html) ng Lolly ang design. Tumatakbo ang tool sa browser o CLI at kumukuha ng mga input mula sa link, script o batch grid, kaya iisang template ang naglilingkod sa taong nag-e-edit ng isang file at sa team na gumagawa ng marami.

![Ang bukas na canvas ng Design, na may Import a design sa Lolly menu ng toolbar](/info/shots/design.svg)

Ang [pribadong collab](/info/collaborate.html) ay direktang nagpapares ng dalawang device, walang account at hindi kailangan ng internet sa shared na network. Nagre-render offline ang standalone na Lolly. Naka-on bilang default ang Content Credentials para sa mga sinusuportahang export, at puwede mo itong i-off.

## Sa isang organisasyon

Nagdaragdag ang Lolly Work ng authenticated na work collab na may shared edit, live cursor at naka-save na team session, kasama ang single sign-on, shared catalogue, project permission, approval at server rendering. Inilalagay ng [Ano ang tumatakbo saan](/info/compare.html#what-runs-where) ang dalawang bahagi nang magkatabi.

Ang Figma ay trademark ng may-ari nito. Inilalarawan ng pahinang ito kung saan nagkakapatong ang dalawang produkto at hindi ito kaugnay ng Figma.
