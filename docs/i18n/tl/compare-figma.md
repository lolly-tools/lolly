# Lolly at Figma

_Huling sinuri: 28 Setyembre 2026._

Kung nagtatrabaho ang mga designer mo sa Figma, sinasabi ng pahinang ito kung ano ang ginagawa ng Figma na hindi ginagawa ng Lolly at kung saan inaako ng Lolly ang paulit-ulit na gawain.

<!--i:eti-award-->
## Ang mas mahusay na ginagawa ng Figma

Pinagsasama ng [Figma Design](https://www.figma.com/design/) ang interface design, mga component, interactive na prototype at pagpapasa sa developer. Mahalaga ang matatag nitong kasanayan sa product design at ecosystem kapag nagdidisenyo at nagtatakda ng mga detalye ng buong application ang isang team. Tumatakbo ang live na pag-edit nito sa laking hindi pa naaabot ng mga work collab ng Lolly.

<!--i:eti-blend-->
## Saan sila magkapareho

Parehong hinahayaan kang mag-ayos ng type, mga hugis at larawan sa canvas at makipagtulungan sa iba. Sinasaklaw din ng Figma ang paggawa para sa brand gamit ang mga template: gumagawa ang [Figma Buzz](https://help.figma.com/hc/en-us/articles/31271566667543-Guide-to-Figma-Buzz) ng mga asset mula sa mga template at pinupunan ang mga ito mula sa mga CSV o XLSX file. Binubuksan ng [Mag-import ng design](/info/design-import.html) ng Lolly ang mga Figma file bilang mga mae-edit na layout, kaya puwedeng magbahagi ng gawa ang dalawa.

<!--i:eti-lolly-->
## Paano ginagawa ng Lolly ang kaparehong gawain

Ginagawang [tool na may mga patakaran at magagamit muli](/info/create-a-tool.html) ng Lolly ang isang design. Tumatakbo ang tool sa browser o CLI. Tumatanggap ito ng mga input mula sa link, script o batch grid. Nagsisilbi ang isang template sa taong nag-e-edit ng isang file at sa team na gumagawa ng marami.

![Ang bukas na canvas ng Lolly Design, na may Import a design sa Lolly menu ng toolbar](/info/shots/design.svg)

Direktang nagpapares ng dalawang device ang [pribadong collab](/info/collaborate.html), na walang account at hindi kailangan ng internet sa iisang network. Nagre-render offline ang standalone na Lolly. Naka-on bilang default ang Content Credentials para sa mga sinusuportahang export, at puwede mo itong i-off.

<!--i:eti-building-->
## Kasama ang isang organisasyon

Idinaragdag ng Lolly Work ang mga authenticated na work collab na may magkakasamang pag-edit, live na cursor at mga na-save na session ng team, kasama ang single sign-on, mga pinagsasaluhang catalog, pahintulot sa proyekto, approval at pag-render sa server. Inilalagay ng [Ano ang tumatakbo saan](/info/compare.html#what-runs-where) ang dalawang bahagi nang magkatabi.

Trademark ng may-ari nito ang Figma. Inilalarawan ng pahinang ito kung saan magkapareho ang dalawang produkto at hindi ito kaanib ng Figma.
