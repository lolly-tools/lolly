# Lolly comparado, ferramenta por ferramenta

O Lolly cobre o trabalho criativo, desde uma única conversão no próprio dispositivo até a produção de ativos de uma organização com governança. Estas páginas comparam os fluxos de trabalho que cada produto oferece, a forma como é implantado e os limites que importam na hora de escolher uma solução.

_Última verificação: 28 de setembro de 2026._

## Um projeto, duas partes implantadas separadamente

**Lolly** é o motor, os apps e as ferramentas para criar, editar, converter e exportar. Ele roda no seu dispositivo, funciona offline quando os ativos necessários estão disponíveis e não exige conta para uso independente.

**[lolly.work](https://lolly.work)** é o serviço de organização do projeto, mantido no [repositório lolly-work](https://github.com/lolly-tools/lolly-work). Ele oferece SSO, provisionamento SCIM, papéis e políticas, catálogos e projetos compartilhados, aprovações, colaboração de trabalho, relatórios de uso, registros de auditoria e renderização no servidor. As duas partes são de código aberto sob MPL-2.0. Uma organização hospeda o lolly.work junto com o Lolly e decide quais serviços ativar.

As comparações cobrem **Lolly + lolly.work**. Os recursos que dependem do serviço de organização são identificados explicitamente. O uso independente mantém os arquivos no dispositivo; ao escolher projetos compartilhados, colaboração de trabalho, renderização no servidor ou entrega, os dados relevantes são enviados aos serviços configurados. O site público do lolly.work é um sandbox; consulte o [guia de implantação](https://github.com/lolly-tools/lolly-work/blob/main/docs/install.md) e o [status atual](https://github.com/lolly-tools/lolly-work/blob/main/docs/status.md) para uma implantação em uma organização.
