# Lolly for the newsroom

You publish on a deadline, in a house style readers recognise. Build the info-editorial style once, then generate publication-quality files from live data as the story develops.

- **Bring data straight into visuals.** Structured data feeds chart, map and table templates: update the numbers and the layout takes care of itself. Templates are authored once, by whoever owns the style - see [Authoring Tools](/info/authoring-tools.html).
- **The house style, enforced.** Type and colour constraints are hard-coded at the template level, not a guideline someone has to remember at deadline. The graphic cannot drift from spec.
- **Print-ready or screen-ready.** SVG, CMYK PDF, high-resolution PNG or 60fps video from the same template. One source, every format the production desk needs - see [Exporting & Formats](/info/exporting.html).
- **Reusable formats for recurring stories.** Election results, quarterly earnings, weather events: build the template once and refill it every time the story runs. Every finished graphic is also a link that re-renders from its own inputs, so the desk can regenerate last night's chart with this morning's numbers - see [URL Mode](/info/url-mode.html).
