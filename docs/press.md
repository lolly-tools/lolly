# Lolly for the newsroom

You publish on a deadline, in a house style readers recognise. Build each graphic format once, then fill it with live data as the story develops.

- **Bring data straight into visuals.** [Chart](/t/chart) and [Diagrams](/t/diagram-builder) take structured data, so you update the numbers and the layout follows, and [Street Map](/t/street-map) draws more than fifty cities as clean vector streets. Whoever owns the style authors new templates; see [Build a tool](/info/authoring-tools.html).
- **The house style on every graphic.** Type and colour are fixed in the template, not a guideline someone has to remember at deadline, so every graphic starts from the spec.
- **Print-ready or screen-ready.** SVG, CMYK PDF, high-resolution PNG or 60 fps video from the same template, for every desk; see [Export a file](/info/exporting.html).
- **Reusable formats for recurring stories.** Election results, quarterly earnings, weather events: build the template once and refill it every time the story runs.

Every finished graphic is also a link that re-renders from its own inputs, so the desk can regenerate last night's chart with this morning's numbers. Nobody drew the chart below: its type, heading and data all arrived in the link. See [URL Mode](/info/url-mode.html).
