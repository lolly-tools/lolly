# Lolly for the newsroom

You publish on a deadline, in a house style readers recognise. Build each graphic format once, then fill it with live data as the story develops.

- **Bring data straight into visuals.** [Lolly Chart](/t/chart) and [Lolly Diagrams](/t/diagram-builder) take structured data. You update the numbers and the layout follows. [Lolly Street Map](/t/street-map) draws more than fifty cities as vector streets. Whoever owns the style authors new templates. See [Build a tool](/info/authoring-tools.html).
- **The house style on every graphic.** Type and colour are fixed in the template. Nobody has to remember a guideline at deadline.
- **Print-ready or screen-ready.** SVG, CMYK PDF, high-resolution PNG or 60 fps video from the same template, for every desk. See [Export a file](/info/exporting.html).
- **Reusable formats for recurring stories.** Election results, quarterly earnings, weather events: build the template once and refill it every time the story runs.

Every finished graphic is also a link that re-renders from its own inputs. The desk can regenerate last night's chart with this morning's numbers. Nobody drew the chart below: its type, heading and data came in the link. See [URL Mode](/info/url-mode.html).
