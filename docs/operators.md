# Manage

Lolly runs on each person's device. When a team needs sign-in, shared projects, governed assets, reviews and server jobs, an organisation adds **Lolly Work**, the open-source organisation server of the same project. These pages are for whoever sets up and looks after that server.

Start with [Use Lolly at your organisation](/info/organisation.html) to see what members get, or [Lolly Work architecture](/info/work-overview.html) for what the server is responsible for.

## Set access and policy

- [Adoption & Governance](/info/adoption-governance.html) covers the rollout and the role of brand rules.
- [Identity and sessions](/info/work-identity.html) covers sign-in and group mapping. [Roles and grants](/info/work-permissions.html) explains roles, grants and the owner guard.
- [Policy and governance](/info/work-governance.html) covers tool overlays, locked inputs and policy. [Manage organisation AI policy](/info/work-ai-policy.html) covers approvals and execution limits.
- [Account data controls](/info/work-account-lifecycle.html) and [Work storage and data lifecycle](/info/work-data-lifecycle.html) cover exports, offboarding, retention and their limits.
- [Profiles, brands and tool configuration](/info/configuration.html) covers which tools and design systems a build of Lolly carries.

## Connect assets and review work

- [Design-system administration](/info/work-design-system-administration.html) covers source inventory, reviewed changes and rollback.
- [Catalog and content](/info/work-catalog.html) covers shared assets and exposure rules. [Provider guides](/info/work-provider-guides.html) gives each source platform's setup and verification requirements.
- [Approvals](/info/work-approvals.html) covers review chains and separation of duties. [Rendering and sharing](/info/work-sharing.html) covers links and server output.
- [Invite an agent to a document](/info/work-document-agents.html) covers scoped document access, expiry and revocation. An invitation does not grant deployment or infrastructure access.

## Find the next task

- [Create](/info/creators.html) has the creative tasks and team playbooks.
- [Deploy](/info/operate.html) covers installing and maintaining Lolly and a Lolly Work server. An instance's configuration is separate from a person's content profile.
- [Trust](/info/trust.html) explains data flows, signatures and security boundaries.
